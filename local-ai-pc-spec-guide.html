로컬 AI(LLM) 돌리는 PC 사양, GPU 메모리·RAM은 얼마나 필요할까

Ollama나 LM Studio로 내 PC에서 AI 모델을 돌리려면 어떤 부품을 먼저 봐야 할까요? 이 글은 공식 문서에 적힌 요건과, 문서에서 바로 계산할 수 있는 어림값만 정리합니다. 모델별 실제 속도나 특정 그래픽카드의 체감 성능은 확인한 자료가 없어 다루지 않습니다.

먼저 결론: 모델이 GPU 메모리에 들어가는지부터 보세요

  • GPU 메모리(VRAM)가 1순위입니다. Ollama 문서는 모델이 한 GPU에 전부 들어가면 PCI 버스로 오가는 데이터가 줄어 보통 가장 성능이 좋다고 설명합니다. 컨텍스트 문서에서도 CPU로 일부가 넘어가는(오프로딩) 상태를 피하라고 안내합니다.
  • RAM은 기본 여유와 넘치는 부분을 받는 역할입니다. LM Studio 문서는 Windows에서 RAM 16GB 이상을 권장합니다.
  • 그래픽카드가 지원되는지도 확인해야 합니다. 오래된 카드나 드라이버는 지원 조건에서 걸러질 수 있습니다.

모델이 메모리를 얼마나 차지하는지 어림하기

모델 가중치만 보면 파라미터 수 × 값 하나당 바이트 수입니다. 16비트(float16)는 2바이트, 8비트는 1바이트, 4비트는 0.5바이트로 계산합니다. Hugging Face의 메모리 추정 문서에 나온 표에서도 정밀도를 한 단계 낮출 때마다 크기가 절반이 되는 것을 확인할 수 있습니다(float16 약 148.6GB → int4 약 37.1GB).

위 숫자는 가중치만의 단순 곱셈입니다. 실제 파일 크기는 양자화 방식에 따라 조금씩 다릅니다. Hugging Face 문서는 모델을 불러오는 크기는 실제 값과 몇 % 안에서 맞지만, 추론할 때는 EleutherAI 조사 기준으로 최대 약 20%가 더 필요하다고 안내합니다. 컨텍스트 길이(아래)에 따라 늘어나는 메모리도 따로 더해야 합니다.

컨텍스트 길이가 길수록 메모리가 더 듭니다

컨텍스트 길이는 모델이 한 번에 기억해 두는 토큰 수입니다. Ollama 문서에 따르면 기본값은 VRAM 크기에 따라 정해집니다.

  • VRAM 24GiB 미만: 4k 컨텍스트
  • VRAM 24~48GiB: 32k 컨텍스트
  • VRAM 48GiB 이상: 256k 컨텍스트

웹 검색, 에이전트, 코딩 도구처럼 긴 컨텍스트가 필요한 작업은 64000 토큰 이상으로 설정하라고 안내합니다. 컨텍스트를 키우면 그만큼 메모리가 더 필요하니, 모델이 들어가는 것과 늘린 컨텍스트가 함께 들어가는 것은 별개의 문제입니다. 또 Ollama FAQ에는 컨텍스트가 커질 때 메모리 사용을 줄여 주는 Flash Attention 설정과, 이 설정을 켰을 때 K/V 캐시를 양자화해 메모리를 줄이는 방법이 설명돼 있습니다.

내 PC 상태 확인하는 방법

  1. 그래픽카드 지원 여부: 카드 이름을 Ollama 하드웨어 지원 문서의 표에서 찾아봅니다. 여러 GPU가 있다면 nvidia-smi -L 명령으로 GPU 목록과 식별값(UUID)을 볼 수 있다고 Ollama 문서에 나와 있습니다.
  2. VRAM 용량(문서 외 일반 점검): 작업 관리자 → 성능 → GPU에서 전용 GPU 메모리를 확인합니다. 노트북은 내장 그래픽과 그래픽카드가 함께 있을 수 있어 어느 GPU를 쓰는지도 같이 봅니다.
  3. GPU로 돌아가는지 확인: 모델을 실행한 뒤 ollama ps를 입력하면 PROCESSOR 열에 GPU와 CPU 사용 비율이 나옵니다. 문서 예시처럼 100% GPU가 아니라면 일부가 CPU로 넘어간 것입니다.
  4. RAM 여유: 작업 관리자 → 성능 → 메모리에서 사용 중인 양을 보고, 모델을 켠 상태에서 얼마나 남는지 확인합니다.

사기 전에, 올리기 전에 생각할 것

  • 목표 모델 크기를 먼저 정하세요. 위 표로 계산한 크기에 약 20%와 컨텍스트 몫을 더한 값이 VRAM보다 작아야 편합니다. 이 판단은 문서 값에서 계산한 기준일 뿐 속도를 보장하지는 않습니다.
  • VRAM이 모자라면 모델을 줄이는 선택지도 있습니다. 더 작은 모델이나 더 낮은 비트 수(양자화)를 고르면 필요한 메모리가 줄어듭니다. 대신 품질이 얼마나 떨어지는지는 모델마다 달라 이 글에서 판단하지 않습니다.
  • 그래픽카드를 바꾼다면 전원과 공간부터 확인하세요. 보조전원 커넥터, 파워 용량, 케이스 길이는 그래픽카드 업그레이드 전 확인사항에서 정리했습니다.
  • RAM·SSD 가격은 지금 오른 상태입니다. 모델 파일도 수 GB에서 수십 GB라 저장 공간이 빨리 찹니다. 구매 시기 판단은 D램·SSD 가격 폭등 가이드를 참고하세요.

내 PC에 RAM을 더 꽂을 수 있는지는 RAM 증설 가능 여부 확인 도구로 먼저 확인하고, 새로 맞추려면 PC 추천받기와 PC 조합 빌더를 이용하세요.

자주 묻는 질문

  • 로컬 AI를 돌리려면 RAM과 GPU 중 무엇이 더 중요한가요? 모델이 GPU 메모리(VRAM)에 통째로 들어가는지가 먼저입니다. Ollama 공식 문서는 모델이 한 GPU에 전부 들어가면 PCI 버스로 오가는 데이터가 줄어 대체로 성능이 가장 좋고, 컨텍스트 문서에서도 CPU로 일부가 넘어가는(오프로딩) 상태를 피하라고 안내합니다. RAM은 VRAM에 다 담지 못하는 부분을 받아 주는 여유 공간이자, LM Studio 문서가 Windows에서 16GB 이상을 권장하는 기본 요건입니다.
  • GPU 없이 CPU와 RAM만으로도 돌릴 수 있나요? Ollama 문서에 CPU 추론(시스템 메모리 사용)이 명시돼 있어 가능은 합니다. 다만 속도가 얼마나 나오는지는 CPU와 모델 크기에 따라 크게 달라 이 문서만으로는 단정할 수 없고, 일반적으로 GPU보다 느리다고 알려져 있습니다.
  • 모델 크기는 어떻게 어림하나요? 가중치만 놓고 보면 파라미터 수에 값 하나당 바이트 수를 곱합니다. 16비트(float16)는 2바이트, 8비트는 1바이트, 4비트는 0.5바이트입니다. 예를 들어 80억 개 파라미터 모델은 16비트로 약 16GB, 4비트로 약 4GB입니다. Hugging Face 문서는 실제 추론에서는 로딩 크기에 최대 약 20%가 더 필요하다고 안내하며, 컨텍스트 길이를 늘리면 메모리가 더 듭니다.
  • 내 그래픽카드가 Ollama에서 지원되는지 어떻게 확인하나요? Ollama 공식 문서 기준으로 NVIDIA는 컴퓨트 capability 5.0 이상이고 드라이버 550 이상이 필요하며(capability 5.0~6.2는 570 이상), 지원 카드 목록이 문서에 표로 있습니다. AMD는 ROCm 또는 Vulkan으로 지원되는 카드가 문서에 따로 정리돼 있습니다.
