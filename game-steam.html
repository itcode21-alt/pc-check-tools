Steam 디스크 쓰기 오류·콘텐츠 파일 잠김 · Disk Write Error · Content File Locked

설치/저장장치참고 자료 있음

Steam이 게임 업데이트나 설치 파일을 저장하지 못할 때 나타나는 오류입니다. 디스크 고장으로 단정하기보다 파일 잠금, 백신 격리, 권한, 여유 공간과 드라이브 상태를 차례로 확인해야 합니다.

가능한 원인

  • 백신 실시간 검사나 Windows 보안 기능이 파일을 잠근 경우
  • Steam 또는 게임 프로세스가 업데이트 파일을 사용 중인 경우
  • 설치 드라이브의 여유 공간·권한·파일 시스템에 문제가 있는 경우
  • 다운로드 중 중단되어 게임 파일 일부가 손상된 경우

점검 순서

  1. 1단계 - Steam과 PC 재시작 (문서 외 일반 점검):
    ① 게임과 Steam을 종료하고 작업 관리자에 남은 Steam 프로세스를 닫기
    ② PC를 재부팅한 뒤 같은 다운로드를 다시 시도
  2. 2단계 - 파일 무결성 확인 (문서 외 일반 점검):
    ① Steam 라이브러리에서 게임 우클릭 → 속성 → 설치된 파일
    ② 게임 파일 무결성 확인을 실행하고 완료 후 재시작
  3. 3단계 - 잠금·보안 확인 (문서 외 일반 점검):
    ① 백신 격리 기록과 Windows 보안의 차단 기록 확인
    ② 원인을 확인한 뒤 Steam·게임 폴더를 신뢰 목록에 추가하고 보호 기능은 다시 켜기
  4. 4단계 - 저장장치 점검 (문서 외 일반 점검):
    ① 설치 드라이브 여유 공간과 파일 시스템 오류를 확인
    ② 여러 게임에서 반복되거나 SMART 경고가 있으면 먼저 데이터를 백업하고 저장장치를 점검

Steam Support: Verify Integrity of Game Files

Steam에서 준비 중만 표시되고 게임이 실행되지 않는 문제 · Preparing to Launch 후 실행 안됨

실행/런처참고 자료 있음

실행 버튼을 누르면 ‘Preparing to Launch’가 잠시 표시된 뒤 다시 실행 버튼으로 돌아오는 증상입니다. 게임 파일, 그래픽 드라이버, 백그라운드 충돌과 시스템 요구사항을 분리해 확인합니다.

가능한 원인

  • 게임 파일 일부가 손상되거나 필수 실행 파일이 누락된 경우
  • 그래픽 드라이버 또는 Windows 구성요소가 오래된 경우
  • 오버레이·백신·튜닝 프로그램이 게임 실행을 가로막는 경우
  • 게임이 요구하는 운영체제·메모리·그래픽 사양을 충족하지 못하는 경우

점검 순서

  1. 1단계 - 먼저 컴퓨터를 완전히 재시작 (Steam 공식 안내):
    ① Steam 문서는 이 안내가 일반적인 점검 순서이며 컴퓨터를 새로 재시작한 뒤에 따르라고 안내합니다.
    ② 게임이 실행되지 않는 것처럼 보이는 경우는 대개 실행 직후 충돌하는 경우라고 설명합니다.
  2. 2단계 - Windows(와 .NET Framework) 업데이트 (Steam 공식 안내):
    ① 시작 → 설정 → Windows 업데이트에서 '업데이트 확인'을 눌러 모두 설치합니다.
    ② Steam 문서는 AMD Radeon 드라이버와 일부 게임이 Microsoft .NET Framework를 요구하므로, Windows 업데이트로 제공되는 .NET Framework(모든 버전)도 최신인지 함께 확인하라고 안내합니다.
  3. 3단계 - 컴퓨터 부품 드라이버 최신화 (Steam 공식 안내):
    ① 그래픽카드뿐 아니라 PC의 여러 부품 드라이버를 최신으로 맞추라고 안내합니다.
    ② 노트북이라면 제조사의 전원·그래픽 드라이버도 함께 확인합니다.
  4. 4단계 - 게임 파일 무결성 확인 (Steam 공식 안내):
    ① 컴퓨터를 재시작한 뒤 Steam을 실행합니다.
    ② 라이브러리에서 게임을 마우스 오른쪽 버튼으로 누르거나, 게임 화면 오른쪽 끝의 톱니바퀴 아이콘을 누릅니다.
    ③ 메뉴에서 '속성'을 선택합니다.
    ④ '설치된 파일' 탭에서 '게임 파일 무결성 확인'을 누릅니다. 검사는 몇 분 걸릴 수 있습니다.
    ⑤ 파일 한두 개가 검증에 실패했다고 나와도 Steam 문서는 대부분의 게임에서 정상이라고 안내합니다. 그 파일은 교체하면 안 되는 로컬 설정 파일이니 무시해도 됩니다.
    ⑥ 디스크 조각 모음이나 바이러스 검사처럼 시스템 자원을 많이 쓰는 작업을 하는 중에는 검사하지 말고, 여러 게임을 동시에 검사하지도 마세요.
  5. 5단계 - 꼭 필요하지 않은 소프트웨어 끄기 (Steam 공식 안내):
    ① 오버레이, 화면 캡처, 튜닝·모니터링 도구처럼 게임과 직접 관계없는 프로그램을 종료합니다. Steam은 이런 충돌 목록을 'Programs Which May Interfere with Steam' 문서로 따로 안내합니다.
  6. 6단계 - 게임 시스템 요구사항과 비교 (Steam 공식 안내):
    ① Steam 상점 페이지의 운영체제·CPU·RAM·GPU 요구사항과 내 PC를 비교합니다.
  7. 7단계 - 그래도 안 되면 개발사 지원 (Steam 공식 안내):
    ① Steam 문서는 위 방법으로도 안 되면 게임 개발사에 자세한 지원을 요청하라고 안내합니다. 개인 PC 구성 문제일 수 있어 가까운 PC 기술자의 도움이 필요할 수도 있다고 설명합니다.

Steam Support: Games do not run after 'Preparing to Launch'

Steam 서버를 사용할 수 없거나 너무 바쁜 문제 · Error 53 · Steam 서버 사용 불가

접속/네트워크참고 자료 있음

Steam 서버가 현재 사용 불가하거나 너무 바쁘다는 메시지, 또는 Error 53이 표시되는 경우입니다. 서버 상태와 지역 다운로드 서버, 방화벽·보안 프로그램을 나눠 확인해야 합니다.

가능한 원인

  • Steam 서버 점검이나 일시적인 접속량 증가
  • 선택한 다운로드 지역의 서버 문제
  • 방화벽·백신·라우터가 Steam 통신을 차단하는 경우
  • Steam 클라이언트 파일이나 다운로드 캐시가 손상된 경우

점검 순서

  1. 1단계 - 방해하는 프로그램 확인 (Steam 공식 안내):
    ① Steam 문서는 Error 53이 'Programs Which May Interfere with Steam'에 나온 프로그램이 Steam의 정상 동작을 막을 때 자주 해결된다고 안내합니다. 그 목록의 프로그램이 설치돼 있는지 확인합니다.
  2. 2단계 - 다운로드 지역 변경 (Steam 공식 안내):
    ① Steam을 실행하고 왼쪽 위 'Steam' 메뉴 → '설정'(Settings)을 엽니다.
    ② '다운로드' 탭의 '다운로드 지역'에서 지금과 다르지만 비교적 가까운 지역을 선택합니다.
    ③ 게임 실행이나 설치를 다시 시도합니다.
  3. 3단계 - 손상된 Steam 파일 복구 (Steam 공식 안내):
    ① Steam 문서는 시간이 지나며 Steam 파일이 손상될 수 있다고 안내합니다.
    ② Steam을 완전히 종료합니다.
    ③ 파일 탐색기에서 Steam 설치 폴더(기본 C:\Program Files (x86)\Steam\)로 이동합니다.
    ④ 폴더 안에서 steam.exe와 steamapps 폴더만 남기고 나머지를 모두 삭제합니다. steamapps에는 게임 파일이 들어 있으니 지우지 마세요.
    ⑤ Steam을 다시 실행해 오류가 사라졌는지 봅니다. (삭제 전에 어떤 파일이 있는지 확인하세요: 일반 주의)
  4. 4단계 - 연결 환경 확인 (Steam 공식 안내):
    ① Steam 문서는 Steam이 네트워크 DMZ(비무장 지대)를 통한 연결을 지원하지 않으므로 공유기에서 DMZ 설정을 꺼야 한다고 안내합니다.
    ② 방화벽이나 공유기가 Steam 통신을 막는 경우가 많다고도 설명합니다.
  5. 5단계 - 다운로드 캐시 지우기와 방화벽 규칙 재확인 (문서 외 일반 점검):
    ① Steam 설정 → 다운로드 → '다운로드 캐시 지우기' 실행 후 Steam 재시작
    ② Steam 업데이트 후 기존 방화벽 규칙이 오래됐는지 확인하고 Steam을 허용 앱으로 다시 등록

Steam Support: Steam Servers Are Currently Unavailable or Too Busy

Steam 게임 실행 파일이 없거나 차단된 문제 · Failed to Start Game (Missing Executable)

실행/파일참고 자료 있음

Steam에서 게임을 시작할 때 실행 파일이 없다는 메시지가 표시되는 경우입니다. 파일이 실제로 삭제된 것인지, 백신이 오탐으로 격리한 것인지, 다운로드가 완료되지 않은 것인지부터 구분해야 합니다.

가능한 원인

  • 백신이나 Windows 보안이 게임 실행 파일을 검역소로 이동한 경우
  • 다운로드·업데이트가 중단되어 필요한 파일이 완성되지 않은 경우
  • 게임 파일 일부가 손상된 경우
  • 게임 폴더 권한이나 디스크 오류로 파일을 읽지 못하는 경우

점검 순서

  1. 1단계 - 백신이 게임 파일을 격리했는지 확인 (Steam 공식 안내):
    ① Steam 문서는 이 오류가 백신이 게임 파일을 악성으로 잘못 판단해 격리할 때 가장 흔하다고 안내합니다.
    ② 백신 프로그램에서 격리·차단된 게임 파일이 있는지 보고, 안전한 파일로 표시(복원)합니다.
    ③ 또는 백신을 게임 모드로 두거나, 검사에서 그 게임 폴더를 제외하도록 설정합니다. 메뉴 이름은 백신마다 다릅니다.
    ④ 'Programs Which May Interfere with Steam' 문서에 나온 프로그램이 있으면 일시적으로 삭제해 봅니다.
  2. 2단계 - 게임 파일 무결성 확인 (Steam 공식 안내):
    ① 컴퓨터를 재시작한 뒤 Steam을 실행합니다.
    ② 라이브러리에서 게임을 마우스 오른쪽 버튼으로 누르거나, 게임 화면 오른쪽 끝의 톱니바퀴 아이콘을 누릅니다.
    ③ 메뉴에서 '속성'을 선택합니다.
    ④ '설치된 파일' 탭에서 '게임 파일 무결성 확인'을 누릅니다. 검사는 몇 분 걸릴 수 있습니다.
    ⑤ 파일 한두 개가 검증에 실패했다고 나와도 Steam 문서는 대부분의 게임에서 정상이라고 안내합니다. 그 파일은 교체하면 안 되는 로컬 설정 파일이니 무시해도 됩니다.
    ⑥ 디스크 조각 모음이나 바이러스 검사처럼 시스템 자원을 많이 쓰는 작업을 하는 중에는 검사하지 말고, 여러 게임을 동시에 검사하지도 마세요.
  3. 3단계 - 그래도 안 되면 Steam 지원에 티켓 제출 (Steam 공식 안내):
    ① 위 두 단계로도 같은 오류가 나면 Steam 지원에 티켓을 제출하라고 안내합니다.
    ② 오류 화면을 자르지 않은 스크린샷, 시스템 보고서(System Report), 'Programs Which May Interfere with Steam' 문서에 따라 제거한 프로그램 목록을 함께 적습니다.

접속/보안참고 자료 있음

보안 게임 서버 연결 실패, Steam 로그인 실패, VAC 서버 연결 불가 메시지가 표시되는 경우입니다. 인터넷 자체보다 방화벽 규칙, 보안 프로그램, 백그라운드 네트워크 도구가 원인일 수 있습니다.

가능한 원인

  • Steam 업데이트 후 방화벽의 이전 허용 규칙이 맞지 않는 경우
  • 백신·방화벽·VPN·트래픽 제한 프로그램이 Steam 통신을 차단하는 경우
  • 공유기·무선 연결·인터넷 회선이 불안정한 경우
  • 다른 안티치트나 P2P 프로그램이 VAC 연결과 충돌하는 경우

점검 순서

  1. 1단계 - 원인 네 가지 구분 (Steam 공식 안내):
    ① Steam 문서는 이 오류가 연결 문제, 보안 소프트웨어, 백그라운드 앱, 타사 안티치트 프로그램 네 가지에서 비롯된다고 설명합니다.
  2. 2단계 - 방화벽·공유기 포트 확인 후 Steam 재시작 (Steam 공식 안내):
    ① 방화벽이 있는 공유기 뒤에 있다면 Steam이 쓰는 포트를 열어야 한다고 안내합니다. 포트 목록은 'Required Ports for Steam' 문서를 따릅니다.
    ② 공유기나 방화벽 설정을 바꾼 뒤에는 Steam을 완전히 종료하고 다시 시작한 다음 접속해야 합니다.
  3. 3단계 - 공유기 문제 가려내기 (Steam 공식 안내):
    ① 공유기, 특히 무선 공유기가 연결 문제를 일으킬 수 있다고 안내합니다.
    ② 독립 공유기를 쓴다면 공유기를 건너뛰고 PC를 모뎀에 직접 연결해 문제가 사라지는지 확인합니다.
    ③ Steam 문서는 Dual WAN 공유기가 Steam과 호환되지 않는다고 안내합니다.
  4. 4단계 - 인터넷 연결 안정성 점검 (Steam 공식 안내):
    ① 불안정한 연결은 다운로드가 잘못되고 게임 서버 연결 시간 초과를 일으킬 수 있다고 안내합니다. 연결 품질 점검 사이트로 안정성을 확인합니다.
  5. 5단계 - VPN·P2P 프로그램 종료와 서버 구분 (문서 외 일반 점검):
    ① VPN·트래픽 제한·P2P 프로그램을 종료
    ② 다른 Steam 기능도 안 되는지 확인하고, 서버 점검이 아니라면 오류 시각과 네트워크 환경을 기록해 Steam 지원에 문의

Steam Cloud 저장이 동기화되지 않는 문제 · Steam Cloud 동기화 오류

저장/동기화참고 자료 있음

게임을 종료한 뒤 Steam Cloud 동기화가 실패하거나 다른 PC에서 최신 세이브가 보이지 않는 경우입니다. 로컬 저장 데이터와 클라우드 데이터 중 어느 쪽이 최신인지 확인한 뒤 선택해야 데이터 덮어쓰기를 줄일 수 있습니다.

가능한 원인

  • 게임 종료 시 네트워크가 끊겨 클라우드 업로드가 완료되지 않은 경우
  • Steam Cloud가 계정 또는 게임별로 꺼져 있는 경우
  • 방화벽·백신이 Steam의 동기화 통신을 차단한 경우
  • 여러 PC에서 같은 세이브를 동시에 수정한 경우

점검 순서

  1. 1단계 - 최신 데이터 확인 (문서 외 일반 점검):
    ① 게임을 다시 실행하기 전에 Steam Cloud 충돌 안내에서 날짜와 파일 크기를 비교
    ② 어느 쪽이 최신인지 모르면 로컬 세이브를 별도 폴더에 먼저 복사
  2. 2단계 - Cloud 설정 확인 (문서 외 일반 점검):
    ① Steam 설정의 Cloud 기능이 켜져 있는지 확인
    ② 게임 속성 → 일반에서 게임별 Steam Cloud 사용 여부 확인
  3. 3단계 - 네트워크·보안 확인 (문서 외 일반 점검):
    ① 동기화가 끝날 때까지 Steam을 종료하지 말고 안정적인 네트워크 사용
    ② Steam의 연결을 막는 방화벽·백신 기록 확인
  4. 4단계 - 충돌 반복 시 (문서 외 일반 점검):
    ① 동기화 충돌 화면을 캡처하고 세이브 백업을 보관
    ② 최신 파일을 임의로 삭제하거나 덮어쓰기 전에 Steam 지원에 문의

VAC가 게임 세션을 확인할 수 없다는 메시지로 입장이 막히는 문제 · VAC was unable to verify your game session

접속/보안참고 자료 있음커뮤니티 사례 포함

매치메이킹 진입 시 'VAC was unable to verify your game session' 메시지가 뜨며 게임에 들어가지 못하는 경우입니다. 대부분 계정 정지와는 무관하며, 게임 파일 손상이나 Steam 서비스, 백그라운드 프로그램 충돌이 원인입니다.

가능한 원인

  • 게임 파일 일부가 손상되어 VAC가 무결성을 확인하지 못하는 경우
  • Steam 자체 서비스(SteamService)가 손상되었거나 오래된 경우
  • 인젝터·트레이너 등 프로세스에 개입하는 프로그램이 실행 중인 경우(비활성 상태라도 감지될 수 있음)
  • Steam을 관리자 권한 없이 실행해 필요한 파일에 접근하지 못하는 경우

점검 순서

  1. 1단계 - 게임 파일 무결성 검사 (이용자 안내):
    ① Steam 라이브러리에서 게임 우클릭 → 속성 → 설치된 파일
    ② '게임 파일 무결성 확인'을 실행하고 완료 후 재시작
  2. 2단계 - Steam 재시작·관리자 권한 (이용자 안내):
    ① Steam을 완전히 종료(작업 관리자에서 잔여 프로세스 확인)
    ② Steam을 관리자 권한으로 다시 실행
  3. 3단계 - 개입 프로그램 종료 (이용자 안내):
    ① 인젝터, 트레이너, 화면 매크로 등 프로세스에 개입할 수 있는 프로그램을 모두 종료
    ② 비활성 상태라도 설치돼 있다면 완전히 제거 후 재시도
  4. 4단계 - Steam 서비스 복구 (이용자 안내):
    ① Steam을 종료한 뒤 실행 창에서 `C:\Program Files (x86)\Steam\bin\SteamService.exe /repair` 실행
    ② 완료 후 Steam을 다시 시작하고 오프라인 봇전으로 짧게 재현 여부 확인

Steam Guard 모바일 인증 코드가 계속 틀리다고 나오며 로그인이 안 되는 문제 · Steam Guard 모바일 인증 실패

계정/로그인참고 자료 있음

로그인 시 Steam 모바일 앱의 Steam Guard 코드를 입력해도 '잘못된 코드'로 반복 거부되는 경우입니다. Steam 지원 문서는 인증기를 다른 기기로 옮긴 경우 새 기기에서 인증기 이동(Move Authenticator)을 쓰고, 앱으로 로그인하기 어려우면 지원 사이트에서 계정을 복구하라고 안내합니다. 기기 시간·앱 버전·네트워크 차단은 문서 외 일반 점검입니다.

가능한 원인

  • 인증기가 다른 기기로 옮겨져 이전 기기의 코드가 더 이상 맞지 않는 경우 (Steam 안내에서 확인되는 경우)
  • 스마트폰의 날짜·시간이 자동 설정이 아니어서 코드와 서버 시간이 어긋난 경우 (문서 외 일반 해석)
  • PC의 방화벽·보안 프로그램이 Steam의 인증 통신을 차단하는 경우 (문서 외 일반 해석)
  • Steam 모바일 앱 자체가 오래된 버전인 경우 (문서 외 일반 해석)

점검 순서

  1. 1단계 - 인증기를 옮긴 적이 있는지 확인 (Steam 안내):
    ① 예전 기기에서 쓰던 인증기가 아직 있다면, 새 기기의 Steam 모바일 앱에 로그인한 뒤 Steam Guard에서 인증기 이동(Move Authenticator)을 선택
  2. 2단계 - 스마트폰 시간 동기화 (문서 외 일반 점검):
    ① 스마트폰 설정 → 날짜 및 시간에서 '자동으로 설정' 활성화
    ② Steam 모바일 앱을 재시작하고 새로 생성된 코드로 재시도
  3. 3단계 - 앱 업데이트 확인 (문서 외 일반 점검):
    ① 스마트폰 앱스토어에서 Steam 앱을 최신 버전으로 업데이트
    ② 업데이트 후에도 실패하면 앱을 재설치
  4. 4단계 - 계정 복구 (Steam 안내):
    ① 기기를 분실했거나 앱으로 로그인할 수 없으면 Steam 지원 사이트(help.steampowered.com)에서 계정 복구 절차를 진행
    ② 평소 비상용 백업 코드를 인쇄해 두면 긴급할 때 쓸 수 있다고 Steam이 권장

Steam 로그인 시 'Error Code: e84·e87'과 함께 로그인에 실패하는 문제

계정/로그인공식 정의 없음 · 제3자 보고 기준

Steam 로그인 중 "로그인하는 동안 문제가 발생했습니다. 나중에 다시 시도해 주세요" 같은 메시지와 함께 e84 또는 e87이 표시되는 경우입니다. Valve 공식 지원 문서에서 이 코드를 정의한 페이지는 확인되지 않았고, 제3자 글과 Steam 커뮤니티 글의 보고를 바탕으로 한 일반 점검만 안내합니다. 공식 정의가 확인되면 이 항목을 고칩니다.

가능한 원인

  • Steam 로그인 서버나 PC의 인터넷 연결에 일시적인 문제가 있는 경우 (제3자 글 보고, 공식 확인 전)
  • PC의 날짜·시간이 어긋난 경우 (제3자 글 보고, 공식 확인 전)
  • 클라이언트의 임시 로그인 정보가 꼬인 경우 (문서 외 일반 해석)

점검 순서

  1. 1단계 - Steam 완전 종료 후 다시 실행 (문서 외 일반 점검):
    ① 작업 표시줄 트레이의 Steam 아이콘을 우클릭해 종료하고, 작업 관리자에 steam 프로세스가 남아 있지 않은지 확인한 뒤 다시 실행합니다.
  2. 2단계 - PC 시간 동기화 (제3자 글 안내):
    ① 설정 → 시간 및 언어 → 날짜 및 시간에서 '시간 자동 설정'을 켜고 '지금 동기화'를 누릅니다.
  3. 3단계 - QR 코드로 로그인 (문서 외 일반 점검):
    ① 비밀번호 입력 대신 Steam 모바일 앱의 QR 로그인으로 시도해 비밀번호 로그인 쪽 문제인지 구분합니다.
  4. 4단계 - 시간을 두고 재시도하고 문의 (문서 외 일반 점검):
    ① 몇 분에서 몇 시간 뒤 다시 시도하고, 계속되면 Steam 지원(help.steampowered.com)에 e84 또는 e87 코드를 함께 알립니다.

  • 무결성 검사에서 일부 파일이 실패하면 게임이 고장 난 건가요? Steam 공식 안내처럼 로컬 설정 파일이 교체 대상이 아니어서 일부 파일이 실패로 표시되는 경우가 있습니다. 검사가 끝난 뒤 실제 게임 실행과 업데이트가 되는지 함께 확인하세요.
