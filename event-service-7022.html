EVENT ID 7022

Service Control Manager 7022 서비스 시작 중 멈춤 점검

서비스가 시작되는 중에 응답하지 않고 멈췄다는 기록입니다. 이벤트 본문에 서비스 이름이 있으므로, 어느 서비스인지와 같은 시각의 7000·7009 기록을 먼저 확인하세요.

7022는 서비스가 시작 도중 응답하지 않고 멈췄다는 기록입니다. 7000이 시작 자체에 실패한 경우라면, 7022는 시작 과정에서 멈춘 경우에 남습니다.

Microsoft 문서는 해결 방법으로 서비스를 수동으로 시작해 보도록 안내합니다. 수동으로 시작했을 때 정상이면 부팅 시점의 순서·부하 문제를, 수동으로도 멈추면 서비스 자체나 종속 항목 문제를 의심하세요.

발생 조건

  • 부팅 직후 특정 기능이 늦게 시작됨
  • 서비스를 수동으로 시작할 때 멈춘 듯 보임
  • 7000·7009·7011 같은 서비스 시작 오류가 함께 남음

가능성 높은 원인

  • 서비스가 의존하는 다른 서비스·드라이버가 아직 준비되지 않음
  • 저장장치·CPU 부하가 높은 상태에서 시작
  • 프로그램 파일 손상이나 구성 충돌
  • 서비스 자체의 시작 코드 오류

점검 순서

  1. 이벤트에 적힌 서비스 이름과 표시 이름 확인 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 서비스 관리자에서 해당 서비스를 수동으로 시작해 보기 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 속성의 종속성 탭에서 종속 서비스 상태 확인 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 같은 시각의 7000·7009·7011과 저장장치 이벤트 비교 — 변경 전후로 증상이 달라지는지 비교해보세요.
  5. 관련 프로그램 업데이트·복구 후 재현 여부 비교 — 여기까지 확인해도 해결되지 않으면 다음 원인을 검토하세요.
주의사항

서비스를 삭제하거나 시작 유형을 임의로 바꾸기 전에 어떤 프로그램의 서비스인지 먼저 확인하세요.

핵심 Windows 서비스라면 레지스트리를 직접 고치기 전에 복구 지점이나 백업을 확보하세요.

자주 묻는 질문

  • 7009와 7022는 어떻게 다른가요? 7009는 서비스가 제한 시간 안에 연결 응답을 보내지 않았다는 기록이고, 7022는 서비스가 시작 도중 멈췄다는 기록입니다. 같은 서비스에 함께 남을 수 있으니 시각과 서비스 이름을 비교하세요.
  • 수동으로 시작하면 되는데 부팅 때만 멈춰요. 시작 순서나 부하 문제일 수 있습니다. 먼저 프로그램 업데이트와 종속 서비스를 확인하고, 시작 유형을 바꾸는 방법은 프로그램 제조사가 허용하는 경우에만 시도하세요.
