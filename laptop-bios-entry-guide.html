BIOS와 부트 메뉴는 다릅니다

BIOS 또는 UEFI 설정 화면은 저장장치 인식, 부팅 순서, 가상화, 보안 부팅 같은 펌웨어 설정을 바꾸는 곳입니다. 부트 메뉴는 이번 한 번만 USB나 다른 디스크로 시작할 장치를 고르는 메뉴입니다.

키가 맞지 않으면 고장처럼 보여도 Windows가 너무 빨리 시작한 것일 수 있습니다. 전원을 완전히 끈 뒤 전원 버튼을 누르고 제조사 로고가 나타나는 순간부터 해당 키를 1초 간격으로 여러 번 누르세요. 일부 노트북은 Fn을 함께 눌러야 합니다.

주의

BIOS 설정을 모르는 상태에서 저장장치 모드, Secure Boot, TPM, 오버클럭을 임의로 바꾸지 마세요. 현재 값을 사진으로 남기고 한 번에 한 항목만 변경해야 원인을 되돌릴 수 있습니다.

키가 작동하지 않을 때

  1. 빠른 시작과 완전 종료 확인

    Windows 빠른 시작 때문에 재부팅 시 펌웨어 키 입력 시간이 짧을 수 있습니다. Shift를 누른 채 종료하거나 관리자 명령 프롬프트에서 shutdown /s /f /t 0으로 완전히 끈 뒤 다시 시도하세요.

  2. Fn Lock과 외장 키보드 확인

    F1~F12가 밝기·음량 키로 동작하면 Fn+F2처럼 눌러 보세요. 내장 키보드가 고장 난 경우에는 USB 키보드를 연결하되, USB 허브보다 노트북 본체 포트에 직접 연결하는 편이 안전합니다.

  3. Windows에서 UEFI 펌웨어 설정으로 이동

    Windows 11에서 설정 > 시스템 > 복구 > 고급 시작 옵션 > 지금 다시 시작을 선택합니다. 파란 화면에서 문제 해결 > 고급 옵션 > UEFI 펌웨어 설정 > 다시 시작을 선택하면 지원되는 기기에서 BIOS로 진입합니다.

  4. 제조사 복구 버튼과 설명서 확인

    Lenovo Novo 버튼, HP Startup Menu, Surface 버튼 조합처럼 일반 키와 다른 모델이 있습니다. 노트북 하판의 정확한 모델명으로 제조사 지원 페이지에서 BIOS 키와 사용자 설명서를 확인하세요.

BIOS에서 부팅 디스크 확인

BIOS에 들어갔다면 Main·Storage·NVMe 메뉴에서 Windows가 설치된 SSD 모델명이 보이는지 확인하세요. Boot 메뉴에서는 Windows Boot Manager를 첫 번째로 둡니다. 저장장치가 아예 보이지 않으면 부팅 순서보다 SSD 슬롯·접촉·저장장치 상태를 먼저 점검해야 합니다.

변경 전 꼭 기록할 항목

  • 현재 BIOS 버전과 날짜
  • Boot Mode: UEFI 또는 Legacy
  • Secure Boot·TPM 상태
  • Storage Mode: AHCI 또는 RAID
  • 가상화·메모리 프로필 설정

자주 묻는 질문

F2를 눌러도 Windows만 시작됩니다.

전원을 완전히 끈 뒤 전원 버튼을 누르자마자 F2를 빠르게 반복해 보세요. Fn Lock 상태라면 Fn+F2를 사용하고, 계속 실패하면 Windows의 UEFI 펌웨어 설정 경로를 이용하세요.

BIOS와 부트 메뉴 중 무엇을 열어야 하나요?

USB 설치 미디어나 다른 디스크로 한 번만 시작하려면 부트 메뉴를, 부팅 순서·Secure Boot·저장장치 모드를 바꾸려면 BIOS/UEFI 설정을 여세요.

BIOS에서 설정을 잘못 바꿔 Windows가 안 켜집니다.

최근 바꾼 항목을 원래대로 되돌리는 것이 우선입니다. 모르는 설정을 여러 개 바꿨다면 Load Optimized Defaults를 고려하되, 저장장치 모드와 부팅 방식이 현재 Windows 설치와 맞는지 확인하고 변경 전 사진을 참고하세요.
