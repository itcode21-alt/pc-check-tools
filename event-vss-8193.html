EVENT ID 8193

VSS 8193 볼륨 섀도 복사본 오류 점검

볼륨 섀도 복사본 서비스(VSS)가 오류로 실패했음을 기록합니다. 백업 소프트웨어와 시스템 복원 지점 생성에 영향을 줍니다.

8193은 볼륨 섀도 복사본 서비스(VSS)가 오류로 실패했다는 기록으로, 백업 소프트웨어 실행이나 시스템 복원 지점 생성 중에 주로 나타납니다. 이벤트 설명에 표시된 오류 코드로 원인 범위를 좁혀야 합니다.

디스크 여유 공간이 충분한지 먼저 확인하고, 백업 소프트웨어를 여러 개 함께 쓰고 있다면 VSS 작성기 충돌 가능성도 열어두세요.

발생 조건

  • 시스템 복원 지점 생성 실패
  • 백업 소프트웨어 오류
  • Windows Server 백업 실패

가능성 높은 원인

  • 디스크 공간 부족
  • VSS 서비스 또는 작성기 오류
  • 백업 중 저장장치 응답 지연

점검 순서

  1. 이벤트 설명의 오류 코드 확인 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 그림자 복사본 스토리지 여유 공간 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. vssadmin list writers 명령으로 작성기 상태 확인 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
주의사항

이 이벤트 반복 시 시스템 복원 지점이 만들어지지 않고 있을 수 있습니다.

관련 코드·가이드

자주 묻는 질문

  • 8193이 뜨면 백업이 실패한 건가요? 백업 소프트웨어나 시스템 복원이 VSS를 사용하는 도중 실패했을 가능성이 큽니다. 백업 프로그램의 실행 로그를 함께 확인해 실제로 완료됐는지 확인하세요.
  • vssadmin list writers는 어떻게 실행하나요? 관리자 권한 명령 프롬프트에서 vssadmin list writers를 입력하면 각 작성기의 상태가 표시됩니다. 오류 상태인 작성기가 있다면 관련 서비스를 재시작해보세요.
