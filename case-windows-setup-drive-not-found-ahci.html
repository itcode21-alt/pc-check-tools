Windows 설치 화면에 SSD가 안 보임 — BIOS의 SATA 모드를 Intel RST에서 AHCI로 바꿔 해결한 PC

Windows를 설치하려는데 「Windows를 설치할 위치」 목록에 SATA SSD가 나타나지 않던 사례입니다. BIOS에서는 SSD가 정상으로 인식되고 있었고, SATA 모드가 Intel RST Premium With Intel Optane System Acceleration으로 되어 있었습니다. 이 항목을 AHCI로 바꾸고 저장한 뒤 다시 설치를 시작하자 SSD가 목록에 나타났습니다.

이 사례를 읽을 때

참고 자료로 읽어 주세요. PC 수리 작업자가 직접 점검하고 해결한 사례이며, 같은 증상이어도 원인은 PC마다 다를 수 있습니다. 이 글에서 확인하지 못한 것은 CPU 세대, 메인보드 모델, 설치 USB를 만든 방법, 설치한 Windows 버전입니다. 「SATA 모드를 AHCI로 바꾼다」는 방법은 이 사례에서 확인된 조치이며, 아래에 적은 Intel·ASUS 공식 문서에는 같은 내용이 없습니다. 고객·장소·모델 정보는 싣지 않았습니다.

증상

  • Windows 설치 화면의 「Windows를 설치할 위치」에 디스크가 하나도 나타나지 않음
  • PC에는 500GB SATA SSD가 연결돼 있음

먼저 확인한 것: BIOS에서는 디스크가 보였습니다

설치 USB로 다시 시도하기 전에 BIOS를 열어 SATA 설정 화면(Advanced Mode의 SATA And RST Configuration)을 확인했습니다.

BIOS 항목값의미
SATA Controller(s)EnabledSATA 컨트롤러는 켜져 있음
SATA Mode SelectionIntel RST Premium With Intel Optane System AccelerationSATA 장치를 Intel RST 방식으로 쓰는 모드
SATA 포트 목록500GB SATA SSD가 연결된 포트에 모델명과 용량(500.1GB)이 표시됨BIOS는 SSD를 인식하고 있음

디스크가 BIOS에서 보이므로 케이블이나 SSD 자체가 문제일 가능성은 낮아졌고, 설치 화면만 디스크를 못 보는 상황으로 좁혀졌습니다.

해석

  • BIOS에서는 보이는데 설치 화면에서만 안 보이면 저장장치 드라이버를 의심합니다. Intel 지원 문서는 운영체제에 저장장치 컨트롤러용 드라이버가 없으면 연결된 장치를 감지하지 못하고, 그럴 때는 설치 도중 드라이버를 불러와야 한다고 안내합니다.
  • 이 PC는 SATA 모드가 RST였습니다. RST 모드의 컨트롤러를 설치 화면이 알아보지 못해 디스크가 목록에 나타나지 않았을 가능성이 높다고 보았습니다. 다만 설치 USB에 어떤 드라이버가 들어 있었는지는 확인하지 못해서 확정은 아닙니다.

해결

  1. BIOS에서 SATA Mode Selection에 Enter를 눌러 AHCI를 선택했습니다.
  2. 저장하고 재부팅(Save & Exit)했습니다.
  3. Windows 설치 USB로 다시 시작하자 설치 화면에 SSD가 나타났습니다.

이후 경과(설치 완료 후 안정성)는 이 글에서 확인하지 못했습니다.

AHCI로 바꾸기 전에 확인할 것

  • Optane 메모리나 RAID를 쓰는 PC라면 바꾸지 마세요. RST 모드를 쓰는 이유가 있는 구성에서는 AHCI로 바꾸면 구성이 풀리거나 인식되지 않을 수 있습니다. 이때는 아래 드라이버 로드 방법을 쓰세요.
  • 이미 Windows가 설치된 디스크를 부팅하려는 경우에는 모드를 함부로 바꾸지 마세요. 설치 모드와 BIOS 모드가 다르면 0x0000007B(INACCESSIBLE_BOOT_DEVICE)로 부팅이 막힐 수 있습니다. 디스크를 지우고 새로 설치하는 경우에는 해당되지 않습니다.
  • 디스크에 남길 데이터가 있다면 설치 화면에서 파티션을 지우거나 포맷하기 전에 백업하세요.
  • BIOS 설정을 기본값으로 초기화하면 이 항목이 되돌아갈 수 있습니다. 설치 후 부팅이 안 되면 모드가 바뀌었는지 먼저 확인하세요(일반 안내이며 이 사례에서 확인한 것은 아닙니다).

공식 문서가 안내하는 다른 방법: 설치 중 드라이버 불러오기

RST 모드를 유지해야 하거나, AHCI로 바꿔도 디스크가 보이지 않으면 설치 중에 저장장치 드라이버를 불러옵니다. Intel 지원 문서의 순서는 다음과 같습니다.

  1. 설치할 저장장치 컨트롤러용 F6 드라이버 패키지를 받아 USB에 압축을 풉니다(Intel RST라면 플랫폼에 맞는 패키지를 고릅니다).
  2. Windows 설치를 시작하고 「드라이버 로드」를 누릅니다.
  3. 「찾아보기」에서 F6 드라이버가 든 USB의 해당 폴더를 선택하고 확인을 누릅니다.
  4. 목록에서 알맞은 드라이버(문서의 예: iaStorAC.sys)를 고르고 다음으로 진행합니다.
  5. 설치할 드라이브를 선택하고 다음으로 진행합니다.

ASUS 지원 문서는 Intel 11~14세대(Tiger Lake·Alder Lake·Raptor Lake·Arrow Lake) 프로세서에서는 Windows 소매 버전을 설치할 때 먼저 Intel RST 드라이버를 불러와야 하며, 방법으로 드라이버를 수동으로 불러오거나 Intel VMD 기술을 끄는 것을 안내합니다. Intel 15세대 이후(Lunar Lake Core Ultra 등)는 Windows 11 24H2 이상에서 드라이버를 따로 설치하지 않아도 된다고 안내합니다.

이 사례에서 배운 점

  • 설치 화면에 디스크가 없어도 먼저 BIOS에서 디스크가 보이는지 확인합니다. 보이면 케이블·SSD보다 SATA 모드와 저장장치 드라이버를 의심합니다.
  • BIOS의 SATA 모드가 Intel RST 계열이면 AHCI로 바꿔 보는 것이 빠른 첫 시도가 됩니다. 단, 기존 Windows 설치나 Optane·RAID 구성이 없는지 확인한 뒤에 합니다.
  • 설치 후 장치 관리자의 「저장소 컨트롤러」에서 표준 SATA AHCI 컨트롤러가 보이는지 확인합니다.

비슷한 증상일 때 확인 순서

  1. 설치 USB로 들어가기 전에 BIOS에서 디스크의 모델명과 용량이 보이는지 확인합니다. 안 보이면 케이블·전원·M.2 장착부터 점검합니다.
  2. 디스크가 보이면 SATA 모드(SATA Mode Selection)가 RST·RAID·VMD 계열인지 확인합니다.
  3. Optane·RAID를 쓰지 않고 새로 설치하는 경우에만 AHCI로 바꾸고 저장·재부팅합니다. 바꾸기 전에 중요한 데이터를 백업합니다.
  4. 그래도 안 보이거나 모드를 바꿀 수 없으면 설치 화면의 「드라이버 로드」로 저장장치 드라이버를 불러옵니다.
  5. 설치가 끝난 뒤 장치 관리자에서 저장소 컨트롤러 상태를 확인합니다. BIOS 부팅 방법은 BIOS 진입·부팅 순서 가이드를 참고하세요.
