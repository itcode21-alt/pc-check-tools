내 PC에 맞는 Ollama 모델 추천

그래픽카드 VRAM과 RAM을 고르면 Ollama에서 들어가는 모델과, 모델마다 할 수 있는 작업(대화·추론·이미지 이해·코드·문서 검색)을 정리해 보여 줍니다. 입력값은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.

🔒 브라우저에서만 처리 · 서버로 전송되지 않음

VRAM은 작업 관리자 → 성능 → GPU의 '전용 GPU 메모리'에서 볼 수 있습니다. 노트북은 내장 그래픽과 그래픽카드가 함께 있을 수 있어 실제로 쓰는 GPU를 확인하세요. 카드 이름은 NVIDIA 공식 사양의 데스크톱 카드만 넣었고, AMD 카드는 VRAM을 직접 고르세요.

어떻게 고르나요 — 계산 기준

  • 모델 목록·파일 크기·기능 표시는 Ollama 모델 라이브러리의 태그 목록과 모델 페이지에서 2026-11-23에 읽은 기본 태그 값입니다. 라이브러리는 자주 바뀌므로 새 모델이 빠져 있을 수 있습니다.
  • 여유 있게 들어감: 파일 크기 × 1.2가 VRAM 이하일 때입니다. Hugging Face 메모리 추정 문서가 추론할 때 로딩 크기에 최대 약 20%가 더 필요하다고 안내한 값입니다. 컨텍스트 길이가 쓰는 메모리는 모델마다 달라 포함하지 못했습니다.
  • 겨우 들어감: 파일은 VRAM에 들어가지만 파일 크기 × 1.2는 넘는 경우입니다. 컨텍스트를 늘리면 모자랄 수 있습니다.
  • 느려도 되면(CPU·RAM): VRAM에 안 들어가는 모델 중 파일 크기 × 1.2가 RAM의 절반 이하인 것입니다. 이 기준은 이 도구가 정한 어림값이며 문서 근거는 없습니다. Ollama 문서는 모델이 CPU로 일부 넘어가는 상태를 피하라고 안내하고, 속도는 이 도구가 알 수 없습니다.
  • 할 수 있는 일은 Ollama 라이브러리의 기능 표시를 풀어 쓴 것입니다. tools는 도구 호출, thinking은 추론 모드, vision은 이미지 입력, embedding은 문서 검색용입니다. 코드 특화는 모델 이름(coder)과 설명 기준입니다. 한국어 답변 품질, 정확도, 실제 속도는 확인한 자료가 없어 판단하지 않습니다.

메모리 계산의 배경은 로컬 AI용 PC 사양 가이드에 정리했습니다. 참고 자료: Ollama 하드웨어 지원·컨텍스트 길이 문서, Ollama 모델 라이브러리, Hugging Face Accelerate 메모리 추정 문서, NVIDIA GeForce 비교표.

자주 묻는 질문

GPU가 없어도 쓸 수 있나요?

Ollama 문서에 CPU 추론(시스템 메모리 사용)이 명시돼 있어 가능은 합니다. 'GPU 없음'을 고르면 RAM 기준으로 후보를 보여 주며, 속도는 CPU와 모델 크기에 따라 크게 달라 이 도구가 판단하지 못합니다.

'겨우 들어감'인 모델은 써도 되나요?

써 볼 수는 있지만 컨텍스트가 길어지면 메모리가 모자라 CPU로 일부가 넘어갈 수 있습니다. Ollama 문서도 이런 오프로딩을 피하라고 안내하니, 먼저 ollama ps의 PROCESSOR 열이 100% GPU인지 확인해 보세요.

같은 이름 카드인데 VRAM이 다릅니다.

RTX 3060(12GB·8GB), RTX 5060 Ti·4060 Ti(16GB·8GB)처럼 판에 따라 VRAM이 다른 카드가 있어 목록에 판을 나눠 적었습니다. 판매 페이지의 메모리 용량을 확인하세요.

모델은 어떻게 받나요?

Ollama를 설치한 뒤 표의 '받는 명령'을 터미널(명령 프롬프트나 PowerShell)에 입력하면 됩니다. 예: ollama run qwen3:8b 처럼 입력하면 모델을 내려받아 대화를 시작합니다.
