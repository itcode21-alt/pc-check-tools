목차

    CPU 쿨러 / 조립

    사제 CPU 쿨러 장착 후 POST 실패 원인과 점검 순서

    사제 CPU 쿨러를 장착하거나 조인 뒤 화면이 없고 CPU·DRAM LED에서 POST가 멈추는 경우

    발열 관리를 위해 사제 공랭 또는 수랭 쿨러를 사용하는 PC에서 쿨러를 장착한 뒤 전원은 들어오지만 화면이 나오지 않고 POST가 끝나지 않는다면, CPU 고장으로 바로 단정하기보다 장착 과정에서 달라진 조건을 먼저 되돌려 봐야 합니다. 이 증상은 특정 CPU에만 한정된 공식 결함이라기보다, 소켓 종류와 관계없이 쿨러 장착 키트와 조임 상태가 맞지 않을 때 일부 시스템에서 관찰될 수 있는 조립 관련 문제입니다.

    CPU 쿨러는 방열판을 CPU에 밀착시키는 부품이므로 적정한 압력이 필요합니다. 그러나 잘못된 스페이서나 백플레이트를 사용하거나 한쪽 나사를 먼저 끝까지 조이면 메인보드가 불균일하게 휘고, 소켓 접촉 또는 메모리 초기화 상태에 영향을 줄 가능성이 있습니다. 이 설명은 가능한 작동 원리를 정리한 것이며 특정 CPU나 쿨러의 공통 결함을 뜻하지 않습니다.

    가장 중요한 단서는 쿨러 장착 전에는 정상 부팅됐는지, CPU와 DRAM 중 어느 디버그 LED에서 멈추는지, RAM 한 개만 사용해도 같은지입니다. 증상을 재현하려고 쿨러를 느슨하게 둔 채 장시간 사용하면 냉각이 불안정해질 수 있으므로 진단 뒤에는 반드시 올바른 장착 상태로 복구해야 합니다.

    이 가이드가 필요한 상황

    • 쿨러 교체 직후부터 화면이 나오지 않는다.
    • CPU 또는 DRAM 디버그 LED가 계속 켜진다.
    • 나사를 조금 풀면 부팅되지만 다시 조이면 POST가 멈춘다.
    • 특정 RAM 슬롯이나 메모리 채널만 인식되지 않는다.

    먼저 확인할 항목

    1. 디버그 LED와 변경 시점 기록 — CPU LED와 DRAM LED는 점검 시작 위치를 크게 줄여 줍니다. 쿨러 장착 전후 상태, 비프음, 팬 반응, CPU·DRAM·VGA·BOOT 중 멈춘 LED를 기록하세요.
    2. AM4·AM5 장착 부품 대조 — 소켓에 맞지 않는 스페이서와 백플레이트는 높이와 압력을 바꿉니다. 쿨러 모델의 공식 설명서에서 소켓별 브래킷, 스페이서 색상·방향, 기본 백플레이트 재사용 여부를 확인하세요.
    3. 소켓과 CPU 접점 검사 — 쿨러를 교체하면서 CPU가 들리거나 핀·접점에 이물질이 생길 수 있습니다. 전원 코드를 빼고 AM4 CPU 핀 또는 AM5 소켓 핀, CPU 접점과 서멀 그리스 유입 여부를 밝은 조명에서 확인하세요.
    4. 대각선으로 균등 재장착 — 한쪽을 먼저 끝까지 조이면 방열판 압력과 보드 휨이 한 방향에 집중됩니다. 새 서멀 그리스를 바르고 네 모서리를 대각선으로 조금씩 번갈아 조이세요. 정지 지점 이후에는 억지로 더 조이지 마세요.
    5. 공식 수치가 있으면 토크 드라이버 사용 — 여러 볼트를 끝까지 조이지 않고 같은 체결력으로 맞춰야 하는 제조사 지정 방식이라면, 손으로 푼 회전 수보다 토크 드라이버가 균일하고 재현 가능합니다. 설명서에 목표 토크나 허용 체결 방식이 있을 때만 저토크 드라이버를 사용해 대각선 순서로 같은 최종값에 맞추세요. 끝까지 체결하도록 설계된 스프링 나사를 임의로 덜 조이거나, 최대값을 목표값으로 해석하면 안 됩니다.
    6. CMOS 초기화와 RAM 한 개 테스트 — 메모리 훈련 실패와 장착 압력 문제를 나누는 데 도움이 됩니다. CMOS를 초기화한 뒤 RAM 한 개만 권장 슬롯(보통 A2)에 장착해 CPU와 DRAM LED가 통과하는지 확인하세요.
    7. 장착 키트 또는 쿨러 교차 확인 — 느슨하게 해야만 부팅된다면 정상적인 해결 상태가 아닙니다. 부품 혼용을 중단하고 제조사의 최신 장착 키트나 다른 정상 쿨러로 교차 테스트하세요.

    원인을 더 정확히 나누는 방법

    AM4와 AM5에서 확인할 차이

    AM4 시스템은 쿨러 종류에 따라 메인보드 기본 백플레이트를 재사용하며, 고정 나사를 풀면 뒤쪽 백플레이트가 움직일 수 있습니다. AM5는 소켓 구조와 백플레이트 고정 방식이 다르므로 AM4용 부품을 임의로 혼용하면 안 됩니다. 항상 해당 쿨러의 소켓별 설명서를 우선하세요.

    CPU LED와 DRAM LED가 번갈아 켜질 때

    AMD 플랫폼은 초기 부팅과 CMOS 초기화 뒤 메모리 훈련에 시간이 걸릴 수 있습니다. 잠깐 LED가 바뀌는 것은 정상일 수 있지만 수분 이상 같은 단계에 머물거나 매번 실패하면 RAM 한 개, 기본 설정, 올바른 장착 상태로 다시 비교해야 합니다.

    토크 수치를 그대로 따라 하면 안 되는 이유

    Noctua는 자사 NM-ALS1 AMD 장착 바 나사와 쿨러를 장착 바에 고정하는 스프링 나사에 최대 0.6 N·m를 안내합니다. 이는 목표 토크가 아니라 넘지 말아야 할 자사 부품의 최대값입니다. 여러 볼트를 끝까지 조이지 않는 방식이 제조사 설명서에 허용되고 목표 토크가 따로 제시된 경우에는 저토크 드라이버로 각 볼트를 대각선 순서로 같은 값에 맞추는 것이 손으로 같은 회전 수만큼 푸는 것보다 정확합니다. 그러나 공식 목표값이 없다면 임의로 낮춘 토크를 영구 설정으로 사용하지 마세요.

    문제가 쿨러 장착에서 시작됐는지 확인하는 방법

    부품을 한꺼번에 바꾸면 원인을 찾기 어렵습니다. 쿨러를 바꾸기 전 마지막으로 정상 부팅한 상태, 새 쿨러를 장착한 직후의 LED, 나사를 조금 조절했을 때의 변화, RAM 한 개 테스트 결과를 순서대로 기록하세요. 쿨러를 다시 올바르게 장착했을 때만 문제가 사라지는지 확인하면 소켓·메모리·전원 문제와 장착 압력 문제를 구분하는 데 도움이 됩니다.

    장착 키트 호환성을 확인하는 기준

    쿨러 포장에 AM4·AM5 또는 여러 소켓 이름이 함께 적혀 있어도 모든 브래킷이 같은 방식으로 설치되는 것은 아닙니다. 쿨러 모델의 개정판, 메인보드 소켓, 백플레이트 두께, 스페이서 높이와 나사 길이를 함께 확인해야 합니다. 중고 쿨러나 누락된 나사 세트는 비슷해 보이는 부품을 섞지 말고 제조사에서 맞는 키트를 받아 사용하세요.

    재부팅 후 온도까지 확인해야 하는 이유

    화면이 나오고 윈도우가 시작되었다고 장착 문제가 해결된 것은 아닙니다. BIOS 하드웨어 모니터나 메인보드 유틸리티에서 유휴 온도와 짧은 부하 때의 온도 상승을 확인하고, 쿨러 팬·펌프 RPM과 CPU_FAN 또는 AIO_PUMP 연결도 점검하세요. 온도가 비정상적으로 빠르게 오르거나 팬이 멈추면 전원을 끄고 정상 장착 상태를 다시 확인해야 합니다.

    확인 결과에 따른 다음 단계

    • 올바르게 재장착하니 정상 부팅될 때 — CPU 결함보다 장착 부품 조합이나 불균일한 조임이 원인이었을 가능성이 큽니다. 온도와 안정성을 확인한 뒤 정상 장착 상태를 유지하세요.
    • 스프링 나사를 조인 뒤 문제가 생길 때 — 쿨러 제조사가 허용 토크 범위나 목표값을 안내했다면 모든 스프링 나사를 먼저 균일하게 풀고, 토크 드라이버를 제조사 범위 안에 설정한 뒤 대각선 순서로 같은 값까지 조금씩 조여 비교할 수 있습니다. 공식 범위가 없다면 토크를 임의로 낮추지 말고 장착 키트·스페이서와 쿨러 호환성을 다시 확인하세요.
    • 토크 드라이버가 없을 때의 임시 비교 — 제조사 설명서에 위반되지 않는 범위에서만, 모든 스프링 나사를 같은 기준으로 조인 뒤 1/4바퀴씩 대각선 순서로 균일하게 풀어 부팅 여부를 비교할 수 있습니다. 1/2바퀴 이상 풀어야만 부팅되면 정상 해결로 보지 말고 즉시 원래 상태로 되돌린 뒤 장착 키트·쿨러 호환성을 점검하세요. 회전량은 실제 토크가 아니므로 이 방법을 최종 체결 기준으로 사용하지 마세요.
    • RAM 한 개에서는 부팅되지만 두 개에서 실패할 때 — RAM 자체, 슬롯, 메모리 설정과 CPU 소켓 접촉을 함께 봐야 합니다. 모듈과 슬롯을 하나씩 바꿔 같은 채널에서만 실패하는지 확인하세요.
    • 다른 정상 쿨러에서도 CPU LED가 멈출 때 — 소켓 핀, CPU, 메인보드 또는 전원 공급 문제까지 범위를 넓혀 교차 테스트하거나 전문 점검을 받는 편이 안전합니다.

    피해야 할 실수

    • 특정 CPU에서만 발생하는 공통 결함이라고 단정하는 것
    • 쿨러를 느슨하게 둔 상태를 영구 해결책으로 사용하는 것
    • AM4와 AM5의 백플레이트·스페이서를 임의로 혼용하는 것
    • 제조사 지침이 다른 토크 수치를 모든 쿨러에 적용하는 것
    • 쿨러 없이 전원을 켜거나 핀을 금속 도구로 억지로 펴는 것

    자주 묻는 질문

    • 발열 관리를 위해 사제 쿨러를 장착하는 과정에서 나타날 수 있는 문제인가요? 쿨러 교체 직후 일부 조립 환경에서 나타날 수 있지만, 특정 CPU 전용 결함으로 확인된 것은 아닙니다. CPU 종류보다 쿨러 장착 부품, 메인보드, 조임 방식과 소켓 접촉 상태를 함께 확인해야 합니다.
    • 나사를 조금 풀면 부팅되는데 그대로 써도 되나요? 권장하지 않습니다. 냉각면 접촉이 부족해 과열될 수 있습니다. 원인을 확인하는 짧은 진단으로만 사용하고, 올바른 장착 키트로 재설치하거나 쿨러를 교체하세요.
