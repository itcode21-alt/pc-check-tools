목차

    CPU 쿨러 / 조립

    사제 CPU 쿨러 장착 후 POST가 멈출 때 확인할 순서

    사제 공랭·수랭 쿨러를 조인 뒤 CPU·DRAM LED에서 멈추는 경우

    AMD CPU를 사용하는 PC에서 쿨러를 교체한 직후 전원은 들어오지만 화면이 나오지 않는다면 CPU 고장부터 단정하지 마세요. 쿨러 교체 전에는 정상 부팅됐는지, CPU와 DRAM 중 어느 디버그 LED에서 멈추는지, RAM 한 개만 꽂았을 때도 같은지가 더 중요한 단서입니다.

    발열 관리를 위해 별도 사제 공랭·수랭 쿨러를 장착하는 과정에서 이런 증상이 간혹 나타날 수 있습니다. 특정 CPU에만 한정된 공식 결함으로 확인된 것은 아니며, 소켓 종류와 관계없이 장착 키트, 스페이서와 백플레이트가 맞지 않거나 나사를 한쪽부터 과도하게 조이면 메인보드가 불균일하게 휘고 소켓 접촉이나 메모리 초기화 조건이 달라질 가능성이 있습니다.

    쿨러를 약하게 조인 상태에서 부팅된다고 해서 그대로 사용하면 안 됩니다. 방열판과 CPU 사이의 접촉이 부족해져 과열될 수 있으므로, 이 결과는 원인을 좁히는 짧은 진단으로만 사용하고 올바른 부품과 조임 방식으로 다시 장착해야 합니다.

    먼저 기록할 증상

    • 쿨러 교체 직후부터 화면이 나오지 않는지 확인합니다.
    • CPU·DRAM·VGA·BOOT 중 어느 디버그 LED에서 멈추는지 기록합니다.
    • 팬이 잠깐 돌다 꺼지는지, 계속 도는지, 비프음이 있는지 확인합니다.
    • 나사를 다시 조일 때만 증상이 바뀌는지 기록합니다.

    안전한 점검 순서

    1. 전원 분리 — 운영체제를 종료하고 PSU 스위치를 끈 뒤 전원 케이블을 분리하세요. 쿨러 없이 전원을 켜거나 작동 중에 나사를 조절하지 마세요.
    2. 장착 설명서 대조 — 쿨러 모델의 공식 설명서에서 AM4 또는 AM5용 브래킷, 스페이서 색상과 방향, 기본 백플레이트 재사용 여부를 확인하세요. 다른 쿨러의 부품을 섞지 마세요.
    3. 핀과 접점 확인 — 쿨러를 분리하고 AM4 CPU 핀 또는 AM5 메인보드 소켓 핀, CPU 접점, 소켓 주변 이물질과 서멀 그리스 유입을 밝은 조명에서 확인하세요.
    4. 스프링 나사 토크 조절 — 스프링 나사를 꽉 조인 직후 문제가 생겼고 제조사가 허용 토크 범위나 목표값을 안내했다면, 모든 나사를 균일하게 풀고 토크 드라이버를 그 범위 안에 설정해 대각선 순서로 같은 값까지 조금씩 조이세요. 공식 범위가 없다면 임의로 낮춘 토크를 사용하지 말고 장착 키트와 호환성을 다시 확인합니다.
    5. 기본 설정에서 부팅 — CMOS를 초기화하고 RAM 한 개를 메인보드 설명서의 권장 슬롯, 일반적으로 A2에 장착해 CPU와 DRAM LED가 통과하는지 확인하세요.
    6. 교차 테스트 — 올바르게 조이면 실패하고 느슨할 때만 부팅된다면 장착 키트나 쿨러가 맞지 않을 수 있습니다. 제조사 최신 키트 또는 다른 정상 쿨러로 비교하세요.

    AM4와 AM5에서 다르게 볼 부분

    AM4 시스템은 쿨러 종류에 따라 메인보드 기본 백플레이트를 재사용합니다. 기본 고정 브래킷을 제거하면 케이스 뒤쪽의 백플레이트가 떨어지거나 움직일 수 있으므로 위치를 잡은 상태에서 설치해야 합니다. AM5는 소켓과 백플레이트 구조가 다르므로 AM4용 부품을 임의로 혼용하면 안 됩니다.

    CPU와 DRAM LED가 잠시 번갈아 켜지는 것은 메모리 훈련 과정일 수 있습니다. 그러나 같은 단계에서 오래 멈추거나 매번 POST가 실패한다면 충분히 기다린 뒤 전원을 끄고 RAM 한 개, 기본 BIOS 설정, 올바른 쿨러 장착 상태로 비교하세요.

    토크 드라이버를 사용할 때

    정확하고 반복 가능한 고정을 원하는 사용자는 제조사가 공식 토크를 제공하는 경우 저토크 범위의 조절식 토크 드라이버를 사용할 수 있습니다. 특히 제조사 설명서에서 볼트를 끝까지 조이지 않는 장착 방식과 목표 토크를 따로 허용한 경우, 여러 볼트를 손으로 같은 회전 수만큼 풀어 맞추는 것보다 토크 드라이버로 같은 최종 체결값을 적용하는 편이 정확합니다. 다만 AMD CPU 쿨러 전체에 적용되는 공통 토크값은 없으며, 수치는 소켓뿐 아니라 쿨러와 장착 키트의 나사 종류에 따라 달라집니다.

    제조사·장착 부품공식 최대 토크적용 범위
    Noctua NM-ALS1 AMD 장착 바 나사0.6 N·mNoctua가 지정한 해당 나사에만 적용
    Noctua 쿨러 고정용 스프링 나사0.6 N·mNoctua 장착 바에 고정하는 해당 스프링 나사에만 적용
    그 밖의 AMD 공랭·수랭 쿨러제품별 설명서 확인공식 수치가 없으면 0.6 N·m를 임의 적용하지 않음

    중요: Noctua의 `0.6 N·m`는 권장 목표값이 아니라 넘지 말아야 할 최대값입니다. 제조사 설명서의 기본 지침은 나사가 멈출 때까지 부드럽게 조이고 과도한 힘을 쓰지 않는 것입니다. 끝까지 체결하도록 설계된 스프링 나사를 부팅 문제 때문에 임의로 덜 조인 채 사용하면 안 됩니다. 볼트를 덜 조이는 방식은 제조사가 허용하고 목표 토크를 제시한 경우에만 사용하세요.

    토크 드라이버를 사용할 때는 모든 스프링 나사를 먼저 균일하게 풀어 둔 뒤 조이는 방향으로 토크를 맞추세요. 풀리는 순간의 토크는 마찰 때문에 실제 체결 토크와 다를 수 있어, 풀림 토크를 측정값으로 사용하면 정확하지 않습니다. 제조사가 허용한 범위가 있다면 그 안에서 낮은 단계부터 시작해 대각선 순서로 2~3회 나누어 같은 최종값에 도달하도록 체결하고, 팬 연결과 쿨러의 흔들림을 확인한 뒤 부팅을 시험합니다. 드라이버는 필요한 값이 측정 범위의 끝이 아닌 정상 사용 범위에 들어가는 제품과 나사 머리에 맞는 비트를 선택해야 합니다.

    토크 드라이버가 없을 때의 임시 비교

    고가의 토크 드라이버를 바로 구매하기 부담스럽다면, 제조사 설명서에 위반되지 않는 범위에서만 스프링 나사를 1/4바퀴 단위로 조금씩 조절해 부팅 여부를 비교할 수 있습니다. 이때 모든 나사를 같은 양만큼, 대각선 순서로 균일하게 조절해야 합니다. 1/2바퀴 이상 풀어야만 부팅된다면 정상적인 해결 상태가 아니므로 장시간 사용하지 말고 장착 키트·스페이서·쿨러 호환성을 다시 확인하세요. 나사 회전량은 실제 토크값과 같지 않으므로 1/4바퀴 또는 1/2바퀴를 최종 조립 기준으로 사용해서는 안 됩니다.

    중단 기준: 쿨러가 흔들리거나 CPU 온도가 빠르게 오르거나, 타는 냄새·보드 휨·비정상 소음이 보이면 즉시 전원을 끄고 전원 케이블을 분리하세요. 진단을 위해 나사를 조절한 뒤에는 반드시 쿨러 제조사가 정한 정상 장착 상태로 복구해야 합니다.

    결과에 따른 판단

    • 재장착 후 정상 부팅 — CPU 결함보다 스페이서·브래킷 조합이나 불균일한 조임이 원인이었을 가능성이 큽니다. 정상 장착 상태에서 CPU 온도도 확인하세요.
    • RAM 한 개에서만 부팅 — RAM 모듈과 슬롯을 하나씩 바꿔 특정 메모리 채널에서만 실패하는지 확인하고, 소켓 접촉 상태도 다시 살펴보세요.
    • 다른 정상 쿨러에서도 실패 — CPU 보조전원, BIOS 지원, 소켓 핀, CPU와 메인보드까지 범위를 넓혀 교차 테스트하거나 전문 점검을 받으세요.

    피해야 할 실수

    • 특정 CPU에서만 발생하는 공통 결함이라고 단정하는 것
    • 쿨러를 느슨하게 둔 상태를 영구 해결책으로 사용하는 것
    • AM4와 AM5용 백플레이트·스페이서를 임의로 혼용하는 것
    • 다른 제조사가 안내한 토크 값을 현재 쿨러에 그대로 적용하는 것
    • 쿨러 없이 전원을 켜거나 소켓 핀을 금속 도구로 억지로 펴는 것

    공식 자료와 해석 범위

    AMD의 데스크톱 부팅 실패 안내는 POST 실패 시 RAM과 CPU 쿨러 장착 상태 등을 확인하도록 안내합니다. AMD의 방열판 설계 자료는 패키지에 가해지는 압력이 지정 범위를 벗어나면 스트레스를 줄 수 있고 압력을 균등하게 적용해야 한다는 일반 원칙을 설명합니다. 다만 이 자료만으로 특정 Ryzen 제품의 결함을 뜻하지는 않습니다.

    Noctua는 자사 NM-ALS1 AMD 장착 바 나사와 쿨러 고정용 스프링 나사에 최대 0.6 N·m를 공개합니다. 이 값은 해당 Noctua 장착 하드웨어에만 적용되며 다른 제조사의 쿨러에는 그대로 사용할 수 없습니다. 현재 사용 중인 쿨러 제조사의 설명서와 지원 문서를 우선하세요.

    • AMD 데스크톱 시스템 부팅 실패 기본 점검
    • AMD 방열판 장착 압력의 일반 원칙
    • Noctua 자사 쿨러 나사 토크 안내

    자주 묻는 질문

    • CPU LED가 켜졌으면 CPU가 고장난 건가요? CPU 전원, BIOS 지원, 소켓 접촉, 메모리 초기화와 쿨러 장착 상태 때문에도 멈출 수 있어 LED 하나만으로 고장을 확정할 수 없습니다.
    • 발열 관리를 위해 사제 쿨러를 장착하는 과정에서 생기나요? 쿨러 교체 직후 일부 조립 환경에서 나타날 수 있지만 특정 CPU 전용 결함은 아닙니다. 제조사가 허용 토크 범위나 목표값을 안내한 경우에만 모든 나사를 풀고 토크 드라이버를 그 범위 안에 설정해 대각선 순서로 균일하게 조이며 비교하세요.
    • 스프링 나사를 조이면 부팅이 안 됩니다. 제조사가 허용 토크 범위나 목표값을 안내한 경우에만 모든 나사를 풀고 토크 드라이버를 그 범위 안에 설정해 대각선 순서로 균일하게 조이며 비교하세요. 공식 범위가 없다면 체결력을 임의로 낮춘 채 사용하지 말고 장착 키트와 쿨러 호환성을 점검해야 합니다.
    • 타는 냄새나 보드 균열이 보입니다. 즉시 전원을 분리하고 더 이상 부팅하지 마세요. 손상 부위와 전원 공급 상태를 전문 점검받는 편이 안전합니다.
