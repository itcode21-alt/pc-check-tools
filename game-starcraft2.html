스타크래프트2 오류 모음 — 원인과 해결 방법

출시된 지 오래된 게임인 만큼, 최신 Windows 업데이트나 그래픽 드라이버와의 호환성 문제로 접속·실행 오류가 꾸준히 보고됩니다. 블리자드 공식 지원 문서 기준으로 점검 순서를 정리했습니다.

바로 이동

  • 배틀넷 로그인 또는 게임 접속이 안 되는 문제 (배틀넷 접속 불가)
  • 게임 실행 중 로딩 화면에서 멈추거나 갑자기 튕기는 문제 (로딩 중 멈춤 · 튕김)
  • KR 서버에서 사용자지정 아케이드 맵에 입장하면 게임이 튕기는 문제 (사용자지정 아케이드 입장 시 튕김)
  • 접속할 때마다 '게임 데이터 준비중'과 함께 대용량 재다운로드가 발생하는 문제 (게임 데이터 준비중 반복 재다운로드)
  • 게임 실행 중 효과음·음성이 전혀 들리지 않는 문제 (소리가 들리지 않음)
  • 게임 서버에 처음 접속하는 단계에서 실패하는 오류(Error 2:5) (Failed to make initial server connection (Error 2:5))
  • 플레이 도중 '응용 프로그램에 예기치 않은 오류' 메시지와 함께 게임이 튕기는 문제 (응용 프로그램에 예기치 않은 오류가 발생했습니다)

배틀넷 로그인 또는 게임 접속이 안 되는 문제 · 배틀넷 접속 불가

접속/서버

Battle.net 런처 로그인은 되는데 스타크래프트2 접속 시 멈추거나, 로그인 자체가 반복 실패하는 문제입니다. 네트워크 경로나 캐시 손상이 흔한 원인입니다.

가능한 원인

  • Battle.net 캐시 파일이 손상된 경우
  • 공유기·방화벽에서 Battle.net 관련 포트가 막힌 경우
  • VPN이나 프록시가 접속 모듈과 충돌하는 경우
  • DNS 응답 지연으로 서버를 찾지 못하는 경우

점검 순서

  1. 1단계 - Battle.net 앱 재시작:
    ① 작업 관리자에서 Battle.net·StarCraft II 프로세스를 모두 종료
    ② Battle.net 앱 재실행 후 재로그인
  2. 2단계 - 스캔 및 복구 (권장):
    ① Battle.net 런처에서 스타크래프트 II 선택
    ② 톱니바퀴(옵션) → '스캔 및 복구' 실행
  3. 3단계 - 네트워크 초기화:
    ① 명령 프롬프트(관리자)에서 ipconfig /flushdns 실행
    ② 공유기 재시작 후 재접속
  4. 4단계 - VPN·프록시 해제:
    ① 사용 중인 VPN을 끄고 재시도
    ② 인터넷 속성의 프록시 설정도 사용 안 함으로 변경
  5. 5단계 - 방화벽 예외 확인:
    ① Windows Defender 방화벽에서 Battle.net·StarCraft II 실행 파일이 허용되어 있는지 확인

그래픽/실행

실행은 되는데 로딩 화면에서 무한정 멈추거나, 플레이 도중 예고 없이 게임이 종료되는 문제입니다. 오래된 게임인 만큼 최신 그래픽 드라이버와의 호환성 문제가 흔합니다.

가능한 원인

  • 그래픽 드라이버가 최신 Windows 업데이트와 호환되지 않는 경우
  • 게임 파일 일부가 손상된 경우
  • 다른 프로그램과의 리소스 충돌

점검 순서

  1. 1단계 - 그래픽 드라이버 재설치:
    ① 그래픽카드 제조사 최신 드라이버로 업데이트하거나, 문제가 최신 드라이버 이후 시작됐다면 이전 버전으로 롤백
  2. 2단계 - 스캔 및 복구:
    ① Battle.net 런처 옵션에서 '스캔 및 복구'로 손상된 게임 파일 재다운로드
  3. 3단계 - 백그라운드 프로그램 정리:
    ① 방송·녹화 프로그램 등 리소스를 많이 쓰는 백그라운드 앱 종료 후 재시도

접속/서버

배틀넷 로그인과 일반 대전은 정상인데, 사용자지정(아케이드) 게임 목록에서 특정 맵에 입장할 때만 게임이 강제 종료되는 문제입니다. 한글 클라이언트에서 반복 보고되고 있으며 재설치로도 해결되지 않는 경우가 많습니다.

가능한 원인

  • 일부 아케이드 맵이 한국어 클라이언트에서 튕기는 알려진 호환성 문제를 갖고 있는 경우
  • 표시 언어가 한국어일 때만 발생하고 영어로 바꾸면 재현되지 않는 사례가 다수 보고됨
  • Battle.net 캐시에 남은 손상된 맵 데이터

점검 순서

  1. 1단계 - 표시 언어를 영어로 임시 전환:
    ① Battle.net 앱에서 톱니바퀴(설정) → 게임 설정 → 스타크래프트 II 선택
    ② 게임 언어(텍스트) 또는 Battle.net 표시 언어를 영어(English)로 바꾼 뒤 재접속
    ③ 같은 맵에 다시 입장해 튕김이 재현되는지 확인 — 언어를 바꾸면 재현되지 않는다는 보고가 많습니다
  2. 2단계 - 스캔 및 복구:
    ① Battle.net 런처에서 스타크래프트 II 선택 → 옵션(톱니바퀴) → '스캔 및 복구' 실행
  3. 3단계 - 문제 맵 회피 및 제보:
    ① 특정 맵에서만 반복된다면 해당 맵 이름과 재현 조건을 적어 공식 포럼 버그 제보 게시판에 신고

설치/패치

가능한 원인

  • Battle.net 캐시나 언어팩 데이터가 매번 최신 버전으로 인식되지 않는 클라이언트 쪽 동기화 오류로 추정(공식 원인 미확정)
  • 일부 사용자는 재부팅·재설치 후에도 재현된다고 보고 — 로컬 설정만의 문제가 아닐 가능성

점검 순서

  1. 1단계 - 스캔 및 복구:
    ① Battle.net 런처에서 스타크래프트 II 옵션 → '스캔 및 복구' 실행 후 재시도
  2. 2단계 - 언어 설정 재확인:
    ① Battle.net 게임 설정에서 텍스트 언어를 한국어가 아닌 언어로 바꿨다가 다시 한국어로 저장 후 재시작
  3. 3단계 - 공식 포럼에 재현 조건 제보:
    ① 현재 알려진 완전한 해결책이 없는 이슈이므로, 재다운로드 용량과 발생 시점을 적어 공식 버그 제보 게시판에 등록해두면 대응 현황을 추적하기 쉽습니다

그래픽/성능

다른 프로그램의 소리는 정상인데 스타크래프트 II에서만 소리가 나지 않는 경우로, 대부분 Windows 또는 게임 내 오디오 장치 설정이 원인입니다. 블루투스 헤드폰 사용 중에는 별도로 알려진 충돌도 있습니다.

가능한 원인

  • Windows 소리 설정에서 출력 장치가 실제 사용 중인 장치와 다르게 지정된 경우
  • 게임 내 오디오 설정의 출력 장치·음소거 상태가 Windows 설정과 어긋난 경우
  • 블루투스 헤드폰 연결 중 게임이 모든 소리를 독점해 다른 장치로 출력이 전환되지 않는 경우

점검 순서

  1. 1단계 - 재부팅 후 확인:
    ① 다른 문제 해결 전에 PC를 재시작해 일시적 오디오 드라이버 문제인지 먼저 배제
  2. 2단계 - Windows 소리 설정 확인:
    ① 작업 표시줄 스피커 아이콘에서 출력 장치가 올바른지, 음량이 0이 아닌지 확인
  3. 3단계 - 게임 내 오디오 설정 확인:
    ① 옵션 → 소리에서 출력 장치와 음량, 음소거 여부를 다시 확인
  4. 4단계 - 다른 하드웨어로 교차 확인:
    ① Windows/게임 설정이 모두 정상이면 다른 프로그램에서 같은 헤드폰·스피커로 소리가 나는지 확인해 하드웨어 문제인지 구분
  5. 5단계 - 블루투스 헤드폰이라면:
    ① 게임 실행 중 블루투스 헤드폰을 새로 연결하지 말고, 헤드폰을 먼저 연결·페어링한 뒤 게임을 실행

접속/네트워크

게임을 실행해 서버에 처음 접속하려는 단계에서 연결이 실패하는 오류입니다. 배틀넷 로그인 자체는 되는데 게임 서버 접속만 막힌다면, 방화벽이나 네트워크 설정이 원인일 가능성이 큽니다.

가능한 원인

  • 방화벽·보안 프로그램이 스타크래프트2 게임 서버 통신을 차단하는 경우
  • 공유기의 QoS·트래픽 제한 설정이 게임 서버 접속에 영향을 주는 경우
  • 일시적인 배틀넷 서버 문제나 네트워크 경로 문제

점검 순서

  1. 1단계 - 배틀넷·게임 재시작:
    ① Battle.net 앱과 게임을 모두 종료 후 재시작
    ② 재로그인 후 접속 재시도
  2. 2단계 - 방화벽 예외 확인:
    ① Windows Defender 방화벽에서 Battle.net·StarCraft II 실행 파일이 허용되어 있는지 확인
    ② 타사 백신·방화벽을 사용 중이면 동일하게 예외 등록
  3. 3단계 - 공유기 설정 확인:
    ① 공유기의 QoS·트래픽 제한 기능을 일시적으로 끄고 재시도
    ② 가능하면 유선 연결로 비교
  4. 4단계 - 서버 상태 확인:
    ① 블리자드 공식 서버 상태 페이지에서 점검 여부 확인
    ② 점검이 아닌데도 반복되면 블리자드 기술 지원 포럼에 네트워크 진단 결과와 함께 문의

가능한 원인

  • 그래픽 드라이버가 최신이 아니거나 최근 업데이트와 호환성 문제가 있는 경우
  • 게임 파일 일부가 손상된 경우
  • 녹화·오버레이·방송 프로그램이 게임과 충돌하는 경우
  • 오버클럭 설정이나 발열로 하드웨어가 불안정한 경우

점검 순서

    ② 업데이트 후 재부팅 필수
  2. 2단계 - 게임 파일 검사·복구:
    ① Battle.net → 스타크래프트 II 선택 → 설정 → 검사 및 복구 실행

  4. 4단계 - 하드웨어 안정성 확인:
    ① 오버클럭·XMP 설정을 기본값으로 되돌려 비교
    ② 계속되면 이벤트 뷰어에서 크래시 시점의 오류 기록을 확인해 원인 범위를 좁히기

  • 스캔 및 복구는 어떻게 하나요? Battle.net 런처에서 스타크래프트 II를 선택한 뒤 톱니바퀴(옵션) 아이콘을 누르고 '스캔 및 복구'를 실행하세요. 손상된 게임 파일만 자동으로 다시 받아옵니다.
  • VPN을 쓰면 무조건 접속이 안 되나요? VPN 자체가 원인이 아니라, 일부 VPN이 Battle.net 접속 모듈과 충돌하는 경우가 있습니다. 접속 문제가 있다면 VPN을 끄고 재시도해 원인인지 먼저 구분하세요.
  • 사용자지정 아케이드에 입장할 때만 튕기는데 왜 그런가요? 일부 아케이드 맵이 한국어 클라이언트에서 튕기는 문제가 공식 포럼에 보고돼 있습니다. Battle.net 게임 설정에서 언어를 영어로 바꾼 뒤 같은 맵에 입장하면 재현되지 않는다는 사례가 많으니 원인 구분에 활용해보세요.
