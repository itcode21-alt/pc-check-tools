홈/가이드/여러 프로그램 실행 안 됨

📑 목차

시스템

실행 파일·작업 관리자 등 여러 프로그램 실행 안 됨 원인과 점검 순서

exe 파일, 작업 관리자, 기본 앱 등 여러 프로그램이 동시에 실행되지 않는 경우

특정 프로그램 하나만 안 열리는 것이 아니라 exe 실행 파일, 사진 뷰어, 작업 관리자 같은 기본 앱까지 함께 안 열린다면, 개별 프로그램의 문제가 아니라 Windows의 파일 연결이나 셸 자체가 손상됐을 가능성이 큽니다.

가장 흔한 원인은 exe 파일의 확장자 연결이 깨진 경우입니다. 원래 exe 파일을 더블클릭하면 그 프로그램이 바로 실행되어야 하는데, 이 연결 정보가 손상되면 아무 반응이 없거나 엉뚱한 프로그램이 열립니다.

파일 연결 문제가 아니라면 시스템 파일 손상이나 악성코드가 원인일 수 있어, SFC와 DISM 명령으로 시스템을 복구하고 백신 검사를 진행하는 것이 다음 순서입니다.

이 가이드가 필요한 상황

  • exe 파일, 이미지 뷰어, 작업 관리자 등 여러 프로그램이 동시에 반응이 없다.
  • 같은 파일을 여러 번 클릭해야 겨우 한 번 열린다.
  • 최근 출처가 불분명한 파일을 실행한 이후 증상이 시작됐다.

먼저 확인할 항목

  1. 시스템 파일 검사(SFC) — 관리자 권한 명령 프롬프트에서 sfc /scannow를 실행하고 완료될 때까지 기다리세요.
  2. Windows 구성 요소 복구(DISM) — dism /online /cleanup-image /restorehealth를 실행한 뒤 SFC를 다시 실행해보세요.
  3. 백신 전체 검사 — Windows 보안 또는 신뢰할 수 있는 백신으로 전체 검사를 진행하세요.
  4. 계정 권한·그룹 정책 확인 — 관리자 계정으로 로그인해보거나, 전산 담당자에게 실행 제한 여부를 문의하세요.

원인을 더 정확히 나누는 방법

exe 파일 연결이 깨졌는지 확인하는 방법

정상적인 exe 파일 아이콘이 흰 종이 모양으로 바뀌어 보이거나, 더블클릭 시 '연결 프로그램 선택' 창이 뜬다면 파일 연결 자체가 깨진 것입니다.

한 번에 여러 증상이 겹칠 때

exe뿐 아니라 이미지 뷰어, 캡처 도구, 작업 관리자까지 함께 안 열린다면 Windows 셸 자체나 사용자 프로필 손상 범위가 더 넓을 가능성이 있습니다.

확인 결과에 따른 다음 단계

  • SFC/DISM으로 해결될 때 — 시스템 파일 손상이 원인이었으므로 복구 후에도 문제가 재발하는지 지켜보세요.
  • 백신 검사에서 악성코드가 발견될 때 — 격리·삭제한 뒤 exe 파일 연결이 정상으로 돌아왔는지 확인하세요.
  • 새 계정에서는 정상일 때 — 기존 사용자 프로필 손상이 원인이므로 새 계정으로 이전하거나 프로필 복구를 진행하세요.

피해야 할 실수

  • 원인 파악 없이 레지스트리를 직접 수정해 파일 연결을 고치려는 것
  • 백신 검사 없이 SFC/DISM만 반복 실행하는 것

자주 묻는 질문

  • sfc /scannow는 어떻게 실행하나요? 명령 프롬프트를 관리자 권한으로 실행한 뒤 sfc /scannow를 입력하세요.
  • 여러 번 클릭해야 겨우 열리는 것도 같은 문제인가요? 네, 파일 연결이나 셸이 불안정할 때 흔히 나타납니다.
  • 초기화까지 해야 하나요? SFC/DISM과 백신 검사로도 안 될 때 마지막 수단으로 고려하세요.
