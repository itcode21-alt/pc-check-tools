📑 목차

에러 코드 상세

0x00000164 · WIN32K_CRITICAL_FAILURE

화면 표시와 입력을 담당하는 Win32k 서브시스템이 치명적인 오류를 만났을 때 나타나는 코드로, 그래픽 드라이버 결함이 흔한 원인입니다.

이 코드를 어떻게 해석해야 하나요?

부품 고장을 코드 하나로 단정 짓기보다는, 발생 시점과 최근 변경 사항, 반복 조건, 안전 모드 재현 여부를 함께 기록해 원인 범위를 좁혀가는 것이 정확합니다.

먼저 기록할 내용: 0x00000164가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

이 코드가 가리키는 것

Win32k는 창, 메뉴, 입력 같은 사용자 인터페이스를 담당하는 커널 구성 요소입니다. 화면 표시와 입력에 두루 관여하므로 그래픽 드라이버와 인터페이스에 개입하는 프로그램이 주된 확인 대상입니다.

첫 점검 항목

  1. 그래픽 드라이버 재설치 — DDU로 기존 드라이버를 완전히 제거한 뒤 제조사 최신 버전을 설치합니다. 최신 버전에서도 재현되면 이전 안정 버전으로 내려 확인해 봅니다.
  2. 화면에 개입하는 프로그램 정리 — 화면 녹화·오버레이 도구, 창 관리 유틸리티, 사용자 지정 커서·테마 프로그램을 하나씩 종료하거나 제거하며 재현 여부를 봅니다. 게임 오버레이 기능도 함께 꺼 보세요.
  3. 시스템 파일 검사 — 관리자 명령 프롬프트에서 sfc /scannow를 실행하고, 복구되지 않으면 DISM /Online /Cleanup-Image /RestoreHealth를 이어서 실행합니다.
  4. 최근 Windows 업데이트와 시점 대조 — 특정 업데이트 이후 시작됐다면 설정 → 업데이트 기록에서 해당 업데이트를 제거해 재현 여부를 확인합니다. 제거 후 안정적이면 다음 누적 업데이트가 나올 때까지 기다리는 편이 낫습니다.

확인 결과에 따른 다음 단계

  • 그래픽 드라이버 재설치로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • 오버레이·화면 녹화 도구 제거로 해결될 때 — 그 프로그램의 수정된 버전이 나올 때까지 사용을 자제하세요.
  • 업데이트 제거로 해결될 때 — 다음 누적 업데이트가 나올 때까지 해당 업데이트 설치를 보류하세요.

데이터와 시스템을 보호하는 주의사항

초기화, 레지스트리 수정, 시스템 파일 수동 교체는 원인이 확실해진 뒤에 시도하는 것이 안전합니다.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

되돌리기 어려운 조치(복구, 초기화, 드라이버 제거 등)에 들어가기 전에는 반드시 중요 데이터를 다른 저장장치로 옮겨 두는 것이 안전합니다.

자주 묻는 질문

  • 블루스크린 코드가 한 번 떴는데 계속 지켜봐야 하나요? 이 문제(0x00000164)가 한 번만 발생했다면 즉시 부품을 교체하기보다 재현 여부와 최근 변경 사항을 먼저 기록해두는 것으로 충분합니다. 반복된다면 그때 하드웨어 점검 범위를 넓히세요.
  • 덤프 파일은 어디서 확인하나요? C:\Windows\Minidump 폴더에 저장되며, BlueScreenView 같은 도구로 열어 정지 코드와 관련 드라이버를 확인할 수 있습니다.
  • 이 오류가 특정 게임에서만 나면요? 특정 게임에서만 반복된다면 그 게임의 오버레이 기능(디스코드, 지포스 익스피리언스 등)과의 충돌을 의심하고 하나씩 꺼서 테스트해보세요.
