WINDOWS NETWORK BASICS

IP를 받아도 인터넷이 안 되면, 연결 단계부터 나눠 확인하세요

케이블 연결, 공유기 통신, DNS 이름 해석은 서로 다른 단계입니다. Windows 기본 기능으로 원인을 먼저 구분하고, 필요하면 공유기 관리자 페이지까지 순서대로 확인하세요.

1. 가장 먼저 확인할 것

  1. 다른 기기에서도 같은 인터넷이 되는지 확인합니다. 다른 기기도 안 되면 PC보다 공유기·회선 문제일 가능성이 큽니다.
  2. 유선은 LAN 포트의 링크 LED와 케이블을 확인하고, 가능하면 다른 포트·케이블로 바꿉니다.
  3. Windows 설정 → 네트워크 및 인터넷에서 비행기 모드, VPN, 프록시가 켜져 있지 않은지 확인합니다.

2. IP·DNS 확인하기

  1. 시작 메뉴에서 명령 프롬프트를 열고 ipconfig를 입력합니다.
  2. 사용 중인 이더넷 또는 Wi-Fi에 IPv4 주소와 기본 게이트웨이가 있는지 확인합니다.
  3. ping 8.8.8.8은 되지만 웹사이트가 안 열리면 DNS 문제일 수 있습니다. ipconfig /flushdns를 실행한 뒤 다시 확인합니다.

3. 공유기 확인과 설정

여기까지 확인해도 해결되지 않았거나, 다른 기기에서도 인터넷이 안 된다면 공유기 쪽을 봐야 합니다. PC 설정을 더 손대기 전에 이 단계를 먼저 지나가세요.

관리자 페이지 접속

주소를 추측하지 말고 ipconfig에서 확인한 기본 게이트웨이 값을 브라우저 주소창에 그대로 입력하는 것이 가장 확실합니다. 그 주소가 곧 공유기입니다.

  • ipTIME — 보통 192.168.0.1
  • ASUS — 192.168.1.1 또는 router.asus.com
  • TP-Link — 192.168.0.1 또는 tplinkwifi.net
  • 넷기어 — 192.168.1.1 또는 routerlogin.net

관리자 암호가 초기값(admin 등) 그대로라면 이번에 변경하세요. 외부에서 설정을 바꿀 수 있는 상태로 오래 두면 위험합니다.

재부팅은 순서가 있습니다

공유기만 껐다 켜는 경우가 많은데, 모뎀을 함께 쓰는 환경이라면 순서를 지켜야 합니다. 공유기는 모뎀에서 주소를 받아야 하므로 모뎀이 먼저 준비돼 있어야 합니다.

  1. 모뎀과 공유기의 전원을 모두 뽑습니다.
  2. 모뎀만 먼저 꽂고 표시등이 안정될 때까지 1~2분 기다립니다.
  3. 그다음 공유기를 꽂고 다시 1~2분 기다린 뒤 연결을 확인합니다.

이중 공유기(이중 NAT) 확인

관리자 페이지의 상태 화면에서 외부(WAN) IP를 봅니다. 이 값이 192.168.x.x나 10.x.x.x처럼 사설 주소라면 위에 공유기가 하나 더 있는 이중 구성입니다.

인터넷 자체는 되지만 게임 접속, 원격 연결, 포트 포워딩이 안 되는 원인이 대부분 이것입니다. 아래쪽 공유기를 브리지 모드(또는 AP 모드)로 바꾸면 해결됩니다.

Wi-Fi가 자주 끊기거나 느릴 때

  • 대역 구분 — 5GHz는 빠르지만 벽을 잘 통과하지 못합니다. 공유기와 방이 떨어져 있으면 2.4GHz가 더 안정적입니다.
  • 채널 — 주변 공유기와 겹치면 간섭이 생깁니다. 자동으로 두고, 계속 불안정하면 2.4GHz에서 1·6·11번 중 하나로 고정해 봅니다.
  • 대역 통합(밴드 스티어링) — 2.4GHz와 5GHz를 같은 이름으로 쓰면 기기가 약한 쪽에 붙어 있을 수 있습니다. 두 이름을 나눠 직접 골라 연결하면 원인 구분이 쉬워집니다.

IP를 아예 받지 못할 때

ipconfig에서 IPv4 주소가 169.254.x.x로 나오면 공유기에서 주소를 받지 못한 상태입니다. 관리자 페이지에서 DHCP 서버가 켜져 있는지, 그리고 MAC 주소 필터나 접속 제한 목록에 이 PC가 걸려 있지 않은지 확인하세요.

공유기 초기화(리셋) 전에

본체의 리셋 핀을 누르면 Wi-Fi 이름·암호는 물론 인터넷 접속 설정까지 지워집니다. 통신사 회선 정보(PPPoE 아이디·암호 등)를 다시 입력해야 연결되는 경우가 있으니, 그 값을 확인할 수 있을 때만 진행하세요. 설정을 바꾸기 전에 현재 화면을 사진으로 남겨 두면 되돌리기 쉽습니다.

4. 어댑터·드라이버 점검

장치 관리자 → 네트워크 어댑터에서 노란 느낌표가 있는지 확인합니다. 최근 업데이트 뒤부터 문제라면 드라이버를 롤백하고, 없다면 PC·메인보드 제조사의 공식 LAN/Wi-Fi 드라이버를 설치합니다. 자동 드라이버 설치 프로그램은 사용하지 마세요.

5. 마지막 수단: 네트워크 초기화

Windows 11은 설정 → 네트워크 및 인터넷 → 고급 네트워크 설정 → 네트워크 초기화에서 실행합니다. 저장된 Wi-Fi, VPN, 가상 어댑터가 제거될 수 있으므로 필요한 접속 정보는 미리 확인하세요. 초기화 뒤 재부팅이 필요합니다.

회사·학교 PC

고정 IP, 프록시, VPN을 사용하는 환경에서는 초기화 전에 관리자에게 설정값을 확인하세요. 임의 초기화로 업무망 접속 정보가 사라질 수 있습니다.
