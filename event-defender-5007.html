EVENT ID 5007

Windows Defender 이벤트 5007 보안 설정 변경 점검

Microsoft Defender Antivirus 설정이 변경되었음을 기록합니다. Defender 업데이트나 정상적인 보호 기능 전환에서도 발생하지만, 예상하지 못한 실시간 보호·예외 설정 변경이면 보안 점검이 필요합니다.

5007은 Microsoft Defender Antivirus 설정이 바뀌었다는 기록입니다. 이벤트에 이전 값(Old value)과 새 값(New value)이 함께 남아 어떤 설정이 바뀌었는지 알 수 있습니다.

Defender 업데이트나 정상적인 보호 기능 전환에서도 남습니다. 예상하지 못한 실시간 보호나 예외 항목 변경이면 Windows 보안의 설정과 비교하고 검사해 보세요. 5007이 있다는 사실만으로 악성코드를 뜻하지는 않습니다.

발생 조건

  • Defender 업데이트 직후
  • 실시간 보호·제어된 폴더 액세스 설정 변경 뒤
  • 보안 프로그램 설치·제거 직후

가능성 높은 원인

  • Defender 플랫폼·보안 인텔리전스 업데이트
  • 관리자 또는 조직 정책의 설정 변경
  • 타사 백신 설치로 인한 보호 기능 전환
  • 원치 않는 프로그램이 보안 설정을 변경한 경우

점검 순서

  1. Old value와 New value에서 실제 변경된 설정 확인 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. Windows 보안의 바이러스 및 위협 방지 설정과 일치하는지 비교 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 예상하지 못한 변경이면 전체 검사와 오프라인 검사를 고려 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 같은 시각 5001·5004·1002 및 최근 설치·정책 변경을 함께 확인 — 변경 전후로 증상이 달라지는지 비교해보세요.
주의사항

5007 단독 발생만으로 악성코드를 의미하지 않습니다. 변경 내용과 사용자의 작업·업데이트 시각이 일치하는지 확인하세요.

보호 기능을 끄거나 Defender 이벤트를 지우는 방식으로 해결하지 마세요.

자주 묻는 질문

  • 5007이 하루에도 여러 번 뜨는데요? Defender가 업데이트되거나 상태를 전환할 때 남을 수 있습니다. Old value와 New value가 실제로 의미 있는 설정 변경인지 확인하세요.
  • 보호 기능이 꺼져 있었다면 어떻게 하나요? 다른 백신을 설치했거나 정책으로 바뀐 경우가 있으니 설치 내역과 조직 정책을 먼저 확인하세요. 모르는 변경이면 전체 검사를 하세요.
