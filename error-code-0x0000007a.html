에러 코드 상세

0x0000007A · KERNEL_DATA_INPAGE_ERROR

페이징 파일에서 커널 데이터 페이지를 읽지 못했을 때 나오는 코드입니다. 문서는 디스크의 배드 블록, 느슨한 케이블, 비페이징 풀 부족, 불량 저장장치나 램 오류, 바이러스를 원인으로 듭니다.

이 코드를 어떻게 해석해야 하나요?

두 번째 매개변수(오류 상태, 보통 I/O 상태 코드)로 원인을 가리는 것이 핵심입니다. Microsoft Learn의 대표 상태 코드는 0xC000009A(비페이징 풀 리소스 부족), 0xC000009C·0xC000016A(디스크 배드 블록), 0xC000009D(케이블 불량·헐거움이거나 컨트롤러가 디스크를 인식하지 못함), 0xC0000185(SCSI 종단·케이블 문제나 같은 IRQ 사용), 0xC000000E(하드웨어 고장이나 드라이브 구성 오류)입니다. 문서는 저장장치 하드웨어 불량이나 램 오류도 흔한 원인이고 바이러스 감염도 원인이 될 수 있다고 하며, 배드 블록은 Autochk와 Chkdsk /f /r로, 램은 제조사 진단의 메모리 검사로 점검하라고 안내합니다.

가능성 높은 원인

  • 디스크의 배드 블록(0xC000009C, 0xC000016A)
  • 케이블 불량·헐거움이나 컨트롤러가 디스크를 인식하지 못하는 경우(0xC000009D)
  • 하드웨어 고장이나 드라이브 구성 오류(0xC000000E)
  • 비페이징 풀 리소스 부족(0xC000009A)
  • 저장장치 하드웨어 불량 또는 램 오류
  • 바이러스 감염

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 시스템을 재시작할 수 있다면 Autochk가 배드 섹터를 표시해 두고, 실행되지 않으면 시스템 파티션에서 Chkdsk /f /r을 실행하세요. 시스템을 시작할 수 없다면 복구 환경에서 Chkdsk /r을 실행하세요.
  2. 공식 문서가 알려 주는 것: 시스템 제조사가 제공하는 하드웨어 진단 도구를 실행하세요. 특히 메모리 검사를 보라고 안내합니다.
  3. 공식 문서가 알려 주는 것: 케이블 연결을 확인하고, 드라이브 제조사의 진단 유틸리티로 드라이브를 점검하세요. 오래된 PATA(IDE) 드라이브라면 마스터/슬레이브 설정도 확인하세요.
  4. 공식 문서가 알려 주는 것: 바이러스 감염도 원인이 될 수 있으니 검사하세요.
  5. 문서 외 일반 점검: 제조사 도구나 CrystalDiskInfo로 S.M.A.R.T 상태를 확인하고, 저장장치 펌웨어와 컨트롤러 드라이버가 최신인지 확인하세요.

확인 결과에 따른 다음 단계

  • 배드 블록(0xC000009C, 0xC000016A)이 의심될 때 — 중요한 파일을 먼저 백업한 뒤 Chkdsk /f /r을 실행하세요. 배드 섹터가 계속 늘면 저장장치 교체를 검토하세요.
  • 케이블이나 연결 문제(0xC000009D)가 의심될 때 — 케이블을 다시 꽂거나 교체하고, 다른 포트에 연결해 같은 증상이 나는지 확인하세요.
  • 저장장치 펌웨어 업데이트로 해결될 때 — 제조사 안내에 따라 업데이트하세요. 이 사이트에는 SSD 펌웨어 업데이트로 해결된 사례가 있지만 문서가 안내하는 방법은 아닙니다.

데이터와 시스템을 보호하는 주의사항

SMART 경고, 읽기 실패, Disk 7·129·153 반복이 있으면 복구 명령보다 중요한 파일 백업을 먼저 진행하세요.

앞 단계로 해결되지 않을 때

백업 후 케이블·포트·M.2 슬롯을 교차하고 제조사 진단과 펌웨어를 확인한 뒤 파일 시스템 검사를 계획하세요.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

공식 참고자료

Microsoft Learn: Bug Check 0x7A KERNEL_DATA_INPAGE_ERROR

자주 묻는 질문

  • 두 번째 값이 0xC000009C라면 무엇인가요? STATUS_DEVICE_DATA_ERROR로, 문서는 하드 디스크의 배드 블록(섹터)을 뜻한다고 설명합니다. 0xC000016A도 같은 의미입니다.
  • SSD에서도 같은 점검을 하나요? 문서의 설명은 하드 디스크와 배드 블록 기준입니다. SSD에는 제조사 진단과 케이블·슬롯 점검 같은 일반 점검을 적용할 수 있습니다(이 부분은 문서 외 일반 안내입니다).
