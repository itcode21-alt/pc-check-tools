📑 목차

에러 코드 상세

0x80073CF9 · Microsoft Store 앱을 설치·업데이트할 수 없습니다

Microsoft Store 앱 설치·업데이트 도중 스토어 캐시나 라이선스 구성 요소 문제로 나타납니다.

이 코드를 어떻게 해석해야 하나요?

Microsoft Store에서 앱을 설치하거나 업데이트할 때 스토어 캐시나 라이선스 구성 요소 문제로 나타나는 오류입니다. Xbox 앱, Store 자체 업데이트 등에서도 같은 코드가 나타날 수 있습니다.

먼저 기록할 내용: 0x80073CF9가 발생한 앱 이름, 설치인지 업데이트인지, 시스템 날짜·시간이 정확한지를 적어 두세요.

가능성 높은 원인

  • Microsoft Store 앱 캐시가 손상된 경우
  • Store 관련 백그라운드 서비스(라이선스 관리자 등)가 응답하지 않는 경우
  • Windows Update와 Store 업데이트가 서로 충돌하는 경우
  • 시스템 날짜·시간이 실제와 맞지 않아 인증서 검증에 실패하는 경우
  • 네트워크 연결이 불안정해 스토어 서버 응답을 받지 못하는 경우

첫 점검 항목

  1. 설정 > 앱에서 Microsoft Store를 선택해 '재설정'을 실행하세요(초기화 아님, 데이터만 삭제).
  2. 명령 프롬프트에서 wsreset.exe를 실행해 스토어 캐시를 지운 뒤 다시 시도하세요.
  3. 시스템 날짜·시간이 자동으로 맞춰져 있는지 확인하세요.
  4. Windows Update를 최신 상태로 진행한 뒤 다시 시도하세요.
  5. 그래도 안 되면 Microsoft Store 앱 자체를 PowerShell로 다시 등록해보세요.

실제 사용자 사례

위 점검 순서로도 해결되지 않았을 때, 다른 원인으로 해결된 사례입니다.

wsreset으로 스토어 오류 해결

Xbox 앱과 Microsoft Store에서 이 오류가 반복됐던 사례가 있습니다. wsreset.exe로 스토어 캐시를 초기화하자 이후 정상적으로 설치·업데이트가 진행됐습니다.

포인트: 스토어 오류는 재설치보다 캐시 초기화(wsreset)로 해결되는 경우가 많아 먼저 시도해볼 가치가 있습니다.

데이터와 시스템을 보호하는 주의사항

스토어 재설정은 앱 자체 데이터가 아니라 스토어 캐시만 지우므로, 설치된 앱이나 파일에는 영향이 없습니다.

앞 단계로 해결되지 않을 때

계속 실패하면 Microsoft 계정 로그아웃 후 재로그인, 또는 새 사용자 계정에서 재현되는지 확인하세요.

관련 증상 가이드 확인하기

같은 증상과 연결된 다른 오류 코드

  • 0x80240FFF · Windows Update 알 수 없는 오류
  • 0xC004C003 · Windows 정품 인증을 받지 않았습니다

공식 참고자료

Microsoft 지원: Microsoft Store 오류 문제 해결

자주 묻는 질문

  • Xbox 앱에서도 같은 코드가 뜨는데 원인이 같은가요? 네, Xbox 앱도 Microsoft Store와 같은 라이선스·캐시 구성 요소를 공유하기 때문에 같은 코드가 나타날 수 있고, 같은 방법(wsreset)으로 해결되는 경우가 많습니다.
  • 스토어를 재설치하면 해결되나요? 재설치보다 재설정(초기화)이나 wsreset.exe로 캐시를 지우는 방법이 먼저 시도해볼 조치입니다. 대부분 재설치 없이 해결됩니다.
