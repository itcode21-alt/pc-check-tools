에러 코드 상세

0x80070002 · 파일을 찾을 수 없음

Windows 시스템 오류 2(ERROR_FILE_NOT_FOUND), 즉 '지정한 파일을 찾을 수 없다'는 코드입니다. Microsoft 지원 문서는 업데이트에서 설치 실패로 안내합니다.

0x80070002는 ERROR_FILE_NOT_FOUND에 해당하는 코드입니다. Windows Update에서는 Microsoft 지원 문서가 '업데이트 설치 실패'로 묶어 PC 재시작, 문제 해결사, 디스크 여유 공간 확인을 안내합니다.

이 코드를 어떻게 해석해야 하나요?

Windows 시스템 오류 코드에서 0x80070002는 지정한 파일을 찾을 수 없다는 뜻입니다. Microsoft의 업데이트 문제 해결 문서는 이 코드를 업데이트 설치 실패로 묶어, PC 다시 시작, Windows Update 문제 해결사 실행, 디스크 여유 공간 확인(32비트 16GB, 64비트 20GB, 작은 디스크는 USB 드라이브 활용)을 안내합니다. 업데이트 캐시 초기화와 날짜·시간 점검은 문서 외 일반 점검입니다.

가능성 높은 원인

  • 윈도우 업데이트 캐시(SoftwareDistribution 폴더)가 손상된 경우
  • 시스템 날짜/시간이 잘못 설정되어 업데이트 서버 인증에 실패하는 경우
  • 이전에 중단된 업데이트나 설치 작업의 잔여 파일이 충돌하는 경우
  • 그룹 정책이나 레지스트리 설정이 업데이트 경로를 잘못 가리키는 경우
  • 디스크 여유 공간 부족으로 임시 파일을 만들지 못하는 경우

첫 점검 항목

  1. 공식 문서가 알려 주는 것: PC를 다시 시작하고 업데이트를 다시 시도하세요.
  2. 공식 문서가 알려 주는 것: 설정 > 시스템 > 문제 해결 > 기타 문제 해결사에서 Windows Update 문제 해결사를 실행하세요.
  3. 공식 문서가 알려 주는 것: 디스크 여유 공간이 32비트 운영 체제는 16GB, 64비트는 20GB 이상인지 확인하세요. 공간이 작은 장치는 USB 드라이브를 활용할 수 있다고 안내합니다. 부족하면 공간 부족이 원인 후보입니다.
  4. 문서 외 일반 점검: services.msc에서 Windows Update 서비스를 중지하고 SoftwareDistribution 폴더 이름을 바꾼 뒤 서비스를 다시 시작해 캐시를 초기화하세요. 성공하면 캐시가 원인이었습니다.
  5. 문서 외 일반 점검: 날짜·시간·시간대가 정확한지 확인하고, 디스크 정리로 임시 파일과 이전 업데이트 잔여 파일을 정리하세요.

확인 결과에 따른 다음 단계

  • 캐시 초기화로 해결될 때 — 관리자 명령 프롬프트에서 net stop wuauserv와 net stop bits로 서비스를 멈춘 뒤 SoftwareDistribution 폴더 이름을 바꾸세요. 다시 시작한 뒤 업데이트를 재시도하세요.
  • 날짜·시간 수정으로 해결될 때 — 설정 → 시간 및 언어에서 '시간 자동 설정'을 켜고 시간대를 맞춘 뒤 업데이트를 다시 시도하세요.
  • 문제 해결사로도 해결되지 않을 때 — Windows 프로 이상 버전에서 gpedit.msc를 열어 컴퓨터 구성 → 관리 템플릿 → Windows 구성 요소 → Windows 업데이트 설정이 막혀 있는지 확인하세요. 회사·학교 PC라면 관리자에게 확인하세요.

데이터와 시스템을 보호하는 주의사항

레지스트리 정리 도구를 쓰거나 시스템 폴더 권한을 바꾸기 전에, 저장 공간과 네트워크, 서비스 상태부터 점검하는 것이 우선입니다.

앞 단계로 해결되지 않을 때

코드가 재발할 경우 Windows Update 기록과 DISM·SFC 결과를 기록해 두고, 설치 미디어의 Windows 버전이 현재 시스템과 일치하는지 확인해보세요.

되돌리기 어려운 조치(복구, 초기화, 드라이버 제거 등)에 들어가기 전에는 반드시 중요 데이터를 다른 저장장치로 옮겨 두는 것이 안전합니다.

공식 참고자료

Microsoft 지원: Windows 업데이트 문제 해결 (0x80070002)

자주 묻는 질문

  • 0x80070002는 업데이트 오류만 뜻하나요? 아닙니다. Windows 시스템 오류 2는 파일을 찾을 수 없다는 일반 코드라 설치, 복구, 앱 실행 등 다양한 곳에서 나올 수 있습니다. 업데이트에서는 Microsoft 지원 문서가 설치 실패로 안내합니다.
  • 찾지 못했다는 파일을 직접 복사해 넣으면 되나요? 권하지 않습니다. 시스템 파일을 임의로 복사하면 버전 불일치가 생길 수 있습니다. 문제 해결사, 디스크 공간 확인, 업데이트 캐시 초기화, 구성 요소 복구 순서로 진행하세요.
