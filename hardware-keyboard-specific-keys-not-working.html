키보드 특정 키 안 눌림 원인과 점검 순서

키보드 전체는 정상인데 특정 키 몇 개만 눌리지 않는 경우

키보드 전체가 먹통이 아니라 특정 키 한두 개만 안 눌린다면, 원인은 크게 두 갈래로 나뉩니다. 하나는 Windows의 필터 키 같은 접근성 설정, 다른 하나는 여러 키를 동시에 누를 때 일부가 무시되는 '고스팅' 현상입니다.

혼자 눌렀을 때도 특정 키만 반응이 없다면 소프트웨어 설정보다 물리적인 문제(이물질, 스위치 마모)일 가능성이 큽니다. 반대로 여러 키를 동시에 누를 때만 문제가 생긴다면 고스팅 현상으로, 게임에서 특정 키 조합이 눌리지 않는 형태로 흔히 나타납니다.

간헐적으로 눌렸다 안 눌렸다 한다면 키 내부 접점의 접촉 불량으로, 청소로 일시적으로 나아질 수 있지만 근본적으로는 키캡·스위치 교체나 키보드 자체 교체가 필요할 수 있습니다.

이 가이드가 필요한 상황

  • 특정 키 한두 개만 혼자 눌러도 입력이 안 된다.
  • 여러 키를 동시에 누르면 그중 일부가 인식되지 않는다.
  • 필터 키·고정 키 같은 접근성 기능을 건드린 적이 없는데도 갑자기 시작됐다.

먼저 확인할 항목

  1. 필터 키·고정 키 설정 확인 — 설정 > 접근성 > 키보드에서 필터 키와 고정 키를 모두 꺼보세요.
  2. 단독 입력과 동시 입력 구분 — 메모장에서 문제 키를 혼자 눌러보고, 그다음 다른 키와 함께 눌러 차이를 확인하세요.
  3. 물리적 청소 — 키보드를 뒤집어 압축공기로 이물질을 제거하세요. 노트북은 무리해서 키캡을 분리하지 마세요.
  4. 다른 프로그램·다른 컴퓨터에서 재현 확인 — 온라인 키보드 테스터 사이트나 다른 컴퓨터에 연결해 같은 키가 안 눌리는지 비교하세요.

원인을 더 정확히 나누는 방법

고스팅(Ghosting)이란?

저가형 키보드는 회로 구조상 특정 키 조합을 동시에 누르면 일부 입력이 인식되지 않는 경우가 있습니다. 이를 고스팅이라 하며, 게임처럼 여러 키를 동시에 눌러야 하는 상황에서 자주 발견됩니다. N키 롤오버(NKRO)를 지원하는 키보드는 이 문제가 없습니다.

간헐적으로 눌렸다 안 눌렸다 하는 경우

완전히 죽은 키가 아니라 눌릴 때도 있고 안 눌릴 때도 있다면, 스위치나 러버돔의 접점이 마모되어 접촉이 불안정해진 상태일 가능성이 높습니다. 청소로 일시 개선될 수 있지만 재발한다면 물리적 교체가 필요합니다.

확인 결과에 따른 다음 단계

  • 동시 입력에서만 문제가 생길 때 — 고스팅 현상일 가능성이 높으므로, 게임 내 키 배치를 서로 간섭하지 않는 조합으로 바꾸거나 NKRO를 지원하는 키보드로 교체를 고려하세요.
  • 혼자 눌러도 특정 키만 안 될 때 — 청소로도 해결되지 않으면 스위치·러버돔 자체의 물리적 고장이므로 키보드 수리나 교체가 필요합니다.

피해야 할 실수

  • 혼자 눌러도 안 되는 물리적 문제인데 접근성 설정만 계속 확인하는 것
  • 청소 없이 바로 키보드를 새로 사는 것

자주 묻는 질문

  • 노트북 키보드도 고스팅이 있나요? 네, 저가형 노트북 키보드에서도 발생할 수 있습니다. 다만 노트북은 키보드 전체 교체가 데스크탑 키보드보다 번거로우므로, 문제 조합을 피하는 것이 우선입니다.
  • 특정 키만 교체할 수 있나요? 기계식 키보드는 스위치 단위로 교체가 가능한 경우가 많지만, 멤브레인·노트북 키보드는 부분 교체가 어려워 전체 교체나 전문 수리가 필요할 수 있습니다.
  • USB 포트를 바꾸면 나아지나요? 일부 구형 키보드는 USB 2.0에서 더 안정적으로 동작하는 경우가 있어 시도해볼 만하지만, 근본적인 고스팅·접점 마모 문제는 포트를 바꿔도 해결되지 않습니다.
