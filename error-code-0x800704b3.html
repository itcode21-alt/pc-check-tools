📑 목차

에러 코드 상세

0x800704B3 · 네트워크 경로를 찾을 수 없음(ERROR_NO_NET_OR_BAD_PATH)

Microsoft 문서에서 0x4B3(ERROR_NO_NET_OR_BAD_PATH, 1203)은 "네트워크 경로를 잘못 입력했거나, 경로가 없거나, 네트워크 공급자를 지금 사용할 수 없음"을 뜻합니다. 문서는 경로를 다시 입력하거나 네트워크 관리자에게 문의하라고 안내합니다.

이 코드를 어떻게 해석해야 하나요?

이 코드는 "그 경로로는 닿을 수 없다"는 뜻이므로, 가장 먼저 확인할 것은 입력한 경로 자체입니다. 프린터 공유나 네트워크 드라이브 연결에서 자주 마주치지만 공식 정의는 RPC나 프린터 서비스에 대한 것이 아니라 네트워크 경로와 공급자에 대한 것입니다. 이름으로는 안 되고 IP로는 되는지 비교하면 이름 확인 문제인지 연결 문제인지 나눌 수 있습니다.

가능성 높은 원인

  • 공식 정의: 네트워크 경로(\\컴퓨터\공유 이름)를 잘못 입력했거나 그 경로가 없습니다.
  • 공식 정의: 네트워크 공급자를 지금 사용할 수 없는 상태입니다.
  • 상대 컴퓨터가 꺼져 있거나 공유가 해제됐거나, 이름 확인이 되지 않는 경우(문서 외 일반 설명)
  • 네트워크 프로필이나 방화벽 때문에 상대에게 닿지 못하는 경우(문서 외 일반 설명)

첫 점검 항목

  1. 공식 안내: 경로를 다시 입력해 보세요. \\컴퓨터이름\공유이름 형식에서 철자와 역슬래시(\) 방향을 확인하세요.
  2. 공식 안내: 회사·학교 네트워크라면 네트워크 관리자에게 경로가 바뀌었거나 접근이 제한됐는지 문의하세요.
  3. 문서 외 일반 점검: 컴퓨터 이름 대신 IP 주소(예: \\192.168.0.10\공유이름)로 접속해 보세요. IP로는 되는데 이름으로는 안 된다면 이름 확인(DNS·NetBIOS) 쪽 문제입니다.
  4. 문서 외 일반 점검: 명령 프롬프트에서 ping 상대IP를 실행해 상대 컴퓨터가 응답하는지 확인하세요. 응답이 없으면 전원·공유 설정·네트워크 연결을 먼저 봅니다.
  5. 문서 외 일반 점검: 상대 컴퓨터에서 해당 폴더나 프린터의 공유가 켜져 있는지, 두 PC의 네트워크 프로필이 "개인"(또는 도메인)인지 확인하세요.

확인 결과에 따른 다음 단계

  • 경로를 고쳐 입력했더니 해결될 때 — 철자나 역슬래시가 원인이었습니다. 자주 쓰는 경로는 바로가기로 저장해 두세요.
  • IP로는 되고 이름으로는 안 될 때 — 이름 확인 문제입니다. IP로 연결하거나 상대 컴퓨터 이름을 확인하세요.
  • IP로도 닿지 않을 때 — 상대 컴퓨터의 전원과 공유 설정, 네트워크 연결, 방화벽을 점검하세요. 회사 네트워크라면 관리자에게 문의하세요.

앞 단계로 해결되지 않을 때

경로·이름·연결을 모두 확인했는데도 같으면 입력한 경로, 상대 컴퓨터 종류(윈도우·NAS 등), ping 결과를 적어 문의하세요.

공식 참고자료

Microsoft Learn: System Error Codes (1000-1299) — ERROR_NO_NET_OR_BAD_PATH

자주 묻는 질문

  • RPC(원격 프로시저 호출) 오류인가요? Microsoft의 정의는 RPC가 아니라 "네트워크 경로나 네트워크 공급자" 오류입니다. RPC 서비스를 건드리기 전에 경로와 상대 컴퓨터의 상태부터 확인하세요.
  • 프린터 공유에서 이 코드가 나오면 어떻게 하나요? 프린터의 공유 경로(\\컴퓨터이름\프린터이름)가 맞는지, 그 컴퓨터가 켜져 있고 프린터 공유가 켜져 있는지부터 확인하세요.
  • IP 주소로는 접속되는데 이름으로는 안 되면요? 이름 확인에 문제가 있다는 신호입니다. 이름 대신 IP로 연결하거나, 공유기·DNS의 이름 설정을 점검하세요.
