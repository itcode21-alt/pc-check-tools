📑 목차

    그래픽

    게임 중 그래픽 장치 제거 오류(DXGI_ERROR_DEVICE_REMOVED, 0x887A0005) 원인과 점검 순서

    게임이나 3D 프로그램이 실행 중 DXGI_ERROR_DEVICE_REMOVED 또는 0x887A0005 같은 그래픽 장치 오류를 띄우며 꺼지는 경우

    단계별로 직접 해보기

    이 증상은 질문에 답하며 해볼 것을 한 단계씩 따라 할 수 있습니다. 준비물과 자세한 방법을 보여 주고, 직접 하기 어려우면 문의로 이어집니다. 화면 문제 자가진단 시작하기 →

    게임이나 3D 프로그램이 실행 도중 갑자기 꺼지면서 DXGI_ERROR_DEVICE_REMOVED 또는 0x887A0005 같은 코드를 보여 주는 경우가 있습니다. DXGI는 Windows가 그래픽 장치를 다루는 기반 계층이고, 이 오류는 게임이 쓰던 그래픽 장치(Direct3D 장치)가 더 이상 유효하지 않다는 뜻입니다. 게임마다 '그래픽 장치가 제거되었습니다', 'D3D device removed' 같은 문구로 풀어 보여 줍니다.

    Microsoft 문서에서 DEVICE_REMOVED(0x887A0005)는 비디오 카드가 시스템에서 물리적으로 제거되었거나 비디오 카드의 드라이버 업그레이드가 일어났다는 뜻으로 정의됩니다. 이 경우 프로그램은 장치를 파괴하고 다시 만들어야 합니다. 비슷해 보이는 DEVICE_HUNG(0x887A0006)은 프로그램이 보낸 잘못된 명령 때문에 장치가 실패한 경우이고, DEVICE_RESET(0x887A0007)도 잘못된 명령으로 장치가 실패한 런타임 문제로 문서에 적혀 있습니다. DRIVER_INTERNAL_ERROR(0x887A0020)는 드라이버가 문제를 만나 장치 제거 상태로 들어간 경우입니다.

    실제 PC에서는 그래픽카드를 뽑은 적이 없는데도 이 오류가 자주 보이는데, 그 배경에 TDR(시간 초과 감지 및 복구)이 있는 경우가 많습니다. 이 가이드는 코드의 공식 정의, TDR이 무엇인지, 일반 사용자가 확인할 수 있는 순서를 Microsoft 문서 기준으로 정리하고, 문서에 없는 점검은 따로 표시합니다.

    이 가이드가 필요한 상황

    • 게임이 실행 중 갑자기 종료되며 DXGI_ERROR_DEVICE_REMOVED, 0x887A0005 또는 이와 비슷한 코드가 표시된다.
    • 게임 중 화면이 잠깐 깜빡이거나 검게 변한 뒤 게임이 꺼진다.
    • 이벤트 뷰어에 '디스플레이 드라이버가 응답하지 않다가 복구되었습니다'에 해당하는 기록이 같은 시각에 남아 있다.

    먼저 확인할 항목

    1. 오류 코드와 뜻 구분하기 — 같은 그래픽 오류처럼 보여도 DEVICE_REMOVED, DEVICE_HUNG, DEVICE_RESET은 Microsoft 문서에서 원인이 다르게 정의됩니다. 어느 쪽인지에 따라 드라이버를 의심할지 게임을 의심할지 방향이 달라집니다. ① 오류 창이나 게임 로그에 나온 코드를 적어 두세요(0x887A0005 / 0x887A0006 / 0x887A0007 / 0x887A0020). ② 0x887A0005와 0x887A0020은 장치 제거·드라이버 쪽, 0x887A0006과 0x887A0007은 문서상 프로그램이 보낸 명령 쪽으로 정의됩니다. ③ 게임이 코드를 보여 주지 않으면 이벤트 뷰어 기록으로 시각과 항목을 확인하세요.
    2. 이벤트 뷰어로 TDR 기록 찾기 — Microsoft 문서에 따르면 TDR로 복구되면 사용자에게 '디스플레이 드라이버가 응답하지 않다가 복구되었습니다'라는 알림이 뜨고 이벤트 뷰어에 같은 내용이 기록됩니다. 게임이 꺼진 시각과 맞는 기록이 있으면 TDR이 관여했다고 볼 수 있습니다. ① 시작 메뉴에서 이벤트 뷰어를 여세요. ② Windows 로그 > 시스템에서 게임이 꺼진 시각 전후를 보세요. ③ 소스가 Display인 이벤트 4101이나 그래픽 드라이버 이름(예: nvlddmkm)의 항목이 있는지 확인하세요. 사이트의 Display 이벤트 4101 해설 페이지도 참고하세요.
    3. 그래픽 드라이버를 공식 경로로 다시 설치 — DEVICE_REMOVED는 문서상 드라이버 업그레이드와도 연결되고, DRIVER_INTERNAL_ERROR는 드라이버 내부 문제입니다. 드라이버 파일이 손상되었거나 업데이트가 어긋난 경우를 먼저 배제할 수 있습니다. ① 그래픽카드 제조사(NVIDIA·AMD·Intel)의 공식 사이트에서 현재 GPU에 맞는 최신 드라이버를 받으세요. ② 설치 옵션에 클린 설치(초기화)가 있으면 선택하세요. ③ 설치 후 재부팅하고 같은 게임에서 오류가 반복되는지 보세요. 문서 외 일반 점검: 최신 버전에서 문제가 시작되었다면 이전 안정 버전으로 되돌려 비교해 보는 것도 방법입니다.
    4. 오버레이·오버클럭·모니터링 프로그램 끄고 비교 — 그래픽 작업을 가로채는 프로그램이나 정격을 벗어난 클럭은 GPU 작업 시간을 늘리거나 불안정하게 만들 수 있습니다. 문서에 직접 나오는 항목은 아니어서 문서 외 일반 점검으로 분리해 비교합니다. ① 게임 오버레이, 화면 녹화, 하드웨어 모니터링 프로그램을 종료하세요. ② 그래픽카드와 메모리의 오버클럭을 끄고 기본값으로 돌리세요. ③ 같은 장면에서 오류가 줄어드는지 확인하세요. 줄어든다면 그 프로그램이나 설정이 원인 후보입니다.
    5. 게임 그래픽 설정을 낮춰 재현 조건 좁히기 — TDR은 GPU가 한 작업을 허용 시간 안에 끝내지 못할 때 발동합니다. Microsoft 문서는 기본 시간을 2초로 설명하며, 게임 중 그래픽 연산이 몰릴 때 흔히 일어난다고 합니다. 설정을 낮추면 한 번에 몰리는 연산이 줄어듭니다. ① 해상도, 그림자, 레이 트레이싱, 텍스처 품질을 한 단계씩 낮추세요. ② 오류가 나던 장면을 반복해 보세요. ③ 어느 설정에서 오류가 사라지는지 적어 두면 GPU 부하와 안정성 문제를 구분하는 단서가 됩니다.
    6. 하드웨어 상태 점검 — 그래픽카드 연결 불량이나 전원·온도 문제는 장치가 끊긴 것처럼 보이게 합니다. 문서 외 일반 점검이지만 DEVICE_REMOVED가 실제 장치 이탈을 가리킨다는 정의와 맞닿아 있습니다. ① 그래픽카드 보조 전원 케이블이 단단히 꽂혀 있는지 확인하세요. ② 게임 중 GPU 온도가 비정상적으로 오르는지 모니터링 프로그램으로 보세요. ③ 다른 PC가 있다면 같은 그래픽카드를 꽂아 증상이 따라오는지 비교하세요. 노트북은 분해하지 말고 제조사 점검을 받으세요.

    원인을 더 정확히 나누는 방법

    TDR(시간 초과 감지 및 복구)이란

    Microsoft 문서에서 TDR은 그래픽카드가 예상보다 오래 걸려 작업을 끝내지 못하는 것을 감지해 GPU를 재설정함으로써 시스템 전체가 멈추는 것을 막는 Windows 기능입니다. 기본 제한 시간은 2초이고, 복구에 성공하면 화면이 한 번 깜빡이며 '디스플레이 드라이버가 응답하지 않다가 복구되었습니다'라는 안내가 표시됩니다. 일부 오래된 DirectX 프로그램은 복구 뒤 검게 렌더링되어 다시 시작해야 하고, 장치 제거를 처리하도록 잘 만든 프로그램은 장치를 다시 만들어 계속 동작한다고 문서에 적혀 있습니다. 게임이 이 과정을 처리하지 못하면 DEVICE_REMOVED를 띄우며 종료될 수 있습니다.

    TDR이 반복되면 블루스크린이 될 수 있다

    문서에 따르면 기본값으로 1분 안에 GPU 정지와 복구가 5번 이상 일어나 6번째에 이르면 운영 체제가 0x117(VIDEO_TDR_TIMEOUT_DETECTED) 버그 체크를 냅니다. 드라이버가 정해진 시간 안에 빠져나오지 못하면 0x116(VIDEO_TDR_FAILURE)이 날 수 있다는 설명도 있습니다. 게임 오류와 함께 블루스크린이 자주 난다면 사이트의 0x116 가이드와 미니덤프 분석기를 같이 보세요.

    TDR 레지스트리 값을 늘리라는 조언을 만났다면

    인터넷에는 TdrDelay 값을 늘리라는 글이 많습니다. 그러나 Microsoft 문서는 TdrLevel·TdrDelay 같은 키를 드라이버 개발 중 테스트와 디버깅 용도로만 쓰라고 하며, 일반 사용자는 이 레지스트리 키를 조작하지 말라고 명시합니다. 이 사이트는 그 값을 늘려 보라는 안내는 하지 않습니다. 오류의 원인을 드라이버, 게임, 하드웨어 쪽에서 찾는 순서를 권합니다.

    DEVICE_HUNG와 DEVICE_RESET은 게임 쪽 문제일 수 있다

    Microsoft 문서는 DEVICE_HUNG을 프로그램이 보낸 잘못된 명령으로 장치가 실패한 설계 단계 문제로, DEVICE_RESET을 잘못된 명령으로 장치가 실패한 런타임 문제로 설명합니다. 특정 게임에서만 반복되고 다른 게임은 멀쩡하다면 게임 버전과 패치 안내를 확인하고 게임사 지원 채널에 코드와 함께 문의하는 것이 빠를 수 있습니다.

    확인 결과에 따른 다음 단계

    • 특정 게임에서만 반복될 때 — 그래픽 드라이버를 다시 설치해도 그 게임만 꺼진다면 게임 버전과 설정 문제일 수 있습니다. 게임을 최신 패치로 올리고, 설정을 낮춰 보고, 게임사 지원 채널에 오류 코드와 이벤트 뷰어 기록을 함께 알려 주세요.
    • 여러 게임과 3D 프로그램에서 모두 반복될 때 — 드라이버 클린 설치, 오버클럭 해제, 전원 케이블과 온도 점검을 순서대로 진행하세요. 그래도 같다면 그래픽카드나 전원 쪽 하드웨어 점검이 필요합니다.
    • 블루스크린과 함께 나타날 때 — 0x116·0x117 계열 스톱 코드가 같이 보이면 TDR이 반복된 것입니다. 해당 가이드와 미니덤프 분석을 함께 확인하세요.

    피해야 할 실수

    • 오류 코드를 구분하지 않고 모든 DXGI 오류를 같은 원인으로 생각하는 것
    • Microsoft가 사용자는 건드리지 말라고 한 TdrDelay 같은 레지스트리 값을 임의로 늘리는 것
    • 출처가 불분명한 드라이버나 '그래픽 오류 수정' 프로그램을 설치하는 것
    • 오버클럭을 켠 채로 드라이버만 계속 다시 설치하는 것
    • 이벤트 뷰어 기록을 확인하지 않고 게임 재설치부터 하는 것

    자주 묻는 질문

    • DXGI_ERROR_DEVICE_REMOVED는 그래픽카드가 고장 났다는 뜻인가요? Microsoft 문서의 정의는 비디오 카드가 물리적으로 제거되었거나 드라이버 업그레이드가 일어났다는 것입니다. 실제 PC에서는 TDR 같은 복구 과정이나 드라이버 문제로도 나타나서, 이 오류만으로 카드 고장이라고 단정할 수 없습니다. 여러 프로그램에서 반복되고 드라이버 재설치로도 안 되면 하드웨어를 점검하세요.
    • 0x887A0005와 0x887A0006은 어떻게 다른가요? 0x887A0005(DEVICE_REMOVED)는 카드 제거나 드라이버 업그레이드로 장치가 사라진 경우, 0x887A0006(DEVICE_HUNG)은 프로그램이 보낸 잘못된 명령으로 장치가 실패한 경우로 Microsoft 문서에 정의되어 있습니다.
