    EVENT ID 1116 · Windows Defender

    탐지 기록일 뿐, 조치 결과는 1117에서 확인하세요 확인 필요

    Windows Defender 이벤트 1116은 Microsoft Defender Antivirus가 악성코드 또는 유해 가능 프로그램(PUA)을 탐지했다는 기록입니다.

    이 이벤트는 탐지 사실만 남기며, 실제로 격리·제거됐는지는 뒤따르는 1117 이벤트의 조치(Action) 값을 봐야 알 수 있습니다. 1116만 반복되고 1117에서 조치가 완료되지 않았다면 위협이 시스템에 남아 실행되고 있을 가능성이 있습니다.

    먼저 구분할 상황

    • 실시간 검사 알림이 떴다면 검사 알림에 표시된 위협 이름과 파일 경로를 그대로 기록합니다.
    • 게임 치트·크랙 도구를 설치한 직후라면 오탐이 아니라 실제 유해 가능 프로그램으로 탐지된 경우가 많습니다.
    • 1116만 있고 1117이 안 보인다면 조치가 아직 완료되지 않았거나 정책상 '허용'으로 설정됐을 수 있습니다.

    안전한 점검 순서

    1. 이벤트 설명에서 위협 이름(Threat Name), 심각도, 탐지된 파일 경로를 기록합니다.
    2. 같은 시각 또는 직후에 기록된 1117 이벤트를 찾아 Action(작업) 값이 격리·제거·정리·허용 중 무엇인지 확인합니다.
    3. Windows 보안 → 바이러스 및 위협 방지 → 보호 기록에서 같은 항목이 있는지 대조합니다.
    4. Action이 '허용'으로 기록됐다면 예외 목록과 조직 정책(ThreatSeverityDefaultAction 등)을 재검토합니다.
    5. 확실하지 않다면 Microsoft Defender Offline 오프라인 검사로 재확인합니다.

    하면 안 되는 실수

    탐지된 파일이 게임·업무에 필요하다는 이유로 확인 없이 곧바로 예외로 등록하지 마세요. 위협 이름을 Microsoft Security Intelligence에서 검색해 실제 성격을 확인한 뒤 결정해야 합니다. 반대로 1116이 한 번 떴다고 시스템 전체를 재설치할 필요는 없으며, 1117의 조치 결과를 먼저 확인하는 것이 우선입니다.

    즉시 점검이 필요한 경우

    1117의 Action이 '허용'이거나 조치 자체가 보이지 않는데 낯선 프로세스·네트워크 연결·비밀번호 변경 요구 팝업이 함께 나타난다면 네트워크 연결을 차단하고 오프라인 검사를 우선 실행하세요.

    자주 묻는 질문

    • 1116만 있고 1117이 없으면 위협이 아직 남아있는 건가요? 가능성이 있습니다. 1116은 탐지만을 뜻하며 실제 격리·제거는 뒤따르는 1117 이벤트에 기록됩니다. 1117이 보이지 않거나 조치가 '허용'으로 표시된다면 위협이 실행된 상태로 남아 있을 수 있으므로 즉시 전체 검사를 실행해야 합니다.
    • 게임 치트나 크랙 프로그램도 1116으로 뜨나요? 네, 실제로 유해 가능 프로그램(PUA)으로 분류된 치트·크랙·키젠 도구는 오탐이 아니라 실제로 탐지된 경우가 많습니다. 신뢰할 수 없는 출처의 도구라면 예외로 등록하기보다는 사용을 중단하는 것이 안전합니다.
    • 위협 이름을 검색해도 정보가 안 나오면 어떻게 하나요? Microsoft Defender의 위협 이름 명명 규칙에 익숙하지 않다면 Microsoft Security Intelligence 사이트에서 위협 이름으로 직접 검색해 상세 설명과 권장 조치를 확인할 수 있습니다.
