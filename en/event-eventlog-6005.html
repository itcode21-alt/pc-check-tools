    EVENT ID 6005

    EventLog Event 6005: Windows Start Time

    6005 is an information record that the Windows Event Log service started. It is normally used as a reference point for the boot time and does not mean an error or an abnormal shutdown.

    When you look for the cause of a reboot, line up 6008, Kernel-Power 41 and User32 1074 with 6005 in time order rather than using 6005 alone.

    When it appears

    • Right after Windows boots
    • After the Event Log service restarts
    • When comparing the time around a reboot

    Likely causes

    • A normal Windows start
    • An Event Log service restart
    • Service initialization after an update or repair

    What to check, in order

    1. Compare the 6005 time with Kernel-Power 41, EventLog 6008 and User32 1074.
    2. Check whether the boot time differs from the time you actually powered on.
    3. If it repeats in a short time, check why the Event Log service restarted and the 7000-series events.
    Caution

    6005 is in most cases a normal boot or service-start record. Do not judge the cause of a reboot from this event alone.

    Frequently asked questions

    • Is it normal that 6005 is logged every time? Yes. It can be logged when Windows boots or when the Event Log service starts. If you see it at every normal boot with no malfunction, it is an ordinary information record.
    • Can 6005 tell me the boot time? It shows roughly when the Event Log service started. It can differ from the exact power-on time, so compare it with other start events.
