STORAGE CHECK

Storage & Data Self-Check

This tool sorts external drive and USB detection, internal SSD or HDD detection, a full C: drive, deleted files and files that will not open, files that cannot be deleted, and SSD health checks into questions. For symptoms where your data is at stake, it steers you away from risky attempts such as formatting or resetting.

🔒 Runs only in your browser · nothing is sent to a server

Pick a symptom

  • An external hard drive or USB drive is not detected
  • An internal SSD or HDD is missing, even in the BIOS
  • The C: drive is running out of space
  • A file was deleted by mistake, or will not open
  • A file cannot be deleted because it is in use
  • I want to check whether my SSD is healthy

The question-by-question check needs JavaScript to be turned on.

What this tool does and does not do

  • What it does: puts protecting your data first and guides you step by step, starting with checks that do not touch the data: ports, cables, Disk Management and BIOS detection.
  • What it does not do: it cannot recover deleted data or a damaged disk for you. If the data is important, it is safer to ask a professional before you run recovery software yourself.
  • What it does not cover: NAS-specific symptoms.

Frequently asked questions

A window asks me to format the disk when I connect it. Is it OK to click it?

If you need the data, do not click it. Formatting erases the data. This prompt also appears when Windows cannot read the file system, so the data may still be there.

Will cleaning up the C: drive delete my files?

Cleaning temporary files and update leftovers does not affect ordinary documents. But check the Downloads folder yourself first and delete only when it holds nothing you need.
