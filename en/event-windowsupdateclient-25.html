    EVENT ID 25

    WindowsUpdateClient Event 25: Update Check Failed

    25 is known as the record that Windows Update failed at the stage of checking for updates. It comes before download failure (31) and install failure (20), so look at the network and the state of the update service first.

    No description of this event could be found in Microsoft's official documentation, so this page is based on reference material that compiles event message wording (lists of Windows event-log providers and event-ID reference sites). Give priority to the message text and the error code of the event on your own PC.

    When it appears

    • Checking for updates in Settings → Windows Update fails
    • The update check takes very long or hangs
    • It repeats together with 31 (download failure) and 20 (install failure)

    Likely causes

    • A network outage, or blocking by a proxy, VPN or firewall
    • The Windows Update service is stopped or not responding
    • A temporary failure of the update server
    • A wrong system date or time

    What to check, in order

    1. Write down the error code of the event. Start with what is easy to undo so you can narrow the range without risk.
    2. Check the internet connection and whether a VPN or proxy is in use. Compare with the first check to narrow the cause candidates.
    3. Check the state of the Windows Update service (services.msc) and the system date and time. If it still reproduces at this step, move on to the next item.
    4. Run the Windows Update troubleshooter in Settings. See whether the symptoms differ before and after the change.
    5. If the error code continues, look up the same code in the update error guide. If it is still unsolved after all this, review the next cause.
    Caution

    Before deleting the SoftwareDistribution folder, stop the services and back up important files.

    A record that appears only once may be a temporary network problem.

    Frequently asked questions

    • How are 25 and 31 different? 25 is known as the record that it was blocked at the stage of checking for updates, and 31 at the stage of downloading. The direction of the check differs depending on which stage was blocked.
    • Where do I see the error code? Write down the error code at the end of the event description (for example a value starting with 0x8024) and look up the same code in the update error guide.
