    EVENT ID 36887

    Schannel Event 36887: TLS Fatal Alert Received

    Schannel is the Windows TLS/SSL component. 36887 means this PC received a “fatal alert” from the other server and the handshake was stopped. You need the actual alert code in the event description and the calling process to narrow down the cause.

    It is a record of a rejection on the server side, but the real cause is often this PC's TLS settings or security software. If it repeats at the same time as 36874 (protocol or cipher mismatch), treat it as an extension of the failed negotiation.

    When it appears

    • Connecting to a particular site or server fails
    • While using a VPN, a proxy or antivirus HTTPS inspection
    • Repeats at the same time as 36874

    Likely causes

    • The server does not support this PC's TLS version or cipher suites
    • The certificate has expired or cannot be trusted
    • HTTPS inspection of antivirus or VPN intercepts the handshake and the server rejects it
    • A wrong system date or time makes certificate validity checks fail

    What to check, in order

    1. Check the fatal alert code and the calling process (PID) in the event description. Start with what is easy to undo so you can narrow the range without risk.
    2. Check in Settings > Time & language that setting the date and time automatically is on. Compare with the first check to narrow the cause candidates.
    3. Temporarily turn off the HTTPS inspection of your antivirus or VPN and compare whether it still reproduces. If it repeats at this step, move on to the next item.
    4. Update the browser and Windows to the latest versions to check the supported TLS range. Compare the symptoms before and after the change.
    5. Tell apart whether it repeats only with one particular server or occurs randomly with many. If it is only one server, the cause is more likely that server's settings.
    Caution

    While antivirus HTTPS inspection is off, its ability to detect phishing and spoofed sites also drops, so turn it back on as soon as you finish checking. Do not enable TLS 1.0 and 1.1 unconditionally just to lower security.

    Frequently asked questions

    • Does 36887 mean I have been hacked? No. Most cases are records that can occur even in a normal network environment, such as an expired certificate, an old TLS version or a conflict with the HTTPS inspection of security software.
    • Why do I see %1 and %3 left as they are in the event description? It happens when you open a log file saved from another PC rather than the PC that recorded the event. The exact values have to be checked on the original PC.
