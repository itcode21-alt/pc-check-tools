    EVENT ID 1033

    MsiInstaller Event 1033: Installation Result Status

    1033 is the record Windows Installer leaves with a result status after finishing an installation task. It is also written for successful installations, so the deciding factor is not that this event exists but whether the status value is 0.

    If the status value is not 0, first check 11708 and the product name at the same time. The meaning of a value can be found in the Windows Installer error code list, and a broad code such as 1603 needs a detailed log to find the cause.

    When it appears

    • Written every time a program installation, removal or update finishes
    • A status value other than 0 means the installation failed
    • 11708 is left with it

    Likely causes

    • Status 0: completed normally
    • Status 1603: a fatal error during installation (the cause is found in the detailed log)
    • Other values: Windows Installer error codes (they differ by product and environment)

    What to check, in order

    1. Check whether the status value is 0. Start with what is easy to undo so you can narrow the range without risk.
    2. If it is not 0, check 11708 and the product name at the same time. Compare with the first check to narrow the cause candidates.
    3. Look up the status value in the Windows Installer error code list. If it repeats at this step, move on to the next item.
    4. Create a detailed log and check the step that failed. Compare the symptoms before and after the change.
    Caution

    Most records are successes (0), so do not treat many 1033 records as a problem by themselves. Move on to checking the cause of a failure only when the status value is not 0.

    Frequently asked questions

    • I see a lot of 1033 — is something wrong? A large number is normal, because it is left every time an installation, removal or update finishes. Look only at the records whose status value is not 0 as failures.
    • What does status value 1603 mean? It is a general code meaning a fatal error occurred during installation. The value alone does not tell the specific cause, so check the part before the line that says Return value 3 in the detailed log.
