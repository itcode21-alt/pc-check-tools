    EVENT ID 10029

    DistributedCOM Event 10029: Timed Out Waiting for a Service to Stop

    DistributedCOM 10029 is an error-level record that, while trying to activate a COM component, the system timed out waiting for the related service to stop. For example, there are cases on the Game Bar capture component such as “AppCaptureShell activation timed out waiting for BcastDVRUserService to stop”.

    It mostly appears at sign-out or shutdown, when a service stop and an activation request overlap, and in many cases there is no clear symptom. If there is none you do not need to act; only if shutdown is unusually slow or Game Bar causes freezes, turn that feature off and compare.

    When it appears

    • When stopping Game Bar or screen-capture services, or at sign-out or shutdown
    • A COM activation request arrives while a user service is stopping

    Likely causes

    • Another component requested activation while the service was slow to stop
    • The shutdown timing of the Xbox Game Bar capture and broadcast components

    What to check, in order

    1. Use the CLSID and the service name (param1, param2) to identify the component. Start with what is easy to undo so you can narrow the range without risk.
    2. If it is Game Bar related, turn off the Game Bar and capture features in Settings and see whether it recurs. Compare with the first check to narrow the cause candidates.
    3. Check the repeat count together with whether a real symptom (slow app shutdown, freezing) exists. If it still reproduces at this step, move on to the next item.
    Caution

    Although it is logged as an error, it is usually not urgent when there are no symptoms. Do not suspect a hardware failure from this event alone.

    Frequently asked questions

    • 10029 repeats. Is something wrong with the PC? If there are no symptoms, usually not. It is a record left when a service stop and an activation request overlap at shutdown. Check the service only when shutdown is slow or apps freeze.
    • Can I turn off the Game Bar? If you do not use screen capture or recording, you can turn off the Game Bar and background recording in Windows Settings. After turning them off, compare whether the same event still appears to narrow the cause.
