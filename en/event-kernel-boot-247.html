    EVENT ID 247

    Kernel-Boot Event 247: Reading the Pluton Firmware Load Failure Record

    Kernel-Boot 247 is a record left with the text "Unable to load Pluton-Windows firmware". It means Windows tried to apply the Microsoft Pluton security processor firmware and could not. When StatusCode is shown together as STATUS_SUCCESS, as on this PC, boot continued normally.

    The wording looks like an error, but it can be left at every boot even on a PC without Pluton, so if there is no boot delay or security feature problem you can ignore it. If you do have a symptom, check the TPM state, the BIOS security settings and motherboard firmware updates.

    When it appears

    • Every boot (on a PC that has no Pluton security processor or does not need firmware applied)

    Likely causes

    • An informational record that is also left on a CPU or motherboard without Pluton
    • Windows tried to apply Pluton firmware and there was nothing to apply

    What to check, in order

    1. Check the StatusCode and Reason values.
    2. Check whether there is any problem with boot speed or security features (TPM, memory integrity).
    3. Check whether the motherboard or CPU maker supports Pluton.
    Caution

    The wording "Unable to load" makes it look like an error, but if there is no symptom you do not have to do anything.

    Frequently asked questions

    • It says Pluton firmware could not be loaded — is there a security problem? If StatusCode is STATUS_SUCCESS and the TPM and memory integrity are normal, it is hard to treat it as a problem. This record can be left even on a PC without Pluton.
    • Can I get rid of this event? It is an informational record, so you can leave it alone. You can update the motherboard BIOS to the latest version, or adjust a Pluton-related BIOS setting if one exists, following the manual.
