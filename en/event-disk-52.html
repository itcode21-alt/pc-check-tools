    EVENT ID 52

    Disk Event 52: Storage Failure Prediction Warning

    52 records that the driver received information from the storage device predicting that it will fail soon. Unlike other storage events, the message itself recommends an immediate backup, so protect your data before analysing the cause.

    The disk number is not the drive letter. Match the number in Disk Management or the manufacturer's tool to find out which drive it is. It is rare, but there are reports of the same warning being left by a cable or controller problem, so after the backup you can cross-check the connection.

    When it appears

    • A SMART warning also appears in the BIOS or the manufacturer's tool
    • Slowdowns, freezes and file-read errors occur together
    • Other storage events such as Disk 7, 11, 51 and 153 follow

    Likely causes

    • The storage device itself is deteriorating (growing reallocated sectors, media errors and so on)
    • End of life of a long-used HDD
    • There are cases where a cable or controller problem turned out to be the cause

    What to check, in order

    1. Immediately back up important files to another storage device.
    2. Identify which drive the disk number in the event (\Device\HarddiskN\DRN) refers to.
    3. Check SMART and the error count with the manufacturer's diagnostic tool.
    4. Change the cable and port and see whether the same warning continues.
    5. If the warning is confirmed, schedule a replacement and move your data to a new drive.
    Caution

    Before the backup is finished, do not run anything that loads the disk, such as chkdsk, defragmentation or a full scan.

    If this record has appeared even once, keep up your regular backups.

    Frequently asked questions

    • 52 appeared once. Do I have to replace the drive right away? Back up first. Then check the SMART state with the manufacturer's diagnostic tool, and plan a replacement if the warning is confirmed or there are symptoms.
    • Is the same record left on an SSD? It can be, whatever the type of storage device, when the device reports failure-prediction information. First check which device the disk number in the event refers to.
