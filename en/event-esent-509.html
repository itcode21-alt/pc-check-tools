    EVENT ID 509

    ESENT Event 509: Read Request Delay Warning

    ESENT 509 is a warning that a file read request succeeded but took an abnormally long time. It has the same form as 508 for write requests and records a delay on the read side.

    Comparing whether it is left at the same time as 508, and whether storage records such as Disk 153 or stornvme 129 overlap, lets you judge whether it is a temporary overload or a storage problem. This explanation is based on event ID reference material and user reports, not on official documentation.

    When it appears

    • Features such as Windows Search, Defender and Update become slow
    • Disk usage spikes at the same time
    • 508 or Disk and Ntfs records are there together

    Likely causes

    • A temporary I/O overload on the storage
    • A problem with the storage, controller or driver
    • Disk use overlapping with background work
    • Storage delay in a virtual machine environment

    What to check, in order

    1. Write down the file path and the delay in seconds in the event text.
    2. Compare the 508, Disk 153, stornvme 129 and Ntfs events at the same time.
    3. Check the disk usage in Task Manager at that time.
    4. Check the storage condition with SMART and the manufacturer's diagnostic tool.
    5. If it repeats, back up and then check the connection, driver and firmware. If it is still not resolved, consider the next cause.
    Caution

    A one-off 509 can be a temporary overload. Judge by whether it repeats and whether there is a symptom such as freezing.

    If a storage error is suspected, back up before checking.

    Frequently asked questions

    • Only 509 repeats and there is no 508 — why? There are cases with only read delays. Look at the disk usage and storage records at the same time, and check the storage condition when there is a symptom.
    • Is it related to the Windows Search index? ESENT is an internal database engine used by several components such as Windows Search, so the file path in the event text tells you which feature it is.
