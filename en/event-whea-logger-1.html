    EVENT ID 1

    WHEA-Logger Event 1: Uncorrectable Hardware Error Record

    WHEA-Logger 1 records an uncorrectable hardware error as an error record. Unlike 18, you must read the shown error source and type yourself to tell whether the CPU, PCIe or memory layer is involved.

    Note ErrorSource, ErrorType, Processor APIC ID and the PCIe device information on the Details tab. Turning XMP/EXPO and overclocking off and checking whether the symptom still reproduces separates a settings problem from a hardware problem. Do not decide on a part from a single record.

    When it appears

    • Before or after a blue screen or forced reboot
    • High-load work such as games or rendering
    • The event repeats with no screen freeze

    Likely causes

    • Unstable CPU cores/cache or memory controller
    • PCIe device or link errors
    • XMP/EXPO, overclock or undervolt settings
    • BIOS, chipset or device firmware problems
    • Physical instability of CPU, RAM, GPU, motherboard or power

    What to check, in order

    1. Record ErrorSource, ErrorType, Processor APIC ID and PCIe device information from Details.
    2. Turn off XMP/EXPO and overclocks and compare whether it reproduces at default settings.
    3. Check BIOS, chipset, GPU and SSD firmware against the vendors' information.
    4. Compare Kernel-Power 41, BugCheck 1001 and WHEA 17/18/19 from the same time.
    5. If it repeats, back up important files and cross-test CPU, RAM, GPU and PCIe devices one at a time.
    Caution

    Do not decide on a specific part from WHEA 1 alone. The source of the error record and the conditions under which it repeats matter more.

    Do not repeat long stress tests without a backup.

    Frequently asked questions

    • Do I need to replace a part right away? No. Back up first, restore settings to default and compare whether it reproduces, then go through BIOS/firmware updates and cross-testing parts.
    • Records repeat but the screen never freezes. Even without symptoms, whether the same error source repeats matters. Keep a note of how often and when it occurs, and compare whether it increases under heavy load.
