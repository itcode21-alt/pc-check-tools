    EVENT ID 10002

    WLAN-AutoConfig Event 10002: Wireless Extensibility Module Stopped

    10002 records that a wireless extensibility module has stopped. It appears while a wireless driver or a manufacturer's extension module is restarting, so first look at whether it is the same time Wi-Fi dropped.

    Write down the Module Path in the event and the wireless adapter model, and check the driver version in Device Manager. If Wi-Fi works and it was a one-off, do not uninstall the driver just from the record. It is also worth comparing whether it is the same time as a record of 8002 (connection failure).

    When it appears

    • Wi-Fi drops and reconnects
    • Wireless instability after wake from sleep
    • Right after a driver update or a switch between wireless networks

    Likely causes

    • A conflict in the wireless driver or its extension module
    • A conflict between the manufacturer's wireless utility and the Windows WLAN service
    • An adapter power-management or wake-from-sleep problem
    • A temporary link change while switching routers

    What to check, in order

    1. Write down the Module Path in the event and the wireless adapter model. Start with what is easy to undo so you can narrow the range without risk.
    2. Check the wireless driver version in Device Manager. Compare with the first check to narrow the cause candidates.
    3. Update or roll back to the manufacturer's driver and compare whether the wireless management utility conflicts. If it still reproduces at this step, move on to the next item.
    4. If the Wi-Fi connection is fine and it was a one-off, do not uninstall the driver just because the errors accumulate. See whether the symptoms differ before and after the change.
    Caution

    Do not conclude that the wireless card is faulty just because 10002 exists. The time must match repeated real disconnections.

    Frequently asked questions

    • Does 10002 mean the wireless card is broken? The record alone cannot show a failure. The standard is whether real disconnections repeat at the same time.
    • What should I do about the driver? Update to the manufacturer's latest driver, or, if it started right after an update, roll back to the previous version and compare.
