    EVENT ID 57

    Ntfs Event 57: Metadata Write Failed

    57 records that writing the NTFS file-system metadata itself failed, which points to a more fundamental file-system integrity problem than event 50. If it repeats, put data backup first.

    If it appears at the same time as event 55 (file-system corruption), the storage device may already be in considerably worse condition, so keep to the order of finishing a backup before running chkdsk.

    When it appears

    • After an abnormal shutdown
    • Write errors on an external drive
    • When the storage device responds slowly

    Likely causes

    • Poor storage-device response
    • A cable or controller problem
    • An unstable power supply

    What to check, in order

    1. Back up your data as soon as it occurs.
    2. Check whether it appears together with event 55.
    3. Check SMART, then decide whether to replace the disk.
    Caution

    If this event repeats, seriously consider replacing the storage device.
