WINDOWS & PROGRAMS CHECK

Windows & Programs Self-Check

This tool sorts a program that won't open or install, a game that won't launch, Windows Update or Windows 11 upgrade failures, activation and Microsoft account sign-in problems, and Microsoft Store, Windows Search, copy and paste and Phone Link problems into questions. Each step shows what you need and how to do it, and if it is too hard to do yourself, it tells you what to do next.

🔒 Runs only in your browser · nothing is sent to a server

Pick a symptom

  • A program won't open or install
  • A game won't launch
  • Windows Update keeps failing
  • Windows isn't activated, or sign-in fails
  • Microsoft Store, search, or copy and paste not working

The question-by-question check needs JavaScript to be turned on.

What this tool does and does not do

  • What it does: guides you step by step through checks that tell the cause: whether only one program or the whole of Windows is affected, error codes, time, storage space and security blocks.
  • What it does not do: it cannot confirm a cause or fix the program or Windows for you. Work that can erase data, such as a reset or reinstall, is kept as a last resort, and it tells you to check your data first.
  • What it does not cover: for a PC that won't turn on or has no picture, use the PC won't turn on self-check; for a slow PC, use the slow & noisy PC self-check. The commands (sfc, DISM and so on) have not been run on this site; they follow the official tools' guidance.

Frequently asked questions

Does running a program as administrator fix it?

You can use it as a temporary test to tell whether it is a permissions problem, but always running as administrator is not a fix. If an error such as 0x80070005 keeps appearing, check the folder permissions and the security block records.

Windows Update keeps failing with the same code. What should I do?

First write down the KB number and error code of the failed item in the update history. If the same code repeats, the cache or a service is more likely the problem, and the update path of this check goes through the troubleshooter, disk space and a manual install in that order.

Windows says it isn't activated. Do I have to buy a new product key?

First check the error code on the activation screen and the license type. If you changed hardware, you may be able to reactivate through the troubleshooter with the digital license linked to your Microsoft account. Do not use activation tools of unclear origin.
