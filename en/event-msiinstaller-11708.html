    EVENT ID 11708

    MsiInstaller Event 11708: Installation Failed

    11708 is a record that a Windows Installer installation failed. It tells you only which product it was, not the reason. The status value that is the reason is in 1033 at the same time, so read the two records as a pair.

    The cause differs by product. Common causes such as permission problems, leftovers of a previous installation and file locks are known, but it is confirmed in the detailed log. The action just before the line where Return value 3 is recorded in the detailed log is the step that failed.

    When it appears

    • “Installation failed” or a rollback is shown during program installation or update
    • The setup wizard shows a code such as error 1603
    • MsiInstaller 1033 is left at the same time

    Likely causes

    • Insufficient permissions (running an installation that needs administrator rights with ordinary rights)
    • Leftovers of a previous installation or damaged installation information
    • A running program locks a file
    • A damaged installation package or unmet installation conditions

    What to check, in order

    1. Check the status value of MsiInstaller 1033 at the same time (1603 is a general code meaning a fatal error during installation).
    2. Run the installer again with administrator rights.
    3. Create a detailed log with msiexec /i package.msi /l*v logfile.txt and check the part before the line that says Return value 3.
    4. Remove the previous version and reinstall.
    5. Check the installation requirements the manufacturer gives (required components, versions). If it is still not resolved, consider the next cause.
    Caution

    Do not turn off security software and run an installation file from an unreliable source.

    Back up before you delete installation information in the registry directly.

    Frequently asked questions

    • How are 11708 and 1033 connected? They are left together at the same time. 1033 holds the installation result status value, and 11708 records the fact that the installation task failed. If the status value is 1603, it is a general code meaning a fatal error occurred during installation.
    • How do I create a detailed log? Run something like msiexec /i package.msi /l*v logfile.txt in a Command Prompt with administrator rights, and the installation process is recorded in detail in the log file. The file can contain paths and user names, so check it before sharing.
