    EVENT ID 200

    Diagnostics-Performance Event 200: Shutdown Time Record

    200 is the Shutdown Performance Monitoring event that records the shutdown time when Windows shutdown finishes. 201–203 point to the apps, devices and services that delayed shutdown, so check them together when the time in 200 is long.

    This event is also not in the System log but under Applications and Services Logs > Microsoft > Windows > Diagnostics-Performance > Operational. Comparing startup and shutdown times side by side in the same log as 100 tells you whether only one side is slow or both.

    When it appears

    • The shutdown or restart screen takes longer than usual
    • Shutdown seems stuck because of a particular program
    • Shutdown time is getting longer

    Likely causes

    • An app, service or device driver that delays shutdown
    • Slow storage writes
    • An update being applied during shutdown

    What to check, in order

    1. Divide the Shutdown Duration value (milliseconds) in the event by 1000 and write it down in seconds.
    2. Check which app, device or service the 201–203 events in the same log point to.
    3. Check which programs were running just before shutdown.
    4. Check whether storage events (Disk 153, Ntfs) are at the same time.
    5. Compare shutdown time after changing the Fast Startup setting. If it is still not resolved, consider the next cause.
    Caution

    A shutdown that applies updates is normally long. Do not judge from a single value.

    Forcing the power off during shutdown leaves an abnormal-shutdown record such as Kernel-Power 41.

    Frequently asked questions

    • Shutdown is slow — can I tell which program is the cause? The 201–203 events sometimes point to the app, device or service that delayed shutdown. Check the name in the records at the same time, and check that program's update or shutdown settings.
    • How many seconds of Shutdown Duration is a problem? There is no fixed standard. Look at whether it grows compared with this PC's usual value and whether the same program is pointed to repeatedly.
