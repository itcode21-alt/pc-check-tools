    EVENT ID 8193

    VSS Event 8193: Volume Shadow Copy Error

    8193 is a record that the Volume Shadow Copy Service (VSS) failed with an error, and it mainly appears while backup software runs or a system restore point is being created. Use the error code shown in the event description to narrow the cause.

    First check that there is enough free disk space, and if you use several backup programs together, keep open the possibility of a conflict between VSS writers.

    When it appears

    • Creating a system restore point fails
    • A backup software error
    • A Windows Server Backup failure

    Likely causes

    • Not enough disk space
    • A VSS service or writer error
    • Slow storage response during a backup

    What to check, in order

    1. Check the error code in the event description. Start with what is easy to undo so you can narrow the range without risk.
    2. Check the free space of the shadow copy storage. Compare with the first check to narrow the cause candidates.
    3. Check the state of the writers with the vssadmin list writers command. Use this to verify the next cause when the earlier steps did not solve it.
    Caution

    If this event repeats, system restore points may not be getting created.

    Frequently asked questions

    • Does 8193 mean the backup failed? It is likely that the backup software or system restore failed while using VSS. Also check the backup program's run log to confirm whether it really completed.
    • How do I run vssadmin list writers? Type vssadmin list writers in an administrator command prompt and the state of each writer is shown. If a writer is in an error state, try restarting the related service.
