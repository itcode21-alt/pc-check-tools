    EVENT ID 98

    Ntfs Event 98: Volume Is Healthy — A Normal Record

    Ntfs 98 appears as “Volume … is healthy. No action is needed.” It means NTFS checked the volume and found no problem with the file system.

    When you investigate storage errors you can use it as a hint that the file system itself is fine. This record only confirms the file system level, though. It says nothing about the physical state of the disk (bad sectors, lifespan). If a disk problem is suspected, also check the SMART values in CrystalDiskInfo and events such as Disk 7, 11 and 153.

    When it appears

    • When Windows periodically checks the volume state
    • At boot or mount time

    Likely causes

    • A record that the state was confirmed healthy

    What to check, in order

    1. Check the CorruptionAction value (if healthy, no action).
    2. Check whether the same volume has errors other than Ntfs 55/98.
    3. When storage errors are suspected, use a volume with this record as a hint that file-system errors are unlikely.
    Caution

    It is a normal record. It does not guarantee the physical disk is healthy, so check SMART too.

    Frequently asked questions

    • Does Ntfs 98 mean the disk is fine? It means the file system is fine. It cannot tell the physical disk state, so check SMART separately.
    • Is it OK if it repeats many times? Yes. It is written every time the volume is checked, so repeating is normal.
