    EVENT ID 1026

    .NET Runtime Event 1026: Unhandled .NET Exception

    .NET Runtime 1026 records that a program running on .NET hit an unhandled exception and the process ended. Check the target app and the exception type before reinstalling anything.

    Do not simply uninstall and reinstall .NET because of this event alone. If it repeats only in one app, look at that app's runtime version, plug-ins and settings; if several .NET apps fail, compare the shared runtime and the Windows Update state.

    When it appears

    • A .NET app closes right after it starts
    • An exception dialog appears in a specific feature
    • It repeats at the same time as event 1000

    Likely causes

    • An error in the app code or its settings
    • A missing .NET runtime component
    • Plug-in, permission or file-access problems

    What to check, in order

    1. Record the exception text and the app name.
    2. Compare the faulting module and exception code in Application Error 1000.
    3. Repair the app, then check the required .NET components and updates.
    4. If several .NET apps repeat it, check system files and storage health.
    Caution

    Do not uninstall and reinstall .NET on the strength of 1026 alone. Check the exception type and the version the app requires first.

    Frequently asked questions

    • Do I need to reinstall .NET when 1026 appears? Not always. First check the exception type and the .NET version the target app requires, and consider repairing or updating from the official installer before anything else.
    • Does 0xC0000005 alongside it mean bad RAM? No. An invalid memory access can also come from an app bug, a plug-in or a driver. Compare whether it repeats only in one app or across several.
