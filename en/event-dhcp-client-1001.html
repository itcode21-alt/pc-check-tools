    EVENT ID 1001

    DHCP-Client Event 1001: IP Address Lease Failed

    1001 records that the DHCP client could not obtain or renew an IP address. With this record, look first at whether the IP address and the default gateway were assigned correctly, before DNS.

    A 169.254.x.x address is the automatic private IP address Windows assigns temporarily when it gets no DHCP answer. Comparing whether other devices on the same router get an IP quickly shows whether the problem is on the PC or on the router or line.

    When it appears

    • No internet connection after boot
    • The IP shows as 169.254 after switching between Wi-Fi and wired
    • The network drops after wake from sleep

    Likely causes

    • The router or DHCP server failed to answer
    • An unstable LAN cable or wireless link
    • The network adapter driver or its power-saving settings
    • A conflict with a VPN or virtual network adapter

    What to check, in order

    1. Check IPv4, the default gateway and the DHCP server address in ipconfig /all. Start with what is easy to undo so you can narrow the range without risk.
    2. Compare whether other devices on the same router also get an IP. Compare with the first check to narrow the cause candidates.
    3. Turn the adapter off and on, then run ipconfig /release and ipconfig /renew. If it still reproduces at this step, move on to the next item.
    4. Cross-check with another cable and port and the latest network driver. See whether the symptoms differ before and after the change.
    Caution

    If you see a 169.254.x.x address, check the DHCP side, the cable and the router before changing DNS.

    Frequently asked questions

    • What does it mean when the IP starts with 169.254? Windows could not get an address from a DHCP server and assigned a temporary one. The internet does not work with this address, so check the cable, the router and the adapter before changing DNS.
    • Are ipconfig /release and /renew safe? They drop the connection briefly and obtain a new address, so they are generally safe. If you are connected remotely the connection may drop, so run them at the PC.
