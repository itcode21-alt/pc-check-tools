    EVENT ID 4625

    Security Event 4625: An Account Failed to Log On

    4625 records that an account failed to log on. The failure reason code and the logon type (interactive / remote / network) tell a simple typo apart from an external access attempt.

    If a specific account fails repeatedly at short intervals at times you did not try, check whether an externally reachable path such as Remote Desktop or a shared folder is exposed.

    When it appears

    • A sign-in failure message
    • Domain account access errors
    • Remote Desktop connection failure

    Likely causes

    • Repeated wrong passwords
    • CapsLock or input-language switching problems
    • Expired saved credentials
    • External brute-force attempts

    What to check, in order

    1. Check the failure reason code (such as 0xC000006D) and the logon type.
    2. See whether only a specific account fails repeatedly.
    3. For remote access, check the source IP.
    Caution

    Repeated failures on the same account clustered in a short time may be a security threat.

    Frequently asked questions

    • Is an occasional 4625 normal? If you mistyped the password or CapsLock/input language was wrong, it is a normal record. What matters is whether it repeats in a burst on a specific account in a short time.
    • The source IP is an unknown external address. What do I do? Check whether Remote Desktop or sharing services are exposed to the internet; if they are not needed, close the port or tighten firewall rules, and change the account password immediately.
