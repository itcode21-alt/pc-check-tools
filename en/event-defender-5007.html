    EVENT ID 5007

    Windows Defender Event 5007: Security Settings Changed

    5007 records that a Microsoft Defender Antivirus setting was changed. The event keeps the old value and the new value, so you can see which setting changed.

    It is also logged after Defender updates and normal protection switches. If the change affects real-time protection or the exclusion list and you did not expect it, compare it with the settings in Windows Security and run a scan. The existence of a 5007 alone does not mean malware.

    When it appears

    • Right after a Defender update
    • After real-time protection or controlled folder access settings were changed
    • Right after a security program was installed or removed

    Likely causes

    • A Defender platform or security-intelligence update
    • A settings change by an administrator or organisation policy
    • A protection switch caused by installing a third-party antivirus
    • An unwanted program changing security settings

    What to check, in order

    1. Check which setting actually changed from the Old value and the New value. Start with what is easy to undo so you can narrow the range without risk.
    2. Compare it with the Virus & threat protection settings in Windows Security. Compare with the first check to narrow the cause candidates.
    3. If the change was unexpected, consider a full scan and an offline scan. If it still reproduces at this step, move on to the next item.
    4. Check events 5001, 5004 and 1002 at the same time and any recent installs or policy changes. See whether the symptoms differ before and after the change.
    Caution

    A 5007 on its own does not mean malware. Check whether the change matches your own work and the update time.

    Do not “fix” it by turning protection off or clearing Defender events.

    Frequently asked questions

    • 5007 appears several times a day. Is that normal? It can be logged whenever Defender updates or switches state. Check whether the Old value and New value are a really meaningful change of setting.
    • What if protection had been turned off? Another antivirus may have been installed or a policy may have changed it, so check the install history and any organisation policy first. If you do not recognise the change, run a full scan.
