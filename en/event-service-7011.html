    EVENT ID 7011

    Service Control Manager Event 7011: Service Control Request Timeout

    7011 records that a service did not respond to a control request in time. It often appears with slow shutdown or reboot.

    If it repeats on every shutdown, disable the background services of recently installed programs one at a time to narrow the cause.

    Signs that point to a deadlock

    • 7011 means a service did not answer a control request (start, stop, pause). If the signs below appear together, it is closer to a deadlock than a simple delay.
    • The “Shutting down services” screen stays for tens of seconds or more at shutdown.
    • 7011 repeats for the same service and each time ends in a forced shutdown.
    • In Task Manager the service's process shows 0% CPU but its state never changes.

    When it appears

    • Slow shutdown or boot
    • A device service hangs

    Likely causes

    • A service deadlock
    • Storage delay
    • A driver that does not respond

    What to check, in order

    1. Record the service name and when it happened: this event is also written after the default 30000 ms wait. Note whether it happened during shutdown or boot, which narrows the next step a lot.
    2. Check whether it comes with slow shutdown: if the “Shutting down services” screen lingers, the service is probably not answering control requests, that is, deadlocked. If EventLog 6008 is also present, it led to a forced shutdown.
    3. Check for 129/153 alongside: if storahci 129 or Disk 153 are present at the same time, storage delay blocked the service response. Check cables, NVMe slot and firmware first.
    4. Rule out third-party services with a clean boot: in msconfig → Services, tick “Hide all Microsoft services”, disable the rest and reboot. If the symptom disappears, re-enable half at a time to find the cause.
    Caution

    Force-deleting a service is the last resort.

    Frequently asked questions

    • Is slow shutdown also caused by this event? Yes. A service that blocks the shutdown sequence without responding can delay shutdown or reboot and also record this event.
    • Can I delete the service by force? Keep that as the last resort. First check whether it reproduces in a clean boot, and try updating or reinstalling the related program.
    • How do I revert after a clean boot test? Open msconfig again, choose Normal startup on the General tab and reboot. If you found the culprit, leave only that item disabled.
