    EVENT ID 153

    Disk Event 153: Repeated I/O Retries on a Drive

    153 records that a disk I/O operation was retried. It can be a temporary delay or an early clue to a connection problem; check whether it grows on the same disk together with events 7 and 129.

    At warning level, the disk number and PDO name at the start of the message, and the logical block address, show which disk and which place saw the retry. On one example PC it was logged on disk 2 at logical block address 0x0.

    If the retry count on the same disk is clearly trending up, move your backup schedule forward even if nothing seems wrong right now.

    What a retry means

    • 153 does not say the I/O failed; it says it was retried and eventually succeeded. So files are not broken right away, but it is also a sign that the response became slower.
    • It is often linked to symptoms such as copy speed suddenly dropping or longer game loading.
    • If the frequency rises it may be an early sign of declining drive health, so look at the SMART values too.

    When it appears

    • Speed drops sharply during a copy
    • A game freezes while loading

    Likely causes

    • Slow device response
    • Cable or port problems
    • The effect of a filter driver

    What to check, in order

    1. Check the disk and the frequency: match the disk number in the description with diskmgmt.msc to identify the device, and filter Event Viewer by this ID to count how many a day. A change in frequency is the indicator of getting worse.
    2. Check whether 129 or 7 come with it: if storahci 129 (device reset) or Disk 7 (bad block) appear at the same time, it is past a temporary delay. Raise the backup priority.
    3. Check SMART and the connection: check status in CrystalDiskInfo; for SATA recheck cable and port, for NVMe recheck the slot seating.
    4. Rule out a filter driver: antivirus, disk-encryption or virtual-drive software can sit in the I/O path and cause delay. If you installed such a program recently, stop it for a while and see whether the frequency drops.
    Caution

    If it repeats, do not dismiss it as a simple performance issue.

    Frequently asked questions

    • Only 153 appears, without 7 or 129. Is that OK? On its own 153 may be a transient retry. But keep watching if real slowdowns appear during game loading or file copy.
    • Is 153 common on external drives? Yes. USB connections can leave this record more often than internal drives, depending on the cable and hub.
