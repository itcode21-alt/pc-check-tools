    EVENT ID 1801

    TPM-WMI Event 1801: Secure Boot Certificate Update Needed

    1801 records that an updated Secure Boot certificate is available but has not yet been applied to the firmware. It relates to Microsoft's ongoing rollout of renewed Secure Boot certificates, as the 2011 certificates approach expiry.

    As the Windows Secure Boot CA certificates issued in 2011 near their expiry, Microsoft is distributing new certificates in stages. TPM-WMI 1801 is an advance notice that the new certificate reached the computer but is not yet reflected in the UEFI firmware (BIOS).

    It is closer to an informational record and does not cause boot or feature problems right now, but if left alone the PC may be unprepared at the later certificate transition, so it is safer to apply the firmware update.

    When it appears

    • Repeated in the System log after Windows Update
    • Piles up quietly with no visible symptom at boot
    • UEFI firmware that uses the maker's certificates has not been updated for a long time

    Likely causes

    • The PC is a target of the Secure Boot certificate renewal rollout under way in 2026
    • The maker's firmware update for the motherboard or laptop is not yet applied
    • The certificate was delivered but the firmware-application step is not complete

    What to check, in order

    1. In Settings → Windows Update, check for pending updates or a pending reboot.
    2. In the update history, check whether Secure Boot–related updates were applied.
    3. On the motherboard or laptop maker's site, check for and apply the latest BIOS/UEFI firmware.
    4. Run msinfo32 and check that Secure Boot state stays “On”.
    Caution

    Do not turn Secure Boot off on your own. The certificate renewal is routine security maintenance that proceeds automatically. A power loss during a firmware update can damage the motherboard, so keep a laptop plugged in.

    Frequently asked questions

    • Could my PC fail to boot now because of this event? No. 1801 is an advance notice that a certificate is not yet applied and does not itself cause boot failure or malfunction. Left alone it could limit Secure Boot–related features later, so applying a firmware update is advisable.
    • What if the maker's BIOS update is not available yet? Motherboard and laptop makers release updates in stages, so if there is none now, check the maker's support page now and then or wait for automatic delivery through Windows Update. There is no need to hurry.
