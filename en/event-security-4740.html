    EVENT ID 4740

    Security Event 4740: A User Account Was Locked Out

    4740 records that an account was locked out. In most cases it is the result of 4625 (failed logon) repeating over a short time. The caller computer name identifies which device kept failing.

    If you changed the password recently, places that still store the old one — Credential Manager, scheduled tasks, a phone mail app — often retry automatically and lock the account.

    When it appears

    • An account-locked message at sign-in
    • No access from a domain-joined PC
    • Errors in apps that use saved credentials

    Likely causes

    • Several devices retrying an expired password on the same account
    • Old passwords in Credential Manager
    • Expired credentials in scheduled tasks or services

    What to check, in order

    1. Use the caller computer name in the event to find the device causing the lockout.
    2. Delete or update the account's entries in Credential Manager.
    3. Update the password of the accounts used by scheduled tasks and services.
    Caution

    Repeated lockouts are often caused by expired credentials stored in several places.

    Frequently asked questions

    • My account gets locked although I did not change the password. Someone else may have tried, but first check Credential Manager and the logins stored on several devices for an old password that is still left.
    • Where do I see the caller computer name? In the General tab text of Event Viewer or in the XML view of the Details tab, look for the Caller Computer Name item; it identifies the device that caused the lockout.
