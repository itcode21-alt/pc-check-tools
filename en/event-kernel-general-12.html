    EVENT ID 12

    Kernel-General Event 12: Operating System Start Time Record

    Kernel-General 12 is an operating system start record left as 'The operating system started at system time …', and its body also contains the Windows version, build and boot mode. It is useful as a reference point for telling boot sessions apart.

    If you pair this event with Kernel-General 13, the shutdown record, you can calculate how many minutes the PC stayed on. If 12 continues without a 13, it means the PC went off without a shutdown record, so check it together with Kernel-Power 41.

    When it appears

    • Every boot

    Likely causes

    • A normal boot record

    What to check, in order

    1. Pair the start time with the shutdown record (Kernel-General 13) and calculate the session length.
    2. If 12 appears without a 13 before it, check whether a normal shutdown was not recorded.
    3. Compare with Kernel-Power 41 from the same time.
    Caution

    It is an informational record and is not a problem by itself.

    Frequently asked questions

    • Is 12 left at every boot? Yes, once per boot. The number of records should equal the number of boots.
    • What if there is a 12 but no 13? It may mean the previous shutdown ended without a normal record. Check Kernel-Power 41 or EventLog 6008 from the same time to separate a forced shutdown, a power outage and a crash.
