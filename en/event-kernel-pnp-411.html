    EVENT ID 411

    Kernel-PnP Event 411: Device Start Problem

    411 is a Plug and Play record that there was a problem while a device was starting. If 219 shows a driver load failure or delay, 411 records the device start problem together with the device instance and the Problem code.

    This event is left under Applications and Services Logs > Microsoft > Windows > Kernel-PnP > Configuration in Event Viewer, so you cannot see it by looking only at the System log. In this site's event log analyzer, choosing “Device recognition or driver problems” in the command builder collects this log as well.

    When it appears

    • A yellow exclamation mark is shown in Device Manager
    • A device such as USB, a touchpad or a fingerprint reader suddenly stops working
    • Right after a driver update or removal

    Likely causes

    • The driver is old or damaged
    • Poor contact in the device, port or cable
    • A conflict with other software or drivers
    • A fault in the hardware itself

    What to check, in order

    1. Find that device in Device Manager with the device instance ID in the event.
    2. Write down the Problem code and the Problem Status value.
    3. Compare with the Device Manager error codes.
    4. Reinstall with the manufacturer's driver, or if it was right after a recent update, roll back to the previous version.
    5. For a USB device, change the port and remove hubs and extension cables. If it is still not resolved, consider the next cause.
    Caution

    If the device works normally now, a record left once during boot can be something to observe.

    Use the manufacturer's official release of the driver.

    Frequently asked questions

    • What does the Problem code mean? Write down the Problem code and Problem Status value shown in the event, and look up the description of the same device in the status message in Device Manager and the error code list. Do not conclude a cause from the value alone.
    • The device works now but 411 remains. It may be a record that startup failed once during boot and then started again. If it repeats on the same device or there is a real drop, check the driver and the port.
