    EVENT ID 36888

    Schannel Event 36888: TLS Fatal Alert

    36888 is a record that a fatal alert occurred during the TLS handshake and the secure connection ended. It often records the result of a connection failure, so it does not tell the cause on its own.

    Write down the fatal alert number and the internal error state in the event description, and match the time against 36874, app errors and Windows Update failures. If it is only in a particular app, first check that app's range of TLS and certificate support.

    When it appears

    • HTTPS sign-in or sync fails
    • Connection errors in a browser or background service
    • Repeats at the same time as 36874

    Likely causes

    • A TLS fatal alert sent by the remote server
    • An unsupported TLS protocol or cipher suite
    • A wrong certificate, a proxy or inspecting security software

    What to check, in order

    1. Write down the fatal alert number and the internal state code.
    2. Compare the times of 36874, app errors and Windows Update errors.
    3. Check the system time, certificates and proxy settings.
    4. If the problem is only in a particular app, first check that app's range of TLS and certificate support.
    Caution

    Event 36888 can be the result of a connection failure, so do not judge a malicious attack or a PC failure from it alone.

    Frequently asked questions

    • Does 36888 mean I have been hacked? There is no basis for judging that. It is a connection failure record that is also commonly left by server-side settings or an old app or proxy. Do a security check only when unfamiliar connections or other security anomalies are there too.
    • How do I find the cause? Check in order which program failed to communicate at the same time, and whether the system time and certificate state are normal.
