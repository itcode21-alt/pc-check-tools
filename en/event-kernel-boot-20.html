    EVENT ID 20

    Kernel-Boot Event 20: Reading the Last Shutdown and Boot Success Status

    Kernel-Boot 20 records at boot whether the previous shutdown and the previous boot ended successfully, in text such as "The last shutdown's success status was true. The last boot's success status was true." When you investigate an unexpected reboot, it is a useful clue that tells you in one line whether the previous shutdown was normal.

    If LastShutdownGood is false, the previous shutdown did not go through the normal procedure, so check whether it appears at the same time as Kernel-Power 41 or EventLog 6008. If it is true, the suspicion of a forced shutdown is smaller, but you still need to look at the records of other boots as well.

    When it appears

    • Every boot

    Likely causes

    • true if the previous shutdown was normal; false for a forced shutdown, a power cut or a blue screen

    What to check, in order

    1. Check whether LastShutdownGood is false.
    2. If it is false, compare with Kernel-Power 41 and EventLog 6008 from the same time.
    3. Use LastBootId to tell which boot it belongs to.
    Caution

    true/true means both the previous shutdown and the previous boot were normal.

    Frequently asked questions

    • Does LastShutdownGood = false always mean a fault? No. A forced shutdown, a power outage, holding the power button and a blue screen can also make it false. Narrow it down with the number of repeats and 41, 6008 and BugCheck 1001 from the same time.
    • Can I count reboots with this event? It is left once per boot, so together with LastBootId it helps you tell the boots apart and find the point where false repeats.
