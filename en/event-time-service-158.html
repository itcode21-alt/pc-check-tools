    EVENT ID 158

    Time-Service Event 158: Reading the VMICTimeProvider Stopped Record

    Time-Service 158 is a record that VMICTimeProvider stopped, saying it does not support the current hardware and operating environment. This time provider is for Hyper-V virtual machines only, so on an ordinary PC (not a virtual machine) it stops as expected after boot and leaves this record. It does not end with one record; the same record can repeat several times at about 17-minute intervals. In a case where one PC was observed, a pattern of 5 records over about 70 minutes, starting about 2 minutes after boot, appeared at almost every boot; the count and interval can differ on other PCs.

    The message includes an explanation to the effect that this behavior is expected in an environment that is not a Hyper-V guest, so even though it looks like a warning, no action is needed. Only when the time is actually drifting should you check the time service synchronization settings and the CMOS battery.

    When it appears

    • Repeating for a while after boot (on a PC that is not a Hyper-V virtual machine)

    Likely causes

    • A time provider meant only for virtual machines is stopped automatically on an ordinary PC

    What to check, in order

    1. Check the name of the time provider (VMICTimeProvider).
    2. Check whether the time is actually drifting.
    3. Check time synchronization problems together with Time-Service 35 (synchronization start).
    Caution

    It is normal for VMICTimeProvider to stop on a PC that is not a Hyper-V guest, so no action is needed.

    Frequently asked questions

    • Time-Service 158 keeps repeating after boot — is time synchronization failing? No. It is a record that a provider meant for virtual machines stopped on an ordinary PC, and it is separate from internet time synchronization. Check synchronization with records such as Time-Service 35.
    • Is it different if I use Hyper-V? Inside a Hyper-V guest (a virtual machine) this provider works normally. On the host PC, it is normal for it to stop.
