    EVENT ID 11

    stornvme Event 11: NVMe Controller Error

    11 records that the driver detected an error on the NVMe controller. The message is similar to Disk 11, but because the source is stornvme, read it separately as a record that came from the NVMe SSD path.

    Official documentation does not list a single cause for this event. In user reports there are cases where adjusting firmware, BIOS or PCIe power management reduced it, and cases where it did not. If it is left only now and then with no symptoms, observe it; act when it repeats together with freezes or slowdowns.

    When it appears

    • Repeats right after boot or restart
    • Freezing during games or large copies
    • stornvme 129 records are present with it

    Likely causes

    • SSD firmware, NVMe driver or BIOS version problems
    • A conflict with the PCIe link speed or power-management settings
    • The controller failed to respond to a special command sent by a backup or disk utility
    • M.2 slot contact or heat

    What to check, in order

    1. Check the firmware version and SMART state with the SSD maker's tool.
    2. Check whether BIOS and chipset driver updates are available.
    3. Compare with stornvme 129 and Disk 153 records from the same time.
    4. Check whether you recently installed a disk utility or backup program.
    5. Try adjusting the PCIe link speed or the SSD power-saving feature only when the maker gives guidance.
    Caution

    If freezes repeat along with the error, back up before you change settings.

    Do not ignore the record just because SMART is normal; keep checking how often it repeats.

    Frequently asked questions

    • Are stornvme 11 and Disk 11 the same event? The messages are similar, but the source differs. Disk 11 is a record left by the disk driver and stornvme 11 by the NVMe driver, so check the source first.
    • SMART is normal but it keeps appearing. What should I do? SMART does not show every problem. Compare firmware, BIOS and chipset driver updates and the power-management settings, and if there are freezes, note whether it repeats together with 129.
