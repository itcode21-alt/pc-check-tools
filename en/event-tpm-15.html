    EVENT ID 15

    TPM Event 15: Hardware Error

    TPM 15 records that the TPM (security chip) driver detected an unrecoverable error in the hardware. TPM-based features such as BitLocker and Windows Hello may not work properly. The cause is more likely BIOS firmware or the TPM module itself than a software setting.

    If the TPM is built into the motherboard (fTPM/PTT), it is often fixed by a BIOS firmware update. If it is a separate module plugged into a header, check the contact first.

    The TPM is the security chip used by BitLocker keys, Windows Hello and some other security features. When this record appears, those features may not work.

    When it appears

    • During boot or sign-in
    • While trying to use BitLocker or Windows Hello

    Likely causes

    • The motherboard BIOS/UEFI firmware is old and has a compatibility problem with the TPM module
    • A defect or failed initialization of the TPM firmware itself
    • Poor contact of the motherboard's TPM module (built in, or a separate header-mounted one)

    What to check, in order

    1. Secure the BitLocker recovery key first. Before touching the TPM, get the recovery key: for a personal PC from the device page of your Microsoft account, for a work PC from your administrator. If you clear the TPM without the key, you may not be able to open the drive.
    2. Check the status in tpm.msc. Type tpm.msc in the Run box to open the TPM Management console and check the status and the manufacturer version. If it says “Compatible TPM cannot be found”, the problem is in the hardware or BIOS settings.
    3. Update the BIOS firmware. Download the latest BIOS/UEFI from the motherboard or laptop maker and apply it. TPM-related fixes are often included, so some cases are resolved at this step.
    4. Check how the module is seated. If the motherboard uses a separate TPM module on a header, turn the power off and check that the module is fully inserted and facing the right way.
    Caution

    Before clearing (resetting) the TPM, always back up the recovery key of any BitLocker-encrypted drive. If you have BitLocker on, secure the recovery key first and, if possible, suspend BitLocker before you proceed.

    Frequently asked questions

    • Does TPM 15 mean I cannot use Windows 11? The PC will not stop booting right away, but features that depend on the TPM, such as BitLocker and Windows Hello, may be limited. It is often fixed by a BIOS update, so try that first.
    • Does resetting the TPM erase my data? Clearing the TPM does not itself erase drive data, but if the drive is encrypted with BitLocker and you do not have the recovery key, access can be blocked, so back up the recovery key first.
