    EVENT ID 100

    winsrvext Event 100: Session and Server Component Record

    winsrvext 100 is a record that the Windows server and session extension component leaves while working. The detailed message of this source can differ by Windows version and server role, so look at the Message, Task and session information in the General tab and the XML, not only the event ID.

    If there is no Remote Desktop disconnection or sign-in delay, it may be a one-off informational record. Only when there is a real functional failure, compare the time with TerminalServices and service events to narrow the cause.

    When it appears

    • After a Remote Desktop or terminal session connected or ended
    • While using a server role or session-based features
    • A one-off record in the system log without a functional failure

    Likely causes

    • A temporary state record of the Windows session or Remote Desktop extension component
    • A change in the server role, RDS configuration or related services
    • A compatibility problem with a recent Windows update, driver or session management program

    What to check, in order

    1. First write down the Message, Task, session and computer role information from the General tab and the XML.
    2. Compare with Remote Desktop, TerminalServices and Service Control Manager events at that time.
    3. Check whether there is a real sign-in or remote session drop or an app launch failure.
    4. If you use a server role or RDS, check the related service state and recent updates.
    5. If it is a one-off without symptoms, observe whether it repeats and whether it affects functions rather than acting. If it is still not resolved, consider the next cause.
    Caution

    The detailed meaning of winsrvext 100 can differ by configuration and Windows version. Do not judge a hardware failure or a security problem from the event ID alone.

    Frequently asked questions

    • Does winsrvext 100 mean the server or hardware is broken? No. It can be a state record of a server or remote session component. Check whether the times of real remote access, sign-in and session failures and the repeats match.
    • What if the General tab shows no special description? Copy the Provider, Task, Message and session or computer role fields from the XML view on the Details tab and analyze them together. It is hard to settle the meaning of this event from the ID alone.
