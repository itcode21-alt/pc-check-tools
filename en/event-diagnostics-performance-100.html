    EVENT ID 100

    Diagnostics-Performance Event 100: Boot Time Record

    100 is the Boot Performance Monitoring event that records the boot time when Windows startup finishes. The record itself is the result of normal operation, and when the time is long it is used as the starting point for investigating slow startup.

    Events 101–110 point to concrete causes such as the apps, drivers and services that delayed startup, so read them together when the time in 100 is long.

    This event is not in the System log. It is left under Applications and Services Logs > Microsoft > Windows > Diagnostics-Performance > Operational. In the event log analyzer's command builder, choosing “Slow startup or shutdown” collects from this log in one go.

    When it appears

    • Boot takes longer than usual
    • Boot time grows longer gradually over several days
    • Programs respond very late right after startup

    Likely causes

    • Many startup programs and services put a heavy load right after boot
    • Slow storage response (HDD, an unstable SSD)
    • Delays in driver or service initialization
    • Changes after a recent update or program installation

    What to check, in order

    1. Divide the Boot Duration value (milliseconds) in the event by 1000 and write it down in seconds.
    2. Check which app, driver or service the 101–110 events in the same log point to.
    3. Compare the items with a high impact in the Startup tab of Task Manager.
    4. Check whether storage events such as Disk 153 and Ntfs are at the same time.
    5. Compare boot time before and after reducing startup programs. If it is still not resolved, consider the next cause.
    Caution

    Do not judge from a single boot time. The first boot after an update commonly takes long.

    The event level shown can look different depending on the environment.

    Frequently asked questions

    • How do I read the Boot Duration number? It is in milliseconds (ms). Divide by 1000 to get seconds. The trend over several days and the increase against the usual value matter more than a single value.
    • 100 shows as an error level — is something wrong? The level display can look different depending on the environment, and 100 is an event that records boot time, so it does not mean a failure by itself. Look at the time value together with the 101–110 events.
