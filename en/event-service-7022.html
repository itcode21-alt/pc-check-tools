    EVENT ID 7022

    Service Control Manager Event 7022: Service Hung on Starting

    7022 records that a service stopped responding in the middle of starting. Where 7000 is logged when the start itself failed, 7022 is logged when it hung during the start.

    Microsoft's documentation suggests starting the service manually as a resolution. If it works when started manually, suspect a boot-time ordering or load problem; if it hangs even when started manually, suspect the service itself or one of its dependencies.

    When it appears

    • A feature starts late right after boot
    • The service seems stuck when started manually
    • Service start errors such as 7000, 7009 and 7011 appear with it

    Likely causes

    • Another service or driver that it depends on is not ready yet
    • Starting while storage or CPU load is high
    • Damaged program files or a configuration conflict
    • An error in the service's own startup code

    What to check, in order

    1. Check the service name and display name in the event. Start with what is easy to undo so you can narrow the range without risk.
    2. Try starting that service manually in the service manager. Compare with the first check to narrow the cause candidates.
    3. Check the state of the dependent services on the Dependencies tab of its properties. If it still reproduces at this step, move on to the next item.
    4. Compare with 7000, 7009 and 7011 and the storage events at the same time. See whether the symptoms differ before and after the change.
    5. Compare whether it reproduces after updating or repairing the related program. If it is still unsolved after all this, review the next cause.
    Caution

    Before deleting a service or changing its startup type, first check which program the service belongs to.

    If it is a core Windows service, make a restore point or a backup before editing the registry directly.

    Frequently asked questions

    • How are 7009 and 7022 different? 7009 is a record that the service did not send a connection response within the time limit, and 7022 is a record that the service hung while starting. They can be logged together for the same service, so compare the time and the service name.
    • It works when I start it manually but hangs only at boot. It may be a start-order or load problem. First check program updates and the dependent services, and try changing the startup type only if the program manufacturer allows it.
