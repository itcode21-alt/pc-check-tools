    EVENT ID 11

    Disk Event 11: The Driver Detected a Controller Error

    11 records that the disk controller detected an error on a disk device. It is classed as a clearer error signal than event 9; if it repeats on the same disk together with event 7, treat it as a storage problem.

    If it repeats during boot or heavy disk work such as file copies, note the conditions under which it reproduces and check the SMART state with the manufacturer's diagnostic tool; that helps narrow the cause.

    When it appears

    • Freezing during a file copy
    • Delays when a particular drive is accessed
    • A disk-recognition error during boot

    Likely causes

    • A loose SATA cable or port
    • A storage controller error
    • An M.2 or SATA SSD firmware problem

    What to check, in order

    1. Check the disk number shown in the error.
    2. Replace the SATA cable or change the port.
    3. Check the disk's health with the manufacturer's diagnostic tool.
    Caution

    If it repeats together with event 7, back up your data immediately.
