    EVENT ID 7040

    Service Control Manager Event 7040: Service Start Type Changed

    7040 is a configuration-change record saying a service's start type was changed. It is not an error, and updates, driver installs and management tools can also leave it.

    Check the service name and the old and new start types in the event, and match them against the installation and update records at the time of the change. If a needed function was switched off, restore only that service to its original state; do not switch everything to automatic.

    When it appears

    • After installing or updating a driver or security program
    • After a service was changed to automatic, manual or disabled
    • A particular function does not work after boot

    Likely causes

    • A normal program or driver installation
    • A Windows component update
    • A clean boot or the user changing service settings
    • An unwanted program switching off a security or update service

    What to check, in order

    1. Write down the service name and the old and new start types in the event. Start with what is easy to undo so you can narrow the range without risk.
    2. Compare with installation records, Windows Update and security events at the time of the change. Compare with the first check to narrow the cause candidates.
    3. Check whether the service is linked to a function you actually need. If it still reproduces at this step, move on to the next item.
    4. If it is an unexpected change of a security service, check Defender's state and recently installed programs. Compare the symptoms before and after the change.
    Caution

    7040 is a configuration-change record, not an error. If you set every service back to automatic start, boot delays or conflicts can occur.

    Frequently asked questions

    • The start type changed from automatic to manual — is that a problem? Windows components or programs often change it normally. Restore it only when that function really does not work.
    • What if a security-related service was turned off? If it is an unexpected change, check the Windows Security status and recently installed programs and run a scan.
