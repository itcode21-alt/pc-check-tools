    EVENT ID 30

    TPM Event 30: Security Chip State Record

    TPM 30 is a record the TPM provider or management component leaves while processing the security chip's state, keys and functions. First separate whether there is a real problem with Windows Hello or BitLocker, or it is a one-off state record.

    If it started after a motherboard replacement or a BIOS update, check the firmware settings, including Intel PTT and AMD fTPM. It is safer to leave actions that reset the TPM as the last step, after you have secured the recovery key.

    When it appears

    • While setting up or using a sign-in PIN or Windows Hello
    • After the BitLocker protection state changed
    • After a BIOS update, a TPM setting change or a motherboard replacement

    Likely causes

    • A problem with the BIOS/UEFI TPM, Intel PTT or AMD fTPM settings or firmware
    • A mismatch of TPM ownership, provisioning or the Windows Hello key state
    • A temporary error in the TPM WMI provider or a related Windows component

    What to check, in order

    1. Write down the error state, command and TPM version information from the General tab and the XML.
    2. Check the TPM ready state and protection state with tpm.msc and PowerShell Get-Tpm.
    3. Check the motherboard maker's BIOS and chipset updates and TPM-related change notes.
    4. Consider resetting the TPM only after you have secured the BitLocker recovery key and another way to sign in.
    5. If there is no problem with Windows Hello or BitLocker, first observe whether it is a one-off record and whether it repeats. If it is still not resolved, consider the next cause.
    Caution

    Clearing the TPM can cause trouble accessing the drive without the BitLocker recovery key. Do not reset it before you have checked the recovery key.

    Do not conclude a TPM chip failure or a security breach from event 30 alone.

    Frequently asked questions

    • Does TPM 30 mean the TPM is broken? No. You have to check whether there is a failure of Windows Hello or BitLocker together with the detailed error state in the event. Do not judge a chip failure from a one-off record.
    • Can I reset the TPM right away? First secure the BitLocker recovery key and another way to sign in. If you clear the TPM without checking the key, problems can occur with the encrypted drive or PIN sign-in.
