    EVENT ID 1530

    User Profile Service Event 1530: Registry Handles Cleaned Up

    1530 records that at sign-out an app or service did not close the user registry hive, so Windows cleaned it up for it. It is described as designed behavior, and a one-off is usually not urgent.

    It matters only when sign-out is really slow or it repeats after closing a particular app. Write down the process name shown in the event, and update that app or compare with a clean boot.

    When it appears

    • Sign-out or shutdown becomes slow
    • Repeats after closing a particular app
    • Only warnings pile up with no functional failure

    Likely causes

    • A background app keeps using the user's settings
    • An old program or service does not respond properly to the sign-out event
    • A delay in closing of security, sync or backup programs

    What to check, in order

    1. Write down the process name shown in the event and the time it occurred. Start with what is easy to undo so you can narrow the range without risk.
    2. Check whether sign-out is really delayed. Compare with the first check to narrow the cause candidates.
    3. Compare whether it reproduces after updating that app, changing its exit settings, and in a clean boot. If it still reproduces at this step, move on to the next item.
    4. If there is no functional failure, do not edit the registry just to reduce the number of events. Compare the symptoms before and after the change.
    Caution

    Do not conclude a memory leak or a damaged user profile from 1530 alone. A single, one-off warning is usually not urgent.

    Frequently asked questions

    • 1530 has piled up — is my profile damaged? It cannot be concluded that way. It is a record that an app did not close a handle, not profile damage, so unless sign-in problems or sign-ins to a temporary profile occur with it, it is something to observe.
    • Can I fix the registry to make it go away? It is not recommended. If there is no problem with functions, do not edit the registry just to reduce the number of records.
