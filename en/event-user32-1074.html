    EVENT ID 1074

    User32 Event 1074: Planned Shutdown or Restart

    1074 is an information record written when Windows receives a shutdown or restart request. Unlike Kernel-Power 41 it does not mean power was cut abruptly.

    Windows Update or an installer requesting a restart can be perfectly normal. If an unexpected process keeps requesting restarts, compare recently installed software and the Security log.

    When it appears

    • Automatic restart after Windows Update
    • Shutdown from the Start menu or the shutdown command
    • A management tool or installer requesting a reboot

    Likely causes

    • Shutdown by the user
    • Windows Update or an installer
    • A shutdown request sent by WMI or a management tool

    What to check, in order

    1. Record the process, user and Reason Code from the description.
    2. Compare with Windows Update and installer events at the same time.
    3. Check whether an actual reboot followed 1074 by comparing times with 6008 and Kernel-Power 41.
    Caution

    1074 is a record of a planned shutdown request. Do not conclude from it alone that a shutdown was unwanted or malicious.

    Frequently asked questions

    • Does 1074 mean the PC is broken? No. A user shutdown or restart, or Windows Update, also writes 1074. Compare the process name and time with what you actually did.
    • Should I look at 1074 together with Kernel-Power 41? Yes. 1074 shows who requested the shutdown; 41 shows that it did not end normally. Comparing the times helps separate a planned restart from a sudden power loss.
