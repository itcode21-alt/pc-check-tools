    EVENT ID 154

    Disk Event 154: Hardware I/O Error

    Disk 154 records that a disk I/O operation failed because of a hardware error. On servers and FC storage it can also come from a communication problem between the adapter and the storage array; on an ordinary PC, look at the disk, controller, cable and slot as a single path.

    If you double-click event 154 in Event Viewer, a properties window opens. It shows, in a sentence, that the source is disk and at which logical block address of which disk (PDO name) the error occurred.

    Even if files open and the PC seems normal again, repeated I/O errors can lead to data loss. Before any repair command, copy important files to another storage device first, and keep the disk number, LBA and port information from the event.

    When it appears

    • Freezes or delays while copying or saving files
    • Storage access errors during boot or while running programs
    • Disk 7, 11, 51, 129, 153 or Ntfs events repeat at the same time

    Likely causes

    • An I/O timeout of the storage device or controller
    • A contact problem with the SATA cable, power or M.2 slot
    • SSD/HDD firmware and chipset/storage driver problems
    • Link, adapter or storage-array communication errors in server and FC environments

    What to check, in order

    1. Back up important files to another storage device first.
    2. Record the disk number, LBA, port and error sentence from the event to identify the target device.
    3. Check health, temperature and media errors with SMART and the manufacturer's diagnostic tool.
    4. Check the SATA cable, power and M.2 seating, and cross-check with another port or slot.
    5. Group Disk, Ntfs, storahci and WHEA events by the same time and compare the conditions under which they repeat.
    6. In server or FC environments, also check the logs and firmware of the adapter, switch and storage vendor.
    Caution

    For a repeating 154, do not first run repair commands or change the disk timeout value in the registry. Data backup and checking the hardware path come first.
