    EVENT ID 25

    Volsnap Event 25: Why Shadow Copies Were Deleted and What to Check

    Volsnap 25 is an error-level record that the shadow copies of a volume (for example C:) were deleted because the shadow copy storage space could not grow in time. It means the reference point for features that depend on volume shadow copies, such as system restore points and Previous Versions, may be gone.

    It occurs in the middle of a large copy, install or backup that crowds disk I/O, or when the volume has almost no free space. If it repeats, raise the maximum usage for System Protection and free up space, and also check with the Disk and Ntfs events at the same time whether the storage device itself is a problem.

    When it appears

    • Shadow copy storage space runs short while disk I/O is heavy
    • System Protection or a backup program is using volume shadow copies

    Likely causes

    • The shadow copy storage space is short or grows too slowly to keep up with I/O
    • High disk load during a large copy, install or backup
    • A volume that is almost full

    What to check, in order

    1. Check the deleted volume (VolumeName) and the time. Start with what is easy to undo so you can narrow the range without risk.
    2. In the System Protection settings, check and raise the maximum usage for that drive. Compare with the first check to narrow the cause candidates.
    3. Check the free disk space and any large job (backup, copy) at the same time. If it still reproduces at this step, move on to the next item.
    4. Check whether there are Disk and Ntfs errors at the same time. See whether the symptoms differ before and after the change.
    Caution

    Restore points may have disappeared, so if you need an important recovery reference point, make a new backup. Do not conclude a disk failure from this event alone.

    Frequently asked questions

    • Did I lose my restore points when Volsnap 25 appears? It is a record that the shadow copies of that volume were deleted, so the restore points from that time may be gone. Check the remaining restore points in the System Protection settings and create a new one if needed.
    • Has the disk failed? This event often appears with storage-space or load problems and on its own is not grounds for a disk failure. Check whether events such as Disk 7, 11 and 153 and Ntfs 55 are present together.
