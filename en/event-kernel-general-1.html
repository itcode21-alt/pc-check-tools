    EVENT ID 1

    Kernel-General Event 1: Reading the System Time Change Record

    Kernel-General 1 records the old time, the new time, the difference (Time Delta) and the reason when the system time was changed. For example, 'System time synchronized with the hardware clock' means the time was corrected by synchronizing with the hardware clock.

    A record with a small difference left after waking from sleep or after the time service synchronizes is normal. If the difference is large and the reason is unclear, or the time drifts at every boot, check the motherboard CMOS battery and the BIOS clock setting.

    When it appears

    • During time synchronization, on waking from sleep, or when the time is changed manually

    Likely causes

    • The system time was synchronized with the hardware clock
    • A normal correction by the time service
    • The time was changed by a user or a program

    What to check, in order

    1. Check Time Delta (ms) and Reason.
    2. If the difference is large and the reason is unclear, check the BIOS clock and the motherboard (CMOS) battery.
    3. Check whether Process is a program that changes the time.
    Caution

    If Reason is synchronization with the hardware clock and the difference is small, it is a normal correction.

    Frequently asked questions

    • It says the system time changed — who changed it? Look at Process and Reason in the body. If it is the time service (w32time) or hardware clock synchronization it is normal; if an unfamiliar program appears, check that program.
    • What if the time drifts at every boot? A drained CMOS battery (the coin cell on the motherboard) is a common cause. If it repeats even after you set the BIOS clock, try replacing the battery.
