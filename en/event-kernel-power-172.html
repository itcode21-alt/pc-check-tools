    EVENT ID 172

    Kernel-Power Event 172: Connectivity State in Standby

    Kernel-Power 172 is an informational record of whether the network connection is kept or dropped in standby, and the reason. For example, “Disconnected, Reason: NIC compliance” means a policy dropped the connection because the network adapter did not meet the requirements for staying connected in standby.

    The record is written every time the PC goes to sleep, so a high count is natural. Check the adapter driver and power management settings only when the internet really does not come back right after waking from sleep.

    When it appears

    • When entering sleep or standby
    • PCs that support Modern Standby

    Likely causes

    • A normal standby connectivity policy (Disconnected/Connected)
    • The network adapter or driver does not support the conditions for staying connected in standby

    What to check, in order

    1. Check only when the network comes back disconnected after resuming from sleep. Start with what is easy to undo so you can narrow the range without risk.
    2. Check the network adapter's power management option and the driver version. Compare with the first check to narrow the cause candidates.
    Caution

    Disconnected by itself is not an error. If there is no symptom, no action is needed.

    Frequently asked questions

    • 172 keeps appearing — is that a problem? Not if there is no symptom. It is written as many times as the PC enters sleep.
    • What if the network is down after sleep? In Device Manager, turn off the network adapter's power management option (Allow the computer to turn off this device to save power), update the adapter driver to the latest manufacturer version, and check whether it still reproduces.
