EVENT ID 100

Diagnostics-Performance 이벤트 100 부팅 시간 기록 점검

Windows 시작이 끝났을 때 부팅에 걸린 시간(Boot Duration)을 남기는 기록입니다. 기록 자체는 정상 동작의 결과이고, 시간이 길게 나온 경우에 느린 시작을 조사하는 출발점으로 씁니다.

100은 Windows 시작이 끝났을 때 부팅 시간을 남기는 Boot Performance Monitoring 이벤트입니다. 101~110은 시작을 지연시킨 앱·드라이버·서비스처럼 구체적인 원인을 짚는 이벤트라서, 100의 시간이 길 때는 함께 읽어야 합니다.

이 이벤트는 시스템 로그가 아니라 응용 프로그램 및 서비스 로그 > Microsoft > Windows > Diagnostics-Performance > Operational에 남습니다. 이벤트 로그 해석기의 수집 명령 만들기에서 "부팅·종료가 느림"을 고르면 이 로그에서 한 번에 모을 수 있습니다.

발생 조건

  • 부팅이 평소보다 오래 걸림
  • 부팅 시간이 며칠에 걸쳐 점점 길어짐
  • 시작 직후 프로그램이 한참 늦게 반응

가능성 높은 원인

  • 시작 프로그램·서비스가 많아 부팅 직후 부하가 큼
  • 저장장치 응답 지연(HDD, 불안정한 SSD)
  • 드라이버·서비스 초기화 지연
  • 최근 업데이트나 프로그램 설치 이후의 변화

점검 순서

  1. 이벤트의 Boot Duration(밀리초) 값을 1000으로 나눠 초로 기록 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 같은 로그의 101~110 이벤트가 어떤 앱·드라이버·서비스를 지목하는지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 작업 관리자 시작 프로그램 탭에서 영향이 큰 항목 비교 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. Disk 153·Ntfs 같은 저장장치 이벤트가 같은 시각에 있는지 확인 — 변경 전후로 증상이 달라지는지 비교해보세요.
  5. 시작 프로그램을 줄이기 전과 후의 부팅 시간 비교 — 여기까지 확인해도 해결되지 않으면 다음 원인을 검토하세요.
주의사항

부팅 시간 한 번만으로 문제를 단정하지 마세요. 업데이트 직후 첫 부팅은 오래 걸리는 것이 흔합니다.

이벤트 수준 표시는 환경에 따라 다르게 보일 수 있습니다.

자주 묻는 질문

  • Boot Duration 숫자는 어떻게 읽나요? 밀리초(ms) 단위입니다. 1000으로 나누면 초가 됩니다. 한 번의 값보다 며칠에 걸친 추세와 평소 값 대비 증가가 더 중요합니다.
  • 100이 오류 수준으로 보이는데 문제가 있는 건가요? 수준 표시는 환경에 따라 다르게 보이며, 100은 부팅 시간을 기록하는 이벤트라 그 자체가 장애를 뜻하지는 않습니다. 시간 값과 101~110 이벤트를 함께 보세요.
