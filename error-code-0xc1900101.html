에러 코드 상세

0xC1900101 · 업데이트 드라이버 호환성 실패

Microsoft 지원 문서에서 호환되지 않는 드라이버 때문에 업데이트가 실패할 때의 코드로 안내합니다. 네트워크·그래픽 드라이버 제거·업데이트와 클린 부팅을 확인합니다.

0xC1900101은 Windows 업그레이드·기능 업데이트가 드라이버 문제로 실패할 때 나오는 코드군입니다. Microsoft 지원 문서는 호환되지 않는 드라이버를 원인으로 설명하고 네트워크·그래픽 드라이버 제거·업데이트와 클린 부팅을 안내합니다.

이 코드를 어떻게 해석해야 하나요?

Microsoft의 업데이트 문제 해결 문서는 0xC1900101을 호환되지 않는 드라이버가 업데이트를 실패하게 하는 경우로 설명합니다. 안내하는 순서는 장치 관리자에서 네트워크 어댑터나 디스플레이 어댑터를 제거한 뒤 재시작, 같은 어댑터의 드라이버를 자동 검색으로 업데이트, 필수가 아닌 시작 프로그램과 서비스를 끄는 클린 부팅입니다. 설치 로그 분석(SetupDiag), 저장장치·USB 장치·BIOS 점검은 Microsoft 업그레이드 문제 해결 문서나 문서 외 일반 점검에 해당합니다.

가능성 높은 원인

  • 저장장치(SSD/NVMe) 컨트롤러 드라이버가 새 Windows 빌드와 호환되지 않는 경우
  • 그래픽 드라이버가 업그레이드 과정에서 초기화에 실패하는 경우
  • USB로 연결된 외장 장치(프린터, 외장하드, 카드리더 등)의 드라이버가 충돌하는 경우
  • 메인보드 BIOS나 제조사 전용 유틸리티가 오래되어 업그레이드 절차와 맞지 않는 경우
  • 이전 업그레이드 시도의 잔여 파일이 새 시도와 충돌하는 경우

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 장치 관리자에서 네트워크 어댑터나 디스플레이 어댑터를 펼쳐 해당 어댑터를 우클릭해 '디바이스 제거'를 선택하고 PC를 다시 시작하세요(어댑터 드라이버는 재시작 후 다시 잡힙니다).
  2. 공식 문서가 알려 주는 것: 같은 어댑터를 우클릭해 '드라이버 업데이트' > '드라이버 자동 검색'으로 최신 드라이버를 설치하세요.
  3. 공식 문서가 알려 주는 것: 필수가 아닌 시작 프로그램과 서비스를 끄는 클린 부팅 상태에서 업데이트를 다시 시도하세요.
  4. 문서 외 일반 점검: 업그레이드 전 외장 USB 장치(프린터, 외장 하드, 카드 리더 등)를 모두 분리하고, 저장장치(SSD/NVMe) 드라이버와 그래픽 드라이버를 제조사 최신 버전으로 맞추세요.
  5. 문서 외 일반 점검: 메인보드 제조사 홈페이지에서 BIOS와 칩셋 드라이버가 최신인지 확인하고, setupact.log 또는 SetupDiag로 실패를 일으킨 드라이버 이름을 확인하세요.

확인 결과에 따른 다음 단계

  • 외장 장치 분리만으로 해결될 때 — 외장 USB와 SD 카드 등을 모두 분리한 뒤 업데이트를 다시 시도하세요.
  • 드라이버 업데이트로 해결될 때 — 장치 관리자에서 노란색 경고 표시가 있는 장치의 드라이버를 제조사 최신 버전으로 업데이트하세요.
  • 클린 업그레이드로도 해결되지 않을 때 — Microsoft의 SetupDiag 도구로 로그를 분석해 원인 드라이버를 확인하세요.

해결 사례 예시

위 점검 순서로도 해결되지 않았을 때 다른 원인으로 해결될 수 있는 예시입니다. 실제 제보를 그대로 옮긴 것이 아니라 일반적인 사례를 바탕으로 구성한 참고용 예시이며, 환경에 따라 결과가 다를 수 있습니다.

구형 드라이버 수동 제거 후 업그레이드 성공

윈도우 10에서 11로 업그레이드 시도 시 이 오류가 반복됐던 사례가 있습니다. SetupDiag 도구로 분석하니 구형 네트워크 카드 드라이버가 원인으로 지목됐고, 해당 드라이버를 제거한 뒤 업그레이드를 다시 시도하자 성공했습니다.

포인트: 업그레이드 중 이 오류가 발생하면 SetupDiag 도구를 먼저 실행해 정확한 원인 드라이버를 찾는 것이 효율적입니다. 원인 드라이버를 제거하고 업그레이드 후 다시 설치하면 됩니다.

데이터와 시스템을 보호하는 주의사항

레지스트리 정리 도구를 쓰거나 시스템 폴더 권한을 바꾸기 전에, 저장 공간과 네트워크, 서비스 상태부터 점검하는 것이 우선입니다.

앞 단계로 해결되지 않을 때

코드가 재발할 경우 Windows Update 기록과 DISM·SFC 결과를 기록해 두고, 설치 미디어의 Windows 버전이 현재 시스템과 일치하는지 확인해보세요.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

공식 참고자료

Microsoft 지원: Windows 업데이트 문제 해결 (0xC1900101)

자주 묻는 질문

  • 0xC1900101이 나오면 윈도우를 새로 설치해야 하나요? 아닙니다. Microsoft 지원 문서는 먼저 네트워크·그래픽 드라이버 제거와 업데이트, 클린 부팅을 안내합니다. 클린 설치는 이런 점검으로 해결되지 않을 때 검토할 선택지입니다.
  • 어떤 드라이버가 문제인지 어떻게 아나요? 코드만으로는 알 수 없습니다. Microsoft 업그레이드 문제 해결 문서는 SetupDiag 같은 도구로 설치 로그를 분석해 원인 드라이버를 찾는 방법을 소개합니다.
