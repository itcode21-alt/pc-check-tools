코드 45 · 이 하드웨어 장치가 현재 연결되어 있지 않습니다 (코드 45)

이전에 연결했던 장치가 현재는 물리적으로 연결되어 있지 않을 때 나타나는 코드입니다. 블루투스 장치에서 가장 흔하지만 USB 드라이브·프린터·도킹 스테이션의 주변기기 등 어떤 장치에서도 나타날 수 있으며, 장치 자체보다 드라이버가 이전 연결 기록만 남긴 상태인 경우가 많습니다.

이 코드를 어떻게 해석해야 하나요?

이 코드만으로 특정 부품의 고장을 단정할 수는 없습니다. 발생 시점과 재현 조건, 최근 변경 사항, 안전 모드 결과를 함께 기록하면 원인 범위를 좁히는 데 도움이 됩니다.

먼저 기록할 내용: 코드 45가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 장치가 물리적으로 분리되었거나 블루투스 페어링이 해제된 경우
  • 장치를 제거한 뒤에도 드라이버 잔여 항목이 남아 있는 경우
  • 다른 USB 포트로 옮긴 뒤 이전 포트의 항목이 그대로 남는 경우
  • 도킹 스테이션·USB 허브를 분리한 뒤 그 안에 연결됐던 장치 항목이 남는 경우
  • 절전·최대 절전에서 복귀하며 장치 재초기화가 지연되는 경우

첫 점검 항목

  1. 실제 연결 상태 확인 — 장치가 지금 정말 꺼져 있거나 분리되어 있는지 먼저 확인하세요. 전원을 켜거나 다시 연결한 뒤 몇 초 기다려 자동으로 항목이 사라지는지 봅니다.
  2. 숨겨진 장치 정리 — 장치 관리자 상단 메뉴 보기에서 "연결이 끊긴 장치 표시"를 켜고, 회색으로 흐리게 표시되는 이전 항목을 마우스 오른쪽 클릭으로 제거하세요.
  3. 블루투스라면 페어링 재등록 — 설정 > Bluetooth 및 장치에서 해당 장치를 제거한 뒤, 장치를 페어링 모드로 만들고 새로 등록하세요.
  4. USB·도킹 장치라면 포트를 바꿔 재현 확인 — 본체의 다른 포트에 직접 연결해 같은 코드가 나는지 비교하면 포트·허브 문제인지 장치 문제인지 구분할 수 있습니다.
  5. 어댑터·컨트롤러 드라이버 재설치 — 위 방법으로도 반복된다면 블루투스 어댑터나 USB 컨트롤러 드라이버를 제거한 뒤 재부팅해 자동 재설치되도록 하세요.

확인 결과에 따른 다음 단계

  • 연결·재연결 시 항목이 정상으로 바뀔 때 — 별다른 조치가 필요 없는 정상 동작입니다. 장치를 분리하면 회색으로 표시되는 것이 정상입니다.
  • 숨겨진 장치를 지워도 계속 다시 생길 때 — 어댑터·컨트롤러 드라이버나 절전 설정을 의심하고 4·5번 단계를 진행하세요.
  • 특정 포트에서만 반복될 때 — 장치보다 그 포트나 허브의 접촉·전력 공급 문제일 가능성이 큽니다.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

시스템 복구나 초기화, 드라이버 삭제처럼 원상복구가 힘든 작업을 시작하기 전에, 중요한 파일은 미리 외장 저장장치나 별도 위치에 백업해 두세요.
