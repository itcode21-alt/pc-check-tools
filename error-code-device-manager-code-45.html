코드 45 · 이 하드웨어 장치가 현재 연결되어 있지 않습니다 (코드 45)

연결이 끊긴 장치를 알리는 상태 표시이며, 고칠 필요가 없는 경우가 많습니다. 장치를 다시 연결하면 저절로 사라진다고 Microsoft가 안내합니다.

이 코드를 어떻게 해석해야 하나요?

Microsoft의 장치 관리자 오류 코드 문서에서 코드 45는 '현재 이 하드웨어 장치는 컴퓨터에 연결되어 있지 않다'는 메시지이고, 해결이 필요하지 않으며 연결이 끊긴 상태를 나타내기 위한 코드라고 설명합니다. 해당 장치를 컴퓨터에 연결하면 오류 코드가 자동으로 사라집니다. 그래서 장치를 쓰지 않는 동안 이 코드가 보이는 것은 정상이고, 연결했는데도 계속 보일 때만 케이블·포트·드라이버를 점검하면 됩니다. 블루투스 장치에만 해당하는 코드는 아닙니다.

가능성 높은 원인

  • 장치가 지금 컴퓨터에 물리적으로 연결되어 있지 않은 경우 — Microsoft 문서가 정의하는 이 코드의 의미입니다
  • 예전에 쓰던 USB·블루투스 등의 장치 항목이 숨겨진 장치로 남아 있는 경우(문서 외 일반 설명)
  • 장치를 다른 포트로 옮겨서 이전 포트의 항목이 남은 경우(문서 외 일반 설명)

첫 점검 항목

  1. 그 장치를 지금 쓰고 싶다면 컴퓨터에 다시 연결하세요. Microsoft 문서에 따르면 장치를 연결하면 이 오류 코드는 자동으로 사라집니다.
  2. 연결했는데도 코드 45가 남는다면 케이블·포트·전원을 확인하고, 다른 포트에 꽂아 보세요.
  3. 쓰지 않는 장치라면 아무것도 하지 않아도 됩니다. 장치 관리자 보기 메뉴에서 '숨겨진 장치 표시'를 켜지 않으면 이런 항목이 보이지 않는 경우가 많습니다(문서 외 일반 설명).
  4. 남은 항목을 정리하고 싶을 때만: 보기 > 숨겨진 장치 표시를 켠 뒤 더 이상 쓰지 않는 장치를 우클릭해 '장치 제거'를 선택하세요. 지금 쓰는 장치를 지우지 않도록 장치 이름을 먼저 확인합니다(문서 외 일반 점검).

확인 결과에 따른 다음 단계

  • 장치를 다시 연결하자 항목이 정상으로 바뀔 때 — 정상입니다. 아무 조치도 필요하지 않습니다.
  • 연결했는데도 코드 45가 남을 때 — 다른 포트와 케이블로 바꿔 보고, 그래도 같다면 장치 드라이버 점검으로 넘어가세요. 코드 28과 코드 10 페이지에서 드라이버 재설치 순서를 확인할 수 있습니다.
  • 쓰지 않는 장치의 항목만 보일 때 — 그대로 두어도 문제가 없습니다. 정리하고 싶다면 숨겨진 장치 표시를 켠 뒤 쓰지 않는 항목만 제거하세요.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

시스템 복구나 초기화, 드라이버 삭제처럼 원상복구가 힘든 작업을 시작하기 전에, 중요한 파일은 미리 외장 저장장치나 별도 위치에 백업해 두세요.

자주 묻는 질문

  • 코드 45는 고쳐야 하는 오류인가요? 아니요. Microsoft 문서는 이 코드가 연결이 끊긴 장치의 상태를 알릴 뿐 해결이 필요하지 않으며, 장치를 연결하면 자동으로 사라진다고 안내합니다. 장치를 쓰고 있는데 안 되는 것이 아니라면 그대로 두셔도 됩니다.
  • 장치는 꽂혀 있는데 코드 45가 보입니다. 포트·케이블·허브 전원을 먼저 확인하고 다른 포트에 연결해 보세요. 그래도 같다면 코드 45 자체보다 드라이버 쪽 문제일 수 있으니 코드 28(드라이버 없음)이나 코드 10(장치를 시작할 수 없음) 페이지의 점검 순서를 이어서 따르세요.
  • 회색으로 보이는 옛 항목을 지워도 되나요? 더 이상 쓰지 않는 장치라면 지워도 됩니다. 다만 지금 쓰는 장치의 항목을 지우면 장치를 다시 연결하거나 '하드웨어 변경 사항 검색'을 해야 하니, 장치 이름을 먼저 확인하세요.
