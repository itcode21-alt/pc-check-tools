정보(INFORMATION) 수준 이벤트 16건

부팅 때마다 남는 정보 기록 — Kernel-Boot·Kernel-General·EventLog 6009

이벤트 뷰어의 시스템 로그를 열면 부팅 직후 정보(Information) 수준 기록이 줄줄이 남아 있습니다. 대부분은 부팅 구성과 시간을 보고하는 정상 기록이며, 이 기록이 있다는 사실만으로 PC에 문제가 있다고 볼 수 없습니다.

이 묶음은 부팅 옵션, 펌웨어가 알려 준 부팅 시간, 시스템 시간 초기화, 레지스트리 유지 관리 같은 기록입니다. 값을 읽어야 의미가 생기는 기록이라, 평소에는 지나쳐도 됩니다.

실제로 쓸 일이 생기는 때는 두 가지입니다. 부팅이 느려서 펌웨어 단계가 긴지 보고 싶을 때(Kernel-Boot 30), 부팅 시각이 어긋나 보일 때(Kernel-Boot 238, Kernel-General 25)입니다.

이 페이지에서 설명하는 기록

원본·ID의미확인할 때
Kernel-Boot 18이 시스템에 설정된 부팅 항목 수(boot options)를 기록합니다.멀티부팅 구성이 의도와 다르면 부팅 항목 수 확인
Kernel-Boot 25부팅 메뉴 정책 값을 기록합니다.부팅 메뉴 동작을 조사할 때 참고
Kernel-Boot 27부팅 종류(BootType)와 로드 옵션(NOEXECUTE, FVEBOOT 등)을 기록합니다.부팅 옵션을 조사할 때 참고
Kernel-Boot 30펌웨어가 보고한 부팅 시간 지표(OS 이미지 로드 시작·부팅 서비스 종료 시점 등)를 기록합니다.부팅이 느릴 때 펌웨어 단계 시간이 긴지 값을 비교
Kernel-Boot 32부트 매니저가 사용자 입력을 기다린 시간(BitlockerUserInputTime)을 기록합니다.BitLocker PIN 입력 때문에 부팅이 늦다면 이 값 확인
Kernel-Boot 238UEFI 펌웨어가 알려 준 시간대 편향과 펌웨어 시간을 기록합니다.부팅 시각이 어긋나 보이면 BIOS 시계와 메인보드 배터리(CMOS) 확인
Kernel-General 15레지스트리 하이브가 재구성(reorganized)되어 크기가 줄었음을 기록합니다.하이브 이름과 크기 변화를 확인
Kernel-General 16레지스트리 하이브의 접근 기록(access history)이 지워졌음을 기록합니다.반복 횟수가 많아도 정상
Kernel-General 20윤초(leap second) 설정이 갱신되었음을 기록합니다.시간 동기화 문제를 조사할 때 참고
Kernel-General 24시간대 정보가 갱신되었음을 기록합니다.시간이 어긋나면 시간대 설정 확인
Kernel-General 25부팅 때 시스템 시간이 초기화된 값(RTC 시각, 로더 시각, Success 여부)을 기록합니다.Success가 false거나 RTC 오류 코드가 0이 아니면 메인보드 배터리와 BIOS 시계 확인
EventLog 6009부팅할 때 Windows 버전·빌드와 프로세서 구성(예: Multiprocessor Free)을 기록하는 정보성 이벤트입니다.부팅 시각과 Windows 빌드를 확인할 때 6005·6013과 함께 참고
Subsys-SMSS 17플랫폼 바이너리(펌웨어가 제공한 실행 파일)가 성공적으로 실행되었음을 기록합니다.펌웨어가 설치하는 프로그램이 의심되면 실행 여부 확인
Wininit 23부팅 앱 롤백 방지(Boot App Anti-Rollback) 초기화 결과를 기록합니다.HRESULT가 성공이 아닌 경우에만 확인
Wininit 24부팅 앱 롤백 방지 타이머가 시작되었음을 기록합니다(시작 시각·유예 기간·만료 시각 포함).Win32Error가 0이 아닌 경우에만 확인
Wininit 25이전 부팅 앱 롤백 방지 타이머가 이어졌음을 기록합니다.HRESULT가 성공이 아닌 경우에만 확인

걱정해야 하는 때

  • 같은 시각에 오류(Error)·경고(Warning) 수준 기록이 없으면 이 묶음은 무시해도 됩니다.
  • 시각이 어긋나 보이면 Kernel-General 25의 Success 값과 RTC 오류 코드, Kernel-Boot 238의 펌웨어 시간을 보고 BIOS 시계와 메인보드 배터리(CMOS)를 확인합니다.
  • 부팅이 느리면 Kernel-Boot 30의 펌웨어 단계 시간을 다른 날과 비교하고, BitLocker PIN 입력 때문이라면 Kernel-Boot 32의 값이 0이 아닌지 봅니다.
  • Wininit 23·24·25는 부팅 앱 롤백 방지 기능의 기록입니다. HRESULT나 Win32Error가 성공(0)이 아닐 때만 확인합니다.
주의사항

정보 수준 기록 하나만으로 부품 고장이나 보안 사고를 판단하지 마세요. 같은 시각의 오류·경고 기록과 실제 증상(끊김, 재부팅, 느려짐)이 함께 있을 때만 단서로 씁니다.

자주 묻는 질문

  • 부팅 때마다 이런 기록이 남는데 PC가 고장 난 건가요? 아닙니다. 정보 수준 기록은 정상 부팅 과정을 보고하는 것이며, 오류를 뜻하지 않습니다. 같은 시각의 오류·경고 기록과 실제 증상이 있을 때만 단서로 씁니다.
  • Kernel-Boot 153도 이 묶음인가요? 아닙니다. Kernel-Boot 153은 가상화 기반 보안 사용 기록이라 별도 묶음(VBS·보안 기록 페이지)에서 설명합니다. 디스크 153이나 그래픽 드라이버 153과는 원본이 다릅니다.
