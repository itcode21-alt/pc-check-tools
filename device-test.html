키보드·모니터·마이크·웹캠·스피커·그래픽 테스트

PC에 연결된 입력·출력 장치가 제대로 동작하는지 브라우저에서 바로 확인합니다. 설치할 프로그램은 없습니다.

🔒 브라우저에서만 처리 · 서버로 전송되지 않음

개인정보 안내 카메라 영상과 마이크 소리는 서버로 전송하지 않고, 녹화·저장도 하지 않으며 이 브라우저 안에서만 처리됩니다. 페이지를 닫거나 "중지"를 누르면 카메라와 마이크 사용이 끝납니다. 카메라·마이크는 보안 연결(https)에서만 사용할 수 있고, 브라우저가 권한을 물어보면 "허용"을 눌러야 합니다.

1. 키보드 테스트

아래 영역을 클릭한 뒤 키를 눌러 보세요. 눌린 키는 초록색으로 표시되어, 안 눌리는 키를 한눈에 찾을 수 있습니다. 점선 테두리 키(한/영·한자)는 한국어 키보드에만 있습니다.

여기를 클릭한 뒤 키를 눌러 보세요.

눌러 본 키 0개

Windows 키·PrintScreen·일부 기능키는 브라우저나 운영체제가 먼저 가져가서 표시되지 않을 수 있습니다. 이 경우 키 자체의 고장이 아닙니다.

2. 모니터 불량화소 테스트

화면 전체를 검정·흰색·빨강·초록·파랑·회색으로 차례로 채웁니다. 한 가지 색 위에서 다른 색으로 보이는 점(밝은 점·어두운 점)이 있는지 살펴보세요. 클릭하거나 스페이스·→ 키로 다음 색, ← 키로 이전 색, Esc 키로 종료합니다.

같은 위치에 계속 보이는 점이 있다면 먼저 화면 청소와 케이블 연결을 확인하고, 다른 해상도·다른 케이블에서도 같은지 비교해 보세요.

3. 마이크 레벨 테스트

마이크에 말을 하면 소리 크기가 막대로 표시됩니다. 소리는 스피커로 다시 재생하지 않습니다.

대기 중

4. 웹캠 미리보기

웹캠 화면이 나오는지, 밝기와 초점이 괜찮은지 확인합니다. 영상은 이 화면에만 표시됩니다.

5. 스피커 좌우 테스트

왼쪽·오른쪽 스피커에서 각각 테스트음이 나오는지 확인합니다. 왼쪽 버튼을 눌렀을 때 오른쪽에서 소리가 나거나, 한쪽에서만 소리가 나면 연결이나 설정을 확인해야 합니다.

소리가 갑자기 날 수 있으니 볼륨을 낮춘 뒤 시작하세요. 테스트음은 약 1초 동안 재생됩니다.

6. 그래픽(GPU) 확인

브라우저가 인식한 그래픽 장치와 하드웨어 가속 여부를 보여 주고, 짧은 화면 렌더링으로 깨짐·끊김을 눈으로 확인합니다. 성능 점수를 내는 벤치마크가 아니라 간이 점검입니다. 표시되는 정보는 이 브라우저 안에서만 쓰이고 서버로 전송하지 않습니다.

렌더링·부하 테스트 중에는 화면이 깜빡이거나 잠시 멈출 수 있습니다. 저사양 PC나 노트북에서는 부하 테스트 전에 작업 중인 문서를 저장하세요. 이상하면 "중지"를 누르세요.

테스트 결과가 이상하다면

  • 마이크·웹캠이 안 잡히면 주소창의 자물쇠 아이콘 → 사이트 설정에서 권한을 확인하고, 화상회의 프로그램이 장치를 쓰고 있지 않은지 확인하세요.
  • 윈도우에서 장치가 보이지 않으면 진단 도구나 장치 관리자 오류 코드 찾기로 원인 후보를 확인할 수 있습니다.
  • 그래픽 장치가 "소프트웨어 렌더링"으로 나오거나 화면 깨짐·끊김이 보이면 그래픽 드라이버 재설치 방법과 그래픽카드 화면 깨짐 가이드를 확인하세요. 테스트 중 화면이 꺼졌다 켜졌다면 그래픽 드라이버 응답 없음(복구됨)도 함께 보세요.
  • 직접 해결이 어렵다면 원격 점검 2만원을 이용해 보세요. 하드웨어 고장은 제조사 A/S 안내를 확인하세요.
