Windows 저장장치 이슈

홈진단가이드PC 추천

STORAGE ISSUE · 2026-07-29

Windows 11 C 드라이브 용량이 계속 줄어든다면 저장장치 공간 누수를 확인하세요

특정 Windows 기록 파일이 비정상적으로 커져 SSD·HDD의 여유 공간을 차지하는 저장장치 공간 누수 사례가 보고됐습니다.

무슨 문제가 발생했나요?

Windows 11 일부 환경에서 CapabilityAccessManager.db-wal 파일이 정상 범위를 넘어 커지는 현상이 보고됐습니다. 이 파일은 앱의 카메라·마이크·위치·화면 캡처 같은 권한 요청을 기록하는 데이터베이스의 임시 기록 파일입니다. 일반적으로는 기록이 데이터베이스에 반영되면서 크기가 관리되어야 하지만, 문제가 발생한 시스템에서는 기록이 정리되지 않고 계속 누적되는 것으로 추정됩니다.

실제로 줄어드는 것은 C 드라이브의 저장공간입니다. Windows 설정에서는 해당 파일이 별도로 보이지 않고 시스템 및 예약 또는 시스템 파일 용량으로 표시될 수 있어 원인을 찾기 어려울 수 있습니다.

대표적인 증상

  • 파일을 많이 저장하지 않았는데 C 드라이브 여유 공간이 계속 감소합니다.
  • Windows 설정의 시스템 파일 또는 시스템 및 예약 공간이 비정상적으로 커집니다.
  • 디스크 정리를 실행해도 공간이 충분히 회복되지 않습니다.
  • SSD 여유 공간 부족, 업데이트 설치 실패, 프로그램 설치 실패가 이어질 수 있습니다.

내 PC가 영향을 받았는지 확인하는 순서

  1. 저장소 화면 확인: 설정 → 시스템 → 저장소 → 더 많은 범주 표시 → 시스템 및 예약 → 시스템 파일 순서로 들어갑니다.
  2. 실제 파일 확인: 다음 경로의 파일 크기를 확인합니다. C:\ProgramData\Microsoft\Windows\CapabilityAccessManager\CapabilityAccessManager.db-wal
  3. 증가 여부 기록: PC를 재시작한 뒤 파일 크기를 기록하고, 몇 시간 후 같은 파일이 다시 커지는지 비교합니다.

관리자 권한 명령 프롬프트에서 아래 명령을 실행하면 파일을 복사하거나 삭제하지 않고 목록과 크기만 확인할 수 있습니다.

robocopy "C:\ProgramData\Microsoft\Windows\CapabilityAccessManager" "%TEMP%\CAMCheck" /L /B /R:0 /W:0 /BYTES /NP

여기서 /L은 목록만 표시하는 옵션입니다. 해당 파일이 수 GB 이상이거나 몇 분 간격으로 계속 증가한다면 이 현상과 일치할 가능성이 높습니다. 단, 파일 크기만으로 원인을 확정하지 말고 최근 Windows 업데이트와 저장소 사용량도 함께 기록하세요.

해결 방법과 업데이트

Microsoft는 Windows 11 24H2와 25H2용 KB5095093 업데이트 설명에서 “CapabilityAccessManager.db-wal 파일의 디스크 공간 사용을 개선”했다고 밝혔습니다. 공개된 빌드는 24H2의 26100.8737, 25H2의 26200.8737입니다.

  1. 중요한 문서와 사진을 외장 저장장치나 클라우드에 먼저 백업합니다.
  2. 설정 → Windows 업데이트에서 최신 누적 업데이트를 설치합니다.
  3. PC를 다시 시작한 뒤 해당 파일이 더 이상 증가하지 않는지 확인합니다.
  4. 업데이트 후에도 증가하면 파일 크기, Windows 버전, 최근 설치한 앱의 권한 사용 여부를 기록합니다.

파일을 바로 삭제해도 될까요?

실행 중인 Windows에서 해당 파일을 임의로 삭제하는 것은 권장하지 않습니다. 이 파일은 권한 관리 구성 요소와 연결되어 있고, 잘못된 파일이나 폴더를 지우면 관련 기능에 문제가 생길 수 있습니다. 특히 C 드라이브가 거의 가득 차 업데이트가 불가능한 상황이라면, 안전 모드나 Windows 복구 환경에서 조치해야 할 수 있으므로 먼저 백업하고 전문가에게 문의하는 편이 안전합니다.
