리니지 클래식 오류 모음 — 원인과 해결 방법

설치·업데이트 도중 자주 보고되는 오류 2가지를 NCSOFT 공식 공지 기준으로 정리했습니다.

바로 이동

  • 업데이트 중 npkcmsvc.exe.gz 압축 해제에 실패해 설치·업데이트가 멈추는 문제 (업데이트 실패)
  • 게임 실행 시 'xml 파일을 읽어들일 수 없습니다' 오류로 접속이 안 되는 문제 (xml 읽기 실패)

업데이트 중 npkcmsvc.exe.gz 압축 해제에 실패해 설치·업데이트가 멈추는 문제 · 업데이트 실패

설치/업데이트

리니지 클라이언트 업데이트 중 npkcmsvc.exe.gz 파일 압축을 풀지 못해 설치·업데이트가 중단되는 문제입니다. 보안 관련 상주 프로세스인 Npkcmsvc가 실행 중인 상태에서는 해당 파일에 접근할 수 없어 발생합니다.

가능한 원인

  • Npkcmsvc(보안 모니터링 상주 프로세스)가 실행 중이어서 설치 파일 접근이 차단되는 경우
  • 이전 설치의 잔여 파일이나 관련 서비스가 완전히 종료되지 않은 경우

점검 순서

  1. 1단계 - 공식 제거 도구 실행:
    ① NCSOFT에서 제공하는 npkuninst.exe 파일을 받아 실행
    ② PC를 재부팅한 뒤 런처를 다시 실행
  2. 2단계 - 서비스 수동 중지:
    ① 관리자 권한 명령 프롬프트에서 sc stop npkcmsvc 명령 실행
    ② 설치를 다시 시도

참고 자료

NCSOFT 공식 공지: 런처 실행 오류 발생 시 해결 방법 안내

게임 실행 시 'xml 파일을 읽어들일 수 없습니다' 오류로 접속이 안 되는 문제 · xml 읽기 실패

실행/설치

클라이언트 실행 시 'xml 파일을 읽어들일 수 없습니다' 오류가 뜨며 게임이 시작되지 않는 문제입니다. 설치된 클라이언트 파일 일부가 손상됐을 때 발생합니다.

가능한 원인

  • 클라이언트 설치 파일 일부가 손상되거나 불완전하게 다운로드된 경우
  • 비정상 종료나 업데이트 강제 중단으로 파일이 깨진 경우

점검 순서

  1. 1단계 - 완전 제거:
    ① 제어판 → 프로그램 추가/제거에서 리니지를 제거
    ② 설치 폴더(기본 경로 C:\Program Files\plaync\lineage)에 남은 파일도 직접 삭제
  2. 2단계 - 재설치:
    ① 공식 홈페이지에서 클라이언트를 새로 내려받아 설치
  3. 3단계 - 문의:
    ① 그래도 해결되지 않으면 NCSOFT 고객센터 1:1 문의를 이용

참고 자료

NCSOFT 공식 공지: 런처 실행 오류 발생 시 해결 방법 안내

자주 묻는 질문

  • npkuninst.exe는 어디서 받나요? NCSOFT 공식 공지(런처 실행 오류 발생 시 해결 방법 안내)에서 배포하는 제거 도구입니다. 실행 후 재부팅하면 Npkcmsvc 프로세스가 정리되어 정상적으로 업데이트를 진행할 수 있습니다.
  • 재설치해도 xml 오류가 반복되면요? 설치 폴더(C:\Program Files\plaync\lineage)에 이전 파일이 남아있는 상태로 재설치하면 손상된 파일이 그대로 남을 수 있습니다. 제어판에서 제거한 뒤 설치 폴더 자체를 직접 삭제하고 나서 재설치하세요.
