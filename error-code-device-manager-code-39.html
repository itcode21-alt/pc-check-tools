코드 39 · 드라이버가 손상되었거나 누락되었습니다 (코드 39)

장치를 제어해야 할 드라이버 파일 자체가 손상되었거나 누락되어 윈도우가 로드하지 못할 때 나타나는 코드입니다. 오디오나 저장장치 컨트롤러에서 자주 보고됩니다.

이 코드를 어떻게 해석해야 하나요?

업데이트 관련 오류 코드는 네트워크, 캐시, 구성 요소 저장소, 디스크 공간, 서비스 상태 중 어느 단계에서 작업이 멈췄는지를 나타냅니다. 실패가 반복되는 시점과 이벤트 로그의 세부 코드를 같이 살펴보면 원인을 좁히기 수월합니다.

먼저 기록할 내용: 코드 39가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 드라이버 파일이 디스크 오류나 강제 종료로 손상된 경우
  • 맬웨어 감염으로 드라이버 파일이 변조되거나 삭제된 경우
  • 레지스트리에서 드라이버 참조 경로가 잘못된 경우
  • 다른 프로그램이 드라이버 파일을 잘못 덮어쓴 경우
  • 시스템 파일 손상이 드라이버 로드 과정에 영향을 준 경우

첫 점검 항목

  1. SFC로 시스템 파일 복구 — 관리자 권한 명령 프롬프트에서 sfc /scannow를 실행해 손상된 시스템 파일을 복구하고 재부팅하세요.
  2. 드라이버 제거 후 재설치 — 장치 관리자에서 해당 드라이버를 우클릭 → 제거 시 "드라이버 소프트웨어 삭제"를 체크하고, 재부팅해 자동 재설치되는지 확인하세요.
  3. 백신 전체 검사 — 실시간 감시 프로그램이 최근 드라이버 파일을 격리하거나 삭제한 기록이 있는지 검역소 로그까지 확인하세요.
  4. 제조사 드라이버 클린 설치 — Windows Update가 아닌 제조사 홈페이지에서 최신 드라이버를 받아, 기존 파일 위에 덮어쓰지 말고 완전히 제거한 뒤 설치하세요.
  5. 디스크 물리 오류 확인 — chkdsk C: /f /r로 드라이버 파일이 저장된 디스크 자체의 배드섹터 여부를 확인하세요.

확인 결과에 따른 다음 단계

  • SFC에서 손상된 파일을 복구했다고 나올 때 — 재부팅 후 코드 39가 다시 나타나는지만 확인하고, 재발하면 드라이버 재설치 단계로 넘어가세요.
  • 재설치 직후에도 코드 39가 곧바로 재발할 때 — 맬웨어가 드라이버 파일을 계속 변조하고 있을 가능성이 크므로 백신 전체 검사를 우선하세요.
  • chkdsk에서 배드섹터가 발견될 때 — 드라이버 재설치보다 디스크 자체 교체를 우선 검토하세요. 배드섹터가 있는 디스크는 파일이 다시 손상될 수 있습니다.

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한 변경이나 레지스트리 정리 도구 사용보다 저장 공간, 네트워크, 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

오류가 반복된다면 Windows Update 기록과 DISM·SFC 실행 결과를 남겨두고, 사용 중인 설치 미디어 버전이 현재 Windows와 일치하는지 확인하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

자주 묻는 질문

  • 소리가 안 나면 스피커나 이어폰부터 바꿔야 하나요? 이 문제(코드 39)는 장치 자체보다 드라이버나 서비스 문제인 경우가 많으니, 다른 장치로 교차 확인한 뒤에 장치 교체를 고려해도 늦지 않습니다.
  • 코드 39가 여러 장치에서 동시에 뜨면요? 개별 드라이버 파일 하나의 문제가 아니라 시스템 파일이나 디스크 손상 같은 공통 원인일 가능성이 높으므로 sfc·chkdsk부터 먼저 실행하세요.
