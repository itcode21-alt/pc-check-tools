에이펙스 레전드 오류 모음 — 원인과 해결 방법

에이펙스 레전드의 오류는 EA 공식 지원 페이지에 번호로 정리되어 있는 경우가 많아, 화면에 뜬 코드를 정확히 확인하는 것이 원인을 좁히는 가장 빠른 방법입니다.

바로 이동

  • 오류 코드 110으로 게임에 접속할 수 없는 문제 (오류 코드 110)
  • 계정 연동 시 오류 코드 102122가 뜨는 문제 (오류 코드 102122)
  • "code:net" 메시지와 함께 게임 연결이 끊기는 문제 (code:net)
  • 시즌 업데이트 이후 실행이 안 되거나 크래시되는 문제 (시즌 업데이트 오류)
  • 교전 중 반복되는 렉과 핑 튐 (렉 · 핑 튐)

오류 코드 110으로 게임에 접속할 수 없는 문제 · 오류 코드 110

접속/계정

일시적인 EA 계정 문제로 나타나는 오류 코드로, 대부분 재시작으로 해결됩니다.

가능한 원인

  • EA 계정 인증이 일시적으로 지연된 경우
  • 서버 측 계정 정보 동기화 문제

점검 순서

  1. 1단계 - 게임 재시작 (공식 권장):
    ① 게임과 플랫폼 클라이언트를 완전히 종료한 뒤 재실행
  2. 2단계 - EA 앱에서 재로그인:
    ① EA 앱을 로그아웃한 뒤 다시 로그인
  3. 3단계 - 계정 상태 확인:
    ① 반복되면 EA 공식 지원 페이지에서 계정 상태 확인

계정 연동 시 오류 코드 102122가 뜨는 문제 · 오류 코드 102122

계정/연동

EA 계정과 플랫폼 계정을 연동할 때 나타나는 일시적인 연결 오류입니다.

가능한 원인

  • EA 서버와 플랫폼 계정 서버 간 일시적 통신 지연

점검 순서

  1. 1단계 - 잠시 후 재시도:
    ① 몇 분 뒤 계정 연동을 다시 시도
  2. 2단계 - 연동 상태 재확인:
    ① EA 계정 연동 페이지에서 현재 연동 상태 확인

"code:net" 메시지와 함께 게임 연결이 끊기는 문제 · code:net

서버/네트워크

EA 서버가 게임 클라이언트의 요청에 응답하지 않을 때 나타나는 오류로, 서버 측 문제인 경우가 많습니다.

가능한 원인

  • EA 서버 장애 또는 점검
  • 로컬 네트워크의 순간적인 연결 끊김

점검 순서

  1. 1단계 - EA 서버 상태 확인:
    ① 공식 상태 페이지에서 장애 여부 확인
  2. 2단계 - 네트워크 재연결:
    ① 공유기 재시작 등으로 로컬 네트워크 상태 점검
  3. 3단계 - 서버 복구 대기:
    ① 서버 자체 문제로 확인되면 EA의 복구를 기다리는 것 외에 방법이 없습니다.

패치/실행

새 시즌 패치 직후 실행이 안 되거나 로딩 중 크래시되는 문제로, 클라이언트가 최신 버전으로 완전히 업데이트되지 않은 경우 흔합니다.

가능한 원인

  • 패치 파일이 불완전하게 적용된 경우
  • 캐시 파일이 이전 버전과 충돌하는 경우

점검 순서

  1. 1단계 - 플랫폼 무결성 검사:
    ① Steam·Origin·EA 앱에서 게임 파일 무결성 검사 실행
  2. 2단계 - 클라이언트 재설치:
    ① 문제가 지속되면 완전히 삭제한 뒤 재설치

그래픽/성능

많은 인원이 몰리는 교전 상황에서 프레임이 떨어지거나 핑이 튀는 문제입니다.

가능한 원인

  • 그래픽 설정이 PC 사양보다 높은 경우
  • 네트워크 대역폭을 다른 프로그램이 점유하는 경우

    ① 게임 내 그래픽 설정을 낮춰 재현 여부 확인
  2. 2단계 - 백그라운드 프로그램 종료:
    ① 다운로드·스트리밍 프로그램 등 대역폭을 쓰는 프로그램 종료
  3. 3단계 - 유선 네트워크로 전환:
    ① Wi-Fi 대신 유선 연결로 핑 안정성 비교

자주 묻는 질문

  • 오류 코드가 뜨면 항상 재시작하면 되나요? 110, 102122처럼 일시적 계정 문제로 안내되는 코드는 재시작으로 해결되는 경우가 많지만, code:net처럼 서버 자체 문제인 경우는 재시작해도 복구를 기다려야 합니다.
  • EA 서버 상태는 어디서 확인하나요? EA 공식 도움말 페이지에서 실시간 장애 여부와 각 오류 코드별 안내를 확인할 수 있습니다.
