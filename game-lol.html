롤 클라이언트 자동 종료 · 클라이언트 크래시

클라이언트참고 자료 있음커뮤니티 사례 포함

롤 클라이언트가 시작 중 또는 실행 중 갑자기 종료되거나 로그인에서 멈추는 현상입니다. Riot 오류 코드 문서는 0xc0000005(관리자 권한 실행, 안 되면 재설치), 치명적인 오류(오버레이 프로그램 종료 후 설치 폴더의 config·data 폴더 삭제), 로그인 중 멈춤(작업 관리자에서 관련 프로세스 종료 후 재실행)을 안내합니다.

가능한 원인

  • Riot 안내: 0xc0000005는 원인이 확인되지 않았고 Windows 문제에 가깝다고 설명합니다
  • Riot 안내: Steam·Origin·Discord 같은 오버레이 프로그램이 함께 실행되며 치명적인 오류를 내는 경우
  • Riot 안내: 로그인 중 실행 중이던 클라이언트가 멈춘 경우
  • 그래픽 드라이버가 오래되었거나, 메모리 부족, 클라이언트 설치 파일 손상(문서 외 일반 추정)

점검 순서

  1. 1단계 - 관리자 권한으로 실행 (Riot 안내, 0xc0000005):
    ① 클라이언트를 관리자 권한으로 실행
    ② 해결되지 않으면 리그 오브 레전드 관련 파일을 모두 제거한 뒤 재설치
  2. 2단계 - 오버레이 프로그램 종료 후 폴더 정리 (Riot 안내, 치명적인 오류):
    ① Steam·Origin·Discord 등 오버레이 프로그램을 모두 종료
    ② Riot Games의 League of Legends 폴더에서 config 폴더와 data 폴더를 삭제 (삭제 전에 폴더를 다른 곳에 복사해 두면 안전)
  3. 3단계 - 로그인 중 멈췄을 때 (Riot 안내):
    ① 작업 관리자에서 League of Legends 관련 작업을 모두 종료한 뒤 클라이언트를 다시 실행
  4. 4단계 - 일반 점검 (문서 외):
    ① 그래픽카드 제조사의 최신 드라이버로 업데이트하고 재부팅
    ② Riot Client 설정에서 게임 데이터 확인·수리 실행
    ③ 메모리를 많이 쓰는 프로그램 종료

패치가 완료되지 않거나 무한 로딩되는 문제 · 패치 진행 불가

설치/패치참고 자료 있음

업데이트 진행률이 특정 지점에서 멈추거나 '패치가 완료되지 않았습니다' 메시지가 반복되는 경우입니다. Riot의 '패치 설치 문제' 문서는 일부가 구형 클라이언트 기준일 수 있어, 단계마다 결과를 확인하며 진행하세요.

가능한 원인

  • Riot Client의 권한이나 방화벽 설정이 패치 설치를 막는 경우 (Riot 안내에 나오는 점검 대상)
  • 무선 인터넷이 불안정해 설치가 오래 걸리거나 멈추는 경우 (Riot 안내: 유선 전환)
  • 패처 창이 보이지 않는 경우 — 모니터 새로 고침 빈도·네트워크 설정 문제 (Riot 안내)
  • 서버와 클라이언트의 패치 데이터가 맞지 않거나 이전 패치 잔여 파일이 충돌하는 경우 (문서 외 일반 추정)

점검 순서

  1. 1단계 - 클라이언트 완전 종료 후 재시도 (문서 외 일반 점검):
    ① 시스템 트레이까지 포함해 Riot Client를 완전히 종료한 뒤 다시 실행 (Riot의 Error 004 문서도 같은 첫 단계를 안내)
    ② 인터넷 연결 상태 확인
  2. 2단계 - 관리자 권한 실행 (Riot 안내):
    ① Riot Client를 우클릭해 관리자 권한으로 실행
  3. 3단계 - 전체 복구 (Riot 안내):
    ① Riot Client 설정 또는 라이엇 정비소(Riot Repair Tool)의 복구 기능 실행
    ② 정비소를 쓸 때는 언어 Korean, 지역 Korea로 설정하고 재패치 강제 수행(Force Repatch)을 체크
    ③ PC 사양에 따라 10~30분 이상 걸릴 수 있음
  4. 4단계 - 방화벽 확인 (Riot 안내):
    ① Riot 프로그램이 방화벽에서 허용돼 있는지 확인하고, 필요하면 방화벽을 업데이트
    ② 방화벽을 잠시 끄는 것은 원인 확인용으로만 하고 확인 뒤 바로 켜기
  5. 5단계 - 설치가 너무 오래 걸릴 때 (Riot 안내):
    ① 무선 인터넷에서 유선 인터넷으로 바꿔 다시 시도
  6. 6단계 - 패처 창이 보이지 않을 때 (Riot 안내):
    ① 디스플레이 설정에서 모니터 새로 고침 빈도를 59Hz 또는 60Hz로 바꾸고 다시 실행
    ② 그래도 같으면 명령 프롬프트(관리자)에서 netsh winsock reset을 실행하고 PC를 재시작한 뒤 다시 실행
  7. 7단계 - 재설치 (문서 외 일반 점검):
    ① 위 방법으로도 해결되지 않으면 클라이언트를 완전 삭제한 뒤 재설치

Riot Support: 패치 설치 문제

"서버에 연결할 수 없습니다" 접속 오류 · 서버에 연결할 수 없습니다

접속/네트워크참고 자료 있음커뮤니티 사례 포함

클라이언트 로그인이나 게임 진입 시 서버 연결에 실패하는 경우로, 라이엇 공식 지원 문서에서 DNS·IPv6·TCP/IP 설정을 기본 점검 항목으로 안내하고 있습니다. Riot 오류 코드 문서에는 서버 과부하(Error 7)와 통신사 문제(Error 1B)도 별도로 안내돼 있습니다.

가능한 원인

  • Riot 안내: Error 7은 서버 과부하일 때 표시되고 연결이 끊기거나 기본 기능을 쓸 수 없음
  • Riot 안내: Error 1B는 ISP(통신사) 문제로 서버 연결이 방해되는 경우
  • 공용 DNS가 아닌 통신사 DNS 응답이 불안정한 경우
  • IPv6가 활성화되어 IPv4 기반 클라이언트와 간헐적으로 충돌하는 경우
  • TCP/IP 설정이 변경되어 연결이 불안정한 경우

점검 순서

  1. 0단계 - 오류 번호가 보일 때 (Riot 안내):
    ① Error 7: 서버 문제이므로 계속 로그인을 시도하고, 지역별 서버 상태는 status.riotgames.com에서 확인
    ② Error 1B: 몇 시간 뒤 자동으로 해결되는 경우가 많으며, PC에서는 클라이언트를 관리자 권한으로 실행해 보기
    ③ 인터넷이 불안정하다는 로그인 오류: 라우터를 초기화하고 DNS를 변경, 그래도 안 되면 통신사에 문의
  2. 1단계 - 기본 조치:
    ① 클라이언트를 완전히 종료 후 재부팅
    ② 인터넷 연결 상태 확인
  3. 2단계 - 공용 DNS로 변경:
    ① 네트워크 어댑터 설정에서 DNS를 8.8.8.8 등 공용 DNS로 변경
  4. 3단계 - IPv6 비활성화:
    ① 네트워크 어댑터 속성에서 인터넷 프로토콜 버전 6(IPv6) 체크 해제
  5. 4단계 - TCP/IP 초기화:
    ① 명령 프롬프트(관리자)에서 netsh winsock reset 입력 후 재부팅

가능한 원인

  • 방화벽이 클라이언트·게임 실행 파일을 차단 목록에 올린 경우
  • 타사 백신이 실시간 감시로 통신을 가로채는 경우

    ② 정상 작동하면 다시 켜고 롤 실행 파일을 예외로 추가
  2. 2단계 - 백신 예외 등록:
    ① 사용 중인 백신 프로그램에서 리그 오브 레전드 설치 폴더를 예외로 등록
  3. 3단계 - 네트워크 어댑터 드라이버 업데이트:
    ① 장치 관리자 → 네트워크 어댑터 → 드라이버 업데이트 실행

픽창·인게임에서 소리가 나오지 않는 문제 · 인게임 소리 안 나옴

그래픽/성능참고 자료 있음커뮤니티 사례 포함

다른 프로그램은 소리가 정상인데 롤 클라이언트나 인게임에서만 소리가 안 나오는 경우로, 볼륨 설정이나 오디오 장치 설정이 원인인 경우가 많습니다.

가능한 원인

  • 인게임 마스터 볼륨이 100일 때 오디오 장치와 충돌하는 경우
  • 설정에서 소리 옵션이 꺼져 있는 경우
  • 전면 패널 오디오 단자 설정이 원인인 경우

점검 순서

  1. 1단계 - 마스터 볼륨 조정:
    ① 인게임 설정에서 마스터 볼륨을 100에서 99로 낮춰보기

Riot 고객지원 문서는 Error 004를 '패치 중 실패가 발생하는 오류'로 설명합니다. 주로 Riot Client가 업데이트를 내려받고 설치하는 데 필요한 권한·저장 공간·네트워크 접근 중 하나 이상이 부족할 때 나타납니다. 같은 문서에서 비슷한 증상인 Error 002는 디스크 여유 공간을 먼저 확인하고, 공간이 충분하면 업데이트 설치를 막을 수 있는 백신 등 검사 소프트웨어를 일시적으로 끄라고 안내합니다.

가능한 원인

  • Riot Client의 권한이 부족한 경우 (Riot 안내의 원인)
  • 게임이 설치된 드라이브에 업데이트를 받을 저장 공간이 부족한 경우 (Riot 안내의 원인)
  • 방화벽 등으로 Riot Client와 서버 사이의 네트워크 접근이 막힌 경우 (Riot 안내의 원인)
  • 임시 문제, 잠긴 파일, 대기 중인 Windows 업데이트가 패치를 방해하는 경우 (Riot 안내: 재시작으로 정리)
  • Riot 안내(Error 002): 디스크 여유 공간 부족이나 백신이 업데이트 설치를 막는 경우

점검 순서

  1. 1단계 - Riot Client 완전 종료 후 재시도 (Riot 안내):
    ① 시스템 트레이까지 포함해 Riot Client를 완전히 종료한 뒤 다시 실행하고 패치를 재시도
  2. 2단계 - PC 재시작 (Riot 안내):
    ① PC를 재시작해 임시 문제, 잠긴 파일, 대기 중인 Windows 업데이트를 정리
  3. 3단계 - 관리자 권한 실행 (Riot 안내):
    ① Riot Client를 관리자 권한으로 실행한 뒤 게임을 다시 실행
  4. 4단계 - 저장 공간 확인 (Riot 안내):
    ① 게임이 설치된 드라이브에 업데이트를 받을 공간이 충분한지 확인하고, 부족하면 확보한 뒤 Riot Client를 재시작
  5. 5단계 - 방화벽·연결 확인 (Riot 안내):
    ① 방화벽이 Riot Client와 서버 통신을 막고 있지 않은지 확인
    ② PC 연결 상태를 점검
  6. 6단계 - 재설치 (Riot 안내):
    ① 게임을 제거한 뒤 다시 설치해 손상되거나 누락된 게임 파일을 교체
  7. 7단계 - 계속되면 지원 문의 (Riot 안내):
    ① Player Support에 티켓을 제출하고 로그를 첨부 (로그 수집은 Riot Repair Tool 안내를 따름)

뱅가드 도입 후 "시스템을 다시 시작해야 합니다" 메시지로 실행이 안 되는 문제 · 뱅가드 Secure Boot·TPM 요구사항 오류

보안/안티치트참고 자료 있음

리그 오브 레전드에 라이엇 뱅가드 안티치트가 도입된 이후, 게임 실행 시 "이 게임을 플레이하려면 시스템을 다시 시작해야 합니다" 또는 이와 비슷한 재부팅 요구 메시지가 뜨며 진행되지 않는 경우입니다. 단순 재부팅으로 해결되지 않는다면, 뱅가드가 요구하는 Secure Boot·TPM 2.0 보안 조건을 PC가 충족하지 못하고 있을 가능성이 큽니다.

가능한 원인

  • BIOS 모드가 Legacy/CSM이고 UEFI로 부팅하지 않는 경우
  • Secure Boot가 꺼져 있거나 기본 키가 등록되지 않은 경우
  • TPM 2.0이 비활성화되었거나 Windows에서 준비 상태로 인식되지 않는 경우
  • 인텔 8세대, AMD 라이젠 2세대 이전처럼 하드웨어 보안 기능이 없는 구형 CPU를 사용 중인 경우

점검 순서

  1. 1단계 - 현재 상태 확인:
    ① Win+R → msinfo32 실행 → BIOS 모드가 UEFI인지, 보안 부팅 상태가 켜짐인지 확인
    ② Win+R → tpm.msc 실행 → TPM이 준비 상태인지 확인
  2. 2단계 - BIOS 설정 변경:
    ① 메인보드 제조사 설명서에 따라 UEFI, Secure Boot, TPM(AMD fTPM 또는 Intel PTT)을 켜기
    ② 설정 전 BitLocker 복구 키를 확보하고, 부팅 불가 위험이 있으면 제조사 지원 이용
  3. 3단계 - 뱅가드 재설치:
    ① 제어판 → 프로그램 및 기능에서 Riot Vanguard 제거 후 재부팅
    ② League of Legends 재실행 시 자동 재설치되는지 확인
  4. 4단계 - 하드웨어 한계 확인:
    ① BIOS에 Secure Boot·TPM 옵션 자체가 없다면 CPU·메인보드가 요구 사양보다 오래된 경우로, 이 경우 소프트웨어 조치로는 해결되지 않습니다.

게임 중 화면이 멈추고 조작이 안 되지만 클라이언트가 꺼지지는 않는 문제 · 인게임 화면 멈춤(크래시 아님)

그래픽/성능참고 자료 있음

챔피언 선택이 아닌 실제 게임 진행 중에 화면이 완전히 멈춰 조작이 반응하지 않는 증상입니다. lol-graphics-texture-glitch(화면이 순간 깨졌다가 돌아오는 문제)와 달리 화면이 정상으로 돌아오지 않고 계속 멈춰 있으며, 그렇다고 클라이언트가 강제 종료되지도 않는 것이 특징입니다.

가능한 원인

  • 그래픽 드라이버가 게임 도중 응답 없음 상태에 빠졌지만 완전히 크래시하지는 않는 경우
  • 백그라운드에서 실행 중인 화면 녹화·오버레이(디스코드, 지포스 익스피리언스 등) 프로그램과의 충돌
  • 저사양 PC에서 순간적으로 CPU·메모리 사용량이 튀며 렌더링 스레드가 멈추는 경우
  • 인터넷 연결은 살아있지만 게임 서버와의 동기화가 순간적으로 끊겨 화면 업데이트만 멈추는 경우

점검 순서

  1. 1단계 - 강제 복귀 시도:
    ① Alt+Tab으로 다른 창을 열었다가 게임으로 돌아와 반응이 오는지 확인
    ② 반응이 없으면 작업 관리자(Ctrl+Shift+Esc)로 리그 오브 레전드 프로세스가 "응답 없음" 상태인지 확인
  2. 2단계 - 오버레이 프로그램 종료:
    ① 디스코드·지포스 익스피리언스·화면 녹화 프로그램의 인게임 오버레이 기능을 꺼본 뒤 재현 여부 확인
  3. 3단계 - 그래픽 드라이버 업데이트:
    ① 그래픽카드 제조사 홈페이지에서 드라이버를 완전히 제거(DDU) 후 최신 버전으로 재설치
  4. 4단계 - 재현 조건 기록:
    ① 멈추는 시점이 특정 스킬 사용, 특정 챔피언, 특정 맵 위치와 겹치는지 기록해두면 라이엇 고객지원 문의 시 원인 파악에 도움이 됨
