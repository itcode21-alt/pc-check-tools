WINDOWS 10 EOL

윈도우10 지원 종료 이후 뭘 해야 하나요

2025년 10월 14일 윈도우10 기술지원이 끝났습니다. 아직 윈도우10을 쓰고 있다면, 지금 당장 뭔가 망가지는 건 아니지만 보안 업데이트가 끊긴 상태라는 것부터 정확히 이해해야 합니다.

지원 종료로 실제로 무엇이 바뀌었나요

지원 종료 자체가 컴퓨터를 못 쓰게 만들지는 않습니다. 다만 새로 발견되는 보안 취약점에 대한 패치가 더 이상 자동으로 제공되지 않아, 시간이 지날수록 알려진 취약점을 통한 공격에 노출될 위험이 커집니다. 인터넷 뱅킹, 온라인 쇼핑처럼 민감한 작업을 계속한다면 이 위험을 방치하지 않는 것이 좋습니다.

ESU(확장 보안 업데이트)로 1년(2027년 10월까지) 더 받는 방법

Microsoft는 개인 사용자도 등록할 수 있는 ESU 프로그램을 운영하고 있습니다. 원래는 2026년 10월까지였지만, 이후 2027년 10월 12일까지로 한 차례 더 연장되었습니다. 아래 세 가지 방법 중 하나로 등록할 수 있습니다.

  • 무료 (계정 동기화) — Microsoft 계정으로 로그인하고 Windows 백업(설정 동기화)을 켜두면 추가 비용 없이 등록됩니다.
  • 무료 (Rewards 포인트) — Microsoft Rewards 포인트 1,000점으로 등록할 수 있습니다.
  • 유료 (일회성 결제) — 30달러(또는 국내 환산 금액, 세금 별도)를 한 번 결제하면 등록됩니다. 결제 시 최대 10개 계정(기기)까지 하나의 라이선스로 등록할 수 있습니다.

등록 방법

  1. 1단계 - Windows Update 최신화: 설정 → 업데이트 및 보안 → Windows Update에서 최신 업데이트를 모두 설치합니다. Windows 10 22H2 버전이어야 등록 옵션이 나타납니다.
  2. 2단계 - 등록 알림 확인: 같은 화면에 지원 종료 안내와 함께 "지금 등록" 링크가 표시됩니다. 보이지 않으면 업데이트를 한 번 더 확인한 뒤 재부팅하세요.
  3. 3단계 - 등록 방식 선택: 안내에 따라 위 세 가지 방법 중 하나를 선택해 등록을 마칩니다. 등록에는 관리자 권한의 Microsoft 계정이 필요합니다.
ESU가 포함하지 않는 것

ESU는 긴급·중요 등급의 보안 패치만 제공합니다. 새 기능, 일반 기술지원, 버그 수정은 포함되지 않습니다. "예전과 똑같이 지원받는 것"이 아니라 "보안 공백만 최소한으로 막아주는 임시 조치"로 이해하는 것이 정확합니다.

Windows 11 업그레이드 vs ESU 유지 vs 새 PC, 무엇을 골라야 하나요

  • PC가 Windows 11 요구사항(TPM 2.0, 지원 CPU)을 충족한다면 — ESU에 의존할 이유 없이 지금 Windows 11로 업그레이드하는 것이 가장 확실한 방법입니다. 업그레이드가 막힌다면 윈도우11 업그레이드 안 될 때 해결 가이드에서 정확한 원인부터 확인하세요.
  • 요구사항은 미충족인데 PC를 조금 더 쓰고 싶다면 — 일단 무료 ESU로 등록해 2027년 10월까지 시간을 벌고, 그사이 다음 PC 교체 계획을 세우는 것이 현실적입니다.
  • 업무·금융 등 보안이 중요한 용도라면 — ESU 기간에 안주하지 말고 가능한 한 빨리 Windows 11 지원 기기로 옮기는 것을 권장합니다. ESU는 어디까지나 한시적 유예 기간입니다.

TPM 2.0이 없어서 업그레이드가 막힌다면

메인보드에 TPM 자체는 있는데 BIOS/UEFI에서 비활성화되어 있어 "미지원"으로 표시되는 경우가 실제로 많습니다. Intel PTT나 AMD fTPM 이름으로 BIOS 안에 숨어 있는 경우가 흔하니, 완전히 포기하기 전에 TPM·보안 부팅 확인 방법부터 점검해보세요. 정말 하드웨어 자체가 없는 구형 PC라면, 레지스트리로 요구사항을 우회하는 방법이 커뮤니티에 알려져 있지만 Microsoft가 공식적으로 권장하지 않으며 향후 업데이트 호환성 문제가 생길 수 있어 신중해야 합니다.

자주 묻는 질문

  • ESU에 등록하면 완전히 예전처럼 지원받을 수 있나요? 아닙니다. ESU는 '긴급·중요 등급의 보안 패치'만 제공합니다. 새 기능 추가, 일반 기술지원, 버그 수정은 포함되지 않습니다. 보안 공백만 막아주는 임시 조치로 이해해야 합니다.
  • ESU를 무료로 받으려면 무엇을 해야 하나요? Microsoft 계정으로 로그인한 뒤 PC 설정 동기화(백업)를 켜두면 추가 비용 없이 등록할 수 있습니다. 계정 동기화를 원하지 않는다면 Microsoft Rewards 포인트 1,000점을 쓰거나 30달러 상당을 결제하는 방법도 있습니다.
  • TPM 2.0이 없어서 Windows 11로 못 올라가면 어떻게 하나요? 메인보드에 TPM 자체는 있는데 BIOS에서 꺼져 있는 경우가 많으니 먼저 확인해보세요. 정말 하드웨어가 없다면 레지스트리로 요구사항을 우회하는 방법도 있지만 Microsoft가 권장하지 않는 방법이라, ESU로 1년 더 시간을 번 뒤 다음 PC 교체 시점에 자연스럽게 넘어가는 것도 현실적인 선택입니다.
