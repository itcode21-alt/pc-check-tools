에러 코드 상세

코드 24 · 이 장치가 존재하지 않거나 작동하지 않거나 모든 드라이버가 설치되어 있지 않습니다 (코드 24)

제거 준비가 된 장치가 이 상태로 남을 수 있다고 Microsoft가 안내하는 코드입니다. 해당 장치를 제거하면 오류가 사라진다고 합니다.

이 코드를 어떻게 해석해야 하나요?

Microsoft의 장치 관리자 오류 코드 문서에서 코드 24는 '이 장치가 없거나, 제대로 작동하지 않거나, 모든 드라이버가 설치되어 있지 않다'는 메시지이며, 제거 준비가 된 장치가 이 상태에 머문다고 설명합니다. 해결 방법은 장치를 제거하는 것이라고 안내합니다. 따라서 더 이상 쓰지 않는 장치라면 항목을 제거하는 것으로 충분하고, 계속 써야 하는 장치라면 다시 연결한 뒤 하드웨어 변경 사항을 검색하고 드라이버를 점검합니다.

가능성 높은 원인

  • 장치가 제거 준비 상태로 남아 있는 경우 — Microsoft 문서가 밝히는 원인입니다
  • 장치에 필요한 드라이버가 일부만 설치된 경우 — 메시지의 '모든 드라이버가 설치되어 있지 않다'는 부분에 해당합니다
  • 장치가 컴퓨터에 제대로 연결되어 있지 않은 경우(문서 외 일반 사례)

첫 점검 항목

  1. 그 장치를 더 쓰지 않는다면 장치 관리자에서 우클릭해 '장치 제거'를 선택하세요. Microsoft 문서는 장치를 제거하면 오류가 사라진다고 안내합니다.
  2. 계속 쓸 장치라면 완전히 분리했다가 다시 연결한 뒤 '동작 > 하드웨어 변경 사항 검색'을 실행하세요. 이 방법으로 정상이 되면 일시적인 제거 대기 상태가 원인이었습니다.
  3. 같은 장치가 계속 코드 24라면 제조사 사이트에서 받은 최신 드라이버로 다시 설치하세요. 이 방법으로 정상이 되면 드라이버가 일부만 설치된 상태가 원인이었습니다.
  4. 노트북 내장 장치(블루투스 등)가 이 상태라면 제조사 지원 문서에서 BIOS·기능 키로 장치가 켜져 있는지 확인하세요(문서 외 일반 점검).

확인 결과에 따른 다음 단계

  • 장치를 제거하자 오류가 사라질 때 — 더 쓰지 않는 장치였다면 그대로 두면 됩니다. 계속 써야 한다면 장치를 연결하고 하드웨어 변경 사항을 검색해 다시 설치하세요.
  • 다시 연결하고 검색해도 코드 24가 남을 때 — 제조사 최신 드라이버로 재설치하세요. 그래도 같다면 다른 포트나 다른 PC에서도 같은 코드가 나오는지 비교해 장치 문제와 PC 문제를 나누세요.
  • 노트북 내장 장치만 이 상태일 때 — 제조사 지원 문서에서 BIOS와 기능 키로 해당 장치가 켜져 있는지 확인하고, 제조사 드라이버를 설치하세요.

데이터와 시스템을 보호하는 주의사항

원인이 분명하지 않은데 초기화·레지스트리 수정·시스템 파일 교체 같은 조치를 먼저 시도하면 오히려 문제가 커질 수 있습니다.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

시스템 복구나 초기화, 드라이버 삭제처럼 원상복구가 힘든 작업을 시작하기 전에, 중요한 파일은 미리 외장 저장장치나 별도 위치에 백업해 두세요.

자주 묻는 질문

  • 코드 24는 장치가 고장 났다는 뜻인가요? 반드시 그렇지는 않습니다. Microsoft 문서는 제거 준비가 된 장치가 이 상태로 남는다고 설명하고 장치를 제거하면 오류가 사라진다고 안내합니다. 장치를 계속 쓰는데 이 코드가 보일 때만 연결과 드라이버를 점검하세요.
  • 블루투스 장치에서만 나오는 코드인가요? 아닙니다. 장치 종류와 상관없이 같은 메시지가 나옵니다. 블루투스 어댑터에서 보이는 경우가 많아 보이더라도 Microsoft 문서는 특정 장치 종류를 구분하지 않습니다.
