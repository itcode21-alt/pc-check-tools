에러 코드 상세

코드 24 · 이 장치가 존재하지 않거나 작동하지 않거나 모든 드라이버가 설치되어 있지 않습니다 (코드 24)

장치가 제거 대기 상태이거나 드라이버가 제대로 로드되지 않을 때 장치 관리자에 나타나는 코드입니다. 블루투스 어댑터에서 특히 자주 보이지만, 그래픽카드·사운드카드·USB 장치 등 어떤 하드웨어에서도 나타날 수 있습니다.

이 코드를 어떻게 해석해야 하나요?

오류 코드는 고장 부품을 확정하는 판정이 아니라 발생 시점과 함께 원인 범위를 좁히는 단서입니다. 최근 변경, 반복 조건, 안전 모드 재현 여부를 함께 기록하세요.

먼저 기록할 내용: 코드 24가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 장치를 방금 제거했거나 제거 대기 중인 경우
  • 드라이버가 손상되었거나 버전이 맞지 않는 경우
  • USB 절전 설정으로 어댑터 전원이 꺼진 경우
  • BIOS에서 내장 블루투스가 비활성화된 경우

첫 점검 항목

  1. 재부팅 후 재검색 — 재부팅한 뒤 장치 관리자를 열어 항목이 자동으로 정상화되는지 먼저 확인하세요. "제거 대기 중" 상태는 재부팅만으로 풀리는 경우가 많습니다.
  2. 드라이버 완전 제거 후 재설치 — 장치를 우클릭 → 제거(드라이버 소프트웨어 삭제 옵션 체크) 후 재부팅해 Windows가 다시 인식하게 하거나, 제조사 사이트에서 정확한 모델의 최신 드라이버를 받아 설치하세요.
  3. USB·허브 절전 관리 해제 — 장치 관리자에서 해당 USB 허브·루트 허브 속성 → 전원 관리 탭 → "전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음"의 체크를 해제하세요.
  4. BIOS/기능 키 확인 — 노트북이라면 BIOS 설정이나 Fn 기능 키에서 해당 장치(블루투스·내장 랜·카메라 등)가 비활성화되어 있지 않은지 확인하세요.
  5. 다른 포트·슬롯으로 교차 확인 — 외장 장치라면 다른 USB 포트에 직접 연결해 특정 포트만의 문제인지 구분하세요.

확인 결과에 따른 다음 단계

  • 재부팅만으로 해결될 때 — "제거 대기" 상태가 일시적으로 남아 있던 것이므로 추가 조치가 필요 없습니다.
  • 드라이버 재설치 후에도 반복될 때 — USB 절전 관리와 BIOS 설정을 함께 점검하세요. 특히 노트북 내장 장치는 BIOS 비활성화가 원인인 경우가 많습니다.
  • 특정 포트에서만 발생할 때 — 장치보다 그 포트의 접촉이나 전력 공급 문제일 가능성이 큽니다.

데이터와 시스템을 보호하는 주의사항

원인이 분명하지 않은데 초기화·레지스트리 수정·시스템 파일 교체 같은 조치를 먼저 시도하면 오히려 문제가 커질 수 있습니다.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

시스템 복구나 초기화, 드라이버 삭제처럼 원상복구가 힘든 작업을 시작하기 전에, 중요한 파일은 미리 외장 저장장치나 별도 위치에 백업해 두세요.
