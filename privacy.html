쿠키와 Google 광고 서비스

이 사이트는 Google AdSense를 사용합니다. Google과 광고 파트너는 쿠키, 웹 비콘, IP 주소 또는 유사한 식별자를 사용해 광고를 제공하고 광고 성과를 측정할 수 있습니다. 사용자의 이전 방문 정보가 광고 선택에 활용될 수 있으며, 지역과 동의 상태에 따라 개인 맞춤 광고 또는 비개인 맞춤 광고가 표시될 수 있습니다.

Google의 광고 데이터 사용 방식은 Google 광고 기술 안내에서 확인할 수 있습니다. 광고 개인 최적화 설정은 내 광고 센터에서 관리할 수 있습니다.

방문 통계와 사이트 검색어 분석

사이트 이용 통계를 확인하기 위해 Google Analytics(GA4)를 사용합니다. 방문한 페이지 주소와 사이트 검색창에 입력한 검색어(검색 결과 주소의 검색어 값)가 Google Analytics로 전송되어 집계됩니다. 이 정보는 자주 찾는 증상과 검색 방식을 파악해 콘텐츠를 개선하는 데 쓰며, 개인을 식별하는 목적으로 사용하지 않습니다.

검색창에 이름, 전화번호, 계정 정보처럼 개인을 알아볼 수 있는 내용을 입력하지 않도록 부탁드립니다. Google Analytics 수집을 원하지 않으면 Google Analytics 수집 중지 브라우저 부가기능을 설치할 수 있습니다.

광고 동의 관리

법령과 Google 정책에 따라 동의가 필요한 지역의 방문자에게는 광고 쿠키와 개인정보 처리 선택 화면을 제공합니다. 유럽경제지역(EEA), 영국, 스위스 방문자에게 개인 맞춤 광고를 제공하는 경우 Google이 인증한 동의 관리 플랫폼(CMP)과 IAB TCF 기준을 적용합니다. 동의하지 않은 경우에는 지역과 설정에 따라 비개인 맞춤 광고가 표시되거나 광고 제공이 제한될 수 있습니다.

방문자는 표시되는 개인정보 선택 화면에서 동의 범위를 결정하거나 변경할 수 있습니다. 광고 또는 분석 서비스가 추가되거나 처리 범위가 바뀌면 이 방침과 시행일을 함께 갱신합니다.

브라우저 저장소

최근 검색한 에러코드는 같은 기기에서 다시 확인할 수 있도록 브라우저의 로컬 저장소에 최대 5개까지 저장될 수 있습니다. 이 정보는 사이트 서버로 전송되지 않으며, 진단 페이지의 ‘최근 검색 비우기’ 기능이나 브라우저 데이터 삭제 기능으로 지울 수 있습니다.

종합진단에서 사용자가 ‘현재 결과 저장’을 누르면 진단 카트 항목, 점검 체크 상태와 종합 분석 요약이 같은 브라우저의 로컬 저장소에 최대 10개까지 저장됩니다. 이 저장 결과는 사이트 서버로 전송되지 않으며, ‘새 진단’ 또는 브라우저 저장소 삭제로 제거할 수 있습니다. JSON 내보내기는 사용자가 직접 선택한 경우에만 파일로 다운로드됩니다.

진단 입력의 처리 방식

에러 코드 입력, 증상 선택, 로그 붙여넣기는 모두 빠른 원인 파악을 위한 기능입니다. 이벤트 로그 분석기 같은 일반 진단 도구에서 선택한 로그 파일은 브라우저 안에서만 읽고 해석하며, 사이트 서버로 업로드하거나 외부에 공개하지 않습니다. 다만 미니덤프 분석기는 정지 코드·결함 모듈·이벤트 집계를 읽기 위해, 사용자가 ‘분석 시작’을 누른 뒤에 올린 .dmp·.evtx·hardware.json을 분석 서버로 보내며(통신은 Cloudflare 터널을 거칩니다), 분석이 끝나면 파일은 삭제됩니다. 작은 메모리 덤프는 호출 스택을 복원하기 위해 서버가 Microsoft 심볼 서버에 모듈의 파일 이름·TimeDateStamp·SizeOfImage만 보내 모듈 이미지를 받아 올 수 있으며, 덤프 내용은 보내지 않습니다. 파일을 고른 직후의 크기·형식·읽기 가능 여부 검사는 브라우저 안에서만 이루어집니다. 분석 화면의 ‘개선 활용 안내’ 항목이 켜져 있으면(기본값) 개인정보를 제외한 요약이 저장되며, 체크를 해제하면 저장하지 않습니다. 로그에 제품 일련번호, 사용자 이름, 장치 이름 같은 정보가 포함될 수 있으므로 공유 PC에서는 사용 후 입력 내용을 지우는 것이 좋습니다.

AI 문의 개선 활용

AI 진단 질문은 답변 생성에 필요한 범위에서 AI 진단 서버로 전송됩니다. 답변 생성 후에는 기본적으로 질문과 로그를 보관하지 않습니다. 사용자가 ‘사이트 진단 자료 개선에 활용’ 항목에 선택 동의한 경우에만 질문 내용과 답변 작성에 참고한 사이트 문서 식별값을 저장하며, 이메일 주소, 전화번호, IP 주소, 윈도우·맥 사용자 경로와 명시된 사용자명·장치명은 저장 전에 자동으로 가립니다.

저장 목적은 자주 문의되는 증상과 현재 자료에서 부족한 진단 항목을 파악해 사이트 콘텐츠를 보완하는 것입니다. IP 주소, 브라우저 식별 정보, AI 답변 전문은 개선 문의 기록에 함께 저장하지 않으며, 저장된 기록은 수집일로부터 90일이 지나면 다음 저장 처리 시 자동 삭제합니다. 동의하지 않아도 AI 진단을 동일하게 이용할 수 있습니다.

게임 접속 문제 신고

게임 오류 페이지의 ‘나도 지금 안 돼요’ 버튼을 누르면 해당 게임 이름과 누른 시각만 집계 서버에 저장되어, 최근 1시간과 24시간의 신고 수로 표시됩니다. 같은 사람이 반복해서 누르는 것을 막기 위해 접속 주소(IP)를 알아볼 수 없는 값으로 바꿔 30분 동안 서버 메모리에서만 대조하며, 파일이나 기록으로 남기지 않습니다. 신고 시각은 24시간이 지나면 삭제됩니다. 이 브라우저에는 다시 누를 수 있는 시각을 확인하기 위한 값이 로컬 저장소에 남습니다.

해결 사례 공유

방문자가 해결 사례 공개에 동의해 제출한 경우에만 문제 요약, 해결 과정, 선택한 사이트 페이지 주소와 제출 시각을 검토 목적으로 저장합니다. 이메일, 전화번호, IP 주소, 사용자 폴더 경로, 제품 키, 장치 일련번호처럼 개인정보 또는 식별 가능 정보가 포함된 제출은 저장·공개하지 않도록 차단하거나 반려합니다.

승인된 사례는 작성자 식별 정보 없이 사이트에 공개될 수 있습니다. 공개 전 운영자가 개인정보, 광고성 문구, 위험한 조작 안내를 검토하며, 공개에 적합하지 않은 사례는 반려합니다. 사례 제출 데이터는 공개 여부 결정과 콘텐츠 품질 관리에만 사용하며, 광고 목적 또는 제3자 판매에 사용하지 않습니다.

수리 의뢰 상담

이 사이트의 운영자(아이티에스)는 별도로 원격 점검과 방문 수리를 합니다. 요금 안내와 사이트 하단의 수리 의뢰 안내에서 카카오톡 채널로 상담을 시작할 수 있으며, 의뢰는 사용자가 직접 채널로 메시지를 보낼 때만 시작됩니다. 사이트가 의뢰 내용을 대신 수집하거나 자동으로 전송하지 않습니다. ‘보낼 내용 복사’ 버튼은 페이지 제목이 들어간 문구를 사용자의 기기에서 복사할 뿐 서버로 보내지 않습니다.

상담 과정에서 받는 정보는 사용자가 보내는 증상 설명, 오류 화면 사진, 희망 지역이며, 방문 수리를 진행하는 경우에 한해 방문 장소와 연락 방법을 추가로 확인합니다. 이 정보는 원인 확인, 원격 점검 안내, 방문 가능 여부와 일정 확인, 수리 진행과 요금 안내에만 사용하며 다른 목적으로 사용하거나 제3자에게 판매하거나 광고 목적으로 제공하지 않습니다. 카카오톡 채널 채팅 자체의 처리는 카카오의 개인정보 처리방침에 따릅니다.

오류 화면 사진에 이름, 계정, 제품 키, 장치 일련번호가 보이면 가린 뒤 보내 주세요. 원격 점검을 받을 때는 화면에 열려 있는 개인 파일이나 계정 정보를 미리 닫아 두시기 바랍니다.

상담 내용은 수리 완료 또는 상담 종료일로부터 90일 동안 사후 문의 응대를 위해 보관한 뒤 삭제합니다. 결제와 관련한 기록처럼 법령에서 보관 기간을 정한 정보는 그 기간 동안 보관합니다. 보관 중인 상담 내용의 삭제를 원하시면 카카오톡 채널이나 문의 페이지로 요청해 주세요. 법령상 보관해야 하는 정보를 제외하고 지체 없이 삭제합니다.

AI 쉬운 요약과 원격 점검 신청

AI 쉬운 요약

덤프(.dmp)·이벤트 로그(.evtx) 분석 결과 아래의 ‘AI 쉬운 요약 보기’ 버튼을 누르면, 서버가 분석 결과에서 직접 뽑은 짧은 요약(정지 코드, 문제 모듈 파일 이름, 이벤트 ID와 발생 횟수 같은 근거 정보)이 같은 서버 안에서 실행되는 AI(Ollama)로 전달되어 일반인용 문장으로 정리됩니다. 외부 AI 서비스나 다른 회사 서버로 보내지 않습니다. 원본 파일과 이벤트 메시지 본문은 AI에 전달하지 않으며, 분석 결과에는 컴퓨터 이름과 사용자 이름을 담지 않습니다. 다만 .dmp·.evtx 원본에는 Windows 사용자 이름·컴퓨터 이름이 들어 있을 수 있으므로 업로드 전에 확인해 주세요.

AI 결과는 참고용 자동 요약이며 최종 진단이 아닙니다. AI가 응답하지 않으면 기본 점검 안내가 대신 표시됩니다. 요약 요청과 결과는 서버에 저장하지 않으며, 같은 IP에서의 AI 요약 요청은 시간당 5회로 제한됩니다(남용 방지용 횟수만 서버 메모리에서 잠시 대조합니다).

분석 후 파일은 곧바로 삭제됩니다. 대신 서버가 추출한 요약에 서명한 값이 분석 화면에서 1시간 동안 AI 요약·원격 점검 신청에 쓰이며, 서버는 이 값을 보관하지 않습니다.

분석 결과 저장·상담용 요약

‘진단 보고서 인쇄·PDF 저장’, ‘텍스트로 저장’, ‘카카오톡 상담용 요약’은 모두 이 브라우저 안에서 만들어지며 서버로 전송되지 않습니다. 저장 파일과 요약에는 분석 ID, 생성 시각, 올린 파일 이름, 정지 코드, 반복 의심 모듈, 주요 이벤트 근거 같은 분석 결과가 들어가므로, 다른 사람에게 보내기 전에 내용을 확인해 주세요. 분석 ID는 서버가 서명한 분석 값에서 만든 짧은 식별자이며 서버에 저장하지 않습니다. 카카오톡 상담용 요약에는 이름·연락처를 넣지 않으며, 사용자가 직접 붙여 넣어 보낸 뒤의 처리는 아래 ‘수리 의뢰 상담’과 카카오의 개인정보 처리방침을 따릅니다. 분석 결과를 링크로 공유하는 기능은 현재 제공하지 않습니다.

원격 점검 신청

분석 결과 하단의 ‘원격 점검 신청’ 폼은 사용자가 직접 제출할 때만 동작합니다. 수집 항목은 이름, 전화번호, 이메일(선택), 희망 연락 방법, 진단 요약(서버가 분석 결과로 다시 만든 내용, 최대 4,000자), 개인정보 동의 시각, 접수번호입니다. 이용 목적은 원격 점검 상담 연락과 접수 확인이며 다른 목적으로 쓰거나 제3자에게 판매하지 않습니다.

접수된 내용은 분석 서버의 접수 기록에 저장되며 운영자가 직접 확인합니다. 현재는 Telegram 등 외부 메신저로 전달하지 않습니다(알림 채널을 추가하게 되면 전달 항목과 함께 이 방침에 먼저 알립니다). 접수 기록은 접수일로부터 90일이 지나면 자동 삭제하고, 고객이 삭제를 요청하면 즉시 삭제합니다.

삭제 요청은 카카오톡 채널이나 문의 페이지로 접수번호와 함께 보내 주세요. 로그와 접수 내용에는 로그 안의 사용자 이름·계정 정보가 섞일 수 있으니 신청서의 진단 요약 외에 추가 개인정보는 적지 마세요.

원격제어 접속·종료

  • 원격제어(Seetrol)는 고객의 동의를 받은 뒤에만 접속합니다.
  • 고객은 언제든 연결을 종료할 수 있습니다.
  • 작업이 끝나면 원격 프로그램을 종료하거나 삭제합니다.
  • 비밀번호·인증서·은행 정보는 고객이 직접 입력하며, 원격 중에는 개인정보가 보이는 화면을 가릴 수 있습니다.

로그 분석 개선 활용

이벤트 로그, HWiNFO 등 하드웨어 로그, 덤프 분석 화면에는 ‘개선 활용 안내’ 항목이 기본으로 켜져 있으며, 켜진 상태에서 분석하면 결과를 개인정보를 제외한 요약으로 만들어 저장합니다. 체크를 해제하면 아무것도 저장하지 않고, 해제해도 분석 기능은 동일하게 이용할 수 있습니다. 저장하는 요약에서 개인을 식별할 수 있는 값을 제외하지만, 로그의 특성상 식별 가능성이 완전히 없다고 단정할 수는 없어 ‘개인정보를 제외한 요약’이라고 표현합니다.

  • 이벤트 로그: 이벤트 ID, 원본(소스) 이름, 수준, 로그 안에서의 상대 시각(첫 이벤트를 0초로 둔 초 단위 값), 부팅 횟수, 정지 코드·전원 버튼 기록 여부 같은 숫자 값, WHEA 오류 유형처럼 짧은 열거형 값, 사이트 규칙의 판정 결과와 규칙 버전. 원본 파일, 이벤트 메시지 본문, 컴퓨터·사용자 이름, 실제 날짜와 시각은 저장하지 않습니다.
  • 하드웨어 로그: 로그 종류, 최고 온도, 사이트가 만든 주의 신호 제목. 원본 로그 파일과 장치 이름·일련번호는 저장하지 않습니다.
  • 덤프(.dmp): 분석 결과 중 정지 코드, 결함 모듈 파일 이름, OS 빌드, 덤프 형식. 덤프 원본과 메모리 내용은 저장하지 않습니다.

저장 목적은 사이트의 진단 규칙이 실제 로그에서 얼마나 자주, 어떻게 판정되는지 확인하고 보완하는 것입니다. IP 주소와 브라우저 식별 정보는 저장하지 않으며, 저장된 기록은 수집일로부터 90일이 지나면 다음 저장 처리 시 자동 삭제합니다. 요약에는 사용자를 식별할 수 있는 값이 없어 개별 기록을 찾아 삭제하기는 어렵습니다. 저장을 원하지 않으면 분석 전에 체크를 해제하면 되며, 이미 저장된 요약은 90일 뒤 삭제됩니다.

분석 결과 아래의 ‘도움됨/아쉬움’ 버튼은 사용자가 누른 경우에만 의견 한 건(도움 여부와 판정된 규칙 이름)을 익명으로 저장하며, 분석 내용은 저장하지 않습니다. 이 기록도 90일 뒤 삭제합니다.

보관과 공유

일반 진단 기능은 브라우저 내 처리 중심으로 설계되어 있어 별도 계정에 저장하지 않습니다. 개선 활용에 동의한 AI 문의와 로그 분석 요약은 위 보관기간 동안 사이트 운영자가 관리하며 제3자에게 판매하거나 광고 목적으로 제공하지 않습니다. 외부 서비스나 처리 방식이 추가되면 이 방침과 시행일을 함께 갱신합니다.
