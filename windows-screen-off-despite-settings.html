전원 설정을 꺼도 화면이 계속 꺼질 때 원인과 점검 순서

설정 앱(설정 → 시스템 → 전원 및 배터리)에서 화면 끄기·절전 모드·최대 절전 모드를 모두 "안 함"으로 바꿨는데도, 몇 분 뒤 화면이 계속 꺼지는 경우입니다.

이 증상은 대부분 새 설정 앱 하나만 만져서 생깁니다. Windows에는 화면을 끄는 경로가 여러 개 남아 있는데, 새 설정 앱은 그중 하나만 바꿔줄 뿐이라 나머지 경로가 그대로 화면을 끄고 있는 것입니다.

가장 흔한 원인은 구식 제어판의 "화면 보호기" 설정이 새 설정 앱과 별개로 남아 있는 경우이고, 그다음은 전원 옵션의 "고급 설정"에 있는 더 세분화된 값이 설정 앱과 동기화되지 않은 경우입니다.

이 가이드가 필요한 상황

  • 설정 앱의 전원 옵션을 모두 "안 함"으로 바꿨다.
  • 그런데도 일정 시간(보통 1~15분)이 지나면 화면이 꺼진다.
  • 화면만 꺼지고 PC 자체는 켜져 있다(절전 모드로 완전히 들어가는 것과는 다름).

먼저 확인할 항목

  1. 화면 보호기 설정 확인 (가장 흔한 원인):
    ① 시작 메뉴에서 "화면 보호기 변경"을 검색해 실행
    ② 화면 보호기가 "없음"이 아니라면 "없음"으로 변경
    ③ 화면 보호기가 이미 "없음"이어도, 이 창을 한 번 열었다가 저장하는 것만으로 값이 재적용되며 해결되는 사례가 있습니다.
  2. 전원 옵션의 고급 설정 직접 확인:
    ① 제어판 → 하드웨어 및 소리 → 전원 옵션
    ② 현재 사용 중인 계획 옆 "계획 설정 변경" → "고급 전원 관리 옵션 변경"
    ③ "디스플레이" 항목을 펼쳐 "디스플레이 끄기" 시간이 실제로 "안 함"인지 확인하고, 아니라면 여기서 직접 변경
  3. 실제 활성화된 전원 관리 계획 확인:
    ① 같은 전원 옵션 화면에서 "균형 조정", "절전" 등 여러 계획 중 무엇이 선택되어 있는지 확인
    ② 설정을 바꾼 계획과 실제 선택된 계획이 다르면 반영되지 않습니다.

원인을 더 정확히 나누는 방법

노트북이라면 배터리·전원 연결 상태를 나눠서 확인

노트북은 배터리 사용 중일 때와 전원 어댑터 연결 중일 때의 화면 끄기 시간이 따로 설정됩니다. 설정 앱과 고급 전원 옵션 모두 이 두 열을 각각 확인해야 하며, 한쪽만 "안 함"으로 두면 다른 상태에서 재현될 수 있습니다.

그래도 안 된다면

위 세 가지를 모두 확인했는데도 반복된다면, 회사·학교에서 지급된 PC이거나 최적화·보안 프로그램을 설치한 적이 있는지 확인하세요. 그룹 정책이나 레지스트리로 화면 끄기 시간이 강제되고 있을 가능성이 있으며, 이 경우 관리자 권한이 필요하거나 IT 담당자에게 문의해야 할 수 있습니다.

확인 결과에 따른 다음 단계

  • 화면 보호기를 "없음"으로 바꾼 뒤 해결될 때 — 별다른 조치가 필요 없습니다. 이후 설정 앱만으로 전원 설정을 바꿔도 화면 보호기 설정은 유지되니, 나중에 값을 바꿀 때는 두 곳을 함께 확인하는 습관을 들이세요.
  • 고급 전원 옵션에서 값이 다르게 나올 때 — 설정 앱과 고급 옵션이 동기화되지 않는 경우로, 앞으로도 설정 앱만으로는 반영되지 않을 수 있으니 이 값을 기준으로 관리하세요.
  • 세 가지 모두 정상인데도 반복될 때 — 그룹 정책·레지스트리에 의한 강제 적용을 의심하고, 회사·학교 PC라면 IT 담당자에게 문의하세요.

피해야 할 실수

  • 설정 앱만 계속 다시 열어서 같은 값을 반복해서 저장하는 것 — 원인이 다른 곳에 있으면 몇 번을 반복해도 해결되지 않습니다.
  • 화면이 꺼지는 것을 절전 모드 진입과 혼동해 절전 관련 드라이버부터 의심하는 것 — 화면만 꺼지고 PC는 계속 켜져 있다면 절전 진입 문제가 아닙니다.

자주 묻는 질문

  • 화면 보호기를 없음으로 했는데도 꺼집니다. 고급 전원 관리 옵션의 디스플레이 끄기 시간이 별도로 남아있을 수 있습니다. 제어판 → 전원 옵션 → 계획 설정 변경 → 고급 전원 관리 옵션 변경에서 디스플레이 항목을 직접 확인하세요.
  • 노트북은 배터리·전원 연결 시 설정이 다른가요? 네, 노트북은 배터리 사용 중과 전원 연결 중의 화면 끄기 시간이 따로 설정됩니다. 지금 어느 쪽으로 테스트하고 있는지 확인하고, 두 상태 모두 값을 맞춰야 합니다.
