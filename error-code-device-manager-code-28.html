코드 28 · 이 장치에 대한 드라이버가 설치되어 있지 않습니다 (코드 28)

윈도우가 해당 하드웨어를 인식했지만 이를 제어할 드라이버를 찾지 못했을 때 나타나는 코드입니다. 새 하드웨어를 처음 연결했거나 윈도우를 새로 설치한 직후 자주 나타납니다.

이 코드를 어떻게 해석해야 하나요?

업데이트 관련 오류 코드는 네트워크, 캐시, 구성 요소 저장소, 디스크 공간, 서비스 상태 중 어느 단계에서 작업이 멈췄는지를 나타냅니다. 실패가 반복되는 시점과 이벤트 로그의 세부 코드를 같이 살펴보면 원인을 좁히기 수월합니다.

먼저 기록할 내용: 코드 28가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 새로 설치한 윈도우에 기본 제공되지 않는 전용 드라이버가 필요한 경우
  • 인터넷 연결 없이 설치해 자동 드라이버 검색이 이루어지지 않은 경우
  • 제조사 드라이버 설치 프로그램이 도중에 실패한 경우
  • 너무 오래되었거나 반대로 너무 최신인 운영체제와 하드웨어 조합
  • 드라이버 설치 파일 자체가 손상된 경우

첫 점검 항목

  1. 장치 관리자에서 노란 느낌표가 있는 장치를 확인하고, 하드웨어 ID로 제조사와 모델을 특정하세요.
  2. 제조사 공식 홈페이지에서 정확한 모델명의 드라이버를 다운로드해 설치하세요.
  3. Windows Update에서 선택적 업데이트에 관련 드라이버가 있는지 확인하세요.
  4. 인터넷에 연결한 상태에서 '하드웨어 변경 사항 검색'을 다시 실행해 보세요.
  5. 다운로드한 드라이버 설치 파일이 완전한지 다시 받아서 재시도하세요.

확인 결과에 따른 다음 단계

  • 제조사 드라이버 설치로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • Windows Update 선택적 업데이트로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • 재다운로드로도 해결되지 않을 때 — 하드웨어 ID로 검색해 정확한 드라이버 페이지를 다시 확인하세요.

데이터와 시스템을 보호하는 주의사항

레지스트리 정리 도구나 시스템 폴더 권한 변경은 마지막 수단으로 남겨두고, 저장 공간과 네트워크, 서비스 상태부터 확인해보세요.

앞 단계로 해결되지 않을 때

코드가 재발할 경우 Windows Update 기록과 DISM·SFC 결과를 기록해 두고, 설치 미디어의 Windows 버전이 현재 시스템과 일치하는지 확인해보세요.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

자주 묻는 질문

  • 장치가 인식이 안 되면 바로 새 제품을 사야 하나요? 이 문제(코드 28)는 장치 고장보다 드라이버나 포트 설정 문제인 경우가 흔합니다. 다른 포트나 다른 PC에서 인식되는지 먼저 확인해보세요.
  • 다른 PC에서는 잘 되는 장치인데 인식이 안 되면 뭐가 문제인가요? 장치 자체보다는 현재 PC의 USB 컨트롤러 드라이버나 전원 관리 설정 문제일 가능성이 높습니다.
  • 하드웨어 ID는 어디서 확인하나요? 장치 관리자에서 해당 장치 속성 → 세부 정보 탭 → 하드웨어 ID를 선택하면 확인할 수 있으며, 이 값으로 제조사 사이트에서 정확한 드라이버를 검색할 수 있습니다.
