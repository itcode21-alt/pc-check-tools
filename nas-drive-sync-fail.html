홈/NAS/Synology Drive 동기화가 안 됨

📑 목차

    저장공간

    Synology Drive 동기화가 안 됨 원인과 점검 순서

    PC나 폴더에서 파일을 옮기거나 지워도 Synology Drive에 반영되지 않거나, 반대로 NAS 쪽 변경이 클라이언트에 동기화되지 않는 경우

    Synology Drive는 File Station(웹 파일 관리)과 별도의 동기화 엔진으로 동작합니다. File Station에서 파일을 옮기거나 지워도 그 변경이 Drive의 동기화 대상으로 자동 반영되지 않는 경우가 있어, "파일은 지웠는데 Drive에는 그대로 보인다" 같은 혼란이 자주 생깁니다.

    동기화가 안 될 때는 먼저 어느 쪽(PC→NAS, NAS→PC) 방향이 안 되는지, 특정 파일만 그런지 폴더 전체가 그런지부터 구분하면 원인을 좁히기 쉽습니다.

    이 가이드가 필요한 상황

    • PC에서 파일을 옮기거나 지웠는데 Synology Drive(또는 File Station)에서 반영되지 않는다.
    • Drive Client 트레이 아이콘에 동기화 오류·보류 표시가 떠 있다.
    • 같은 파일 이름 뒤에 conflicted copy가 붙은 파일이 생긴다.

    먼저 확인할 항목

    1. 동기화 상태 아이콘 확인 — Drive Client 트레이 아이콘을 클릭해 동기화 대기·오류 항목이 있는지 확인하세요. 오류 항목을 클릭하면 구체적인 원인(잠김, 권한 등)이 표시됩니다.
    2. 동기화 작업(태스크) 포함 여부 확인 — Drive Client 설정에서 동기화 작업 목록에 해당 공유 폴더·하위 폴더가 포함돼 있는지 확인하고, 없다면 추가하세요.
    3. 파일 잠금·사용 중 여부 확인 — 동기화가 안 되는 파일을 열어둔 프로그램(오피스, PDF 뷰어 등)을 모두 닫고 몇 분 뒤 다시 확인하세요.
    4. 파일 충돌(conflicted copy) 정리 — conflicted copy가 붙은 파일을 찾아 최신 버전을 확인한 뒤 필요 없는 사본을 정리하세요.

    원인을 더 정확히 나누는 방법

    File Station 변경이 Drive에 안 보일 때

    File Station과 Synology Drive는 같은 파일을 다르게 취급할 수 있습니다. File Station에서 옮기거나 지운 파일은 Drive의 동기화 이력에 반영되기까지 시간이 걸리거나, 동기화 작업에 포함되지 않은 경로라면 아예 반영되지 않습니다.

    Drive Client와 DSM 버전 불일치

    DSM의 Synology Drive Server 패키지와 PC의 Drive Client 버전 차이가 크면 동기화 오류가 발생할 수 있습니다. 둘 다 최신 버전으로 맞추는 것이 안전합니다.

    확인 결과에 따른 다음 단계

    • 동기화 작업에 폴더를 추가한 뒤 해결될 때 — 새 폴더가 동기화 대상에서 빠져 있던 것이 원인입니다. 앞으로 공유 폴더를 새로 만들 때는 Drive 동기화 작업에도 함께 추가하는 습관을 들이세요.
    • 파일 잠금 해제 후에도 계속 실패할 때 — Drive Client와 Drive Server 버전 불일치나 네트워크 문제일 수 있습니다. 두 버전을 모두 최신으로 업데이트한 뒤 Client를 재시작해보세요.

    자주 묻는 질문

    • File Station에서 지운 파일이 Drive에서는 왜 안 지워지나요? File Station과 Synology Drive의 동기화 대상 경로가 다르거나, 반영에 시간이 걸리는 경우입니다. 먼저 Drive Client 설정에서 해당 폴더가 동기화 작업에 포함돼 있는지 확인하세요.
    • conflicted copy 파일은 지워도 되나요? 최신 버전을 먼저 확인한 뒤에 지우세요. 여러 기기에서 동시에 수정된 경우 어느 쪽이 최신인지 파일을 열어 직접 비교해야 안전합니다.
