📑 목차

    네트워크

    원격 데스크톱(RDP) 연결 안될 때 원인과 점검 순서

    다른 PC에 원격 데스크톱으로 연결이 안 되거나, 연결 시도 중 오류가 나는 경우

    원격 데스크톱(RDP) 연결 오류는 호스트 PC의 에디션·설정 문제, 방화벽, 네트워크 경로, 로그인 방식 중 하나인 경우가 대부분입니다. 가장 먼저 확인할 것은 연결받는 쪽(호스트) PC가 Windows Pro 이상인지입니다 — 이 조건을 놓쳐서 헤매는 경우가 매우 흔합니다.

    Microsoft 공식 문서에 따르면 원격 데스크톱으로 '연결받는' PC는 반드시 Windows Pro 버전이어야 합니다. 연결하는 쪽(클라이언트) PC는 Home이어도 상관없습니다 — 이 방향을 혼동하기 쉽습니다. 같은 사무실 안에서는 되는데 외부에서는 안 되는 경우와, 아예 처음부터 안 되는 경우는 원인이 다르므로 먼저 같은 네트워크 안에서 되는지부터 확인하면 원인을 빠르게 좁힐 수 있습니다.

    이 가이드가 필요한 상황

    • 원격 데스크톱 연결 시 '원격 컴퓨터를 찾을 수 없습니다' 또는 '연결할 수 없습니다' 오류가 뜬다.
    • PC 이름이나 IP를 정확히 입력해도 응답이 없다.
    • 로그인 화면까지는 뜨는데 PIN을 입력하면 인증에 실패한다.

    먼저 확인할 항목

    1. 호스트 PC의 Windows 에디션 확인(가장 흔한 원인) — 연결받을 PC에서 설정 → 시스템 → 정보로 이동해 Windows 사양의 버전을 확인하세요. Home이라면 원격 데스크톱을 켤 수 없습니다.
    2. 호스트 PC의 원격 데스크톱 설정 확인 — 호스트 PC에서 설정 → 시스템 → 원격 데스크톱으로 이동해 '원격 데스크톱'을 켜고, PC 이름을 기록해두세요.
    3. 방화벽에서 원격 데스크톱 허용 여부 확인 — 제어판 → Windows Defender 방화벽 → 앱 또는 기능이 방화벽을 통해 통신하도록 허용에서 '원격 데스크톱' 항목이 체크돼 있는지 확인하세요.
    4. PC 이름·IP 주소와 네트워크 경로 확인 — 같은 네트워크 안에서 먼저 연결이 되는지 확인하고, 외부에서 접속해야 한다면 회사 VPN이 필요합니다.

    원인을 더 정확히 나누는 방법

    클라이언트(연결하는 쪽) PC는 에디션 제약이 없음

    Windows Pro 조건은 '연결받는' 호스트 PC에만 적용됩니다. 연결을 시도하는 쪽(클라이언트) PC는 Home이든 Pro든 상관없고, macOS·iOS·Android에서도 'Windows 앱'(구 원격 데스크톱 앱)으로 접속할 수 있습니다. 반대로 착각해서 클라이언트 PC의 에디션만 확인하다가 시간을 허비하는 경우가 많습니다.

    사무실 안에서는 되는데 집·외부에서는 안 될 때

    이는 네트워크 경로 문제입니다. 회사 네트워크는 보통 외부에서 직접 PC 이름으로 접근할 수 없도록 막혀 있으므로, 회사 VPN에 먼저 연결한 뒤 원격 데스크톱을 시도해야 합니다. 공유기에서 직접 포트포워딩을 설정하는 방법도 있지만, 보안 위험이 있어 회사 환경에서는 VPN 경유를 권장합니다.

    원격 데스크톱과 원격 지원(빠른 지원)의 차이

    원격 데스크톱은 Pro 이상에서만 '받을' 수 있는 반면, Windows에 내장된 '빠른 지원' 앱은 Home 에디션에서도 화면을 남에게 보여주고 제어를 맡길 수 있습니다. Home PC를 원격으로 도와줘야 한다면 원격 데스크톱 대신 빠른 지원이나 TeamViewer 같은 별도 프로그램을 사용하세요.

    PIN 로그인이 실패할 때

    Windows Hello PIN은 기본적으로 원격 데스크톱 로그인에서 지원되지 않아, PIN을 입력하면 인증에 실패하는 경우가 있습니다. 원격 데스크톱 연결 화면에서 '다른 계정 사용'을 선택하고 PIN이 아니라 비밀번호를 입력해보세요.

    확인 결과에 따른 다음 단계

    • 호스트 PC가 Home 에디션일 때 — 원격 데스크톱 자체를 켤 수 없습니다. Pro로 업그레이드하거나, 빠른 지원 같은 다른 원격 지원 도구를 사용하세요.
    • 같은 네트워크 안에서는 되는데 외부에서는 안 될 때 — 네트워크 경로 문제입니다. 회사 VPN을 먼저 연결한 뒤 시도하거나, IT 담당자에게 외부 접속 방법을 문의하세요.
    • PIN 입력 시에만 실패할 때 — PIN이 아니라 비밀번호로 로그인하세요.

    자주 묻는 질문

    • 원격 데스크톱을 쓰려면 두 PC 모두 Windows Pro여야 하나요? 아닙니다. 연결받는 쪽(호스트) PC만 Pro 이상이면 됩니다. 연결하는 쪽(클라이언트)은 Home이어도 상관없고, macOS·iOS·Android에서도 접속할 수 있습니다.
    • 집에 있는 Home 에디션 PC를 원격으로 제어하려면 어떻게 하나요? 원격 데스크톱으로는 안 됩니다. Windows에 내장된 '빠른 지원' 앱이나 TeamViewer, AnyDesk 같은 별도 원격 지원 프로그램을 사용하세요.
    • PIN으로 로그인했더니 원격 데스크톱 연결에 실패합니다. 원격 데스크톱은 PIN 로그인을 기본적으로 지원하지 않습니다. 연결 화면에서 '다른 계정 사용'을 선택해 비밀번호로 로그인하세요.
