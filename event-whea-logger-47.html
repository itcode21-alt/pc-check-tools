WHEA-Logger 47 메모리 수정 오류 점검

수정된 하드웨어 오류가 발생했으며, 오류 구성 요소가 메모리로 표시되는 경우 RAM·메모리 컨트롤러·메모리 설정을 우선 확인해야 합니다.

WHEA-Logger 47은 수정된 하드웨어 오류가 발생했다는 기록입니다. 이벤트 세부 정보에서 Component가 Memory로 표시되면 RAM 자체뿐 아니라 메모리 컨트롤러, XMP·EXPO, BIOS 호환성과 슬롯 접촉을 함께 확인해야 합니다.

수정된 오류라서 즉시 장애로 이어지지 않을 수 있지만, 짧은 시간에 반복되거나 재부팅·블루스크린이 동반되면 안정성이 무너지는 신호일 수 있습니다. 기본 메모리 설정과 모듈별 교차 테스트를 먼저 진행하세요.

발생 조건

  • 부하 중 또는 유휴 상태에서 반복
  • 예기치 않은 재부팅 전후
  • 이벤트 XML의 Component가 Memory로 표시

가능성 높은 원인

  • RAM 모듈 불안정 또는 접촉 불량
  • XMP·EXPO·메모리 오버클럭 설정
  • CPU 메모리 컨트롤러·BIOS 호환성
  • 메인보드 슬롯 또는 전원 안정성 문제

점검 순서

  1. 오류 횟수·Component·ErrorSource·PhysicalAddress를 XML에서 기록 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. XMP·EXPO와 오버클럭을 끄고 기본 메모리 속도에서 재현 여부 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. RAM 모듈을 한 개씩 같은 슬롯에서 검사한 뒤 슬롯을 바꿔 교차 테스트 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
  4. MemTest86+ 또는 Windows 메모리 진단을 실행하고 WHEA 19·46·Kernel-Power 41과 발생 시각 비교 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
  5. 반복되면 중요 파일을 백업하고 BIOS·칩셋 업데이트와 메모리 호환 목록을 확인 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
주의사항

수정된 오류라는 이유만으로 무시하지 마세요. 짧은 시간에 반복되거나 재부팅·블루스크린이 동반되면 하드웨어 불안정 신호일 수 있습니다.

WHEA 47만으로 특정 RAM 모듈이나 CPU를 확정하지 말고 모듈·슬롯·기본 설정을 나눠 검사하세요.

자주 묻는 질문

  • 47이 뜨면 RAM 불량인가요? 아닙니다. RAM, CPU 메모리 컨트롤러, XMP·EXPO, BIOS, 슬롯 접촉 문제가 모두 후보입니다. 모듈과 슬롯을 나눠 검사해야 합니다.
  • 수정된 오류인데 무시해도 되나요? 단발성 기록은 관찰할 수 있지만 반복 횟수가 늘거나 재부팅·블루스크린이 함께 발생하면 백업 후 메모리 기본 설정과 진단 도구를 확인하세요.
