에러 코드 상세

인쇄 스풀러 서비스 응답 없음 · 인쇄 스풀러(Print Spooler) 서비스가 응답하지 않아 프린터 추가가 멈춤

프린터를 추가하거나 인쇄할 때 내부적으로 동작하는 인쇄 스풀러 서비스가 멈추거나 응답하지 않으면, 프린터 추가 화면이 검색 중 상태로 멈추거나 인쇄 대기열이 쌓이는 증상이 나타납니다.

이 코드를 어떻게 해석해야 하나요?

오류 코드는 원인 후보를 좁히는 단서일 뿐, 고장 부품을 확정하는 근거는 아닙니다. 최근에 무엇이 바뀌었는지, 어떤 조건에서 반복되는지, 안전 모드에서도 재현되는지를 함께 기록해두세요.

먼저 기록할 내용: 인쇄 스풀러 서비스 응답 없음가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 스풀러 서비스가 중지되었거나 손상된 스풀 파일이 쌓인 경우
  • 손상된 프린터 드라이버가 스풀러를 함께 멈추게 하는 경우
  • 대기열에 오래된 인쇄 작업이 남아 있는 경우
  • RPC(원격 프로시저 호출) 서비스가 함께 중지되어 스풀러가 시작되지 못하는 경우

첫 점검 항목

  1. 서비스 재시작 — services.msc에서 Print Spooler 서비스를 재시작해보세요.
  2. 대기 파일 정리 — 서비스를 중지한 뒤 C:\Windows\System32\spool\PRINTERS 폴더의 파일을 모두 삭제하고 서비스를 다시 시작하세요.
  3. 드라이버 재설치 — 최근 설치한 프린터 드라이버를 제거하고 다시 설치해보세요.
  4. 드라이버별 원인 특정 — 여러 프린터가 있다면 하나씩 제거하며 어떤 드라이버가 원인인지 좁혀보세요.
  5. RPC 서비스 확인 — services.msc에서 Remote Procedure Call(RPC) 서비스가 실행 중인지 확인하세요. 이 서비스가 중지되어 있으면 스풀러도 시작되지 않습니다.

확인 결과에 따른 다음 단계

  • 서비스 재시작만으로 해결될 때 — 재발 방지를 위해 시작 유형이 "자동"으로 되어 있는지 확인하세요.
  • 대기 파일 정리 후에도 반복될 때 — 특정 드라이버가 스풀 파일을 계속 손상시키고 있을 가능성이 크므로 드라이버 재설치로 넘어가세요.
  • RPC 서비스가 중지되어 있었을 때 — 자동으로 설정하고 시작한 뒤, 반복되면 맬웨어나 그룹 정책 변경 여부를 확인하세요.

데이터와 시스템을 보호하는 주의사항

아직 원인을 특정하지 못했다면 초기화나 레지스트리 편집, 시스템 파일 교체 같은 조치는 뒤로 미루세요.

앞 단계로 해결되지 않을 때

동일한 코드가 계속 나타난다면 이벤트 로그와 장치 상태를 남겨두고, 코드가 매번 바뀐다면 메모리·전원·온도 등 시스템 전반의 안정성을 점검하세요.

시스템 복구나 초기화, 드라이버 삭제처럼 원상복구가 힘든 작업을 시작하기 전에, 중요한 파일은 미리 외장 저장장치나 별도 위치에 백업해 두세요.

자주 묻는 질문

  • 프린터를 재설치하면 바로 해결되나요? 이 문제(인쇄 스풀러 서비스 응답 없음)는 드라이버보다 서비스나 권한 문제인 경우가 많아, 재설치 전에 스풀러 서비스 상태부터 확인하는 것이 순서상 더 빠릅니다.
  • 제조사 전용 프로그램을 꼭 설치해야 하나요? Windows 기본 드라이버로도 인쇄는 가능하지만, 제조사 프로그램을 설치하면 고급 기능과 상태 모니터링을 이용할 수 있습니다.
  • 네트워크 프린터에서도 같은 증상이 나면요? 네트워크 프린터라면 내 PC의 스풀러 문제 외에도 프린터를 공유하는 서버 PC의 스풀러 상태를 함께 확인해야 합니다.
