    EVENT ID 372 · PrintService

    함께 표시되는 Win32 오류 코드로 원인을 좁히세요 확인 필요

    PrintService 이벤트 372는 인쇄 작업이 프린터에서 실패했다는 기록입니다.

    "The document failed to print" 설명과 함께 Win32 오류 코드가 표시되며, 코드에 따라 원인이 크게 달라집니다. 1722는 RPC 서버 사용 불가(네트워크·연결 문제), 87은 매개 변수 오류, 259는 추가 데이터 없음(인쇄 데이터 자체 문제)을 뜻합니다.

    먼저 구분할 상황

    • 네트워크 프린터에서 오류 코드 1722가 표시된다면 프린터·프린트 서버와의 연결 및 서비스 상태를 먼저 봅니다.
    • 특정 문서에서만 반복된다면 오류 코드 87·259와 함께 문서 자체의 인쇄 데이터 문제를 의심합니다.
    • 여러 문서·프린터에서 광범위하게 발생한다면 스풀러 서비스나 드라이버 손상 가능성이 큽니다.

    안전한 점검 순서

    1. 이벤트에 포함된 Win32 오류 코드를 확인하고 의미를 대조합니다.
    2. services.msc에서 Print Spooler 서비스를 재시작합니다.
    3. 그래도 실패하면 스풀러를 정지한 뒤 C:\Windows\System32\spool\PRINTERS 폴더의 남은 작업 파일을 정리하고 서비스를 다시 시작합니다.
    4. 프린터 드라이버를 제조사 최신 버전으로 업데이트하거나 재설치합니다.
    5. 네트워크 프린터라면 양방향 지원(bidirectional support) 옵션을 끄고 재현 여부를 확인합니다.

    하면 안 되는 실수

    오류 코드를 확인하지 않고 무조건 프린터를 재설치하거나 드라이버를 삭제하지 마세요. 코드에 따라 네트워크 문제인지, 문서 자체의 문제인지, 스풀러 손상인지가 다르므로 먼저 코드를 확인하고 그에 맞는 조치를 선택하는 것이 효율적입니다.

    즉시 점검이 필요한 경우

    여러 프린터·여러 PC에서 동시에 372가 반복된다면 프린트 서버 자체의 장애일 수 있으니 서버 상태를 우선 확인하세요.

    자주 묻는 질문

    • 오류 코드 1722는 무슨 뜻인가요? RPC 서버를 사용할 수 없다는 뜻으로, 네트워크 프린터나 프린트 서버와의 연결이 끊어졌거나 해당 장치의 인쇄 스풀러 서비스가 응답하지 않을 때 나타납니다. 네트워크 연결과 프린터·서버의 전원, 인쇄 서비스 상태를 먼저 확인하세요.
    • 스풀러를 재시작해도 계속 실패하면 어떻게 하나요? 스풀 폴더에 남아있는 손상된 작업 파일이 원인일 수 있습니다. 스풀러 서비스를 정지한 뒤 spool\PRINTERS 폴더의 파일을 정리하고 서비스를 다시 시작해보세요. 그래도 반복되면 프린터 드라이버를 최신 버전으로 재설치하세요.
    • 특정 문서에서만 반복되면 무엇을 확인해야 하나요? 오류 코드 87(매개 변수 오류)이나 259(추가 데이터 없음)가 함께 표시된다면 해당 문서의 인쇄 데이터 자체에 문제가 있을 수 있습니다. 다른 형식으로 다시 저장하거나 다른 프린터로 인쇄해 문서 자체의 문제인지 구분하세요.
