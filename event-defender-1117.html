    EVENT ID 1117 · Windows Defender

    Action 값이 위협 제거 여부를 결정합니다 확인 필요

    Windows Defender 이벤트 1117은 앞서 1116에서 탐지된 위협에 대해 Defender가 실제로 어떤 조치를 실행했는지 기록합니다.

    Action(작업) 값이 격리·제거·정리라면 정상적으로 처리된 것이지만, '허용'으로 기록됐다면 위협이 격리·제거되지 않고 그대로 실행이 허용됐다는 뜻입니다. 1116과 1117을 반드시 짝지어 확인해야 실제 처리 결과를 알 수 있습니다.

    먼저 구분할 상황

    • Action이 격리·제거·정리라면 정상적으로 위협이 처리된 것이며 격리함에서 최종 확인만 하면 됩니다.
    • Action이 '허용'이라면 예외 설정이나 정책 때문에 위협이 그대로 실행됐을 수 있어 즉시 재검토가 필요합니다.
    • 재부팅이 필요하다는 안내가 있다면 조치가 다음 재시작 후 완료되므로 재부팅 전까지는 위협이 남아있을 수 있습니다.

    안전한 점검 순서

    1. 이벤트 설명에서 Action(작업) 값과 대상 위협 이름, 파일 경로를 확인합니다.
    2. Windows 보안 → 바이러스 및 위협 방지 → 보호 기록에서 같은 항목의 처리 상태를 재확인합니다.
    3. Action이 '허용'이면 설정의 제외 목록과 실시간 보호·클라우드 제공 보호 설정을 점검합니다.
    4. 격리함에 있는 항목은 안전이 확인되면 영구 삭제하거나, 오탐이 의심되면 위협 이름을 검색해 재확인 후 복원 여부를 결정합니다.
    5. 재부팅이 필요한 항목이라면 재부팅 후 Microsoft Defender Offline으로 다시 검사해 완전히 제거됐는지 확인합니다.

    하면 안 되는 실수

    Action이 '허용'으로 표시된 항목을 확인 없이 그대로 두지 마세요. 신뢰할 수 있는 소프트웨어의 오탐이 아니라면 위협이 실행 중일 수 있습니다. 반대로 조치가 정상적으로 완료된 격리·제거 기록을 보고 시스템 전체 재설치 같은 과도한 조치를 취할 필요도 없습니다.

    즉시 점검이 필요한 경우

    Action이 '허용'으로 반복되거나, 조치 완료 뒤에도 낯선 프로세스·네트워크 연결·계정 이상이 계속된다면 네트워크 연결을 차단하고 Microsoft Defender Offline 검사를 우선 실행하세요.

    자주 묻는 질문

    • Action이 '허용'으로 기록되면 무슨 뜻인가요? 탐지된 위협을 격리·제거하지 않고 그대로 실행을 허용했다는 뜻입니다. 신뢰할 수 있는 프로그램을 오탐으로 예외 처리한 경우가 아니라면, 낯선 프로그램에 대해 Action이 '허용'으로 남아 있는 것은 위협이 시스템에 그대로 남아 있다는 경고 신호이므로 예외 설정과 정책을 즉시 재검토해야 합니다.
    • 격리된 파일은 안전하게 삭제해도 되나요? Windows 보안의 보호 기록에서 격리함 항목을 확인한 뒤 영구 삭제할 수 있습니다. 다만 오탐이 의심되는 정상 파일이라면 삭제 전에 위협 이름을 검색해 실제 성격을 확인하는 것이 안전합니다.
    • 조치가 완료됐는데도 증상이 계속되면 어떻게 하나요? 1117에서 조치가 완료로 표시돼도 재부팅이 필요한 파일이거나 다른 악성 구성 요소가 남아 있을 수 있습니다. Microsoft Defender Offline으로 재부팅 전 오프라인 검사를 실행해 완전히 제거됐는지 다시 확인하세요.
