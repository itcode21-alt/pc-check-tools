    네트워크

    NAS 외부 접속이 느림(QuickConnect) 원인과 점검 순서

    QuickConnect로 외부에서 NAS에 접속하면 속도가 느리거나 자주 끊기는 경우

    QuickConnect는 공유기에서 별도 포트포워딩 설정 없이도 외부에서 NAS에 접속할 수 있게 해주는 편의 기능입니다. 다만 직접 연결 경로를 만들지 못하면 시놀로지의 중계(릴레이) 서버를 거치게 되는데, 이 릴레이 서버는 대역폭이 제한돼 있어 파일 전송이나 스트리밍이 눈에 띄게 느려집니다.

    집에서 로컬 네트워크로 접속할 때는 빠른데 외부(모바일 데이터, 다른 Wi-Fi)에서만 느리다면 이 릴레이 경유 여부부터 확인하는 것이 첫 단계입니다.

    이 가이드가 필요한 상황

    • 집 안 네트워크에서는 빠른데 외부에서만 느리다.
    • 대용량 파일을 다운로드하면 예상 시간이 비정상적으로 길게 표시된다.
    • DS file·Synology Drive 모바일 앱에서 스트리밍이 자주 끊긴다.

    먼저 확인할 항목

    1. 연결 방식 확인 — DSM → 제어판 → 외부 액세스 → QuickConnect에서 연결 상태가 '릴레이'인지 '직접 연결(P2P)'인지 확인하세요.
    2. 공유기 포트포워딩 설정 — 공유기 관리 페이지에서 외부 포트 5000(HTTP)·5001(HTTPS)을 NAS의 내부 IP로 전달하도록 설정하세요. 공유기 기종마다 메뉴 위치가 다르니 제조사 매뉴얼도 함께 확인하세요.
    3. DDNS로 직접 연결 구성 — DSM → 제어판 → 외부 액세스 → DDNS에서 호스트 이름을 등록하고, 위 포트포워딩을 함께 설정하세요.
    4. 이중 NAT 여부 확인 — 통신사 모뎀이 자체 공유기 기능을 겸하고 있다면 브리지 모드로 전환하거나, 통신사 모뎀에서도 동일하게 포트포워딩을 설정하세요.

    원인을 더 정확히 나누는 방법

    QuickConnect vs DDNS, 뭐가 더 안전한가요

    QuickConnect는 설정이 간단하지만 릴레이 경유 시 느리고, 시놀로지 서버 상태에 영향을 받습니다. DDNS+포트포워딩은 설정이 조금 더 필요하지만 속도가 안정적입니다. 자주 대용량 파일을 주고받는다면 DDNS 방식을 권장합니다.

    포트포워딩이 보안상 괜찮은가요

    불특정 다수에 노출되는 것이므로, DSM 자체 비밀번호를 강력하게 설정하고 2단계 인증을 켜는 것이 좋습니다. 가능하면 기본 포트(5000/5001) 대신 다른 포트로 변경해 자동화된 스캔을 피하는 것도 방법입니다.

    확인 결과에 따른 다음 단계

    • 포트포워딩 후 속도가 개선될 때 — 릴레이 경유가 원인이었던 것이 확인된 것입니다. 공유기 재부팅 후에도 설정이 유지되는지 한 번 더 확인하세요.
    • 포트포워딩을 해도 여전히 릴레이로 표시될 때 — 이중 NAT 환경일 가능성이 큽니다. 통신사 모뎀의 브리지 모드 전환을 고려하세요.

    자주 묻는 질문

    • QuickConnect 연결이 왜 이렇게 느린가요? 포트포워딩이나 DDNS가 설정돼 있지 않으면 시놀로지 릴레이 서버를 거쳐 연결되는데, 이 릴레이는 대역폭이 제한돼 있어 느립니다. 공유기에서 포트포워딩을 설정하면 직접 연결로 전환되어 속도가 개선됩니다.
    • 포트포워딩을 했는데도 계속 느립니다. 이중 NAT(통신사 모뎀+개인 공유기가 함께 연결된 환경)일 가능성이 있습니다. 통신사 모뎀을 브리지 모드로 전환하거나 모뎀에서도 같은 포트를 전달하도록 설정해야 합니다.
