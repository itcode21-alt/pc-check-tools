EventLog 6005 Windows 시작 시각 확인

Windows 이벤트 로그 서비스가 시작되었음을 기록하는 정보성 이벤트입니다. 보통 시스템 부팅 시각을 잡는 기준점으로 사용하며, 오류 자체가 아닙니다.

6005는 Windows 이벤트 로그 서비스가 시작되었음을 기록하는 정보성 이벤트입니다. 보통 부팅 시각을 확인하는 기준점으로 사용하며, 오류나 비정상 종료를 의미하지 않습니다.

재부팅 원인을 찾을 때는 6005 하나보다 6008·Kernel-Power 41·User32 1074를 함께 시간순으로 배열하는 것이 효과적입니다.

발생 조건

  • Windows 부팅 직후
  • 이벤트 로그 서비스가 다시 시작된 뒤
  • 재부팅 전후 시간대를 비교할 때

가능성 높은 원인

  • 정상적인 Windows 시작
  • 이벤트 로그 서비스 재시작
  • 업데이트·복구 작업 뒤 서비스 초기화

점검 순서

  1. 6005 시각을 Kernel-Power 41·EventLog 6008·User32 1074와 비교 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 부팅 시각과 실제 전원 켜기 시각이 다른지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 짧은 시간에 반복되면 이벤트 로그 서비스 재시작 원인과 7000 계열을 함께 확인 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
주의사항

6005는 정상 부팅·서비스 시작 기록인 경우가 대부분입니다. 이 이벤트만으로 재부팅 원인을 판단하지 마세요.

자주 묻는 질문

  • 6005가 매번 기록되는 것이 정상인가요? 네. Windows가 부팅하거나 이벤트 로그 서비스를 시작할 때 기록될 수 있습니다. 기능 장애 없이 정상 부팅할 때마다 보인다면 일반적인 정보성 기록입니다.
  • 6005로 부팅 시간을 알 수 있나요? 대략적인 이벤트 로그 서비스 시작 시각을 확인할 수 있습니다. 정확한 전원 인가 시각과는 차이가 있을 수 있으므로 다른 시작 이벤트와 함께 비교하세요.
