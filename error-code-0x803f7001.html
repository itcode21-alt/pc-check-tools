에러 코드 상세

0x803F7001 · Windows 라이선스를 찾을 수 없음

Windows 활성화에 사용할 유효한 디지털 라이선스나 제품 키를 찾지 못할 때 나타납니다.

이 코드를 어떻게 해석해야 하나요?

이 코드는 Windows가 현재 설치된 에디션을 활성화할 수 있는 유효한 디지털 라이선스나 제품 키를 찾지 못했다는 뜻입니다. 메인보드 교체 같은 하드웨어 변경, Microsoft 계정 연결, Home·Pro 에디션 차이를 함께 확인해야 합니다.

먼저 기록할 내용: 0x803F7001가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 메인보드 교체로 이전 디지털 라이선스가 기억하는 하드웨어 정보와 불일치
  • Microsoft 계정에 라이선스를 연결하지 않은 상태에서 재설치
  • 복제한 디스크 이미지나 sysprep 없이 만든 이미지로 여러 PC에 설치
  • 가상머신용 이미지를 물리 PC로(또는 그 반대로) 옮겨 설치
  • 평가판(Evaluation)·Insider 빌드에서 정식 빌드로 전환

첫 점검 항목

  1. 에디션 확인 — 설정 > 시스템 > 정품 인증에서 Home·Pro와 활성화 상태를 확인하세요.
  2. 계정 연결 여부 확인 — 이전에 이 PC를 인증했던 Microsoft 계정으로 로그인되어 있는지 확인하세요. 로컬 계정만 썼다면 라이선스가 계정에 연결되지 않았을 수 있습니다.
  3. 정품 인증 문제 해결사 실행 — 설정 > 시스템 > 정품 인증 > 문제 해결에서 "최근 이 장치의 하드웨어를 변경했습니다"를 선택해 재인증을 시도하세요.
  4. 제품 키 확인 — 구매 증빙·패키지·제조사 기록의 25자리 키가 현재 에디션과 일치하는지 확인하세요.
  5. 라이선스 상태 확인 — 관리자 명령 프롬프트에서 slmgr /dlv로 활성화 상태와 라이선스 채널을 확인하세요.

확인 결과에 따른 다음 단계

  • Microsoft 계정에 연결되어 있었을 때 — 문제 해결사의 "최근 이 장치의 하드웨어를 변경했습니다" 옵션으로 대부분 자동 재인증됩니다.
  • 계정에 연결된 적이 없을 때 — 문제 해결사가 작동하지 않으므로 정품 제품 키를 직접 입력해야 합니다. 키를 찾을 수 없다면 구매처나 PC 제조사에 문의하세요.
  • 복제된 이미지로 여러 PC에 설치했을 때 — 같은 라이선스를 여러 대에서 동시에 쓰는 상태일 수 있습니다. 각 PC마다 정식 라이선스를 개별 구매해야 합니다.
  • 가상머신 ↔ 물리 PC 이동이었을 때 — 대부분 별도의 라이선스가 필요합니다. 같은 키를 계속 재사용하면 이 오류가 반복됩니다.

데이터와 시스템을 보호하는 주의사항

정확한 원인을 파악하기 전에 초기화나 레지스트리 수정, 시스템 파일 수동 교체부터 시도하지 않는 것이 좋습니다.

앞 단계로 해결되지 않을 때

같은 코드가 반복되면 이벤트 로그와 장치 상태를 보존하고, 코드가 계속 달라지면 메모리·전원·온도처럼 시스템 전체 안정성을 확인하세요.

되돌리기 어려운 조치(복구, 초기화, 드라이버 제거 등)에 들어가기 전에는 반드시 중요 데이터를 다른 저장장치로 옮겨 두는 것이 안전합니다.

자주 묻는 질문

  • 메인보드를 바꾸면 다시 구매해야 하나요? Microsoft 계정에 연결된 디지털 라이선스라면 문제 해결사를 통해 재활성화를 시도할 수 있습니다. 라이선스 종류에 따라 결과가 다릅니다.
  • 제품 키를 웹에서 찾아 입력해도 되나요? 출처가 불분명한 키나 인증 우회 도구는 사용하지 말고 구매처·제조사·Microsoft 공식 경로를 이용하세요.
  • 로컬 계정만 쓰고 있었다면 방법이 없나요? Microsoft 계정으로 전환해 로그인한 뒤 문제 해결사를 다시 실행해보세요. 과거에 그 계정으로 한 번이라도 인증한 적이 있다면 라이선스가 연결되어 있을 수 있습니다.
