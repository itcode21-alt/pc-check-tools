에러 코드 상세

0x00000117 · VIDEO_TDR_TIMEOUT_DETECTED

디스플레이 드라이버가 제때 응답하지 않았음을 나타내는 라이브 덤프 식별 값입니다. 문서는 이 값이 실제 블루스크린 코드로는 쓰이지 않는다고 설명합니다.

이 코드를 어떻게 해석해야 하나요?

문서에 따르면 0x117은 실제 버그 체크로 쓰이지 않고 라이브 덤프(시스템을 멈추지 않고 수집하는 덤프)를 식별하는 값입니다. 의미는 TDR(시간 초과 감지 및 복구) 과정과 같습니다. GPU가 그래픽 작업(보통 게임 중)을 처리하느라 응답하지 않으면 Windows가 감지해 드라이버를 초기화하고 GPU를 재설정하며, 기본 제한 시간은 2초입니다. 복구에 성공하면 "디스플레이 드라이버가 응답을 멈췄다가 복구되었습니다" 메시지가 보입니다. 원인과 점검은 0x116과 같게 문서가 안내합니다. 오래된 디스플레이 드라이버, 오버클럭된 구성 요소, 메모리 구성·타이밍 설정 문제, 부족한 냉각이나 전력, 불량 부품, 시각 효과나 백그라운드 프로그램 때문에 PC가 느려진 경우입니다.

이 코드가 가리키는 것

원인 후보(문서 설명 기준): TDR 과정을 제대로 지원하지 않는 오래된 디스플레이 드라이버; 오버클럭된 구성 요소(메인보드 등); 구성 요소 호환성이나 설정 문제, 특히 메모리 구성과 타이밍; 부족한 시스템 냉각 또는 부족한 전력; 메모리 모듈이나 메인보드 같은 불량 부품; 시각 효과나 많은 백그라운드 프로그램으로 PC가 느려져 비디오 카드가 제때 응답하지 못하는 경우.

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 이 값은 블루스크린 코드가 아니라 라이브 덤프 식별 값입니다. 실제 블루스크린이 났다면 화면의 코드는 다른 값(예: 0x116)일 수 있으니 그 코드 페이지를 보세요.
  2. 공식 문서가 알려 주는 것: 디스플레이 드라이버를 최신 업데이트로 설치해 TDR 과정을 제대로 지원하게 하세요. 무료 도구로 재설치하는 방법 보기 →
  3. 공식 문서가 알려 주는 것: 오버클럭을 기본값으로 되돌리고, 메모리 구성과 타이밍, 시스템 냉각과 전력, 불량 부품 여부를 점검하세요.
  4. 공식 문서가 알려 주는 것: 시각 효과를 줄이고 백그라운드 프로그램을 정리해 PC가 느려지지 않게 한 뒤 재현 여부를 보세요.
  5. 문서 외 일반 점검: GPU 온도를 확인하고 그래픽카드 보조 전원 케이블이 완전히 꽂혀 있는지 보세요.

확인 결과에 따른 다음 단계

  • 실제로 블루스크린이 났을 때 — 화면에 표시된 코드를 확인하세요. 디스플레이 드라이버 복구가 실패한 경우는 0x116으로 표시될 수 있습니다. 이 연결은 문서가 두 코드를 같은 TDR 과정으로 설명하는 데 근거합니다.
  • 드라이버 재설치로 해결될 때 — 같은 버전에서 반복되면 한 단계 이전 버전을 써 보세요. 이 사이트에는 클린 재설치로 해결된 사례가 있습니다.
  • 고부하에서만 나오고 온도가 높을 때 — 냉각을 점검하고 오버클럭을 기본값으로 되돌려 재현 여부를 확인하세요.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

반복되는 코드가 같다면 이벤트 로그와 장치 상태를 남겨두세요. 코드가 매번 다르다면 메모리·전원·온도 등 시스템 전체 안정성부터 확인하는 것이 순서입니다.

되돌리기 어려운 조치(복구, 초기화, 드라이버 제거 등)에 들어가기 전에는 반드시 중요 데이터를 다른 저장장치로 옮겨 두는 것이 안전합니다.

자주 묻는 질문

  • 0x117이 블루스크린에 뜨나요? Microsoft Learn은 이 코드가 실제 버그 체크로는 사용할 수 없고 라이브 덤프를 식별하는 데만 쓰인다고 설명합니다. 블루스크린이 났다면 화면의 코드는 다를 가능성이 큽니다.
  • 0x116과 무엇이 다른가요? 둘 다 디스플레이 드라이버의 TDR과 관련됩니다. 0x116은 복구에 실패해 시스템이 멈추는 실제 블루스크린이고, 0x117은 라이브 덤프를 식별하는 값입니다.
