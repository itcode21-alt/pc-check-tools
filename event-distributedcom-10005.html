EVENT ID 10005

DistributedCOM 이벤트 10005 서비스 시작 오류 점검

DCOM이 필요한 서비스를 시작하려 했지만 오류를 반환했다는 기록입니다. 이벤트 설명에 서비스 이름과 오류 번호가 포함되므로 10005 자체보다 그 서비스를 먼저 확인해야 합니다.

10005는 DCOM이 필요한 서비스를 시작하려다 오류를 만났다는 기록입니다. 기록 자체보다 이벤트 설명에 적힌 서비스 이름과 오류 번호가 단서입니다.

의존하는 서비스가 중지됐거나 시작 유형이 바뀐 경우가 흔합니다. services.msc에서 해당 서비스와 의존 서비스를 확인하고, 같은 시각의 Service Control Manager 7000·7001·7023 기록과 비교하세요.

발생 조건

  • 특정 기능 실행 실패
  • 로그인·부팅 중 서비스 시작 오류
  • 검색·인증·네트워크 기능이 함께 작동하지 않음

가능성 높은 원인

  • 의존 서비스가 중지되었거나 시작 유형이 바뀐 경우
  • 서비스 파일·앱 구성 손상
  • 보안 정책이나 클린 부팅으로 서비스가 꺼진 경우

점검 순서

  1. 이벤트 설명의 서비스 이름과 오류 번호 기록 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. services.msc에서 해당 서비스와 의존 서비스 상태 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. Service Control Manager 7000·7001·7023과 발생 시각 비교 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 필요 서비스라면 Windows 구성 요소 복구나 해당 앱 재설치를 검토 — 변경 전후로 증상이 달라지는지 비교해보세요.
주의사항

모든 서비스를 일괄적으로 자동 시작으로 바꾸거나 레지스트리를 수정하지 마세요.

관련 코드·가이드

0x80070422 오류 코드 확인하기0x80070005 오류 코드 확인하기앱 실행 불가 가이드

자주 묻는 질문

  • 서비스를 전부 자동으로 바꾸면 해결되나요? 권하지 않습니다. 필요한 서비스만 확인해야 하고, 일괄 변경은 부팅 지연이나 충돌을 만들 수 있습니다.
  • 오류 번호는 어디서 보나요? 이벤트 설명 문장 안에 서비스 이름과 함께 오류 번호가 적혀 있습니다. 번호를 기록해 두고 같은 번호의 Windows 오류 코드 설명을 찾아보세요.
