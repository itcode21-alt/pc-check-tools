EVENT ID 129

stornvme 이벤트 129 NVMe 장치 재설정 점검

NVMe 저장장치에 보낸 요청이 제한 시간 안에 끝나지 않아 Windows가 해당 장치 경로를 재설정(Reset)했다는 기록입니다. 메시지의 RaidPort 번호는 디스크 번호가 아니라 저장소 포트 번호입니다.

129는 Storport가 저장장치에 보낸 요청이 제한 시간 안에 끝나지 않아 해당 경로를 재설정했다는 기록입니다. Microsoft의 문제 해결 안내도 129를 디스크 요청의 시간 초과로 설명하며, 원인이 SSD 하나로 정해지지는 않습니다.

storahci 129는 SATA 장치에서, stornvme 129는 NVMe 장치에서 같은 종류의 재설정이 일어났다는 뜻입니다. 한두 번이면 일시적 지연일 수 있고, 멈춤과 함께 반복되면 장치·드라이버·전원 설정을 순서대로 비교하세요.

발생 조건

  • 게임·파일 복사·부팅 중 순간적으로 멈췄다가 풀림
  • 절전 복귀 직후 한동안 반응이 느림
  • stornvme 11 또는 Disk 153·Ntfs 기록이 같은 시각에 함께 남음

가능성 높은 원인

  • SSD 펌웨어 또는 NVMe·칩셋 드라이버 문제
  • PCIe 링크 상태·전원 관리(절전) 설정과 SSD의 궁합 문제
  • M.2 슬롯 접촉 불량이나 과열로 인한 응답 지연
  • SSD 자체의 응답 지연이나 수명 저하

점검 순서

  1. 중요한 파일을 다른 저장장치에 먼저 백업 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 제조사 진단 도구로 SSD 상태(SMART)·온도·펌웨어 버전 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 같은 시각의 stornvme 11, Disk 153, Ntfs 이벤트가 함께 있는지 비교 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 메인보드 BIOS와 칩셋·NVMe 드라이버 업데이트 여부 확인 — 변경 전후로 증상이 달라지는지 비교해보세요.
  5. 전원 관리 옵션을 고성능으로 바꿔 재현 여부 비교 — 여기까지 확인해도 해결되지 않으면 다음 원인을 검토하세요.
주의사항

레지스트리의 디스크 제한 시간(TimeOutValue)을 임의로 바꾸지 마세요. 제조사 안내 없이 바꾸면 원인이 가려질 수 있습니다.

멈춤이 반복되면 점검보다 백업이 먼저입니다.

자주 묻는 질문

  • 129가 뜨면 SSD가 고장 난 건가요? 단정할 수 없습니다. 펌웨어·드라이버·PCIe 전원 관리·발열로도 같은 기록이 남습니다. 반복 빈도와 SMART 상태, 같은 시각의 stornvme 11·Disk 153 기록을 함께 보고 판단하세요.
  • RaidPort0이면 RAID를 쓰고 있다는 뜻인가요? 아닙니다. NVMe SSD도 같은 저장소 포트 이름으로 기록되며, 번호는 디스크 번호가 아니라 포트 번호입니다. 어느 장치인지는 같은 시각의 다른 기록이나 SSD 제조사 도구로 확인하세요.
