Security 4625 로그온 실패 점검

계정이 로그온에 실패했음을 기록합니다. 반복되면 잘못된 비밀번호 입력, 계정 잠금, 또는 외부 접근 시도를 나타낼 수 있습니다.

4625는 계정 로그온이 실패했다는 기록입니다. 실패 이유 코드와 로그온 유형(대화형/원격/네트워크)을 함께 확인해야 단순 오타인지 외부 접근 시도인지 구분할 수 있습니다.

본인이 시도하지 않은 시각에 특정 계정만 짧은 간격으로 반복 실패한다면, 원격 데스크톱이나 공유 폴더처럼 외부에서 접근 가능한 경로가 노출되어 있는지 함께 확인하세요.

발생 조건

  • 로그인 실패 메시지
  • 도메인 계정 접근 오류
  • 원격 데스크톱 연결 실패

가능성 높은 원인

  • 비밀번호 오입력 반복
  • CapsLock 또는 한영 전환 문제
  • 저장된 자격 증명 만료
  • 외부 무차별 대입 시도

점검 순서

  1. 실패 이유 코드(0xC000006D 등)와 로그온 유형 확인 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 특정 계정만 반복 실패하는지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 원격 접근이면 소스 IP 확인 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
주의사항

같은 계정의 반복 실패가 짧은 시간에 몰린다면 보안 위협일 수 있습니다.

자주 묻는 질문

  • 4625가 가끔 있는 건 정상인가요? 본인이 비밀번호를 잘못 입력했거나 CapsLock·한영 전환 상태였다면 정상적으로 남는 기록입니다. 특정 계정에서 짧은 시간에 몰아서 반복되는지가 핵심 판단 기준입니다.
  • 소스 IP가 낯선 외부 주소인데 어떻게 해야 하나요? 원격 데스크톱이나 공유 서비스가 인터넷에 노출되어 있는지 확인하고, 불필요하다면 포트를 닫거나 방화벽 규칙을 강화하며 즉시 계정 비밀번호를 변경하세요.
