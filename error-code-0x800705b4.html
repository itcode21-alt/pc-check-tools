에러 코드 상세

0x800705b4 · 작업 시간 초과

Windows 시스템 오류 1460(ERROR_TIMEOUT)으로 '제한 시간이 지나 작업이 반환되었다'는 코드입니다. Microsoft 지원 문서는 업데이트가 너무 오래 걸리거나 중단된 경우로 안내합니다.

이 코드를 어떻게 해석해야 하나요?

Windows 시스템 오류 코드에서 0x800705B4는 제한 시간이 지나 작업이 반환되었다는 시간 초과로 정의됩니다. Microsoft의 업데이트 문제 해결 문서는 이 코드를 업데이트가 설치되는 데 너무 오래 걸렸거나 중단된 경우로 설명하고, 인터넷 연결 확인, 바이러스 백신·방화벽을 잠시 끈 뒤 백신 업데이트, PC 다시 시작을 안내합니다. Windows 10에서는 문제 해결사 실행과 SoftwareDistribution 초기화도 안내합니다. 디스크 상태나 시간대 변경은 문서 외 일반 점검입니다.

가능성 높은 원인

  • 네트워크 속도가 느리거나 불안정해 다운로드가 지연되는 경우
  • 디스크 응답 속도가 느려 파일 처리가 지연되는 경우
  • 백그라운드에서 다른 무거운 작업이 동시에 실행되고 있는 경우
  • 서버 측 응답이 느린 시간대에 접속한 경우
  • 보안 소프트웨어의 검사로 인해 처리 속도가 느려진 경우

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 설정 > 네트워크 및 인터넷에서 인터넷 연결을 확인하고 끊겨 있으면 다시 연결하세요.
  2. 공식 문서가 알려 주는 것: 바이러스 백신이나 방화벽을 짧은 시간 동안만 잠시 끄고, 백신 소프트웨어를 최신으로 업데이트한 뒤 다시 켜세요. 끈 상태로 오래 두지 마세요.
  3. 공식 문서가 알려 주는 것: PC를 다시 시작하고 업데이트를 재시도하세요. Windows 10에서는 문제 해결사를 실행하고, Windows Update 서비스를 중지한 뒤 C:\Windows\SoftwareDistribution 안의 내용을 지우고 서비스를 다시 시작하는 방법도 안내합니다.
  4. 문서 외 일반 점검: 다른 무거운 프로그램을 종료하고 유선 연결로 바꿔 다시 시도하세요. 성공하면 자원 경합이나 네트워크가 원인이었습니다.
  5. 문서 외 일반 점검: 디스크 응답이 느린지(특히 HDD, SSD는 여유 공간) 점검하고, 트래픽이 적은 시간대에 다시 시도해 보세요.

확인 결과에 따른 다음 단계

  • 유선 연결로 전환한 뒤 해결될 때 — 무선 신호가 약하다면 공유기 위치를 옮기거나 유선 연결을 유지하세요.
  • 다른 프로그램 종료 후 해결될 때 — 작업 관리자에서 큰 용량을 쓰는 백그라운드 프로그램을 확인하고, 필요 없는 프로그램은 자동 시작에서 끄세요.
  • 시간대를 바꿔도 반복될 때 — 서버 쪽 일시 장애일 수 있으니 시간을 두고 다시 시도하세요.

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한을 손대거나 레지스트리 정리 프로그램을 실행하기보다는, 디스크 여유 공간과 네트워크 연결, 관련 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

코드가 재발할 경우 Windows Update 기록과 DISM·SFC 결과를 기록해 두고, 설치 미디어의 Windows 버전이 현재 시스템과 일치하는지 확인해보세요.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

공식 참고자료

Microsoft 지원: Windows 업데이트 문제 해결 (0x800705b4)

자주 묻는 질문

  • 0x800705B4는 인터넷이 느리다는 뜻인가요? Windows 시스템 오류의 정의는 제한 시간 초과입니다. Microsoft 지원 문서는 업데이트 설치가 너무 오래 걸리거나 중단된 경우로 설명하며, 원인이 네트워크일 수도 있고 보안 프로그램일 수도 있어 코드만으로는 구분되지 않습니다.
  • 백신을 끄고 업데이트해도 안전한가요? Microsoft 문서는 짧은 시간 동안만 잠시 끄고 백신 소프트웨어를 업데이트하라고 안내합니다. 끈 상태로 오래 두지 말고 업데이트가 끝나면 바로 다시 켜세요.
