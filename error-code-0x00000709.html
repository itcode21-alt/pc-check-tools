📑 목차

에러 코드 상세

0x00000709 · 프린터를 기본 프린터로 설정할 수 없습니다

공유된 네트워크 프린터를 기본 프린터로 설정하려 할 때 프린터 이름을 인식하지 못해 나타날 수 있습니다.

이 코드를 어떻게 해석해야 하나요?

네트워크로 공유된 프린터를 기본 프린터로 지정하려 할 때 나타나는 오류로, 프린터 이름이 실제 공유 이름과 일치하지 않거나 인쇄 스풀러·드라이버 문제로 프린터를 정상적으로 인식하지 못할 때 발생합니다.

먼저 기록할 내용: 0x00000709가 발생한 시각, 어떤 프린터(로컬/네트워크)였는지, 최근 프린터를 새로 추가하거나 공유 설정을 바꾼 적이 있는지를 적어 두세요.

가능성 높은 원인

  • 프린터를 공유하는 호스트 PC에서 프린터 이름이 변경되었거나 공유가 해제된 경우
  • 클라이언트 PC에 해당 프린터 드라이버가 제대로 설치되지 않은 경우
  • 인쇄 스풀러 서비스가 응답하지 않거나 손상된 경우
  • 네트워크 프린터 연결 프로토콜(공유 폴더 권한 등)에 문제가 있는 경우
  • 공유 프린터에 접근할 사용자 권한이 없는 경우

첫 점검 항목

  1. 제어판에서 문제의 네트워크 프린터를 제거한 뒤 다시 추가해보세요.
  2. 인쇄 스풀러 서비스를 재시작(services.msc)한 뒤 다시 시도하세요.
  3. 프린터를 공유하는 호스트 PC에서 프린터 이름과 공유 상태가 그대로인지 확인하세요.
  4. 제조사 홈페이지에서 최신 드라이버를 받아 다시 설치하세요.
  5. 공유 프린터에 접근할 사용자 계정 권한이 있는지 호스트 PC에서 확인하세요.

실제 사용자 사례

위 점검 순서로도 해결되지 않았을 때, 다른 원인으로 해결된 사례입니다.

인쇄 스풀러 재시작으로 해결

사무실 네트워크 프린터를 기본 프린터로 지정할 때마다 이 오류가 반복됐던 사례가 있습니다. 인쇄 스풀러 서비스를 재시작하고 프린터를 다시 추가하자 정상적으로 설정됐습니다.

포인트: 프린터를 다시 추가하기 전에 인쇄 스풀러 서비스부터 재시작해보는 것이 가장 간단하고 효과적인 첫 조치입니다.

데이터와 시스템을 보호하는 주의사항

프린터를 제거하기 전에 인쇄 대기열에 중요한 문서가 남아있지 않은지 확인하세요.

앞 단계로 해결되지 않을 때

같은 오류가 계속되면 호스트 PC와 클라이언트 PC의 Windows 버전·업데이트 상태를 비교하고, 다른 PC에서도 같은 프린터에 접근되는지 교차 확인하세요.

레지스트리를 직접 수정하는 방법은 마지막 수단으로 남겨두고, 먼저 프린터 제거·재설치와 스풀러 재시작으로 해결되는지 확인하세요.

관련 증상 가이드 확인하기

같은 증상과 연결된 다른 오류 코드

  • 0x80070005 · Access Denied
  • 0x800704B3 · 원격 프로시저 호출(RPC)이 실패했습니다
  • 인쇄 스풀러 서비스 응답 없음

공식 참고자료

자주 묻는 질문

  • 프린터를 삭제하고 다시 추가하면 설정이 다 사라지나요? 기본 인쇄 설정(용지 크기, 품질 등)은 초기화될 수 있지만, 문서나 인쇄 기록이 사라지지는 않습니다. 다시 추가한 뒤 필요한 설정만 다시 지정하면 됩니다.
  • 다른 PC에서는 같은 프린터가 잘 되는데 제 PC에서만 안 돼요. 내 PC의 프린터 드라이버가 오래됐거나 손상됐을 가능성이 큽니다. 제조사 홈페이지에서 최신 드라이버를 받아 다시 설치해보세요.
