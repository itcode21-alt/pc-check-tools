에러 코드 상세

0x000000EA · THREAD_STUCK_IN_DEVICE_DRIVER

장치 드라이버의 스레드가 무한 루프에 빠져 있을 때 나오는 코드입니다. 문서는 하드웨어 자체의 문제나 드라이버의 잘못된 하드웨어 제어를 원인으로 보고, 자주 불량 비디오 카드나 디스플레이 드라이버 문제라고 설명합니다.

이 코드를 어떻게 해석해야 하나요?

드라이버가 하드웨어가 유휴 상태가 되기를 기다리며 무한히 돌고 있으면 감시 장치가 이를 감지해 이 블루스크린을 냅니다. Microsoft Learn은 이것이 하드웨어 자체의 문제이거나 드라이버가 하드웨어를 잘못 제어한 결과이고, 자주 불량 비디오 카드나 디스플레이 드라이버가 원인이라고 설명합니다. 세 번째 매개변수가 문제가 된 드라이버 이름을 가리킵니다. 문서의 해결 절차는 디버거로 멈춘 스레드를 찾는 방법뿐이라, 일반 사용자 점검은 문서 외 일반 점검입니다.

가능성 높은 원인

  • 드라이버가 하드웨어가 유휴 상태가 되기를 기다리며 무한 루프에 빠진 경우
  • 하드웨어 자체의 문제
  • 드라이버가 하드웨어를 잘못 제어한 경우
  • 불량 비디오 카드나 디스플레이 드라이버 문제(문서가 자주 있는 경우로 설명)

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 덤프를 분석할 수 있다면 세 번째 매개변수가 가리키는 드라이버 이름을 확인하세요. 문서는 !analyze와 스택 추적으로 멈춘 스레드를 찾으라고 안내합니다.
  2. 문서 외 일반 점검: 그래픽 드라이버를 제조사 최신 버전으로 클린 재설치하세요. 무료 도구로 재설치하는 방법 보기 →
  3. 문서 외 일반 점검: 고사양 작업 중 반복되는지, 그래픽카드 온도와 보조 전원 케이블 연결 상태를 확인하세요.
  4. 문서 외 일반 점검: GPU나 메모리를 오버클럭했다면 기본값으로 되돌려 재현 여부를 확인하세요.
  5. 문서 외 일반 점검: 가능하다면 다른 그래픽카드나 내장 그래픽으로 바꿔 같은 증상이 나는지 비교하세요.

확인 결과에 따른 다음 단계

  • 그래픽 드라이버 재설치 뒤 사라질 때 — 같은 버전에서 반복되면 한 단계 이전 버전을 써 보세요. 문서가 자주 있는 원인으로 디스플레이 드라이버를 든 점과 일치하는 결과입니다.
  • 다른 그래픽카드로 바꾸면 사라질 때 — 원래 그래픽카드를 의심하세요. 문서는 불량 비디오 카드가 자주 있는 원인이라고 설명합니다. 카드 교체나 수리를 검토하세요.
  • 화면에 그래픽 외 드라이버 이름이 나올 때 — 그 드라이버가 속한 장치(저장장치, 네트워크 등)의 제조사 최신 드라이버로 업데이트하세요. 같은 코드가 반복되는 드라이버 이름을 기록해 두세요.

데이터와 시스템을 보호하는 주의사항

드라이버를 여러 버전으로 연속 덮어쓰기보다 현재 버전과 발생 조건을 기록한 뒤 안정 버전 하나로 비교하세요.

앞 단계로 해결되지 않을 때

화면 깨짐이나 고온이 동반되면 부하 테스트보다 냉각과 전원 연결을 먼저 확인하고, 정상 온도에서도 반복되면 다른 출력 경로와 GPU를 교차합니다.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

자주 묻는 질문

  • 무한 루프에 빠진 드라이버는 왜 블루스크린이 되나요? Microsoft Learn은 감시 장치(watchdog)가 드라이버 스레드가 너무 오래 돌고 있는 것을 감지해 이 버그 체크를 낸다고 설명합니다. 대개 드라이버가 하드웨어가 유휴 상태가 되기를 기다리는 중입니다.
  • 그래픽카드가 아니어도 나오나요? 나옵니다. 문서는 '자주' 불량 비디오 카드나 디스플레이 드라이버 때문이라고 하지만, 하드웨어를 기다리는 모든 장치 드라이버가 해당될 수 있습니다. 세 번째 매개변수가 가리키는 드라이버 이름으로 구분합니다.
