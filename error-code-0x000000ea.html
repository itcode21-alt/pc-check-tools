에러 코드 상세

0x000000EA · THREAD_STUCK_IN_DEVICE_DRIVER

그래픽 드라이버나 특정 디바이스 드라이버가 응답 없이 무한 대기 상태에 빠졌을 때 나타나는 코드로, 고사양 그래픽 작업 중 자주 나타납니다.

이 코드를 어떻게 해석해야 하나요?

그래픽 계열 정지는 드라이버 복구 실패뿐 아니라 GPU 온도, 보조전원, 오버클럭, 특정 앱의 하드웨어 가속에서도 발생합니다. 화면이 돌아왔는지와 시스템 전체가 재부팅됐는지를 먼저 구분하세요.

먼저 기록할 내용: 0x000000EA가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 그래픽 드라이버가 고부하 상황에서 응답을 멈추는 경우
  • GPU 과열로 하드웨어 자체가 응답 지연을 일으키는 경우
  • 오래되었거나 손상된 그래픽 드라이버 파일
  • 그래픽카드 전원 공급 불안정
  • 다중 모니터 구성에서 드라이버가 동기화에 실패하는 경우

첫 점검 항목

  1. 그래픽 드라이버를 클린 재설치(DDU 도구로 완전 제거 후 재설치)하세요. <a href="graphics-driver-guide.html">무료 도구로 재설치하는 방법 보기 →</a>
  2. GPU 온도를 모니터링해 부하 시 과열 여부를 확인하세요.
  3. 그래픽카드 보조 전원 연결과 파워 용량이 충분한지 점검하세요.
  4. 다중 모니터를 사용 중이라면 하나만 연결한 상태에서 재현 여부를 확인하세요.
  5. 다른 그래픽 집약적 작업(게임, 영상 편집)에서도 동일하게 발생하는지 확인하세요.

확인 결과에 따른 다음 단계

  • 드라이버 클린 재설치로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • 온도가 높게 측정될 때 — 쿨링 시스템(써멀 재도포, 팬 청소) 점검을 우선하세요.
  • 모니터 하나만 연결했을 때 해결될 때 — 다중 모니터 관련 드라이버 설정을 점검하세요.

데이터와 시스템을 보호하는 주의사항

드라이버를 여러 버전으로 연속 덮어쓰기보다 현재 버전과 발생 조건을 기록한 뒤 안정 버전 하나로 비교하세요.

앞 단계로 해결되지 않을 때

화면 깨짐이나 고온이 동반되면 부하 테스트보다 냉각과 전원 연결을 먼저 확인하고, 정상 온도에서도 반복되면 다른 출력 경로와 GPU를 교차합니다.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

자주 묻는 질문

  • 게임할 때만 재부팅되면 그래픽카드 문제인가요? 이 문제(0x000000EA)는 그래픽 드라이버 문제일 가능성이 높지만 전원 공급이나 온도 문제와 겹치는 경우도 많아, 드라이버 재설치와 함께 온도·전력 상태도 함께 확인하는 것이 좋습니다.
  • 콘센트나 멀티탭도 원인이 될 수 있나요? 드물지만 불안정한 멀티탭이나 정전압 문제가 원인이 될 수 있어, 다른 콘센트로 테스트해보는 것도 방법입니다.
  • 노트북에서는 원인이 다른가요? 노트북은 냉각 공간이 좁아 과열이 더 흔한 원인이므로 통풍구 청소와 쿨링 패드 사용을 먼저 고려해보세요.
