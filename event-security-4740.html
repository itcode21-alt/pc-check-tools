Security 4740 계정 잠금 점검

사용자 계정이 잠겼음을 기록합니다. 반복 로그인 실패 또는 만료된 자격 증명이 자동으로 재시도되고 있는 경우입니다.

4740은 계정이 잠겼다는 기록으로, 대부분 4625(로그온 실패)가 짧은 시간 동안 반복된 결과로 나타납니다. 호출자 PC 이름을 확인하면 어떤 장치가 반복 실패를 일으켰는지 특정할 수 있습니다.

비밀번호를 최근에 변경했다면, 자격 증명 관리자나 예약 작업, 모바일 메일 앱처럼 예전 비밀번호를 저장해 둔 곳이 자동으로 재시도하며 계정을 잠그는 경우가 흔합니다.

발생 조건

  • 로그인 시 계정 잠금 메시지
  • 도메인 연결 PC에서 접근 불가
  • 저장된 자격 증명이 있는 앱에서 오류

가능성 높은 원인

  • 여러 장치에서 동일 계정 만료 비밀번호 자동 재시도
  • 자격 증명 관리자의 오래된 비밀번호
  • 스케줄 작업 또는 서비스의 만료 자격 증명

점검 순서

  1. 이벤트의 호출자 PC 이름으로 잠금 원인 장치 찾기 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 자격 증명 관리자에서 해당 계정 항목 삭제·갱신 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 예약 작업과 서비스의 실행 계정 비밀번호 갱신 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
주의사항

반복 잠금은 만료된 자격 증명이 여러 장소에 저장된 경우가 많습니다.

자주 묻는 질문

  • 비밀번호를 바꾼 적 없는데 계정이 잠겨요. 다른 사람이 시도했을 수도 있지만, 우선 자격 증명 관리자와 여러 장치에 저장된 로그인 정보 중 오래된 비밀번호가 남아있는지부터 확인하세요.
  • 호출자 PC 이름은 어디서 확인하나요? 이벤트 뷰어의 일반 탭 본문 또는 자세히 탭의 XML 보기에서 Caller Computer Name 항목을 확인하면 잠금을 유발한 장치를 특정할 수 있습니다.
