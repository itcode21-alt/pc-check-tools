에러 코드 상세

0x000000A5 · ACPI_BIOS_ERROR

컴퓨터의 ACPI BIOS가 ACPI 규격을 완전히 준수하지 않을 때 나오는 코드입니다. 문서는 디버깅을 하지 않는 경우 BIOS 제조사에서 새 BIOS를 받으라고 안내합니다.

이 코드를 어떻게 해석해야 하나요?

첫 번째 매개변수가 오류 종류를 가리키며, 문서는 Plug and Play·전원 관리·PCI 루트 버스 리소스 목록·장치 상태 매핑 등 여러 유형을 설명합니다. 예를 들어 PCI가 해독한다고 주장하는 리소스 목록이 E820 BIOS 인터페이스가 보고한 메모리 영역과 겹치는 경우는 어떤 경우에도 허용되지 않는다고 합니다. 일반 사용자에게 문서가 안내하는 해결책은 하나입니다. 이 오류는 새 BIOS를 구해야 한다는 뜻이므로 제조사에 문의하거나 인터넷에서 새 BIOS를 받으라고 합니다. 문서에는 BIOS 업데이트를 구할 수 없을 때 쓰는 구형 설치 환경의 우회 방법도 있지만, 현재 Windows 버전에 해당하는지는 확인하지 못했습니다.

가능성 높은 원인

  • ACPI BIOS가 ACPI 규격을 완전히 준수하지 않는 경우
  • BIOS의 PCI·전원 관리·리소스 목록 설명이 규격과 맞지 않는 경우(첫 매개변수로 유형 구분)
  • 오래되어 업데이트가 끊겼거나 호환성이 낮은 메인보드(문서 외 일반 해석)

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 제조사나 판매처에서 새 BIOS(펌웨어)를 받아 업데이트하세요. 문서는 디버깅을 하지 않는 사용자에게 이 오류가 새 BIOS를 구해야 한다는 뜻이라고 설명합니다.
  2. 공식 문서가 알려 주는 것: 블루스크린의 첫 번째 매개변수 값을 기록해 두세요. 문서가 값별로 오류 종류(Plug and Play, 전원 관리, PCI 리소스 등)를 나눕니다.
  3. 문서 외 일반 점검: BIOS 업데이트 전에 제조사 안내의 주의사항(전원 유지, 중간에 끄지 않기)을 확인하세요. 업데이트 전 확인할 사항 보기 →
  4. 문서 외 일반 점검: BIOS 설정을 기본값으로 되돌려 재현되는지 확인하세요.
  5. 문서 외 일반 점검: 최근 추가한 하드웨어(특히 PCIe 장치)를 빼 보고, 가능하면 다른 PC에서 그 장치를 시험해 보세요.

확인 결과에 따른 다음 단계

  • BIOS 업데이트로 해결될 때 — 업데이트한 버전과 날짜를 기록해 두세요. 이 사이트에는 BIOS 업데이트로 해결된 사례가 있습니다.
  • BIOS 업데이트가 더 이상 제공되지 않을 때 — 문서는 BIOS 업데이트를 구할 수 없거나 최신 BIOS도 규격을 지키지 않는 경우의 우회 방법을 적지만 텍스트 모드 설치 단계 기준이라 현재 Windows에 해당하는지는 확인하지 못했습니다. 이런 경우에는 제조사에 호환 여부를 문의하거나 장치를 교체하는 쪽을 검토하세요.
  • 새 장치를 추가한 뒤부터일 때 — 그 장치를 빼고 증상이 사라지는지 확인하세요. 사라지면 장치와 BIOS 사이의 호환 문제일 수 있으니 제조사에 BIOS 호환 정보를 문의하세요.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

같은 코드가 재발할 때는 이벤트 로그와 장치 상태 기록을 보관하고, 코드가 그때그때 달라진다면 메모리·전원·발열 같은 전반적인 안정성 문제를 의심해보세요.

이런 조치는 취소가 어려운 경우가 많으므로, 복구·초기화·드라이버 제거를 실행하기 전에 중요한 파일부터 별도 저장장치에 백업해 두시길 권장합니다.

공식 참고자료

Microsoft Learn: Bug Check 0xA5 ACPI_BIOS_ERROR

자주 묻는 질문

  • BIOS 업데이트는 안전한가요? Microsoft Learn은 이 오류의 해결책으로 새 BIOS를 받으라고 안내합니다. 업데이트 도중 전원이 끊기면 부팅이 안 될 수 있어 제조사의 순서를 정확히 따라야 합니다(이 주의는 문서 외 일반 안내입니다).
  • 첫 번째 매개변수 값은 무엇인가요? 오류 종류입니다. 문서는 값에 따라 Plug and Play나 전원 관리 관련 오류, PCI 루트 버스 리소스 목록 오류, 장치 상태 매핑 오류 등으로 나누고 매개변수 의미도 달라진다고 설명합니다.
