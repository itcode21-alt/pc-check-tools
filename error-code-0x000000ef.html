📑 목차

에러 코드 상세

0x000000EF · CRITICAL_PROCESS_DIED

윈도우 핵심 프로세스가 예기치 않게 종료되며 나타나는 블루스크린으로, 0xC000021A와 증상이 유사하지만 커널 레벨에서 발생한다는 차이가 있습니다.

이 코드를 어떻게 해석해야 하나요?

이 코드만으로 특정 부품의 고장을 단정할 수는 없습니다. 발생 시점과 재현 조건, 최근 변경 사항, 안전 모드 결과를 함께 기록하면 원인 범위를 좁히는 데 도움이 됩니다.

먼저 기록할 내용: 0x000000EF가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 시스템 파일이 손상되어 핵심 프로세스가 비정상 종료되는 경우
  • 최근 설치한 드라이버가 커널 프로세스와 충돌하는 경우
  • 디스크 오류로 필요한 시스템 파일을 읽지 못하는 경우
  • 맬웨어 감염으로 시스템 프로세스가 강제 종료되는 경우
  • 업데이트 도중 강제 종료되어 파일이 일부만 반영된 경우

첫 점검 항목

  1. 안전 모드 부팅이 가능한지 확인하고, 가능하다면 최근 설치 항목부터 점검하세요.
  2. 명령 프롬프트에서 sfc /scannow와 DISM /Online /Cleanup-Image /RestoreHealth를 차례로 실행하세요.
  3. 디스크 상태를 chkdsk로 점검하세요.
  4. 최근 설치한 드라이버나 프로그램을 제거한 뒤 재현 여부를 확인하세요.
  5. 백신 프로그램으로 전체 검사를 실행해 맬웨어 감염 여부를 확인하세요.

확인 결과에 따른 다음 단계

  • sfc·DISM으로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • 최근 드라이버·프로그램 제거로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • chkdsk·백신 검사로도 해결되지 않을 때 — 사례처럼 다른 보조 저장장치를 분리해 테스트해보세요.

실제 사용자 사례

위 점검 순서로도 해결되지 않았을 때, 다른 원인으로 해결된 사례입니다.

보조 하드디스크 제거로 해결한 사례

부팅 드라이브(SSD)가 재부팅 후 인식되지 않으면서 이 블루스크린이 반복됐던 사례가 있습니다. SSD 자체는 여러 진단에서 정상으로 나왔는데, 시스템에 함께 연결되어 있던 오래된 보조 하드디스크(HDD)를 완전히 분리한 뒤 문제가 사라졌습니다. 상태가 나빠진 보조 디스크가 SATA 컨트롤러 전체를 물고 늘어지면서 부팅 드라이브까지 응답하지 않게 만들었던 것으로 보입니다.

포인트: 부팅 드라이브 자체는 정상으로 진단되는데도 이 오류가 반복된다면, 함께 연결된 다른 저장장치(특히 오래된 보조 하드디스크)를 하나씩 분리해보며 원인을 좁혀보세요.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

이런 조치는 취소가 어려운 경우가 많으므로, 복구·초기화·드라이버 제거를 실행하기 전에 중요한 파일부터 별도 저장장치에 백업해 두시길 권장합니다.

관련 증상 가이드 확인하기

같은 증상과 연결된 다른 오류 코드

  • 0xC000021A · Critical System Process 종료
  • 0x00000050 · PAGE_FAULT_IN_NONPAGED_AREA
  • 0x000000D1 · DRIVER_IRQL_NOT_LESS_OR_EQUAL
  • 0x0000003B · SYSTEM_SERVICE_EXCEPTION

자주 묻는 질문

  • 블루스크린 코드가 한 번 떴는데 계속 지켜봐야 하나요? 이 문제(0x000000EF)가 한 번만 발생했다면 즉시 부품을 교체하기보다 재현 여부와 최근 변경 사항을 먼저 기록해두는 것으로 충분합니다. 반복된다면 그때 하드웨어 점검 범위를 넓히세요.
  • 블루스크린 이후 데이터가 손상되나요? 대부분은 강제 재시작만 발생할 뿐 저장된 파일이 곧바로 손상되지는 않지만, 저장하지 않은 작업 내용은 사라질 수 있습니다.
  • 이 오류가 부팅 중에만 발생하면요? 부팅 중 반복된다면 복구 환경에서 sfc·DISM을 오프라인으로 실행하거나 시동 복구를 먼저 시도하세요.
