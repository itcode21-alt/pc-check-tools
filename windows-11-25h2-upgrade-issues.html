📑 목차

Windows 11 버전 25H2

윈도우11 25H2 업그레이드 전 확인할 것 — 알려진 문제 3가지

마이크로소프트는 25H2에 대해 광범위한 신규 소비자 문제는 없다고 밝히고 있지만, 특정 하드웨어·소프트웨어 조합에서 반복적으로 보고되는 문제가 있습니다. 업그레이드 전이나 이미 문제를 겪고 있다면 아래 세 가지부터 확인하세요.

1. "시스템 예약 파티션을 업데이트할 수 없습니다" (EFI 파티션 100MB 문제)

24H2 이하 버전을 오래 사용해 온 PC 중 일부는 EFI 시스템 예약 파티션이 100MB로 만들어져 있습니다. 이전 버전에서는 문제가 없었지만, 25H2부터 최소 200MB를 요구하도록 기준이 바뀌면서 파티션 용량 부족으로 업그레이드가 실패합니다. 오류 메시지 자체는 "이 PC는 Windows 11 사양을 충족하지 않습니다"처럼 원인과 무관하게 표시되는 경우도 있어 헷갈리기 쉽습니다.

  1. 먼저 Windows 11 설치 도우미(Installation Assistant)로 재시도해 보세요. 일부 환경에서는 이 방식이 자동으로 처리해 줍니다.
  2. 그래도 실패하면 관리자 권한 명령 프롬프트에서 레지스트리 값을 추가하는 방법이 있습니다: reg add "HKLM\SYSTEM\CurrentControlSet\Control\Bfsvc" /v EspPaddingPercent /t REG_DWORD /d 0 /f. 레지스트리를 편집하기 전에는 반드시 시스템 복원 지점을 만들거나 백업하세요.
  3. 가장 근본적인 해결은 파티션 도구로 EFI 파티션 자체를 260MB 이상으로 늘리는 것이지만, 시스템 파티션 작업은 실수하면 부팅이 안 될 수 있는 위험한 작업입니다. 직접 하기 부담스럽다면 무리하지 말고 전문가의 도움을 받으세요.

2. 삼성 갤럭시북 등 "C:\에 액세스할 수 없음 – 액세스가 거부됨"

심각도가 높은 문제입니다

단순 오류 메시지가 아니라 C 드라이브 접근 자체가 막혀 Outlook, 오피스, 브라우저 등 대부분의 프로그램이 실행되지 않는 증상으로 이어질 수 있습니다. 삼성 노트북(특히 갤럭시북4 계열)에서 25H2(또는 24H2) 적용 후 이 증상이 나타난다면 아래 해결 방법을 최우선으로 시도하세요.

마이크로소프트와 삼성이 공동으로 확인한 원인은 Windows 자체가 아니라 삼성 갤럭시 커넥트(Galaxy Connect) 앱과 연속성(Continuity) 서비스의 충돌로, 이 앱이 시스템 권한을 잘못 변경하면서 발생합니다.

  1. 일반 부팅으로 로그인이 안 되거나 프로그램이 실행되지 않는다면, 먼저 안전 모드로 부팅하세요.
  2. 안전 모드에서 설정 → 앱 → 설치된 앱으로 이동해 삼성 갤럭시 커넥트(Galaxy Connect) 앱을 찾아 완전히 제거하세요.
  3. 제거 후 일반 모드로 재부팅해 C 드라이브 접근과 프로그램 실행이 정상화됐는지 확인하세요.
  4. 스마트폰 연동 기능이 꼭 필요하다면, 문제가 해결된 것이 확인된 이후 최신 버전으로만 재설치하세요.

3. 설치 오류 0x800f0991

특정 하드웨어 문제라기보다 Windows 업데이트 구성 요소나 시스템 파일 손상, 업데이트 캐시 문제로 발생하는 일반적인 설치 오류입니다.

  1. 설정 → 시스템 → 문제 해결 → 기타 문제 해결사에서 Windows 업데이트 문제 해결사를 실행하세요.
  2. 관리자 권한 명령 프롬프트에서 sfc /scannow, 이어서 DISM /Online /Cleanup-Image /RestoreHealth를 실행해 시스템 파일을 검사·복구하세요.
  3. C:\Windows\SoftwareDistribution\Download 폴더 내용을 비운 뒤 Windows Update 서비스를 재시작하고 다시 시도하세요.
  4. 계속 실패한다면 Windows Update를 통한 자동 설치 대신 Windows 11 설치 도우미를 마이크로소프트 공식 홈페이지에서 내려받아 직접 실행하세요.

자주 묻는 질문

  • 25H2 업그레이드 중 '시스템 예약 파티션을 업데이트할 수 없습니다' 오류가 떠요. 오래된 PC에 남아 있는 100MB 크기의 EFI 시스템 예약 파티션이 원인인 경우가 많습니다. 25H2부터 최소 200MB를 요구하기 때문입니다. Windows 11 설치 도우미로 다시 시도해 보고, 그래도 안 되면 레지스트리 편집이나 파티션 도구를 이용한 해결책이 있지만 파티션 작업은 실수하면 부팅 자체가 안 될 수 있으니 백업 후 신중하게 진행하거나 전문가의 도움을 받으세요.
  • 삼성 노트북에서 25H2 이후 C 드라이브에 접근할 수 없다고 나옵니다. 삼성 갤럭시북 일부 모델에서 보고된 문제로, Windows 자체가 아니라 삼성 갤럭시 커넥트(Galaxy Connect) 앱과의 충돌이 원인으로 확인됐습니다. 안전 모드로 부팅한 뒤 갤럭시 커넥트 앱을 제거하면 대부분 해결됩니다.
  • 업데이트 오류 0x800f0991은 왜 발생하나요? 특정 하드웨어 문제라기보다 Windows 업데이트 구성 요소나 시스템 파일 손상, 업데이트 캐시 문제로 발생하는 일반적인 설치 오류입니다. SFC·DISM 검사, 업데이트 캐시 초기화, 그래도 안 되면 Windows 11 설치 도우미로 직접 설치하는 순서로 해결을 시도해 보세요.
