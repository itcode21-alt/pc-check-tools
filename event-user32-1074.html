EVENT ID 1074

누가 종료·재시작을 요청했는지 먼저 확인하세요

User32 이벤트 1074는 Windows가 종료나 재시작 요청을 받았을 때 남기는 정보 기록입니다. Kernel-Power 41처럼 갑작스러운 전원 차단을 뜻하는 이벤트가 아닙니다.

기록에서 볼 값

일반 탭이나 XML에서 프로세스 이름, 사용자, Reason Code, Shutdown Type을 기록하세요. Windows Update나 설치 프로그램이 재시작을 요청했는지, 사용자가 직접 종료했는지 구분하는 데 이 값이 핵심입니다.

점검 순서

  1. 1074 발생 시각을 실제 재부팅 시각과 비교합니다.
  2. 프로세스 이름과 사용자 계정을 확인합니다.
  3. 같은 시간의 WindowsUpdateClient 20, EventLog 6008, Kernel-Power 41을 비교합니다.
  4. 예상하지 못한 프로세스가 반복 요청하면 최근 설치 프로그램과 보안 로그를 확인합니다.
주의

1074 단독으로 악성코드나 고장을 확정하지 마세요. 종료를 요청한 프로세스와 사용자의 작업 맥락이 함께 필요합니다.
