에러 코드 상세

0x8007000D · 업데이트 파일 누락 또는 손상

Windows 시스템 오류 13(ERROR_INVALID_DATA), 즉 '데이터가 올바르지 않다'는 코드입니다. Microsoft 지원 문서는 업데이트에서 이 코드를 Windows Update 파일 문제나 업데이트 캐시 손상으로 안내합니다.

이 코드를 어떻게 해석해야 하나요?

Windows 시스템 오류 코드에서 0x8007000D는 '데이터가 올바르지 않다'로 정의됩니다. Microsoft의 업데이트 문제 해결 문서는 이 코드를 Windows Update 파일의 문제나 업데이트 캐시의 손상으로 설명하고, 업데이트 문제 해결사를 실행한 뒤 Windows Update 서비스를 중지하고 C:\Windows\SoftwareDistribution 안의 파일과 폴더를 지운 다음 서비스를 다시 시작하라고 안내합니다. 구성 요소 저장소 복구(DISM)와 네트워크 환경 점검은 문서 외 일반 점검입니다.

가능성 높은 원인

  • 다운로드한 업데이트 패키지 파일 일부가 손상되었거나 불완전한 경우
  • 업데이트 캐시(SoftwareDistribution)에 남아있는 이전 파일과 충돌하는 경우
  • 디스크 오류나 갑작스러운 전원 차단으로 파일이 깨진 경우
  • 네트워크 연결 불안정으로 다운로드가 중간에 끊긴 경우
  • 구성 요소 저장소 일부가 손상되어 설치 파일 검증에 실패하는 경우

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 설정 > 시스템 > 문제 해결 > 기타 문제 해결사에서 Windows Update 문제 해결사를 실행하세요.
  2. 공식 문서가 알려 주는 것: Win+R에서 services.msc를 열어 Windows Update 서비스를 중지하고, C:\Windows\SoftwareDistribution 안의 모든 파일과 폴더를 지운 뒤 서비스를 다시 시작하세요. 이후 업데이트가 설치되면 손상된 캐시가 원인이었습니다.
  3. 문서 외 일반 점검: 유선 연결 등 안정적인 네트워크에서 다시 받아 다운로드 중 손상이 원인인지 확인하세요.
  4. 문서 외 일반 점검: DISM /Online /Cleanup-Image /RestoreHealth로 구성 요소 저장소를 복구한 뒤 sfc /scannow를 실행하세요. 복구 뒤 설치되면 저장소 손상이 원인이었습니다.
  5. 문서 외 일반 점검: 반복 실패하면 해당 KB를 Microsoft 업데이트 카탈로그에서 직접 받아 설치하거나 업데이트 어시스턴트·미디어 생성 도구를 써 보세요.

확인 결과에 따른 다음 단계

  • 문제 해결사 실행만으로 해결될 때 — 설정 → 문제 해결 → 기타 문제 해결사에서 Windows 업데이트를 실행하세요. 완료 후 업데이트를 다시 시도해 설치되는지 확인하세요.
  • 캐시 폴더 이름 변경으로 해결될 때 — 관리자 명령 프롬프트에서 net stop wuauserv와 net stop bits를 입력해 서비스를 멈춘 뒤, C:\Windows\SoftwareDistribution 폴더 이름을 SoftwareDistribution.old로 바꾸세요. 이후 net start wuauserv, net start bits로 다시 시작하고 업데이트를 재시도하세요.
  • DISM 복구로도 해결되지 않을 때 — Windows 설치 미디어(ISO)를 준비해 setup.exe를 실행하고, '개인 파일과 앱 유지'를 선택해 인플레이스 업그레이드를 진행하세요. 진행 전에 중요한 데이터를 백업하세요.

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한 변경이나 레지스트리 정리 도구 사용보다 저장 공간, 네트워크, 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

코드가 재발할 경우 Windows Update 기록과 DISM·SFC 결과를 기록해 두고, 설치 미디어의 Windows 버전이 현재 시스템과 일치하는지 확인해보세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

자주 묻는 질문

  • 0x8007000D는 파일이 없다는 뜻인가요? Windows 시스템 오류의 정의는 '데이터가 올바르지 않다'입니다. 업데이트에서는 Microsoft 문서가 업데이트 파일이나 업데이트 캐시의 문제로 설명하며, 파일이 사라진 경우(0x80070002)와는 다른 코드입니다.
  • SoftwareDistribution 폴더를 지워도 되나요? Microsoft 문서가 Windows Update 서비스를 먼저 중지한 뒤 폴더 안의 내용을 지우고 서비스를 다시 시작하라고 안내합니다. 폴더 이름을 바꿔 두는 방식은 문서 외 변형이니, 서비스를 반드시 중지한 상태에서 진행하세요.
