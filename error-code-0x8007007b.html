에러 코드 상세

0x8007007B · 제품 키가 올바르지 않습니다 (재인증 실패)

Windows 재인증이나 제품 키 입력 과정에서 인증 서버와 통신에 실패하거나 키가 일치하지 않을 때 나타납니다.

이 코드를 어떻게 해석해야 하나요?

Windows를 재인증하거나 제품 키를 다시 입력할 때 네트워크 연결 문제, 잘못된 키 입력, 또는 라이선스 불일치로 인증 서버와 정상적으로 통신하지 못해 나타나는 오류입니다.

먼저 기록할 내용: 0x8007007B가 발생한 상황(재인증/제품 키 입력), 사용 중인 네트워크(유선/무선), 입력한 제품 키의 출처를 적어 두세요.

가능성 높은 원인

  • 인터넷 연결이 끊어져 있거나 불안정해 인증 서버와 통신하지 못하는 경우
  • 제품 키를 잘못 입력했거나 다른 Windows 에디션용 키를 입력한 경우
  • 이미 다른 PC에서 사용 중인 라이선스를 중복으로 입력한 경우
  • 손상된 시스템 파일로 인증 관련 서비스가 정상 동작하지 않는 경우
  • 방화벽·보안 프로그램이 인증 서버 접속을 차단하는 경우

첫 점검 항목

  1. 인터넷 연결 상태를 확인하고, 가능하면 유선 연결로 다시 시도하세요.
  2. 제품 키와 Windows 에디션(Home/Pro 등)이 일치하는지 다시 확인하세요.
  3. 명령 프롬프트(관리자)에서 sfc /scannow를 실행해 시스템 파일을 점검하세요.
  4. 방화벽·백신을 잠시 끄고 인증을 다시 시도해 차단 여부를 확인하세요.
  5. 반복되면 설정 > 정품 인증의 문제 해결사를 실행하거나 Microsoft 지원팀에 문의하세요.

확인 결과에 따른 다음 단계

  • 유선 연결로 해결될 때 — 무선 환경 개선을 검토하세요.
  • sfc /scannow로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • 방화벽 해제로도 해결되지 않을 때 — Microsoft 지원팀에 문의하세요.

실제 사용자 사례

위 점검 순서로도 해결되지 않았을 때, 다른 원인으로 해결된 사례입니다.

유선 연결로 재인증 성공

무선 네트워크에서 계속 이 오류가 나던 사례가 있습니다. 유선 랜으로 연결을 바꾼 뒤 재인증을 시도하자 바로 성공했습니다.

포인트: 인증 서버와의 통신이 불안정하면 이 오류가 흔히 발생합니다. 키 자체보다 네트워크 연결부터 점검하는 것이 빠릅니다.

데이터와 시스템을 보호하는 주의사항

제품 키를 여러 번 잘못 입력하면 일시적으로 잠길 수 있으니, 정확한 키를 확인한 뒤 시도하세요.

앞 단계로 해결되지 않을 때

정식 구매 경로와 영수증을 확인하고, Microsoft 지원팀에 문의하세요.

관련 증상 가이드 확인하기

같은 증상과 연결된 다른 오류 코드

  • 0xC004C003 · Windows 정품 인증을 받지 않았습니다
  • 0xC004F050 · 제품 키를 사용할 수 없습니다
  • 0x803F7001 · Windows 라이선스를 찾을 수 없음

공식 참고자료

자주 묻는 질문

  • 제품 키를 정확히 입력했는데도 이 오류가 뜨는 이유는? 키 자체보다 인증 서버와의 통신 문제인 경우가 흔합니다. 네트워크 연결부터 점검하고, 방화벽·백신이 차단하고 있지 않은지 확인하세요.
  • 다른 PC에서 쓰던 키를 입력해도 되나요? 소매용(Retail) 키가 아니라면 한 번에 한 대의 PC에서만 활성화됩니다. 이미 다른 PC에서 사용 중이라면 이 오류가 발생할 수 있습니다.
  • 전화 인증도 시도해볼 수 있나요? slui.exe 4 명령으로 전화 인증 메뉴를 열어 시도할 수 있으며, 온라인 인증이 계속 실패할 때 대안이 됩니다.
