에러 코드 상세

0x8007007B · 정품 인증에서 "DNS 이름이 없습니다"

Microsoft의 정품 인증 오류 코드 문서에서 0x8007007B는 KMS 클라이언트가 DNS에서 KMS SRV 리소스 레코드를 찾지 못할 때 나타나는 "DNS 이름이 없습니다" 오류입니다. 같은 값을 Win32 오류 코드표는 ERROR_INVALID_NAME(파일·디렉터리 이름이나 볼륨 레이블 구문 오류)으로 정의합니다.

이 코드를 어떻게 해석해야 하나요?

이 코드를 "제품 키를 잘못 입력했다"는 뜻으로 설명하는 글이 많지만, Microsoft의 정품 인증 문서는 이 코드를 KMS 클라이언트가 DNS에서 KMS 레코드를 찾지 못한 오류로 분류합니다. 제품 키 자체의 문제는 문서에서 다른 코드(예: 0xC004C003 "키가 차단됨")로 표시됩니다. 그래서 먼저 이 PC가 조직(KMS) 방식으로 인증하는지, 아니면 개인 라이선스인지부터 구분해야 합니다.

가능성 높은 원인

  • 공식 문서: KMS 클라이언트가 DNS에서 KMS SRV 리소스 레코드를 찾지 못했습니다(KMS는 조직용 볼륨 정품 인증 방식).
  • 공식 문서의 해결 방법은 KMS와 DNS 이슈에 대한 일반 문제 해결 절차를 따르는 것이며, 조직의 DNS·KMS 호스트 설정은 IT 관리자가 확인해야 합니다.
  • 정품 인증이 아닌 다른 작업에서 이 값이 나오면 Win32 정의(이름 구문 오류)로 읽어야 합니다. 어느 쪽인지는 오류가 뜬 화면으로 구분합니다.
  • 개인용 PC에서 정품 인증 중 이 코드가 보이는 경우의 원인은 공식 문서에서 확인하지 못했습니다.

첫 점검 항목

  1. 공식 안내: 회사·학교 PC라면 IT 관리자에게 DNS에 KMS SRV 레코드가 있는지, KMS 호스트에 접근되는지 확인해 달라고 요청하세요.
  2. 설정 → 시스템 → 정품 인증에서 현재 인증 상태와 메시지를 확인하고, 오류 화면의 문구를 그대로 적어 두세요.
  3. 문서 외 일반 점검: 개인 PC라면 인터넷에 연결된 상태에서 설정 → 시스템 → 정품 인증 → 문제 해결을 실행하세요.
  4. 문서 외 일반 점검: 조직 VPN에 연결하거나 회사 네트워크 안에서 다시 시도하면 KMS 호스트를 찾을 수 있는지 확인하세요(조직 PC인 경우).
  5. 문서 외 일반 점검: 반복되면 오류 화면, 설치된 Windows 에디션, 라이선스를 받은 경로(소매·OEM·조직)를 적어 Microsoft 지원이나 문의에 전달하세요.

확인 결과에 따른 다음 단계

  • 조직(회사·학교) PC일 때 — DNS의 KMS SRV 레코드와 KMS 호스트 접근을 IT 관리자가 확인해야 합니다.
  • 개인 PC에서 정품 인증 중 나타날 때 — 정품 인증 문제 해결을 실행하고, 오류 화면·에디션·라이선스 구매 경로를 적어 문의하세요.
  • 정품 인증이 아닌 다른 작업에서 나타날 때 — Win32 정의(이름 구문 오류)로 읽고, 입력한 파일·폴더 이름과 경로에 잘못된 문자가 없는지 확인하세요.

앞 단계로 해결되지 않을 때

위 확인으로 구분되지 않으면 오류가 뜬 화면, Windows 에디션, 라이선스 경로를 적어 문의하세요.

자주 묻는 질문

  • 제품 키를 잘못 입력해서 나는 오류인가요? Microsoft 문서의 표에서 이 코드는 키 오류가 아니라 "DNS 이름이 없습니다"로 분류됩니다. 키 문제는 0xC004C003처럼 키를 직접 언급하는 코드로 나타납니다.
  • KMS가 무엇인가요? 조직이 여러 PC를 한 서버로 인증하는 볼륨 정품 인증 방식입니다. 가정용 소매·OEM 라이선스는 보통 이 방식을 쓰지 않습니다. 어떤 방식인지는 조직 관리자나 구매 경로로 확인하세요.
  • 인터넷은 되는데도 나올 수 있나요? 공식 문서가 말하는 원인은 인터넷 연결이 아니라 DNS에 KMS 레코드가 없는 것입니다. 일반 웹 접속이 되는 것과는 별개일 수 있습니다.
