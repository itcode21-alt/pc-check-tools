BOOTMGR is missing

홈/가이드/BOOTMGR is missing

📑 목차

    부팅

    BOOTMGR is missing·부팅 장치를 찾을 수 없음 원인과 점검 순서

    전원을 켜면 Windows 로고 전에 BOOTMGR is missing, Operating system missing 같은 문구가 뜨고 부팅이 멈추는 경우

    전원을 켰는데 Windows 로고가 나오기 전에 검은 화면에 BOOTMGR is missing, Press Ctrl+Alt+Del to restart 같은 문구가 뜨고 멈추는 경우가 있습니다. Microsoft 문서에서 Bootmgr missing or corrupted는 BCD missing or corrupted, Boot file or MBR corrupted, Operating system missing, Boot sector missing or corrupted와 함께 '부트 로더 단계'에서 멈췄을 때 나타나는 대표 메시지로 정리됩니다. 화면이 검고 커서만 깜빡이는 경우도 같은 단계 문제로 봅니다.

    Windows는 PreBoot(펌웨어), Windows Boot Manager, Windows OS Loader, 커널 순서로 시작합니다. Microsoft 문서에 따르면 BIOS 방식 PC의 부팅 관리자는 %SystemDrive%\bootmgr 파일이고, UEFI 방식 PC는 \EFI\Microsoft\Boot\bootmgfw.efi입니다. 이 단계에서 멈췄다는 것은 디스크 자체는 인식되지만 부팅 관리자나 부팅 정보를 찾지 못했다는 뜻이라, Windows 파일 전체가 사라진 것은 아닌 경우가 많습니다.

    이 가이드는 Microsoft의 'Windows 시작 문제 해결' 문서를 기준으로 시작 복구, bootrec 명령, BCD 재구성 순서를 정리합니다. 이 문서는 지원 담당자와 IT 전문가를 대상으로 쓰였고 명령은 디스크의 부팅 영역을 수정하므로, 데이터가 중요하면 먼저 백업하고 어려우면 전문가 점검을 받으세요.

    이 가이드가 필요한 상황

    • Windows 로고가 나오기 전에 BOOTMGR is missing 또는 Bootmgr missing or corrupted가 표시된다.
    • Operating system missing, Boot sector missing or corrupted, BCD missing or corrupted 같은 문구가 보인다.
    • 검은 화면에 커서만 깜빡이거나 Press Ctrl+Alt+Del to restart만 반복된다.

    먼저 확인할 항목

    1. 외장 장치 제거와 부팅 순서 확인 — 부팅 순서의 첫 장치가 부팅 불가 장치이면 같은 문구가 뜰 수 있습니다. 문서 외 일반 점검이지만 비용이 가장 적게 드는 확인입니다. ① PC를 끄고 USB 저장장치, SD카드, 외장 디스크를 모두 뽑으세요. ② 다시 켜서 BIOS·UEFI 설정 화면(제조사별 Del·F2 등)으로 들어가세요. ③ 시스템 디스크가 목록에 보이는지, 부팅 순서 첫 번째가 Windows가 설치된 디스크(또는 Windows Boot Manager)인지 확인하세요. 디스크가 아예 보이지 않으면 연결 케이블이나 디스크 문제이니 부팅 파일 복구보다 하드웨어 점검이 먼저입니다.
    2. Windows 설치 USB로 복구 환경 진입 — Microsoft 문서는 부트 로더 단계 오류 해결을 Windows 설치 미디어로 부팅해 시작하라고 안내합니다. 실행 중인 Windows가 없어도 쓸 수 있는 복구 도구입니다. ① 정상 PC에서 같은 버전의 Windows 설치 USB를 만드세요. ② 문제 PC에 꽂고 USB로 부팅하세요. ③ Windows 설치 화면에서 다음 > 컴퓨터 복구를 선택하세요. ④ 옵션 선택 화면에서 문제 해결을 고르세요. 명령 프롬프트가 필요하면 설치 화면에서 Shift+F10을 누르세요.
    3. 시작 복구(Startup Repair) 실행 — 시작 복구는 부팅 로그를 분석해 원인을 찾고 자동으로 수정을 시도합니다. Microsoft 문서가 첫 번째 방법으로 안내합니다. ① 복구 환경의 고급 옵션 화면에서 시작 복구를 선택하세요. ② 끝나면 종료를 선택하고 PC를 다시 켜 Windows가 정상 시작하는지 보세요. ③ 실패하면 로그 파일 %windir%\System32\LogFiles\Srt\Srttrail.txt가 남는다고 문서에 나와 있으니 내용을 확인하세요.
    4. 부트 코드와 부트 섹터 복구 — Microsoft 문서의 두 번째 방법으로, 마스터 부트 레코드(MBR)와 부트 섹터의 부팅 코드를 다시 씁니다. ① 복구 환경 명령 프롬프트에서 BOOTREC /FIXMBR 를 실행하세요. ② 이어서 BOOTREC /FIXBOOT 를 실행하세요. ③ 재부팅해 확인하세요. 문서는 FIXMBR이 마스터 부트 코드만 덮어쓰므로 MBR 손상이 파티션 테이블까지 미쳤다면 이 방법으로 해결되지 않을 수 있다고 주의를 줍니다.
    5. BCD 오류 수정 — BCD가 없거나 손상된 경우를 다루는 세 번째 방법입니다. 설치된 Windows를 다시 찾고 BCD를 새로 만듭니다. ① Bootrec /ScanOS 로 설치된 Windows를 검색하고 재부팅해 확인하세요. ② 해결되지 않으면 문서 순서대로 bcdedit /export c:\bcdbackup, attrib c:\boot\bcd -r -s -h, ren c:\boot\bcd bcd.old, bootrec /rebuildbcd 를 차례로 실행하세요. ③ 재부팅하세요. 문서 외 일반 점검: 복구 환경에서는 Windows 드라이브 문자가 C:와 다를 수 있으니 dir 명령으로 실제 드라이브 문자를 확인하고 명령의 c:를 바꿔 입력하세요.
    6. 그래도 안 될 때 — 문서는 앞의 세 방법으로 해결되지 않을 때 부트매니저 파일을 시스템 예약 파티션으로 옮기는 방법과 레지스트리 시스템 하이브 복원을 별도 방법으로 안내합니다. 둘 다 고급 작업입니다. ① 부팅 파일 교체와 하이브 복원은 오작동 시 데이터 손실 위험이 있으므로 일반 사용자는 시도하지 마세요. ② 시스템 복원 지점이 있다면 복구 환경의 시스템 복원을 먼저 고려하세요(문서가 하이브 복구에 복원 지점을 권장). ③ 중요한 데이터가 있으면 다른 PC에서 읽을 수 있는지 확인하고 전문가 점검을 받으세요.

    원인을 더 정확히 나누는 방법

    BIOS 방식과 UEFI 방식은 부팅 파일이 다르다

    Microsoft 문서의 표에 따르면 PreBoot 단계에서 BIOS 방식 PC는 MBR과 부팅 코드를 쓰고, UEFI 방식 PC는 UEFI 펌웨어가 부팅 관리자 EFI 응용 프로그램을 직접 시작합니다. Windows Boot Manager는 BIOS 방식에서 %SystemDrive%\bootmgr, UEFI 방식에서 \EFI\Microsoft\Boot\bootmgfw.efi입니다. 그래서 같은 오류라도 PC가 어느 방식인지에 따라 영향받는 파일이 다릅니다. Azure 가상 머신 문서는 1세대(BIOS) VM에만 활성 파티션 확인이 해당하고 2세대(UEFI)는 활성 파티션을 쓰지 않는다고 구분합니다.

    BOOTMGR is missing 메시지를 일으키는 원인

    Microsoft의 Azure VM 문서는 BOOTMGR is missing 원인으로 부팅 과정이 활성 시스템 파티션을 찾지 못한 경우, BCD 저장소에 Windows 파티션을 찾는 참조가 빠진 경우, 랜섬웨어 공격을 듭니다. 이 문서는 가상 머신 기준이지만 메시지의 원인 분류는 물리 PC에도 참고가 됩니다. 랜섬웨어가 의심되면 디스크 루트에 복구 요구 메시지 텍스트 파일이 있는지 확인하라고 안내하며, 해당될 경우 백업에서 복원하거나 다시 구성해야 한다고 합니다.

    Startup Repair 무한 반복과 복구 옵션 화면

    문서에는 PC가 복구 옵션 화면에서 계속 멈추면 Bcdedit /set {default} recoveryenabled no 로 반복을 끊고, F8 옵션이 먹지 않으면 Bcdedit /set {default} bootmenupolicy legacy 를 쓰라는 주의 사항이 있습니다. 사이트의 자동 복구 루프 가이드와 함께 보세요.

    BIOS 단계에서 멈춘 것과 구분하기

    Microsoft 문서는 디스크 표시등이 켜지지 않거나 NumLock 표시등이 전환되지 않으면 BIOS 단계에서 멈춘 것이며 하드웨어 문제일 수 있다고 안내합니다. BOOTMGR 메시지가 보인다면 BIOS 단계는 통과해 부트 로더 단계에 있는 것입니다.

    확인 결과에 따른 다음 단계

    • 외장 장치를 뽑거나 부팅 순서를 고치자 해결될 때 — 부팅 파일 문제가 아니라 부팅 순서 문제였습니다. 이후 외장 장치를 연결한 채 부팅하지 않도록 순서를 정리하세요.
    • BIOS에서 시스템 디스크가 보이지 않을 때 — 부팅 복구 명령이 의미 없습니다. 케이블·슬롯·디스크 상태를 점검하고 SSD라면 사이트의 SSD 건강 판정을 참고하세요.
    • 시작 복구나 bootrec으로 복구되었을 때 — 원인 후보(갑작스러운 전원 차단, 디스크 오류, 최근 업데이트)를 떠올려 보고 중요한 데이터는 백업하세요.
    • 명령을 모두 써도 안 되거나 데이터가 매우 중요할 때 — 디스크를 다른 PC에 보조 드라이브로 연결해 데이터를 먼저 옮기고, 그 뒤 Windows 재설치를 고려하세요. 임의로 부팅 파일 교체를 시도하지 마세요.

    피해야 할 실수

    • BIOS에서 디스크가 보이는지 확인하지 않고 부팅 복구 명령부터 실행하는 것
    • 복구 환경에서 C: 드라이브 문자를 확인하지 않고 명령을 그대로 입력하는 것
    • 데이터 백업 없이 파티션이나 부팅 파일을 임의로 수정하는 것

    자주 묻는 질문

    • BOOTMGR is missing이 뜨면 Windows가 지워진 건가요? 반드시 그렇지는 않습니다. 이 메시지는 부팅 관리자나 부팅 정보를 찾지 못한다는 뜻으로, Microsoft 문서도 부트 로더 단계의 문제로 분류합니다. 디스크 전체가 사라진 것이 아니라 부팅 파일·BCD·부팅 순서 문제일 때가 많습니다.
    • Windows 설치 USB가 꼭 필요한가요? Microsoft 문서의 시작 복구와 bootrec 방법은 Windows 설치 미디어로 복구 환경에 들어가서 진행합니다. 부팅이 안 되는 PC는 다른 PC에서 설치 USB를 만들어야 합니다.
