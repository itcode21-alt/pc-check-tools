EVENT ID 6006

EventLog 6006 정상 종료 여부 확인

Windows 이벤트 로그 서비스가 정상적인 종료 절차에서 중지되었음을 기록하는 정보성 이벤트입니다. 6006이 있고 6008이 없다면 정상 종료에 가까운 패턴으로 볼 수 있습니다.

6006은 Windows 이벤트 로그 서비스가 종료 절차에서 중지되었음을 기록하는 정보성 이벤트입니다. 6006이 있고 6008이 없다면 정상 종료에 가까운 패턴으로 볼 수 있지만, 이벤트 하나만으로 전원 상태를 확정하지는 않습니다.

갑작스러운 전원 차단이나 강제 종료가 있었다면 6006 없이 6008·Kernel-Power 41이 남을 수 있습니다. 종료 요청 주체는 User32 1074에서 함께 확인하세요.

발생 조건

  • 시작 메뉴에서 정상 종료·재시작한 뒤
  • Windows Update가 재부팅을 완료한 뒤
  • 정상 종료와 강제 종료를 시간순으로 비교할 때

가능성 높은 원인

  • 사용자가 실행한 정상 종료·재시작
  • Windows Update·설치 프로그램의 계획된 재부팅
  • 관리자가 이벤트 로그 서비스를 재시작한 경우

점검 순서

  1. 6006 시각과 User32 1074의 종료 요청 시각 비교 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 같은 부팅 주기에 6005가 다시 기록됐는지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 6006 없이 6008·Kernel-Power 41만 있다면 전원 차단·강제 종료 가능성을 먼저 확인 — 앞 단계에서 해결되지 않을 때 다음 원인을 검증합니다.
주의사항

6006 자체는 오류가 아닙니다. 정상 종료 기록이 없는 것이 문제인지, 실제로 강제 종료 증상이 있었는지를 구분하세요.

자주 묻는 질문

  • 6006은 오류 이벤트인가요? 아닙니다. 정상 종료 또는 이벤트 로그 서비스 중지 과정에서 남는 정보성 기록입니다. 실제 문제는 6006이 없는 비정상 종료와 주변 이벤트에서 찾아야 합니다.
  • 6006과 6008을 함께 보면 무엇을 알 수 있나요? 6006은 정상 종료 과정의 기록이고 6008은 이전 종료가 정상적이지 않았다는 사후 기록입니다. 두 이벤트의 존재 여부와 시각을 비교하면 종료 패턴을 구분하는 데 도움이 됩니다.
