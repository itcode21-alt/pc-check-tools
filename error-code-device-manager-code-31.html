코드 31 · 이 장치가 제대로 작동하고 있지 않습니다 (코드 31)

드라이버는 로드됐지만 장치가 필요한 정보를 제공하지 못해 정상 동작하지 않을 때 나타나는 코드입니다. 리소스 충돌이나 구형 드라이버가 흔한 원인입니다.

이 코드를 어떻게 해석해야 하나요?

업데이트 과정에서 나오는 이런 코드는 네트워크, 캐시, 구성 요소 저장소, 디스크 공간, 서비스 상태 중 어디서 작업이 끊겼는지 보여줍니다. 언제 반복되는지, 이벤트 로그의 세부 코드는 무엇인지 함께 확인하면 원인을 좁힐 수 있습니다.

먼저 기록할 내용: 코드 31가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 다른 장치와 하드웨어 리소스(IRQ 등)가 충돌하는 경우
  • 드라이버가 오래되어 현재 시스템 구성과 맞지 않는 경우
  • 장치가 절전 상태에서 제대로 복귀하지 못하는 경우
  • 메인보드 칩셋 드라이버가 오래된 경우
  • 장치 자체의 초기화 실패

첫 점검 항목

  1. 장치 관리자에서 리소스 탭(있는 경우)으로 다른 장치와의 충돌 여부를 확인하세요.
  2. 메인보드 칩셋 드라이버를 최신 버전으로 업데이트하세요.
  3. 장치 드라이버를 제거 후 재부팅해 자동 재설치를 유도하세요.
  4. 절전 모드에서 복귀한 직후에만 발생하는지 확인해 전원 관리 설정을 점검하세요.
  5. 가능하다면 다른 슬롯이나 포트로 장치를 옮겨 재현 여부를 확인하세요.

확인 결과에 따른 다음 단계

  • 다른 포트로 옮겼을 때 정상 작동할 때 — 원래 포트의 전력 공급 문제이므로 허브 대신 메인보드 직결 포트를 사용하세요.
  • 칩셋 드라이버 업데이트로 해결될 때 — 재발 방지를 위해 정기적으로 드라이버 업데이트를 확인하세요.
  • 절전 복귀 후에만 발생할 때 — USB 선택적 절전 설정을 끄고 재현 여부를 확인하세요.

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한 변경이나 레지스트리 정리 도구 사용보다 저장 공간, 네트워크, 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

반복해서 같은 오류가 난다면 Windows Update 이력과 DISM·SFC 결과를 저장하고, 설치 미디어 버전이 지금 쓰는 Windows와 맞는지부터 확인하세요.

되돌리기 어려운 조치(복구, 초기화, 드라이버 제거 등)에 들어가기 전에는 반드시 중요 데이터를 다른 저장장치로 옮겨 두는 것이 안전합니다.

공식 참고자료

Microsoft 지원: Device Manager error codes

자주 묻는 질문

  • 장치가 인식이 안 되면 바로 새 제품을 사야 하나요? 이 문제(코드 31)는 장치 고장보다 드라이버나 포트 설정 문제인 경우가 흔합니다. 다른 포트나 다른 PC에서 인식되는지 먼저 확인해보세요.
  • USB 포트 전원 관리 설정이 영향을 주나요? 네, Windows의 USB 선택적 절전 설정이 활성화되어 있으면 일부 장치의 연결이 끊기거나 인식이 지연될 수 있습니다.
  • 코드 31이 계속 재발하면 장치 자체 결함인가요? 여러 포트와 다른 PC에서도 모두 재현된다면 장치 자체 결함일 가능성이 높으니, 다른 PC에서 테스트해보세요.
