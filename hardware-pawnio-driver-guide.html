PawnIO 드라이버 가이드

홈/가이드/PawnIO 드라이버 가이드

📑 목차

    하드웨어

    센서·메모리 SPD 값이 안 읽힘(PawnIO 드라이버) 원인과 점검 순서

    모니터링 도구에서 온도·팬·전압이 0이나 N/A로 나오거나 메모리 SPD가 읽히지 않을 때 PawnIO 드라이버의 설치·상태·제거를 확인하는 경우

    하드웨어 모니터링 도구에서 CPU 온도가 0도로 나오거나 팬 속도가 비고, 메모리 모듈 정보(SPD)가 읽히지 않는 경우가 있습니다. 이때 도구가 센서나 메모리 칩에 접근하는 통로가 되는 드라이버가 없거나 막혀 있는 것이 원인일 수 있습니다.

    PawnIO는 namazso가 만든 범용 커널 드라이버로, 이를 지원하는 프로그램이 서명된 모듈을 통해 하드웨어에 접근하게 해 줍니다. 공식 사이트(pawnio.eu)는 자신을 '스크립트 방식의 범용 커널 드라이버'로 소개합니다. 예전에 널리 쓰이던 WinRing0 드라이버를 대신하는 방향으로 일부 모니터링 도구가 PawnIO를 쓰기 시작했다고 알려져 있습니다.

    다만 PawnIO가 없어서 값이 안 읽히는 것인지, 보드나 도구가 그 값을 지원하지 않는 것인지는 구분해야 합니다. 이 가이드는 설치 여부 확인, 공식 경로로 설치, 문제가 생겼을 때 제거까지를 순서대로 다룹니다. 커널 드라이버를 설치하는 일이므로, 특히 고객·매장 PC에서는 동의를 받고 필요한 만큼만 쓰는 것을 전제로 합니다.

    이 가이드가 필요한 상황

    • 모니터링 도구에서 온도·팬·전압 값이 0이나 N/A로 표시된다.
    • 메모리 모듈의 SPD(제조사·용량·클럭) 정보가 비어 있거나 읽기에 실패한다.
    • 도구를 업데이트하거나 새로 받은 뒤부터 이전에 보이던 센서가 보이지 않는다.

    먼저 확인할 항목

    1. 어떤 값이 안 읽히는지 구분하기 — 센서 전체가 안 읽히는 것과 특정 값 하나만 비는 것은 원인이 다릅니다. 전체가 비면 드라이버나 권한 문제일 가능성이 크고, 하나만 비면 그 보드가 해당 센서를 제공하지 않는 경우도 많습니다. ① 도구 화면에서 CPU 온도·팬·전압·메모리 정보 중 어느 항목이 비는지 적어 두세요. ② 도구 이름과 버전을 확인하세요(도구의 정보 화면이나 파일 속성). ③ 도구 설명서나 공식 안내에 PawnIO가 필요하다는 내용이 있는지 보세요. 도구마다 필요 여부가 다르므로 PawnIO를 일단 설치하기 전에 이 확인이 먼저입니다.
    2. 관리자 권한으로 실행하고 도구 버전 확인 — 드라이버를 통해 하드웨어에 접근하는 기능은 관리자 권한이 필요한 경우가 많습니다. 권한만 올려도 값이 나오는 경우가 흔합니다. ① 도구를 닫고 실행 파일을 우클릭해 '관리자 권한으로 실행'을 선택하세요. ② 값이 나오면 권한 문제였던 것입니다. ③ 그래도 비어 있으면 도구의 최신 버전이 있는지 공식 배포처에서 확인하세요. 오래된 버전은 예전 드라이버 방식을 쓰기 때문에 보안 프로그램에 막히거나 최신 보드를 지원하지 못할 수 있습니다.
    3. PawnIO 설치 여부 확인 — 설치돼 있는지 모르는 채 다시 설치하면 중복 작업이 되고, 설치돼 있는데 값이 안 나오면 원인이 드라이버가 아닌 다른 곳에 있다는 뜻이라 방향이 달라집니다. ① 시작 메뉴에서 cmd를 입력해 명령 프롬프트를 실행하세요. ② winget list --id namazso.PawnIO -e 를 입력하세요. ③ 목록에 PawnIO와 버전이 나오면 설치된 것이고, '입력 조건과 일치하는 설치된 패키지를 찾을 수 없습니다'가 나오면 설치되지 않은 것입니다. ④ winget이 없는 PC라면 설정 → 앱 → 설치된 앱에서 PawnIO를 찾아보세요.
    4. 공식 경로로 설치하기 — PawnIO는 커널 수준에서 동작하는 드라이버입니다. 출처가 불분명한 파일이나 재배포본을 쓰면 보안 위험이 큽니다. 공식 배포처만 쓰는 것이 기본입니다. ① 브라우저에서 pawnio.eu에 접속해 Download Now로 PawnIO_setup.exe를 받으세요(파일은 GitHub의 namazso/PawnIO.Setup 릴리스로 연결됩니다). ② 또는 관리자 권한 명령 프롬프트에서 winget install --id namazso.PawnIO -e 를 실행하세요. ③ 설치기에서 에디션을 고르게 되면 서명된 Official 에디션을 선택하세요. Unrestricted 에디션은 서명 검사를 없앤 시험용이라 일반 점검에는 쓰지 않습니다. ④ 설치 후 재부팅을 요구하면 재부팅하세요.
    5. 설치 후 값 비교하기 — 설치만으로 모든 센서가 나오는 것은 아닙니다. 값이 나온다고 해서 정확하다는 보장도 없어서, 다른 경로와 비교해야 합니다. ① 도구를 관리자 권한으로 다시 실행해 이전에 비던 값이 나오는지 보세요. ② CPU 온도는 BIOS 화면의 온도, 팬은 BIOS의 팬 속도 화면과 대략 비교해 보세요. ③ 여전히 0이거나 N/A인 항목은 '읽지 못함'으로 기록하고, 정상 값으로 간주하지 마세요. ④ 특히 점검 보고서나 판단 근거로 쓸 때는 읽지 못한 항목을 '미확인'으로 따로 표시하세요.
    6. 문제가 생기면 제거하기 — 설치 후 게임이 실행되지 않거나 블루스크린이 생기는 등 이상이 보이면, 원인을 가르려면 드라이버를 제거한 상태와 비교해야 합니다. ① 설정 → 앱 → 설치된 앱에서 PawnIO를 찾아 제거하거나, 관리자 권한 명령 프롬프트에서 winget uninstall --id namazso.PawnIO -e 를 실행하세요. ② 제거 후 재부팅하세요. ③ 다시 winget list --id namazso.PawnIO -e 를 실행해 목록에서 사라졌는지 확인하세요. ④ 블루스크린이 있었다면 미니덤프 분석기로 원인을 확인하세요.

    원인을 더 정확히 나누는 방법

    PawnIO는 무엇이고 왜 필요한가

    일반 프로그램은 윈도우 보안 구조 때문에 센서 칩이나 메모리 모듈의 SPD(SMBus)에 직접 접근할 수 없습니다. 그래서 모니터링 도구는 커널 드라이버를 통해 접근합니다. PawnIO는 이 통로를 제공하는 드라이버로, 임의의 코드를 열어 두는 대신 서명된 모듈만 실행하는 방식을 내세웁니다. 어떤 도구가 PawnIO를 요구하는지는 도구마다 다르니, 도구 안내를 우선하세요.

    Official·Unrestricted 에디션의 차이

    공식 사이트는 서명된 Official 에디션, 서명 검사를 하지 않는 Unrestricted 에디션, 소스가 공개된 오픈 소스 에디션, 별도 라이선스 에디션을 구분해 안내합니다. Unrestricted는 서명되지 않은 모듈도 불러오는 용도라서 윈도우의 시험 서명 모드 같은 추가 설정이 필요할 수 있습니다. 일반 점검 목적이라면 Official 에디션이면 충분하고, 시험 서명 모드는 켜지 않는 것이 안전합니다.

    값 0을 믿으면 안 되는 이유

    드라이버나 센서 매핑이 맞지 않으면 도구는 오류 대신 0을 표시하는 경우가 있습니다. 실제로 다른 모니터링 도구가 드라이버를 바꾸는 과정에서 일부 센서가 0으로 나오는 문제가 보고된 적이 있습니다. 그래서 0도, 0RPM, 0V는 '측정값이 0'이 아니라 '읽지 못함'으로 보고, 다른 도구나 BIOS 화면과 교차 확인하세요.

    고객·매장 PC에서 쓸 때의 주의점

    커널 드라이버를 설치하는 일이므로, 고객 PC에서는 설치 사실을 알리고 동의를 받으세요. 점검이 끝난 뒤 계속 둘지 제거할지 상의하세요. 설치 파일은 우리 쪽에서 내려받아 다시 배포하지 말고 공식 배포처 링크로 안내하세요. winget 정보에는 라이선스가 'Proprietary (Freeware)'로 표시되므로, 무료로 쓸 수 있지만 재배포 조건은 공식 사이트에서 확인해야 합니다.

    확인 결과에 따른 다음 단계

    • 관리자 권한으로 실행하면 값이 나올 때 — 권한 문제였습니다. 점검 때마다 관리자 권한으로 실행하세요. PawnIO를 추가로 설치할 필요가 없을 수 있습니다.
    • PawnIO가 설치돼 있지 않고 도구가 필요하다고 안내할 때 — 공식 경로로 설치하고 재부팅한 뒤 값을 다시 확인하세요. 설치 후에도 값이 비는 항목은 미확인으로 기록하세요.
    • PawnIO가 설치돼 있는데 같은 항목만 계속 비어 있을 때 — 드라이버보다 보드나 도구 지원 문제일 가능성이 큽니다. 도구를 최신 버전으로 올려 보고, 그래도 비면 BIOS 화면의 값을 기준으로 삼으세요.
    • 설치 뒤 게임 보안 프로그램이나 블루스크린 문제가 생길 때 — PawnIO를 제거하고 재부팅해서 증상이 사라지는지 보세요. 블루스크린이라면 미니덤프 분석기로 원인 드라이버를 확인하고, 게임은 모니터링 도구를 끈 상태에서 실행해 보세요.

    피해야 할 실수

    • 출처가 불분명한 사이트나 재배포 파일로 PawnIO를 설치하는 것
    • 센서가 0으로 표시된 값을 실제 측정값으로 믿고 '온도가 낮다'고 판단하는 것
    • 필요 여부를 확인하지 않고 모든 모니터링 도구에 PawnIO부터 설치하는 것

    자주 묻는 질문

    • PawnIO는 바이러스 아닌가요? 공개된 프로젝트의 정식 드라이버이지만 커널 수준 접근을 다루기 때문에 보안 프로그램이 경고할 수 있습니다. 공식 사이트(pawnio.eu)나 winget의 namazso.PawnIO 패키지처럼 출처가 확실한 경로로만 설치하고, 그 외 경로의 파일은 쓰지 마세요.
    • 무료인가요? 오픈 소스인가요? 공식 사이트는 서명된 Official 에디션과 소스가 공개된 오픈 소스 에디션, 별도 라이선스 에디션을 안내합니다. 한편 winget 정보에는 라이선스가 'Proprietary (Freeware)'로 표시됩니다. 설치 파일은 무료로 쓸 수 있지만 조건이 바뀔 수 있으니 재배포나 상업적 사용은 공식 사이트에서 확인하세요.
    • 예전에는 되던 도구가 갑자기 센서를 못 읽어요. 도구가 예전 WinRing0 방식에서 PawnIO 방식으로 바뀐 경우가 있다고 알려져 있습니다. 새 버전이라면 도구 안내에서 PawnIO 필요 여부를 확인하세요. 반대로 오래된 버전은 보안 프로그램이 예전 드라이버를 막아 값이 비는 경우도 있습니다.
    • 설치하면 게임에 영향이 있나요? 일부 게임 보안 프로그램은 외부 커널 드라이버를 민감하게 볼 수 있다는 언급이 있습니다. 게임을 하기 전에는 모니터링 도구를 종료하고, 문제가 있으면 PawnIO를 제거한 뒤 다시 확인하세요.
    • 설치한 뒤 블루스크린이 났어요. PawnIO 2.2.0 릴리스 노트에는 Windows 10 일부 빌드(RS5, 19H1, 19H2)에서 생기던 블루스크린 수정이 들어 있습니다. 설치된 버전이 낮다면 최신 버전으로 올리고, 그래도 반복되면 제거한 뒤 미니덤프를 분석해 PawnIO가 원인인지 확인하세요.
