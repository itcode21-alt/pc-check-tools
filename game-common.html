그래픽/화면 전환참고 자료 있음

Alt+Tab, 전체화면 전환, 로딩 화면 진입·복귀 직후 프레임이 급격히 떨어진 뒤 검은 화면이나 모니터 신호 없음이 나타나는 증상입니다. Windows 그래픽 드라이버가 응답하지 못하는 TDR인지, 케이블·전원·발열 문제인지 먼저 구분해야 합니다.

가능한 원인

  • 전체화면과 바탕화면 전환 중 그래픽 드라이버가 재설정되는 경우
  • 최근 그래픽 드라이버 업데이트 또는 손상된 셰이더 캐시·게임 파일
  • 오버레이·녹화·모니터링 프로그램이 화면 전환에 개입하는 경우
  • GPU 발열, 보조전원·케이블 접촉, 파워 용량·전압 불안정
  • 오버클럭·언더볼트나 높은 메모리 설정으로 전환 순간 안정성이 무너지는 경우

점검 순서

  1. 1단계 - 화면을 먼저 복구 (문서 외 일반 점검):
    ① 화면이 꺼졌지만 PC가 동작하면 Win+Ctrl+Shift+B를 눌러 그래픽 드라이버 재설정
    ② 복구되면 이벤트 뷰어 → Windows 로그 → 시스템에서 Display 4101, LiveKernelEvent 141·117 기록을 확인
  2. 2단계 - 전환 조건을 단순화 (문서 외 일반 점검):
    ① 게임을 무테 창모드로 바꾸고 Alt+Tab 재현 여부를 비교
    ② Discord·Steam·GeForce·AMD 녹화·모니터링 오버레이를 모두 끈 뒤 하나씩 다시 켜 원인을 분리
  3. 3단계 - 드라이버와 캐시 점검 (문서 외 일반 점검):
    ① 증상이 드라이버 업데이트 직후 시작됐다면 롤백을 비교
    ② 계속되면 공식 드라이버를 클린 설치하고 게임 셰이더 캐시·게임 파일 복구를 진행
  4. 4단계 - 하드웨어 확인 (문서 외 일반 점검):
    ① GPU 온도와 팬 속도를 기록하고 그래픽카드 보조전원·케이블을 다시 연결
    ② 오버클럭·언더볼트를 기본값으로 되돌리고 다른 케이블·모니터·주사율로 비교
  5. 5단계 - 수리 판단 (문서 외 일반 점검):
    ① 여러 게임과 바탕화면에서도 신호가 끊기거나 재부팅되면 GPU·파워·메인보드 점검을 우선
    ② TDR 레지스트리 시간을 임의로 늘리는 방법은 원인 은폐가 될 수 있어 기본 해결책으로 사용하지 않기

특정 게임에서만 프레임이 고정되거나 뚝뚝 끊기는 문제 · 전체 화면 최적화로 인한 프레임 저하

그래픽/성능참고 자료 있음

Windows 11의 '전체 화면 최적화'·'창이 있는 게임에 대한 최적화' 기능은 대부분 게임에 도움이 되지만, 일부 게임·그래픽 드라이버 조합에서는 오히려 프레임이 고정되거나 끊기는 원인이 됩니다. 특정 게임 하나에서만 증상이 나타난다면 이 설정부터 의심해볼 만합니다.

가능한 원인

  • 전체 화면 최적화가 게임의 자체 전체화면 처리 방식과 충돌하는 경우
  • 다중 평면 오버레이(MPO)가 특정 그래픽 드라이버·모니터 조합에서 버벅임을 일으키는 경우
  • 게임 바(Game Bar) 오버레이가 백그라운드에서 프레임 드랍을 유발하는 경우

점검 순서

  1. 1단계 - Windows 11의 '창 게임에 대한 최적화' 확인 (Microsoft 공식 안내):
    ① Microsoft 지원 문서는 이 최적화가 창 모드와 테두리 없는 창 모드에서 실행되는 DirectX 10·11 게임의 성능을 높이는 기능이라고 설명합니다. 호환 게임을 예전 blt 방식에서 최신 플립 모델로 바꿔 프레임 대기 시간을 줄여 준다고 안내합니다.
    ② 시작 → 설정 → 시스템 → 디스플레이 → 그래픽을 엽니다.
    ③ '기본 설정'의 'Windows 게임에 대한 최적화'(창 게임에 대한 최적화) 스위치를 켜거나 꺼서 프레임 차이를 비교합니다. 바꾼 뒤에는 게임을 다시 시작합니다.
    ④ 자동 HDR을 켜면 이 최적화가 자동으로 켜집니다. 최적화를 끄려면 먼저 자동 HDR을 꺼야 한다고 안내합니다.
  2. 2단계 - 앱별로 최적화·GPU 지정 (Microsoft 공식 안내):
    ① 설정 → 시스템 → 디스플레이 → 그래픽에서 '앱에 대한 사용자 지정 옵션'의 목록에서 해당 게임을 선택하고 '옵션'을 누릅니다.
    ② GPU가 둘 이상이면 '절전'이나 '고성능' 중에서 그 게임에 쓸 그래픽 성능을 고릅니다.
    ③ 이 게임만 창 게임 최적화를 끄려면 해당 스위치를 끄고, 자동 HDR을 끄려면 '자동 HDR 사용 안 함'에 체크합니다.
    ④ '저장'을 누르고 게임을 다시 시작합니다.
  3. 3단계 - 전체 화면 최적화 끄기 - 위 기능과는 다른 설정 (문서 외 일반 점검):
    ① 이 방법은 Microsoft 문서의 '창 게임 최적화'와는 다른 설정이라 위 문서에서 확인하지 못했습니다.
    ② 게임 실행 파일(.exe)을 마우스 오른쪽 버튼으로 눌러 '속성' → '호환성' 탭을 엽니다.
    ③ '전체 화면 최적화 사용 안 함'에 체크하고 '적용'을 누른 뒤 게임을 다시 실행합니다.
  4. 4단계 - 게임 바 끄기 (문서 외 일반 점검):
    ① 설정 → 게임 → 게임 바에서 기능을 꺼서 오버레이가 프레임에 영향을 주는지 배제
  5. 5단계 - 그래픽 드라이버 클린 설치 (EA 공식 안내):
    ① EA 지원 문서는 새 드라이버를 설치할 때 기존 드라이버를 삭제한 뒤 클린 설치하면 이전 드라이버와 새 드라이버가 충돌할 확률을 줄일 수 있다고 안내합니다.
    ② 드라이버 제조사(AMD·Intel·NVIDIA)의 클린 설치 지침에 따라 최신 드라이버를 설치합니다.

그래픽/실행참고 자료 있음

Windows에 내장된 Xbox Game Bar는 녹화·스크린샷을 위해 여러 게임에서 백그라운드로 함께 동작합니다. 다른 오버레이 프로그램과 함께 켜져 있으면 단축키가 충돌하거나, 오버레이 자체가 프레임을 갉아먹는 경우가 있습니다.

가능한 원인

  • 다른 프로그램(스트리밍·녹화 툴)과 Win+G 단축키가 겹치는 경우
  • 여러 오버레이 프로그램이 동시에 실행돼 서로 간섭하는 경우
  • 게임 바 백그라운드 프로세스가 멈춘 상태로 남아있는 경우

점검 순서

  1. 1단계 - 게임 바 요건과 설정 확인 (Xbox 공식 안내):
    ① Xbox 지원 문서는 2024년 10월부터 Xbox 앱과 Game Bar의 일부 기능이 제대로 작동하려면 Windows 10 22H2 이상이 필요하다고 안내합니다. 설정 → 시스템 → 정보 → Windows 사양 → 버전에서 확인합니다.
    ② Windows N 버전을 쓴다면 추가 소프트웨어(미디어 기능 팩)를 내려받아야 할 수 있다고 안내합니다.
    ③ 설정 → 게임 → 게임 바에서 기능이 켜져 있는지, 다른 프로그램과 단축키가 겹치지 않는지 확인합니다.
  2. 2단계 - 다른 오버레이 정리 (문서 외 일반 점검):
    ① GeForce Experience·Discord·백신 등 다른 오버레이 프로그램을 하나씩 꺼서 어떤 조합에서 충돌하는지 확인
  3. 3단계 - 게임 바 자체를 끄기 (문서 외 일반 점검):
    ① 녹화·스크린샷 기능이 필요 없다면 설정 → 게임 → 게임 바를 꺼서 오버레이 자체를 비활성화
  4. 4단계 - 백그라운드 프로세스 재시작 (문서 외 일반 점검):
    ① 작업 관리자에서 Xbox 관련 프로세스를 종료한 뒤 재부팅

그래픽/실행참고 자료 있음

음성 채팅이나 인게임 상점을 표시하는 오버레이는 게임 그래픽 위에 별도 레이어를 그리는 방식이라, 게임·그래픽 드라이버와의 궁합에 따라 크래시로 이어질 수 있습니다. 디스코드 공식 안내에 따르면 오버레이는 '트루 전체화면'에서는 아예 지원되지 않고 창모드·테두리 없는 창모드에서만 동작합니다.

가능한 원인

  • 게임이 '트루 전체화면'으로 실행 중이라 오버레이와 렌더링 방식이 충돌하는 경우
  • 디스코드 하드웨어 가속과 게임의 그래픽 API가 같은 GPU 자원을 두고 충돌하는 경우
  • 여러 오버레이(디스코드+스팀+GeForce 등)가 동시에 게임에 주입되는 경우

점검 순서

  1. 1단계 - 게임 화면 모드 확인 (Discord 공식 안내):
    ① Discord의 오버레이 알려진 문제 문서(2024년 개편 안내)는 새 오버레이가 모든 게임에서 기본으로 켜지고, 창 전체화면과 테두리 없는 창 전체화면에서는 작동하지만 진짜 전체화면(true fullscreen)에서는 작동하지 않는다고 안내합니다.
    ② 게임 옵션에서 화면 모드를 '테두리 없는 창모드'로 바꿔 오버레이가 지원되는 모드에서도 같은 증상이 나는지 확인합니다.
    ③ 문서는 게임 창이 포커스를 잃으면 오버레이가 숨겨지고, 게임 창을 화면 공유해도 오버레이는 캡처되지 않는다고도 안내합니다.
  2. 2단계 - 디스코드 오버레이 끄기 (문서 외 일반 점검):
    ① 디스코드 설정 → 오버레이(Overlay) → 게임 내 오버레이 활성화를 꺼서 재현 여부 확인
  3. 3단계 - 하드웨어 가속 끄기 (문서 외 일반 점검):
    ① 디스코드 설정 → 고급(Advanced) → 하드웨어 가속을 끈 뒤 재시도
  4. 4단계 - 스팀 오버레이도 함께 확인 (문서 외 일반 점검):

가능한 원인

  • 네트워크 구성 문제 (에픽게임즈 지원 안내)

점검 순서

  1. 1단계 - 드라이버·Windows 업데이트 (에픽게임즈 공식 안내):
    ① 그래픽 드라이버와 Windows가 최신 버전인지 확인하고 업데이트합니다.
  2. 2단계 - 런처 웹 캐시 삭제 (에픽게임즈 공식 안내):
    ① 시스템 트레이의 에픽게임즈 런처 아이콘을 우클릭해 종료를 선택합니다.

    ③ Epic Games Launcher 폴더 → Saved 폴더를 열고 웹 캐시(webcache) 폴더를 삭제합니다.
    ④ 컴퓨터를 다시 시작하고 런처를 실행합니다.
  3. 3단계 - 연결 문제 점검 (에픽게임즈 공식 안내):
    ① 위 방법으로도 해결되지 않으면 에픽게임즈의 '연결 문제 해결 방법' 문서를 따릅니다.

    ① AS-202: 유효하지 않은 응답 패키지, 손상된 웹 캐시, 네트워크 연결 문제로 로그인·인증 요청이 실패할 때 나타납니다. 웹 캐시 삭제와 드라이버·Windows 업데이트를 안내합니다.
    ② AS-1010: 로그인 중 나타나며 장치의 시계가 동기화되지 않았을 수 있다고 안내합니다. 시계를 동기화합니다.
    ③ AS-18004: 로그인 시도 실패 횟수가 너무 많다는 뜻입니다. 올바른 계정 정보를 입력하는지 확인하고 비밀번호를 재설정합니다.
    ④ AS-18031: 입력한 계정 사용자 이름 또는 비밀번호가 잘못됐다는 뜻입니다. 올바른 계정 정보를 확인하고 비밀번호를 재설정합니다.

  • 화면이 꺼지면 그래픽카드가 고장 난 건가요? 반드시 그렇지는 않습니다. 드라이버가 일시적으로 재설정되는 TDR, 케이블·모니터·오버레이 문제도 같은 증상을 만들 수 있습니다. 여러 게임과 바탕화면에서도 반복되는지로 범위를 좁혀보세요.
  • TDR 레지스트리 값을 늘리면 해결되나요? 응답 시간만 늘려 증상을 늦출 수 있어 권장되는 첫 해결책이 아닙니다. 드라이버·발열·전원·오버클럭 원인을 먼저 점검하고 변경 전 복원 지점을 준비하세요.
  • Win+Ctrl+Shift+B 단축키는 안전한가요? Windows가 그래픽 드라이버를 재설정하는 기본 단축키입니다. 화면이 잠시 깜빡이거나 알림음이 난 뒤 복구되는지 확인하는 용도로 사용할 수 있습니다.
  • 여러 오버레이 프로그램을 동시에 켜두면 안 되나요? 디스코드·스팀·GeForce Experience 등 오버레이를 여러 개 동시에 켜두면 서로 간섭해 프레임 저하나 크래시로 이어질 수 있습니다. 증상이 있다면 하나씩 꺼보면서 원인이 되는 프로그램을 좁히는 것이 가장 빠릅니다.
