📑 목차

에러 코드 상세

0x80070102 · 대기 시간 초과(WAIT_TIMEOUT)

Microsoft 문서에서 0x102(WAIT_TIMEOUT, 258)는 "대기 작업이 제한 시간을 넘었다"는 뜻입니다. 앞의 0x8007은 Win32 오류를 HRESULT로 감싼 표기이며, 어떤 장치나 서비스를 기다리다 실패했는지는 코드만으로 알 수 없습니다.

이 코드를 어떻게 해석해야 하나요?

이 코드는 "기다리다가 시간이 지났다"는 결과만 알려 줍니다. 무엇을 기다렸는지는 담겨 있지 않기 때문에, 오류 문구보다 오류가 뜬 작업(어떤 프로그램의 어떤 단계)이 더 중요한 단서입니다. 인터넷 검색에서 이 코드를 네트워크 어댑터 문제로 설명하는 글을 볼 수 있지만, Microsoft의 정의에는 그런 내용이 없습니다.

가능성 높은 원인

  • 공식 정의: 기다리던 작업이 제한 시간 안에 끝나지 않았습니다.
  • 응답이 늦은 쪽(네트워크 상대, 저장장치, 드라이버, 서비스 등)은 오류가 뜬 작업에 따라 달라집니다. 문서에는 구체적인 원인이 없습니다.
  • 일시적인 지연이었을 수도 있고, 같은 단계에서 반복된다면 그 작업이 기다리는 대상에 문제가 있을 수 있습니다(문서 외 일반 설명).

첫 점검 항목

  1. 문서 외 일반 점검: 오류가 뜬 순간 무엇을 하고 있었는지(어떤 프로그램·업데이트·설치·복사) 적어 두세요. 코드만으로는 원인을 알 수 없어서 어떤 작업이었는지가 다음 단계를 정합니다.
  2. 문서 외 일반 점검: 같은 작업을 한 번 더 시도해 같은 단계에서 반복되는지 보세요. 한 번만 나고 사라졌다면 일시적인 지연이었을 가능성이 큽니다.
  3. 문서 외 일반 점검: PC를 재시작한 뒤 같은 작업을 다시 해 보세요.
  4. 문서 외 일반 점검: 이벤트 뷰어(eventvwr.msc) → Windows 로그 → 시스템에서 오류가 난 시각 전후의 경고·오류를 확인하세요. 같은 시각에 디스크나 드라이버 관련 이벤트가 있으면 그쪽이 먼저 볼 대상입니다.
  5. 문서 외 일반 점검: 네트워크나 외장 저장장치를 쓰는 작업이라면 다른 네트워크, 다른 USB 포트·드라이브에서도 같은지 비교해 보세요.
단계별로 직접 해보기

이 오류와 가까운 증상은 질문에 답하며 해볼 것을 한 단계씩 따라 할 수 있습니다. 준비물과 자세한 방법을 보여 주고, 직접 하기 어려우면 문의로 이어집니다. 인터넷·네트워크 자가진단 시작하기 →

확인 결과에 따른 다음 단계

  • 같은 작업을 다시 하면 성공할 때 — 일시적인 지연이었을 가능성이 큽니다. 자주 반복되면 그 시각의 이벤트 로그를 확인하세요.
  • 특정 프로그램이나 업데이트에서만 반복될 때 — 그 프로그램 이름과 멈춘 단계를 적어 해당 가이드나 문의에 함께 전달하세요.
  • 여러 작업에서 반복될 때 — 저장장치 상태와 시스템 이벤트 로그를 확인하고, 중요한 파일은 먼저 백업하세요.

앞 단계로 해결되지 않을 때

같은 단계에서 계속 반복되면 프로그램 이름, 멈춘 단계, 오류 시각을 적어 두세요. 이 세 가지가 있으면 이벤트 로그와 맞춰 원인을 좁힐 수 있습니다.

관련 증상 가이드 확인하기

같은 증상과 연결된 다른 오류 코드

  • 0x800704CF · 네트워크 위치에 접근할 수 없음(ERROR_NETWORK_UNREACHABLE)
  • 0x80070718 · IP 주소를 가져올 수 없음
  • 0x80070490 · 요소를 찾을 수 없음(업데이트 검색 실패)
  • 배틀넷 연결 오류 · 배틀넷 오류로 오버워치 등이 실행되지 않음 (BLZBNTBNA0000)

자주 묻는 질문

  • 이 코드는 네트워크 어댑터나 케이블 문제인가요? Microsoft의 정의에는 네트워크 어댑터나 케이블 이야기가 없습니다. "대기 시간 초과"라는 결과만 알려 주므로, 어떤 작업에서 났는지로 원인을 좁혀야 합니다.
  • 0x102와 0x80070102는 같은 코드인가요? 같은 값의 다른 표기입니다. Win32 오류 258(0x102)을 HRESULT 형식으로 감싸면 0x80070102가 됩니다.
  • 재시작하면 해결되나요? 일시적인 지연이었다면 재시작 뒤 사라질 수 있습니다. 같은 단계에서 계속 반복되면 그 작업이 기다리는 대상(네트워크, 저장장치, 서비스)을 점검해야 합니다.
