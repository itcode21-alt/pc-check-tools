에러 코드 상세

0xC000000E · 부팅 장치를 찾을 수 없음

Windows가 부팅에 필요한 디스크나 시스템 파티션에 접근하지 못할 때 나타나는 부팅 오류입니다.

이 코드를 어떻게 해석해야 하나요?

이 코드는 Windows Boot Manager 또는 winload.exe가 부팅에 필요한 장치나 시스템 파티션에 접근하지 못했다는 단서입니다. SSD·HDD 연결, BIOS 부팅 모드, BCD 손상을 구분해야 하며 코드만으로 저장장치 고장을 확정할 수는 없습니다.

먼저 기록할 내용: 0xC000000E가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • SATA·M.2 케이블 접촉 불량이나 디스크 자체의 인식 실패
  • BIOS 부팅 순서가 바뀌었거나 UEFI/Legacy(CSM) 모드가 설치 당시와 다르게 전환된 경우
  • BCD(부팅 구성 데이터)가 손상되었거나 EFI 시스템 파티션 정보가 유실된 경우
  • 파티션 작업 도구로 디스크 구성을 바꾸다 부팅 파티션 문자가 바뀐 경우
  • 디스크 자체의 배드섹터·컨트롤러 고장

첫 점검 항목

  1. 디스크 연결 확인 — SATA 케이블·전원 케이블과 M.2 고정 상태를 확인하고 중요한 파일이 있다면 반복 부팅을 줄이세요.
  2. BIOS 확인 — 부팅 디스크와 Windows Boot Manager가 보이는지, UEFI·Legacy 설정이 설치 당시와 같은지 확인하세요.
  3. 설치 USB로 부팅 후 시동 복구 — Windows 설치 미디어로 부팅해 "컴퓨터 복구" → "문제 해결" → "고급 옵션" → "시동 복구"를 먼저 실행하세요.
  4. bootrec 명령으로 BCD 복구 — 시동 복구로 안 되면 명령 프롬프트(복구 환경)에서 순서대로 실행하세요: bootrec /fixmbr → bootrec /fixboot → bootrec /scanos → bootrec /rebuildbcd. /rebuildbcd에서 설치를 찾으면 Y를 눌러 추가합니다.
  5. UEFI 시스템에서는 bcdboot 사용 — bootrec으로 해결되지 않고 UEFI 부팅이라면 bcdboot C:\Windows /l ko-kr /s S: /f UEFI (S:는 EFI 시스템 파티션 문자, diskpart의 list volume으로 먼저 확인)를 시도하세요.

확인 결과에 따른 다음 단계

  • BIOS에서 디스크가 보이지 않을 때 — 케이블·전원 연결을 다시 점검하고, 다른 SATA 포트나 M.2 슬롯으로 옮겨 인식되는지 확인하세요. 여전히 안 보이면 디스크 고장 가능성을 우선하세요.
  • BIOS에는 보이지만 부팅이 안 될 때 — bootrec/bcdboot 명령으로 대부분 해결됩니다. UEFI/Legacy 모드가 설치 당시와 다른지부터 확인하세요.
  • bootrec·bcdboot로도 해결되지 않을 때 — 파일 시스템 손상이 의심되므로 복구 환경에서 chkdsk C: /f /r을 실행하고, 그래도 안 되면 디스크 자체의 SMART 상태를 다른 PC에서 점검하세요.

데이터와 시스템을 보호하는 주의사항

아직 원인을 특정하지 못했다면 초기화나 레지스트리 편집, 시스템 파일 교체 같은 조치는 뒤로 미루세요.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

시스템 복구나 초기화, 드라이버 삭제처럼 원상복구가 힘든 작업을 시작하기 전에, 중요한 파일은 미리 외장 저장장치나 별도 위치에 백업해 두세요.

자주 묻는 질문

  • BIOS에서 SSD가 보이면 디스크 고장은 아닌가요? BIOS 인식과 Windows Boot Manager·BCD 정상 여부는 별개입니다. 부팅 순서와 EFI 시스템 파티션을 함께 확인하세요.
  • 복구 명령을 바로 실행해도 되나요? 중요한 파일이 있다면 먼저 백업을 고려하세요. BIOS에서도 디스크가 사라지거나 읽기 오류가 반복되면 데이터 보존과 저장장치 점검을 우선해야 합니다.
