접속 로딩 화면에서 멈추고 진입이 안 되는 문제 · 로딩 화면 멈춤

접속/실행참고 자료 있음

게임 접속을 위한 로딩 화면은 뜨지만 그 이후로 진행되지 않는 경우입니다. 펄어비스 공식 FAQ에 등록된 사례로, OneDrive 폴더 동기화가 원인인 경우가 있습니다.

가능한 원인

  • 게임 관련 폴더가 OneDrive와 동기화되며 파일 접근이 지연되는 경우
  • 런처 또는 게임 클라이언트 파일이 손상된 경우
  • 네트워크 연결이 불안정한 경우

점검 순서

  1. 1단계 - OneDrive 동기화 일시 중지 (공식 안내):
    ① 작업 표시줄의 OneDrive 아이콘 실행
    ② 톱니바퀴 → '동기화 일시 중지' → 2시간 선택
    ③ 설정 후 게임 재접속 시도
  2. 2단계 - 런처에서 클라이언트 복구:
    ① 검은사막 런처의 설정에서 '게임 복구/검사' 기능 실행
  3. 3단계 - 오류 보고 후 1:1 문의 (펄어비스 공식 안내):
    ① 펄어비스는 OneDrive 동기화를 멈춘 뒤에도 해결되지 않으면 오류 보고를 하고 고유 ID와 함께 1:1 문의를 접수하라고 안내합니다.
    ② 런처 오른쪽 아래 '오류 보고' 버튼을 누릅니다.
    ③ 검은사막 설치 경로(기본: 설치 드라이브 → Pearlabyss → BlackDesert)에서 PERS.exe 파일을 실행합니다.
    ④ 생성된 고유 ID를 1:1 문의에 적어 접수합니다.

그래픽/성능커뮤니티 사례 포함

평상시에는 괜찮다가 전투나 사람이 몰리는 지역에서 프레임이 급격히 떨어지는 경우로, 미니맵·UI 렌더링 부하가 원인 중 하나로 자주 지목됩니다.

가능한 원인

  • 2D 미니맵 등 UI 요소가 프레임 저하를 유발하는 경우
  • 그래픽 옵션 중 자동 최적화·저전력 옵션이 오히려 프레임을 제한하는 경우
  • 많은 캐릭터가 몰리는 구간에서 렌더링 부하가 급증하는 경우

점검 순서

  1. 1단계 - 전투집중모드 활용 (이용자 안내):
    ① 설정 → UI 편집모드 → 전투집중모드 켜기
    ② 필요한 인터페이스(채팅창, 미니맵 등)만 선택적으로 표시
  2. 2단계 - 성능 옵션 조정 (이용자 안내):
    ① 그래픽 설정에서 '자동 프레임 최적화'와 '저전력' 옵션을 끄고 '성능 최적화'는 켜기
  3. 3단계 - 그래픽 옵션 하단 최적화 설정 적용 (이용자 안내):
    ① 그래픽 설정 가장 아래의 최적화 설정 항목을 모두 적용

커뮤니티에서 확인된 사례

  • 커뮤니티 사례 보기 — 검은사막 인벤 팁과노하우 게시판의 프레임 최적화 정리글. 미니맵과 UI 렌더링이 프레임 저하의 주요 원인으로 지목됩니다.

"패치 파일 적용에 실패하였습니다" 오류로 실행 불가 · 패치 파일 적용 실패

런처/설치참고 자료 있음

검은사막 패치 적용 도중 실패 메시지가 뜨며 실행이 막히는 경우로, 펄어비스 공식 FAQ에서 네트워크·보안 프로그램·디스크 공간을 주요 점검 항목으로 안내하고 있습니다.

가능한 원인

  • 무선(Wi-Fi) 네트워크 환경에서 패치 파일이 불안정하게 받아지는 경우
  • VPN·프록시가 패치 서버 접속을 방해하는 경우
  • 백신이 검은사막·EasyAntiCheat 설치 폴더를 차단하는 경우
  • 설치 드라이브 여유 공간이 60GB 미만인 경우

점검 순서

  1. 1단계 - 네트워크 문제 확인 (펄어비스 공식 안내):
    ① 펄어비스는 이 오류가 개인 PC나 네트워크 환경 등 여러 원인으로 생길 수 있다고 안내합니다(2026-03 갱신 FAQ 기준).
    ② 무선(Wi-Fi) 대신 유선 네트워크로 연결합니다.
    ③ VPN·프록시 설정을 해제합니다.
    ④ 네트워크 방화벽을 일시적으로 비활성화한 뒤 검은사막을 업데이트합니다. 끝나면 다시 켭니다.
  2. 2단계 - 다른 프로그램 충돌·백신 오탐 확인 (펄어비스 공식 안내):
    ① 검은사막 외 다른 프로그램을 모두 종료한 상태에서 업데이트합니다.
    ② 사용 중인 백신으로 바이러스 검사를 합니다.
    ③ 백신에서 '검은사막 설치 폴더'와 C:\Program Files (x86)\EasyAntiCheat 폴더를 탐지에서 제외합니다. 메뉴 이름은 백신마다 다릅니다.
  3. 3단계 - 운영체제·디스크 점검 (펄어비스 공식 안내):
    ① 윈도우를 최신 버전으로 업데이트합니다.
    ② 파일 탐색기에서 '보기' 메뉴 → '숨긴 항목'(또는 폴더 옵션의 '숨김 파일, 폴더 및 드라이브 표시')을 켭니다.
    ③ 기본 드라이브(예: C드라이브) → Pearlabyss → BlackDesert 폴더에서 patch_temp 폴더를 찾아 삭제합니다.
    ④ C드라이브를 마우스 오른쪽 버튼으로 눌러 '속성' → '도구' 탭 → '오류 검사'를 실행합니다.
    ⑤ 검은사막 런처에서 파일 검사를 진행합니다.
  4. 4단계 - 디스크 저장 공간 확보 (펄어비스 공식 안내):
    ① 펄어비스는 검은사막 설치에 약 80GB 이상의 여유 저장 공간이 필요하다고 안내합니다(이 카드에 있던 '60GB'는 갱신 전 수치였습니다).
    ② 파일 탐색기 → '내 PC'에서 설치 드라이브의 남은 공간을 확인하고, 부족하면 확보한 뒤 다시 설치합니다.
  5. 5단계 - 그래도 안 되면 오류 보고 후 문의 (펄어비스 공식 안내):
    ① 검은사막 런처 오른쪽 아래의 '오류 보고' 버튼을 누릅니다.
    ② 정보 수집에 동의하고 카테고리를 설정합니다.
    ③ 오류 유형을 고르고 문제가 생긴 상황을 적습니다(최소 10자).
    ④ 화면 왼쪽 아래 '보내기'를 눌러 로그 파일을 전송합니다. 보내기 전에 화면 아래의 '고유 ID'를 복사해 둡니다.
    ⑤ 전송이 끝나면 고객센터 '설치/실행' 카테고리로 문의하면서 그 '고유 ID'를 적어 보냅니다. 고유 ID는 오류 보고를 할 때마다 바뀌니 해당 증상의 ID를 적어야 합니다.
    ⑥ 문의할 때 패치 다운로드 실패 메시지가 보이는 스크린샷과 사용 중인 백신 프로그램 이름을 함께 적습니다.

    ① 검은사막 런처 오른쪽 아래의 '오류 보고' 버튼을 누릅니다.

    ③ 오류 유형을 고르고 문제가 생긴 상황을 적습니다(최소 10자).
    ④ 화면 왼쪽 아래 '보내기'를 눌러 로그 파일을 전송합니다. 보내기 전에 화면 아래의 '고유 ID'를 복사해 둡니다.
    ⑤ 전송이 끝나면 고객센터 '설치/실행' 카테고리로 문의하면서 그 '고유 ID'를 적어 보냅니다. 고유 ID는 오류 보고를 할 때마다 바뀌니 해당 증상의 ID를 적어야 합니다.

    ① 그래픽카드 제조사 최신 드라이버로 업데이트
  3. 3단계 - 게임 파일 무결성 검사 (문서 외 일반 점검):
    ① 런처의 게임 복구/검사 기능으로 손상 파일 확인

스팀을 통해 검은사막에 접속하려 할 때, 로그인한 스팀 계정에 게임이 등록되어 있지 않아 나타나는 안내 메시지입니다.

가능한 원인

  • 스팀 계정에 검은사막이 구매·등록되어 있지 않은 경우
  • 여러 스팀 계정을 사용 중이라 다른 계정으로 로그인된 경우

점검 순서

  1. 1단계 - 로그인 계정 확인:
    ① 현재 스팀에 로그인된 계정이 검은사막을 구매한 계정이 맞는지 확인
  2. 2단계 - 스팀 계정 전환:
    ① 스팀에서 로그아웃 후 검은사막을 보유한 계정으로 다시 로그인
  3. 3단계 - 고객센터 문의:
    ① 정상 계정인데도 반복되면 펄어비스 고객센터로 문의

  4. 4단계 - NVIDIA 제어판에서 그래픽카드 지정 (펄어비스 공식 안내):
    ① NVIDIA 제어판을 엽니다.
    ② '3D 설정' → '3D 설정 관리' → '프로그램 설정'에서 Black Desert를 추가하거나, '전역 설정'의 'CUDA - GPU'에서 그래픽카드를 선택합니다(NVIDIA 기준).
  5. 5단계 - 그래픽 드라이버 버전 조정 (펄어비스 공식 안내):
    ① 최신 버전을 쓰고 있다면 이전 버전으로 되돌리거나 그래픽카드 제조사가 권장하는 버전으로 설치합니다.
    ② 최신 버전이 아니라면 업데이트 시점으로부터 약 한 달 지나 안정화된 드라이버를 설치합니다.
    ③ 자세한 설치 방법은 사용하는 GPU 제조사 홈페이지에서 확인합니다.
  6. 6단계 - 런처가 느릴 때 외장 그래픽카드 선택 (펄어비스 공식 안내):
    ① 런처 오른쪽 위 톱니바퀴(설정)를 누릅니다.
    ② '그래픽 카드'를 NVIDIA GeForce나 AMD Radeon 같은 외장 그래픽카드로 선택합니다.
  7. 7단계 - 완전 삭제 후 재설치 (문서 외 일반 점검):
    ① 위 방법으로 해결되지 않으면 클라이언트를 완전히 삭제 후 재설치

검은사막 DirectX 12·FSR 3.1 추가 안내와 런처에서 DirectX 버전을 바꾸는 방법 · DirectX 11 / DirectX 12 선택

그래픽/설정참고 자료 있음

검은사막은 2026년 10월 28일 업데이트로 DirectX 12와 AMD FSR 3.1을 추가했습니다. 공식 공지는 기존 DirectX 11도 계속 이용할 수 있고, 초기 기본 설정은 DirectX 11이며, 런처 설정에서 DirectX 버전을 선택할 수 있다고 안내합니다. DirectX 12 사용 중 튕김이나 프레임 문제가 생겼을 때의 원인·해결 절차를 정의한 공식 문서는 확인되지 않았습니다.

알아둘 점

  • DirectX 12로 실행할 수 없는 환경이면 게임이 DirectX 11로 실행됩니다 (공식 안내)
  • DirectX 12 적용에 따른 성능 변화는 PC 사양, 그래픽카드와 드라이버, 게임 내 환경에 따라 다를 수 있습니다 (공식 안내)
  • FSR 3.1은 DirectX 12 환경과 Windows 10 22H2 이상에서만 쓸 수 있습니다 (공식 안내)

점검 순서

  1. 1단계 - 런처에서 DirectX 버전 확인·변경 (펄어비스 공식 안내):
    ① 검은사막 런처 상단의 톱니바퀴 아이콘을 눌러 '설정' 창을 엽니다.
    ② 'DirectX 버전' 항목에서 DirectX 11 또는 DirectX 12를 선택합니다. 초기 기본 설정은 DirectX 11입니다.
    ③ 현재 사용 중인 DirectX 버전은 게임 설정에서도 확인할 수 있습니다.
  2. 2단계 - 업스케일러 조건 확인 (펄어비스 공식 안내):
    ① DirectX 11에서는 FSR 1.0만, DirectX 12에서는 FSR 3.1만 사용할 수 있습니다.
    ② FSR 3.1은 Windows 10 22H2 이상(Windows 11 권장)과 DirectX 12 환경에서 쓸 수 있고, 이번 업데이트에서는 프레임 생성 기능은 지원하지 않습니다.
  3. 3단계 - 문제가 생기면 이전 설정으로 (문서 외 일반 점검):
    ① DirectX 12로 바꾼 뒤 튕김이나 프레임 저하가 생기면 같은 설정 창에서 DirectX 11로 되돌려 같은 증상이 계속되는지 비교합니다.
    ② 그래픽 드라이버를 최신으로 업데이트해 둡니다. DirectX 12 문제의 원인이 무엇인지는 공식 문서로 확인되지 않았습니다.

런처/설치참고 자료 있음

런처 접속에 필요한 루트 인증서가 자동 갱신되지 않아 발생하는 오류로, 레지스트리 설정 변경으로 해결할 수 있습니다.

가능한 원인

  • Windows의 루트 인증서 자동 업데이트가 비활성화된 경우
  • Windows 업데이트와 XIGNCODE 안티치트 간의 일시적 호환성 문제

점검 순서

  1. 1단계 - 루트 인증서 자동 업데이트 켜기 - 1번 방법, 권장 (펄어비스 공식 안내):
    ① 펄어비스는 이 문구가 런처 접속에 필요한 인증서가 없거나 자동 갱신이 이뤄지지 않아 나타난다고 설명하고, 정기 자동 업데이트를 위해 1번 방법을 권장합니다.
    ② 윈도우 검색에 '레지스트리 편집기'를 입력하거나 Windows + R을 누르고 regedit를 입력해 엽니다.
    ③ 위쪽 경로 입력란에 HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\SystemCertificates\AuthRoot 를 입력합니다.
    ④ DisableRootAutoUpdate 값을 0으로 바꾸고 저장한 뒤 컴퓨터를 재부팅합니다.
    ⑤ 위 경로나 값이 없거나 해결되지 않으면 아래 2번 방법을 진행합니다. 레지스트리를 바꾸기 전에는 현재 값을 메모해 두세요(일반 주의).
  2. 2단계 - 인증서 수동 설치 - 2번 방법 (펄어비스 공식 안내):
    ① 펄어비스 FAQ의 '인증서 다운로드' 링크로 인증서 파일을 내려받습니다.
    ② 내려받은 인증서 파일을 더블클릭합니다.
    ③ '인증서 설치'를 누르고 '로컬 컴퓨터'를 선택한 뒤 '다음'을 누릅니다.
    ④ '인증서 종류를 기준으로 인증서 저장소를 자동으로 선택'을 고르고 '다음' → '마침'을 누릅니다.
    ⑤ 설치 중 권한 허용 메시지가 뜨면 '예'를 선택합니다.
  3. 3단계 - 그래도 안 되면 오류 보고 후 문의 (펄어비스 공식 안내):
    ① 검은사막 설치 드라이브 → Pearlabyss → BlackDesert 폴더의 pers.exe를 실행해 오류 보고를 진행합니다.
    ② 정보 수집 동의와 카테고리를 설정하고, 오류 유형을 고른 뒤 상황을 적습니다(최소 10자).
    ③ 화면 왼쪽 아래 '보내기'를 눌러 로그를 전송하고, 보내기 전에 복사해 둔 '고유 ID'를 고객센터 '설치/실행' 카테고리 문의에 적습니다.
  4. 4단계 - XIGNCODE 최신 패치 확인 (문서 외 일반 점검):
    ① 특정 Windows 업데이트와의 충돌 문제는 XIGNCODE 개발사의 패치로 해결된 사례가 있으므로 게임·클라이언트를 최신 상태로 유지

자주 묻는 질문

  • 혼잡 지역에서만 프레임이 떨어지는 이유는 무엇인가요? 다른 캐릭터와 이펙트가 몰리는 구간은 CPU·GPU 부하가 급격히 늘어나는 지점입니다. 그래픽 옵션 중 캐릭터·이펙트 표시 관련 항목을 우선 낮춰 비교해보세요.

  • 그래픽카드 인식 안 됨 해결 가이드 — 런처가 외장 그래픽카드 대신 내장 그래픽을 쓸 때 카드 인식부터 확인합니다.
  • 게임 렉·프레임 드랍 원인과 해결 — 혼잡 지역에서의 프레임 드랍 원인을 병목별로 가립니다.
  • 그래픽 드라이버 재설치 방법 — 클라이언트가 갑자기 종료될 때 드라이버를 먼저 점검합니다.
