프린터 인쇄 대기열 걸림 원인과 점검 순서

인쇄 대기열에 문서가 걸려 진행되지 않거나 취소해도 지워지지 않는 경우

인쇄를 눌러도 진행되지 않고 대기열에 계속 쌓이기만 하거나, 취소를 눌러도 문서가 지워지지 않는다면 대부분 인쇄 스풀러(Print Spooler) 서비스의 문제입니다.

가장 먼저 시도할 것은 Print Spooler 서비스를 다시 시작하는 것입니다. 이것만으로 해결되지 않는다면 스풀 폴더에 남은 손상된 인쇄 작업 파일이 원인일 수 있어, 서비스를 멈춘 뒤 해당 폴더의 파일을 직접 삭제해야 합니다.

서비스 재시작과 스풀 폴더 정리로도 해결되지 않는다면 프린터 드라이버나 연결 자체의 문제로 범위를 넓혀야 합니다.

이 가이드가 필요한 상황

  • 인쇄를 눌러도 대기열에 문서만 쌓이고 실제로 인쇄되지 않는다.
  • 대기열의 문서를 취소해도 계속 남아있다.
  • 다른 문서를 인쇄하려 해도 이전 대기열 때문에 진행되지 않는다.

먼저 확인할 항목

  1. Print Spooler 서비스 재시작 — 작업 관리자 > 서비스 탭에서 Print Spooler를 찾아 우클릭 후 '다시 시작'을 누르세요.
  2. 스풀 폴더 파일 삭제 — 서비스를 중지한 뒤 C:\Windows\System32\spool\PRINTERS 폴더의 파일을 모두 삭제하고 서비스를 다시 시작하세요.
  3. 프린터 드라이버 재설치 — 제조사 홈페이지에서 최신 드라이버를 받아 재설치하세요.
  4. 프린터 연결 상태 확인 — USB 케이블이나 와이파이·네트워크 연결 상태를 확인하세요.

원인을 더 정확히 나누는 방법

서비스 재시작만으로 해결되지 않는 이유

서비스를 재시작해도 스풀 폴더에 손상된 파일이 그대로 남아있으면 서비스가 다시 그 파일을 읽으려다 같은 문제를 반복할 수 있습니다.

반복적으로 이 문제가 생긴다면

특정 문서(대용량 파일, 손상된 PDF 등)를 인쇄할 때마다 반복된다면, 그 문서 자체가 원인일 수 있습니다.

확인 결과에 따른 다음 단계

  • 서비스 재시작으로 해결될 때 — 일시적인 서비스 오류였으므로 이후 재발하는지 지켜보세요.
  • 스풀 폴더 정리가 필요했을 때 — 특정 문서에서 반복된다면 그 문서 자체의 손상 여부도 확인하세요.
  • 위 방법으로도 해결되지 않을 때 — 드라이버 재설치와 연결 상태 점검으로 범위를 넓히세요.

피해야 할 실수

  • 서비스 재시작 없이 스풀 폴더 파일만 삭제하려는 것(파일이 사용 중이라 삭제 안 됨)
  • 드라이버 문제 확인 없이 프린터를 반복 재설치하는 것

자주 묻는 질문

  • 스풀 폴더 파일을 삭제해도 안전한가요? 네, 대기 중인 인쇄 작업의 임시 파일만 저장되어 있어 안전합니다.
  • Print Spooler 서비스는 어떻게 찾나요? 작업 관리자의 서비스 탭에서 이름순으로 찾으면 됩니다.
  • 매번 이 문제가 반복되면요? 드라이버를 최신 버전으로 재설치하거나 문서 자체를 확인하세요.
