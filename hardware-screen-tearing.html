화면 티어링(찢어짐) 원인과 점검 순서

게임·영상 재생 중 화면이 위아래로 어긋나며 찢어진 것처럼 보이는 경우

화면 티어링은 그래픽카드가 그리는 속도와 모니터가 화면을 표시하는 속도가 서로 맞지 않아 한 화면에 두 개의 다른 장면이 겹쳐 보이는 현상입니다. 고장이 아니라 동기화 설정의 문제인 경우가 대부분입니다.

가장 효과적인 해결책은 V-Sync나 G-Sync·FreeSync 같은 동기화 기술을 켜는 것입니다. 이 기능들은 그래픽카드의 출력을 모니터의 주사율에 맞춰 조절해 티어링을 방지합니다.

동기화 기능을 켜면 티어링은 해결되지만 입력 지연이 약간 늘어날 수 있어, 경쟁적인 게임에서는 대신 프레임 제한(FPS Cap)만 걸어 사용하는 경우도 많습니다.

이 가이드가 필요한 상황

  • 화면 상단과 하단이 서로 다른 장면으로 어긋나 보인다.
  • 화면을 빠르게 회전하거나 움직일 때 특히 심하게 나타난다.
  • 특정 게임이나 고프레임 상황에서만 나타난다.

먼저 확인할 항목

  1. V-Sync 켜기 — 게임 설정이나 그래픽 드라이버 제어판에서 수직 동기화(V-Sync)를 켜세요.
  2. G-Sync·FreeSync 활성화 확인 — 모니터 OSD 메뉴와 그래픽 드라이버 설정 양쪽에서 모두 켜져 있는지 확인하세요.
  3. 프레임 제한(FPS Cap) 설정 — 게임 내 설정이나 그래픽 드라이버에서 프레임을 모니터 주사율과 비슷하게 제한하세요.
  4. 발생 범위 확인 — 다른 게임이나 영상 재생에서도 같은 현상이 나타나는지 확인하세요.

원인을 더 정확히 나누는 방법

V-Sync와 입력 지연의 트레이드오프

V-Sync는 화면을 안정시키지만 그래픽카드가 다음 프레임을 준비하고도 모니터 갱신 시점까지 대기해야 해서 약간의 입력 지연이 생깁니다.

특정 게임에서만 나타난다면

그 게임의 자체 그래픽 설정에서 동기화 옵션이 꺼져 있거나 그래픽 드라이버의 전역 설정과 충돌하고 있을 가능성이 있습니다.

확인 결과에 따른 다음 단계

  • V-Sync로 해결될 때 — 입력 지연이 거슬린다면 G-Sync·FreeSync나 프레임 제한으로 대체해보세요.
  • G-Sync·FreeSync 지원 모니터일 때 — V-Sync보다 이 기능을 우선 사용하는 것이 일반적으로 더 낫습니다.
  • 여러 프로그램에서 나타날 때 — 그래픽 드라이버의 전역 설정을 확인하고 최신 버전으로 업데이트하세요.

피해야 할 실수

  • V-Sync를 켜보지 않고 바로 모니터나 그래픽카드를 의심하는 것
  • 프레임 제한 없이 무조건 최고 성능만 추구해 불필요하게 높은 프레임을 유지하는 것

자주 묻는 질문

  • 티어링이 하드웨어 고장 신호인가요? 아닙니다. 대부분 동기화 설정의 문제입니다.
  • V-Sync를 켜면 프레임이 떨어지는 것 같아요. 정상입니다. G-Sync·FreeSync가 더 나은 대안일 수 있습니다.
  • 모니터가 G-Sync를 지원하는지 어떻게 아나요? 모니터 사양표나 NVIDIA 제어판에서 확인할 수 있습니다.
