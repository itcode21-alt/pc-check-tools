Aw Snap 오류 · 이런! 페이지 로드 중 문제가 발생했습니다 (Aw, Snap!)

크롬 기반 브라우저에서 특정 탭이 크래시하며 나타나는 오류 화면으로, 메모리 부족이나 확장 프로그램, GPU 드라이버 문제가 흔한 원인입니다.

이 코드를 어떻게 해석해야 하나요?

업데이트 관련 오류 코드는 네트워크, 캐시, 구성 요소 저장소, 디스크 공간, 서비스 상태 중 어느 단계에서 작업이 멈췄는지를 나타냅니다. 실패가 반복되는 시점과 이벤트 로그의 세부 코드를 같이 살펴보면 원인을 좁히기 수월합니다.

먼저 기록할 내용: Aw Snap 오류가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 시스템 메모리가 부족해 탭 프로세스가 강제 종료된 경우
  • 특정 확장 프로그램이 페이지와 충돌하는 경우
  • 그래픽 드라이버가 오래되어 하드웨어 가속 렌더링에 실패하는 경우
  • 브라우저 프로필이나 캐시가 손상된 경우
  • 해당 웹페이지 자체의 스크립트 오류나 과도한 리소스 사용

첫 점검 항목

  1. 탭·메모리 정리 후 새로고침 — 작업 관리자(Shift+Esc, 브라우저 자체 작업 관리자)로 메모리를 많이 쓰는 탭을 종료한 뒤 Ctrl+Shift+R로 새로고침하세요.
  2. 확장 프로그램 비활성화 확인 — 주소창에 chrome://extensions를 입력해 전체 확장 프로그램을 끈 뒤 재현 여부를 확인하고, 재현되지 않으면 하나씩 다시 켜서 원인을 특정하세요.
  3. 하드웨어 가속 끄고 재현 확인 — chrome://settings/system에서 "가능한 경우 하드웨어 가속 사용"을 끄고 재시작해, 그래픽 드라이버 문제인지 구분하세요.
  4. 브라우저 업데이트 — chrome://settings/help에서 최신 버전인지 확인하고 업데이트 후 재시작하세요.
  5. 새 프로필로 재현 확인 — 새 사용자 프로필을 추가해 같은 사이트에 접속했을 때도 재현되는지 확인하세요.

확인 결과에 따른 다음 단계

  • 하드웨어 가속을 껐을 때 재현되지 않으면 — 그래픽 드라이버 문제이므로 드라이버를 최신 버전으로 업데이트하세요.
  • 확장 프로그램 하나를 끄니 안정되면 — 해당 확장 프로그램을 제거하거나 최신 버전으로 교체하세요.
  • 새 프로필에서는 재현되지 않으면 — 기존 프로필의 캐시나 설정 손상이 원인이므로, 북마크를 내보낸 뒤 프로필을 삭제하고 새로 만드는 것을 고려하세요.

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한을 손대거나 레지스트리 정리 프로그램을 실행하기보다는, 디스크 여유 공간과 네트워크 연결, 관련 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

반복해서 같은 오류가 난다면 Windows Update 이력과 DISM·SFC 결과를 저장하고, 설치 미디어 버전이 지금 쓰는 Windows와 맞는지부터 확인하세요.

시스템 복구나 초기화, 드라이버 삭제처럼 원상복구가 힘든 작업을 시작하기 전에, 중요한 파일은 미리 외장 저장장치나 별도 위치에 백업해 두세요.

자주 묻는 질문

  • 브라우저가 자주 멈추면 다른 브라우저로 바꿔야 하나요? 이 문제(Aw Snap 오류)는 브라우저 자체보다 확장 프로그램이나 캐시 문제인 경우가 많아, 브라우저를 바꾸기 전에 확장 프로그램 정리부터 시도해보세요.
  • 특정 사이트에서만 반복되면요? 브라우저 자체보다 그 사이트의 스크립트나 리소스 사용량 문제일 수 있으니, 다른 사이트에서도 재현되는지 먼저 비교해보세요.
