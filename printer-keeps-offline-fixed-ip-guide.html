홈/가이드/프린터가 자꾸 오프라인이 될 때

📑 목차

    OFFLINE AGAIN

    껐다 켜면 되는데 며칠 뒤 또 오프라인이라면

    네트워크 프린터가 반복해서 오프라인이 되는 가장 흔한 이유는 프린터의 IP 주소가 바뀌는 것입니다. 주소를 고정해 한 번에 끝내는 방법을 정리했습니다.

    "어제까진 됐는데"의 흔한 원인

    무선 프린터는 공유기에 접속할 때마다 IP 주소를 새로 받습니다(DHCP). 공유기를 껐다 켰거나, 정전이 있었거나, 프린터가 오래 절전 상태였다면 같은 프린터가 어제와 다른 주소를 받을 수 있습니다. 그런데 PC는 처음 추가할 때 알았던 옛 주소로 계속 말을 걸기 때문에 프린터는 멀쩡해도 '오프라인'으로 표시됩니다.

    프린터를 껐다 켜거나 다시 추가하면 잠시 해결된 것처럼 보이는 이유도 같습니다. 이때 주소를 다시 맞춰서 되는 것이고, 며칠 뒤 주소가 또 바뀌면 같은 일이 반복됩니다. 이 글은 그 고리를 끊는 방법입니다.

    먼저 진짜 원인이 주소 불일치인지 확인하기

    1. 프린터의 현재 IP를 확인합니다. 프린터 화면의 네트워크 설정 메뉴나 '네트워크 설정 출력' 기능에서 볼 수 있습니다.
    2. 윈도우가 쓰는 IP를 확인합니다. 설정에서 프린터를 선택해 프린터 속성 → 포트 탭을 열면 사용 중인 포트의 주소가 보입니다.
    3. 두 주소가 다르면 원인이 맞습니다. 같다면 이 글이 아니라 프린터 오류 해결 마법사에서 다른 원인을 확인하세요.
    4. PC에서 프린터에 닿는지도 봅니다. 명령 프롬프트에서 아래처럼 입력합니다.
    ping 프린터IP주소
    ping 결과뜻다음
    응답이 온다(시간 ms 표시)PC와 프린터 사이 네트워크는 연결돼 있다포트의 주소가 맞는지, 스풀러·대기열 설정을 점검
    요청 시간이 만료되었습니다주소가 바뀌었거나 프린터가 네트워크에 없다프린터 화면에서 현재 IP를 다시 확인
    대상 호스트에 연결할 수 없습니다PC와 프린터가 다른 네트워크에 있을 수 있다같은 공유기·같은 Wi-Fi인지 확인(게스트 Wi-Fi 주의)

    해결 방법 두 가지, 그리고 어느 쪽이 나은지

    방법 A. 공유기에서 프린터에 같은 주소를 "예약"하기 (권장)

    프린터는 그대로 두고 공유기가 이 프린터에게 항상 같은 주소를 주도록 지정하는 방식입니다. 프린터 설정을 건드리지 않아 가장 안전합니다.

    1. PC에서 명령 프롬프트를 열어 ipconfig를 실행하고 기본 게이트웨이 주소를 봅니다. 이 주소가 공유기 관리 페이지 주소입니다.
    2. 브라우저 주소창에 그 주소를 입력해 공유기 관리 페이지에 로그인합니다. 계정은 공유기 아래쪽 스티커나 설명서에 있는 경우가 많습니다.
    3. 연결된 기기 목록에서 프린터를 찾아 IP 주소 고정(예약) 할당 같은 이름의 메뉴로 현재 주소를 등록합니다. 메뉴 이름은 제조사마다 다릅니다.
    4. 프린터 전원을 껐다 켜서 같은 주소를 다시 받는지 확인합니다.

    방법 B. 프린터 자체에 고정 주소를 입력하기

    프린터 화면의 네트워크 설정에서 IP를 '자동'이 아닌 '수동'으로 바꿔 주소를 직접 적는 방식입니다. 공유기에 접근할 수 없을 때 씁니다. 다만 공유기가 다른 기기에게 나눠 주는 범위와 겹치면 주소가 충돌해서 두 기기가 모두 불안정해질 수 있습니다. 공유기의 자동 할당 범위 바깥의 주소를 쓰고, 이미 쓰는 주소인지 ping으로 먼저 확인하세요.

    고정은 한쪽에서만 하세요

    공유기 예약(A)과 프린터 수동 입력(B)을 둘 다 하면 서로 어긋날 수 있습니다. 하나를 정해서 진행하고, 둘 중 어느 쪽으로 했는지 메모해 두세요.

    윈도우 쪽도 맞춰 두기

    1. 프린터 속성의 포트 탭에서 사용 중인 포트를 선택하고 포트 구성에서 프린터의 고정 주소를 입력합니다.
    2. 포트 이름이 'WSD…'로 시작한다면 이 포트는 주소 대신 장치 검색 방식으로 연결하기 때문에 환경에 따라 오프라인 표시가 반복되는 경우가 있습니다. 이럴 때 표준 TCP/IP 포트를 새로 만들어 프린터 IP를 직접 지정하면 안정되는 경우가 많습니다.
    3. 대기열에 문서가 쌓여 있다면 모두 취소하고 스풀러를 재시작합니다. 방법은 마법사의 대기열 걸림 순서에 있습니다.

    재발 방지 체크리스트

    • 고정하고 나면 프린터 IP와 방법(A/B)을 프린터 옆이나 메모에 적어 둡니다.
    • 공유기를 바꾸거나 초기화하면 예약이 사라집니다. 이후 프린터가 갑자기 오프라인이 되면 이 글의 확인 단계부터 다시 하세요.
    • 프린터를 새로 교체했다면 예전 프린터의 예약을 지우고 새 프린터로 다시 등록합니다.
    • 같은 증상이 고정 후에도 계속되면 주소가 아니라 스풀러·드라이버 문제일 수 있으니 오프라인 가이드의 다른 단계를 확인하세요.

    자주 묻는 질문

    • USB로 연결한 프린터도 IP를 고정해야 하나요? 아닙니다. USB는 주소 개념이 없어서 이 문제와 상관없습니다. USB 프린터가 오프라인이면 케이블·포트, 대기열의 '오프라인으로 프린터 사용' 설정, 스풀러를 확인하세요.
    • 공유기 관리 페이지에 로그인을 못 하겠어요. 공유기 설치 때 비밀번호를 바꿨다면 그 값이 필요합니다. 모르면 공유기를 초기화해야 하는데, 이 경우 인터넷 설정까지 지워지니 통신사 설정을 확인한 뒤에 진행하세요. 어렵다면 방법 B(프린터에 직접 입력)를 쓰는 것도 방법입니다.
    • 집이 아니라 회사에서 같은 증상이 생겼는데요. 사무실은 전산 담당자가 DHCP 범위와 프린터 주소를 관리하는 경우가 많습니다. 임의로 고정하면 충돌할 수 있으니 담당자에게 프린터용 고정 주소 배정을 요청하세요.
