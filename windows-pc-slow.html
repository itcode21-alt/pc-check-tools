속도 저하

컴퓨터·노트북 전반적으로 느려짐 원인과 점검 순서

부팅 이후 평소 사용 중에도 계속 느리게 느껴지는 경우 — 무엇부터 확인해야 할지 구분합니다

컴퓨터가 느려졌다고 느껴질 때는 원인이 하나로 정해져 있지 않습니다. CPU, 메모리, 디스크, 저장공간, 온도 중 어느 쪽이 병목인지에 따라 점검 방법이 완전히 달라지므로, 무작정 포맷하거나 램부터 늘리기 전에 먼저 원인을 구분하는 것이 순서입니다.

가장 빠른 구분 방법은 작업 관리자(Ctrl+Shift+Esc)의 '성능' 탭입니다. CPU, 메모리, 디스크 사용률을 몇 분간 지켜보면서 어느 항목이 평소에도 계속 높게 유지되는지 확인하세요.

부팅할 때만 유독 오래 걸리고 로그인 이후에는 정상이라면, 이 페이지보다 부팅 속도 저하 페이지에서 시작 프로그램 위주로 확인하는 것이 더 정확합니다.

이 가이드가 필요한 상황

  • 웹 서핑처럼 가벼운 작업에서도 버벅임이 느껴진다.
  • 프로그램을 두세 개만 동시에 켜도 전체적으로 느려진다.
  • 예전보다 확실히 느려졌다는 느낌이 몇 주 이상 계속된다.

먼저 확인할 항목

  1. 작업 관리자로 병목 구분 — CPU·메모리·디스크 중 무엇이 원인인지에 따라 이후 점검 방향이 완전히 달라집니다. Ctrl+Shift+Esc로 작업 관리자를 열고 성능 탭에서 몇 분간 각 항목의 사용률을 지켜보세요.
  2. 디스크 사용률 확인 — 디스크가 상시 100%에 가깝다면 백그라운드 작업이나 저장장치 자체 지연이 원인일 가능성이 큽니다. 디스크 사용률이 계속 높게 유지되면 원인별 점검 순서를 확인하세요.
  3. 저장공간 여유 확인 — C드라이브 여유 공간이 부족하면 Windows가 임시 파일을 쓸 공간이 부족해 전반적으로 느려집니다. 여유 공간이 10% 미만이라면 정리를 먼저 진행하세요.
  4. 온도·발열 확인 — 부하가 없는데도 온도가 높게 유지되면 성능이 자동으로 제한(스로틀링)되어 느려질 수 있습니다. 무거운 작업을 하지 않을 때도 팬 소음이나 발열이 심한지 확인하세요.

원인을 더 정확히 나누는 방법

부팅 지연과 사용 중 저하는 다른 문제

부팅 시간만 길고 로그인 이후에는 문제가 없다면 시작 프로그램이 핵심 원인입니다. 반대로 로그인 이후에도 계속 느리다면 상시 실행 중인 프로세스나 하드웨어 자체의 병목을 봐야 합니다.

체감 저하와 실제 병목은 다를 수 있음

"예전보다 느려졌다"는 체감은 실제로는 백그라운드 업데이트, 백신 검사, 클라우드 동기화처럼 일시적인 원인 때문인 경우도 많습니다. 며칠에 걸쳐 반복되는지, 특정 시점에만 나타나는지 구분하세요.

확인 결과에 따른 다음 단계

  • CPU가 상시 높게 유지될 때 — 작업 관리자에서 어떤 프로세스가 CPU를 많이 쓰는지 확인하고, 불필요한 시작 프로그램과 백그라운드 앱을 정리하세요.
  • 디스크가 상시 100%에 가까울 때 — 디스크 사용률 100% 가이드에서 원인별 점검 순서를 확인하세요.
  • 저장공간이 부족할 때 — C드라이브 용량 부족 가이드에서 정리 순서를 확인하세요.
  • 온도가 높게 유지될 때 — 쿨링 상태를 먼저 점검하고, 필요하면 과열 관련 가이드를 참고하세요.

피해야 할 실수

  • 원인을 구분하지 않고 곧바로 포맷·초기화부터 진행하는 것
  • 디스크나 저장공간 문제인데 램부터 늘리는 것
  • 일시적인 업데이트·백신 검사 중 저하를 영구적인 고장으로 오인하는 것

자주 묻는 질문

  • 포맷하면 확실히 빨라지나요? 저장공간 부족이나 불필요한 프로그램 누적이 원인이라면 효과가 있지만, 저장장치 노후화나 하드웨어 자체의 한계가 원인이라면 포맷 후에도 다시 느려질 수 있습니다. 먼저 병목을 구분하는 것이 순서입니다.
  • SSD로 바꾸면 해결되나요? 아직 HDD를 쓰고 있다면 체감 개선이 크지만, 이미 SSD를 쓰는데도 느리다면 디스크가 원인이 아닐 가능성이 높아 다른 항목부터 확인해야 합니다.
