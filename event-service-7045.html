EVENT ID 7045

Service Control Manager 7045 새 서비스 설치 기록 점검

Windows에 새 서비스 또는 커널 드라이버 서비스가 설치되었음을 기록합니다. 정상적인 드라이버·보안 프로그램 설치에도 발생하지만, 모르는 실행 파일 경로가 보이면 보안 확인이 필요합니다.

7045는 새 서비스나 커널 드라이버 서비스가 설치됐다는 감사 기록입니다. 오류가 아니라 무엇이 언제 설치됐는지를 남기는 기록입니다.

드라이버나 보안 프로그램을 설치할 때도 정상적으로 남습니다. 서비스 이름, 서비스 파일 경로, 계정, 시작 유형을 기록하고 설치한 프로그램과 시각이 맞는지, 파일 서명이 있는지 확인하세요. 낯선 경로의 서비스가 예상하지 못한 시각에 생겼을 때만 보안 점검이 필요합니다.

발생 조건

  • 드라이버·프로그램 설치 직후
  • 예상하지 못한 서비스 생성
  • 재부팅·보안 이상과 같은 시각

가능성 높은 원인

  • 정상 프로그램·드라이버 설치
  • Windows Defender 정의 업데이트
  • 관리 도구·업데이트 작업
  • 사용자가 모르는 프로그램의 지속성 확보 시도

점검 순서

  1. 서비스 이름·서비스 파일 경로·계정·시작 유형 기록 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 설치한 프로그램·드라이버와 시각이 일치하는지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 파일 서명과 게시자 확인 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 예상하지 못한 항목이면 네트워크 연결을 보존한 채 보안 검사와 최근 설치 목록을 점검 — 변경 전후로 증상이 달라지는지 비교해보세요.
주의사항

7045는 오류가 아니라 설치 감사 기록입니다. Microsoft·제조사 경로라도 이름이 낯설 수 있으므로 파일 서명과 경로를 함께 확인하세요.

서비스를 바로 삭제하거나 비활성화하기 전에 복구 방법과 설치 주체를 확인하세요.

자주 묻는 질문

  • 7045가 많이 보이는데 문제인가요? 드라이버 업데이트나 프로그램 설치 때마다 남는 기록이라 많은 것 자체는 문제가 아닙니다. 설치한 기억이 없는 서비스인지가 기준입니다.
  • 낯선 서비스를 발견하면 어떻게 하나요? 바로 삭제하거나 끄지 말고 파일 경로, 서명, 설치 시각을 먼저 기록한 뒤 보안 검사를 하세요.
