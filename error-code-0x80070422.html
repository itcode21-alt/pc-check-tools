에러 코드 상세

0x80070422 · 필요한 서비스가 비활성화됨

Microsoft 오류 목록에서 'Windows Update 서비스가 작동을 멈췄거나 실행 중이 아니다'로 설명된 코드입니다. 서비스 상태와 시작 유형부터 확인하세요.

0x80070422는 Windows Update 오류 목록에서 Windows Update 서비스가 멈췄거나 실행 중이 아닌 경우로 설명됩니다. 서비스 시작 유형이 '사용 안 함'으로 바뀌었는지가 첫 확인 항목입니다.

이 코드를 어떻게 해석해야 하나요?

Microsoft의 Windows Update 오류 코드 목록은 0x80070422를 'Windows Update 서비스가 작동을 멈췄거나 실행 중이 아니다'로 설명합니다. 따라서 가장 먼저 services.msc에서 Windows Update 서비스의 상태와 시작 유형을 확인하는 것이 맞습니다. 최적화 프로그램이나 보안 설정이 서비스를 꺼 둔 경우, BITS·암호화 서비스처럼 연관 서비스가 함께 멈춘 경우는 문서 외 일반 점검입니다.

가능성 높은 원인

  • Windows Update(wuauserv) 서비스가 중지되었거나 시작 유형이 '사용 안 함'으로 설정된 경우
  • PC 최적화·튜닝 프로그램이 불필요한 서비스로 오인해 Windows Update 관련 서비스를 꺼버린 경우
  • BITS나 암호화 서비스(cryptsvc) 등 연관 서비스가 함께 중지된 경우
  • 그룹 정책이나 레지스트리로 특정 서비스 시작이 제한된 경우
  • 보안 소프트웨어가 서비스 실행을 차단하는 경우

첫 점검 항목

  1. 공식 문서가 알려 주는 것: Windows Update 서비스가 멈췄거나 실행 중이 아닐 때 나오는 코드입니다. services.msc를 열어 Windows Update 서비스의 상태와 시작 유형을 확인하고, 중지되어 있으면 시작하세요.
  2. 시작 유형이 '사용 안 함'이면 '수동' 또는 '자동'으로 바꾼 뒤 서비스를 시작하세요. 서비스를 켠 뒤 업데이트가 되면 서비스가 꺼져 있었던 것이 원인입니다.
  3. 문서 외 일반 점검: BITS와 암호화 서비스(cryptsvc)도 함께 실행 중인지 확인하세요. 하나라도 멈춰 있으면 원인 후보입니다.
  4. 문서 외 일반 점검: 최근 설치한 최적화·튜닝 프로그램이 서비스 설정을 바꿨는지 확인하고, 필요하면 명령 프롬프트(관리자)에서 sc config wuauserv start=auto로 시작 유형을 설정해 보세요.
  5. 문서 외 일반 점검: Windows Update 문제 해결사를 실행해 서비스 상태를 자동 점검하세요. 해결되지 않으면 그룹 정책이나 보안 프로그램이 서비스 시작을 막는지 봅니다.

확인 결과에 따른 다음 단계

  • 서비스 시작 유형 변경만으로 해결될 때 — 서비스 관리(services.msc)에서 해당 서비스의 시작 유형을 자동으로 유지하세요.
  • sc config 명령으로 해결될 때 — 명령 프롬프트(관리자)에서 설정한 sc config 명령을 기록해 두고, 재부팅 후 서비스가 자동으로 시작되는지 확인하세요.
  • 문제 해결사로도 해결되지 않을 때 — 서비스 관리(services.msc)에서 해당 서비스를 확인하고, 그룹 정책이나 보안 프로그램이 서비스를 막고 있는지 점검하세요.

해결 사례 예시

위 점검 순서로도 해결되지 않았을 때 다른 원인으로 해결될 수 있는 예시입니다. 실제 제보를 그대로 옮긴 것이 아니라 일반적인 사례를 바탕으로 구성한 참고용 예시이며, 환경에 따라 결과가 다를 수 있습니다.

Windows Update 서비스 수동 시작으로 해결

업데이트 창에서 이 오류가 반복됐던 사례에서, 서비스 관리자(services.msc)를 확인하니 Windows Update 서비스가 비활성화된 상태였습니다. 서비스를 수동으로 시작하고 시작 유형을 자동으로 변경하자 업데이트가 정상적으로 진행됐습니다.

포인트: 이 오류는 대부분 필요한 서비스가 중지되어 있어서 발생합니다. services.msc에서 Windows Update, BITS, Cryptographic Services 세 가지 서비스가 실행 중인지 먼저 확인하세요.

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한 변경이나 레지스트리 정리 도구 사용보다 저장 공간, 네트워크, 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

오류가 반복된다면 Windows Update 기록과 DISM·SFC 실행 결과를 남겨두고, 사용 중인 설치 미디어 버전이 현재 Windows와 일치하는지 확인하세요.

이런 조치는 취소가 어려운 경우가 많으므로, 복구·초기화·드라이버 제거를 실행하기 전에 중요한 파일부터 별도 저장장치에 백업해 두시길 권장합니다.

자주 묻는 질문

  • 0x80070422는 Windows Update 서비스와만 관련 있나요? Microsoft 오류 목록은 Windows Update 서비스가 멈췄거나 실행 중이 아니라는 설명을 제공합니다. 같은 코드가 다른 서비스가 꺼져 있을 때 나올 수도 있지만, 이 문서에는 그 경우가 나와 있지 않습니다.
  • 서비스를 켜도 다시 꺼져요. 시작 유형을 바꿔도 다시 꺼진다면 최적화 프로그램, 그룹 정책, 보안 프로그램이 서비스를 제어하고 있을 수 있습니다. 이는 문서 외 일반 점검이니 회사·학교 PC는 관리자에게 확인하세요.
