에러 코드 상세

0x00000119 · VIDEO_SCHEDULER_INTERNAL_ERROR

그래픽 드라이버를 관리하는 비디오 스케줄러가 치명적인 오류를 감지했을 때 나타나는 코드로, GPU 드라이버나 하드웨어 문제와 관련이 깊습니다.

이 코드를 어떻게 해석해야 하나요?

오류 코드는 원인 후보를 좁히는 단서일 뿐, 고장 부품을 확정하는 근거는 아닙니다. 최근에 무엇이 바뀌었는지, 어떤 조건에서 반복되는지, 안전 모드에서도 재현되는지를 함께 기록해두세요.

먼저 기록할 내용: 0x00000119가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

이 코드가 가리키는 것

그래픽 스케줄러는 GPU에 보낼 작업 순서를 관리하는 구성 요소입니다. 이 코드는 그 관리 과정에서 규칙에 어긋난 상태가 감지됐다는 뜻으로, 0x00000117과 마찬가지로 그래픽 드라이버와 GPU 안정성을 중심으로 확인합니다.

첫 점검 항목

  1. 그래픽 드라이버를 완전 제거 후 재설치 — DDU로 안전 모드에서 기존 드라이버를 완전히 제거한 뒤 제조사 최신 버전을 설치합니다. 최신 버전에서 재현되면 한두 단계 이전의 안정 버전으로 내려 보는 것도 방법입니다.
  2. GPU 오버클럭·언더볼팅 되돌리기 — 오버클럭은 물론 언더볼팅 설정도 불안정의 원인이 될 수 있습니다. 유틸리티 설정을 모두 기본값으로 돌리고 재현 여부를 확인하세요.
  3. 특정 게임·프로그램에서만 나는지 구분 — 한 가지 프로그램에서만 발생한다면 그 프로그램의 그래픽 옵션(레이 트레이싱, 프레임 생성 등)을 낮춰 봅니다. 여러 프로그램에서 고르게 발생한다면 드라이버나 하드웨어 쪽입니다.
  4. 다른 그래픽 출력으로 교차 확인 — 내장 그래픽이 있는 CPU라면 그래픽카드를 빼고 내장 출력으로 사용해 봅니다. 내장에서 문제가 없다면 그래픽카드 쪽으로 범위가 좁혀집니다.

확인 결과에 따른 다음 단계

  • 드라이버 재설치로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • 오버클럭·언더볼팅 해제로 해결될 때 — 재적용하지 말고 기본값을 유지하세요.
  • 내장 그래픽에서는 정상일 때 — 그래픽카드 자체의 결함 가능성이 있으므로 다른 시스템에서 테스트해보세요.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

코드가 매번 동일하게 반복된다면 이벤트 로그와 장치 상태를 기록해두고, 코드가 바뀐다면 메모리·전원·온도처럼 시스템 전체의 안정성을 먼저 살펴보세요.

이런 조치는 취소가 어려운 경우가 많으므로, 복구·초기화·드라이버 제거를 실행하기 전에 중요한 파일부터 별도 저장장치에 백업해 두시길 권장합니다.

자주 묻는 질문

  • 블루스크린 코드가 한 번 떴는데 계속 지켜봐야 하나요? 이 문제(0x00000119)가 한 번만 발생했다면 즉시 부품을 교체하기보다 재현 여부와 최근 변경 사항을 먼저 기록해두는 것으로 충분합니다. 반복된다면 그때 하드웨어 점검 범위를 넓히세요.
  • 덤프 파일은 어디서 확인하나요? C:\Windows\Minidump 폴더에 저장되며, BlueScreenView 같은 도구로 열어 정지 코드와 관련 드라이버를 확인할 수 있습니다.
  • 노트북에서도 이 오류가 자주 나나요? 노트북은 하이브리드 그래픽(내장+외장 전환) 드라이버 충돌로도 발생할 수 있으니 그래픽 드라이버 제어판에서 전환 설정을 확인해보세요.
