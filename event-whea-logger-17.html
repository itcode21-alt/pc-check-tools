EVENT ID 17

WHEA-Logger 17 PCIe 수정된 오류 점검 근거 부족

PCIe 계열 하드웨어 오류가 수정되어 시스템이 계속 실행된 기록입니다.

17은 PCIe 계열 하드웨어 오류가 발생했지만 자체적으로 수정되어 시스템이 계속 실행됐다는 기록입니다. 수정됐다고 안심하기보다 반복 횟수가 늘어나는지를 지켜봐야 합니다.

이 기록이 뜨는 시점에 온도나 부하가 유난히 높았는지 비교해보면, 냉각 문제인지 장치 자체의 노후화인지 힌트를 얻을 수 있습니다.

발생 조건

  • GPU·NVMe 부하 중
  • 절전 복귀 뒤

가능성 높은 원인

  • PCIe 링크 불안정
  • 장치 펌웨어·드라이버
  • 오버클럭 또는 전원 관리

수정된 오류와 치명적 오류의 차이

17은 PCIe 구간에서 오류가 발생했지만 정정되어 시스템이 계속 동작한 기록입니다. 즉 지금 당장 고장 난 상태는 아닙니다. 다만 정정이 반복된다는 것은 링크가 불안정하다는 신호입니다.

기록에 남는 버스·장치·기능 번호(예: 0:1:0)를 장치 관리자의 장치 속성 → 자세히 → 위치 정보와 대조하면 어느 슬롯의 장치인지 특정할 수 있습니다.

점검 순서

  1. 장치 위치 특정 — 기록의 버스·장치·기능 번호를 장치 관리자 → 장치 속성 → 자세히 → 위치 정보와 대조해 어느 슬롯의 장치인지 확인합니다. 보통 그래픽카드나 NVMe입니다.
  2. 물리적 장착 상태 확인 — 전원을 끄고 해당 장치를 다시 장착합니다. 그래픽카드는 슬롯 걸쇠와 보조전원을, NVMe는 나사와 슬롯 삽입을 확인하세요. PCIe 링크 불안정은 접촉 문제로도 생깁니다.
  3. BIOS와 장치 펌웨어 갱신 — 메인보드 BIOS, 칩셋 드라이버, NVMe 펌웨어를 최신으로 올립니다. PCIe 링크 안정성은 펌웨어 수정으로 개선되는 경우가 많습니다.
  4. 기본 클럭에서 반복 여부 확인 — PCIe 속도를 수동 지정했거나 오버클럭 중이면 기본값으로 되돌립니다. 필요하면 BIOS에서 PCIe 세대를 한 단계 낮춰(예: Gen4 → Gen3) 안정되는지 확인합니다.
주의사항

수정된 오류라도 반복 횟수가 늘면 점검이 필요합니다.

관련 코드·가이드

0x00000124 오류 코드 확인하기게임 중 재부팅 가이드

자주 묻는 질문

  • 17은 수정된 오류라던데 무시해도 되나요? 수정되어 시스템이 계속 실행됐다는 뜻이지만, 반복 횟수가 늘어난다면 PCIe 장치나 드라이버 문제가 진행 중일 수 있으므로 지켜봐야 합니다.
  • GPU와 NVMe 중 어느 쪽부터 확인해야 하나요? 이벤트 세부 정보의 버스 위치(Bus)와 장치 ID를 확인하면 어떤 장치와 연관됐는지 특정할 수 있습니다.
