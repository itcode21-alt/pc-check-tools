EVENT ID 51

Disk 이벤트 51 페이징 지연 점검 확인 필요

페이징 작업 중 저장장치 입출력 오류가 발생했음을 나타냅니다.

51은 페이징 작업 중 저장장치 입출력이 지연됐다는 경고 기록입니다. 심각도가 오류(7)보다 낮게 분류되지만, 반복 빈도가 늘어난다면 같은 저장장치 문제의 초기 신호일 수 있습니다.

가벼운 작업에서는 거의 나타나지 않다가 대용량 파일 작업이나 여러 프로그램을 동시에 켰을 때만 나타난다면, 저장장치 자체보다 시스템 자원(RAM) 부족이 배경일 수 있습니다.

발생 조건

  • 대용량 작업 중 멈춤
  • 페이지 파일 접근 중 지연

가능성 높은 원인

  • 디스크 응답 지연
  • 케이블·전원 불안정
  • 저장장치 상태 저하

이 기록이 가리키는 범위

페이징은 Windows가 메모리와 디스크 사이에서 데이터를 옮기는 작업입니다. 그 과정에서 오류가 났다는 것은 저장장치가 요청에 제때 정상 응답하지 못했다는 뜻입니다.

  • 기록에 나오는 \Device\Harddisk0\DR0 형태의 이름에서 숫자가 몇 번 디스크인지 알려줍니다. 디스크 관리(diskmgmt.msc)의 디스크 번호와 대조하면 어느 장치인지 특정됩니다.
  • 한 번만 기록됐다면 일시적 지연일 수 있지만, 같은 디스크에서 반복된다면 백업을 먼저 확보해야 합니다.

점검 순서

  1. 기록에서 디스크 번호 특정 — 설명의 \Device\HarddiskN\DR에서 N을 확인하고 diskmgmt.msc의 디스크 번호와 대조합니다. 여러 저장장치를 쓰는 PC에서 어느 장치인지 먼저 확정해야 이후 점검이 헛돌지 않습니다.
  2. 중요한 파일부터 백업 — 저장장치 응답 이상이 확인된 상태이므로 검사보다 백업이 먼저입니다. 다른 물리 저장장치나 클라우드로 옮겨 두세요.
  3. SMART 상태 확인 — CrystalDiskInfo 등으로 재할당 섹터·대기 중 섹터·복구 불가 섹터 수치를 봅니다. 이 값들이 0이 아니고 늘어나는 중이면 교체를 검토해야 합니다.
  4. 연결 상태 점검 — SATA 드라이브는 케이블을 다른 포트와 케이블로 바꿔 시험하고, M.2 NVMe는 나사를 풀어 다시 완전히 삽입합니다. 케이블 불량이 원인인 경우가 생각보다 흔합니다.
주의사항

반복될수록 데이터 손실 위험이 커질 수 있습니다.

관련 코드·가이드

자주 묻는 질문

  • 51은 이벤트 7보다 덜 심각한 건가요? 경고(warning) 수준으로 분류되지만, 반복되면 7과 마찬가지로 저장장치 상태 저하의 초기 신호일 수 있습니다. 등급보다 반복 빈도를 우선 확인하세요.
  • 메모리 사용량이 높을 때만 뜨는 이유는 무엇인가요? 페이지 파일에 접근하는 순간 디스크 응답이 느리면 기록되므로, 메모리가 부족해 페이징이 잦아지는 상황에서 더 자주 나타날 수 있습니다.
