홈/가이드/절전·복귀 이벤트 1·42

POWER EVENTS

절전에 들어간 기록과 깨어난 원인을 나눠 보세요

Kernel-Power 42는 절전 진입 기록이고, Power-Troubleshooter 1은 절전 해제 원인을 설명하는 기록입니다. 두 이벤트를 함께 보면 PC가 저절로 깨어난 것인지, 사용자가 직접 조작한 것인지 구분할 수 있습니다.

이 두 이벤트는 전원 문제를 바로 확정하는 코드가 아닙니다. 42의 절전 시각과 1의 Wake Source, 실제 마우스·키보드 사용 여부를 비교한 뒤에야 절전 설정이나 주변 장치를 점검할 수 있습니다.

기록에서 확인할 값

  • Kernel-Power 42: 절전에 들어간 시각과 절전 원인을 확인합니다.
  • Power-Troubleshooter 1: Wake Source에 표시된 장치·예약 작업을 기록합니다.
  • 발생 간격: 매번 같은 장치가 깨우는지, 특정 시간대에만 반복되는지 비교합니다.

점검 순서

  1. 실제 사용 여부 비교 — 잠자리에 든 시간과 1의 Wake Source를 비교해 정상 입력인지 확인합니다.
  2. powercfg 결과 확인 — 관리자 명령 프롬프트에서 powercfg /lastwake와 powercfg /waketimers를 실행해 최근 깨움 장치와 예약 작업을 확인합니다.
  3. 장치 깨우기 권한 점검 — 장치 관리자에서 네트워크 어댑터·마우스·키보드의 전원 관리 항목을 확인하고, 필요할 때만 깨우기 권한을 조정합니다.
  4. 절전 복귀 실패 비교 — 화면이 검게 남거나 재부팅된다면 Display, WHEA, Kernel-Power 41을 같은 시각에 함께 확인합니다.
  5. BIOS·드라이버 확인 — 절전 관련 문제가 업데이트 뒤 시작됐다면 칩셋·그래픽·네트워크 드라이버와 BIOS 변경 시점을 비교합니다.
주의사항

이벤트 1이나 42 하나만으로 메인보드·파워 고장을 확정하지 마세요. 절전에서 깨어난 기록과 복귀 실패 기록을 분리하면 불필요한 부품 교체를 줄일 수 있습니다.

자주 묻는 질문

  • Power-Troubleshooter 1이 있으면 PC가 저절로 켜진 건가요? 1은 절전에서 깨어난 원인을 기록한 이벤트입니다. 마우스·키보드·네트워크·예약 작업이 원인일 수 있으므로 Wake Source 값을 확인해야 합니다.
  • Kernel-Power 42가 전원 고장을 뜻하나요? 42는 Windows가 절전에 들어갔다는 기록입니다. 전원 고장으로 단정하지 말고 실제 절전 시각과 복귀 시각, 주변 장치 이벤트를 함께 비교하세요.
