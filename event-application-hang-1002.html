Application Hang 1002

홈진단가이드PC 추천

EVENT ID 1002

앱이 종료된 것인지 멈춘 것인지 구분하세요

Application Hang 1002는 프로그램이 응답하지 않는 상태가 일정 시간 이어졌을 때 기록됩니다. 앱이 예외로 종료되는 Application Error 1000과는 확인할 값이 다릅니다.

먼저 기록할 정보

멈춘 앱 이름, Hang 유형, 멈춤이 시작된 작업과 회복 여부를 적습니다. 특정 앱에서만 발생하면 앱 설정·플러그인 범위를, 여러 앱에서 발생하면 그래픽·저장장치·메모리 범위를 비교합니다.

점검 순서

  1. 오버레이, 모니터링 도구, 플러그인을 끄고 같은 작업을 재현합니다.
  2. 작업 관리자에서 CPU·메모리·디스크 사용률이 멈춤 시점에 치솟는지 확인합니다.
  3. 게임이나 그래픽 앱이면 Display 4101과 그래픽 드라이버 버전을 비교합니다.
  4. 파일을 여는 앱이면 Disk 7·129·153과 저장장치 상태를 함께 확인합니다.
  5. 앱 복구 후에도 여러 프로그램이 멈추면 메모리 검사와 클린 부팅으로 범위를 넓힙니다.
판단 기준

한 앱에서만 반복되는 1002와 여러 앱이 같은 시간에 멈추는 1002는 점검 방향이 다릅니다.
