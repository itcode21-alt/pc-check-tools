EVENT ID 1001

DHCP-Client 이벤트 1001 IP 주소 임대 실패 점검

DHCP 클라이언트가 네트워크에서 IP 주소를 임대받거나 갱신하지 못했음을 기록합니다. 인터넷이 안 된다는 결과만으로 DNS 문제라고 단정하지 말고 IP·게이트웨이 할당부터 확인해야 합니다.

1001은 DHCP 클라이언트가 IP 주소를 새로 받거나 갱신하지 못했다는 기록입니다. 이 기록이 있으면 DNS보다 먼저 IP 주소와 기본 게이트웨이가 정상적으로 할당됐는지부터 봐야 합니다.

169.254.x.x 주소는 DHCP 응답을 받지 못했을 때 Windows가 임시로 붙이는 자동 사설 IP 주소입니다. 같은 공유기에서 다른 기기는 IP를 받는지 비교하면 PC 쪽 문제인지 공유기·회선 쪽 문제인지 빠르게 갈립니다.

발생 조건

  • 부팅 후 인터넷 연결 안 됨
  • Wi-Fi·유선 전환 뒤 IP가 169.254로 표시
  • 절전 복귀 후 네트워크 끊김

가능성 높은 원인

  • 공유기·DHCP 서버 응답 실패
  • 랜 케이블·무선 링크 불안정
  • 네트워크 어댑터 드라이버·절전 설정
  • VPN·가상 네트워크 어댑터 충돌

점검 순서

  1. ipconfig /all에서 IPv4, 기본 게이트웨이, DHCP 서버 주소 확인 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 같은 공유기의 다른 기기도 IP를 받는지 비교 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 어댑터를 껐다 켜고 ipconfig /release·ipconfig /renew 실행 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 다른 케이블·포트와 최신 네트워크 드라이버로 교차 확인 — 변경 전후로 증상이 달라지는지 비교해보세요.
주의사항

169.254.x.x 주소가 보이면 DNS를 바꾸기 전에 DHCP·케이블·공유기부터 확인하세요.

자주 묻는 질문

  • 169.254로 시작하는 IP가 나오면 무슨 뜻인가요? DHCP 서버에서 주소를 받지 못해 Windows가 임시 주소를 붙인 상태입니다. 이 주소로는 인터넷이 되지 않으니 DNS를 바꾸기 전에 케이블, 공유기, 어댑터부터 확인하세요.
  • ipconfig /release와 /renew는 안전한가요? 연결을 잠깐 끊었다가 주소를 새로 받는 명령이라 일반적으로 안전합니다. 원격으로 접속 중이면 연결이 끊길 수 있으니 PC 앞에서 실행하세요.
