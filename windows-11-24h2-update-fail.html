업데이트

Windows 11 24H2 업데이트 설치 실패 원인과 점검 순서

Windows 11 24H2 기능 업데이트가 설치되지 않고 오류 코드와 함께 실패하는 경우

Windows 11 24H2는 매달 나오는 일반 누적 업데이트가 아니라 버전 자체를 올리는 대규모 기능 업데이트라, 설치에 필요한 조건이 훨씬 까다롭습니다. 다운로드까지는 되는데 설치 단계에서 되돌아가거나, 아예 시작 화면에서 "이 PC는 아직 준비되지 않았습니다" 같은 문구와 함께 막히는 경우가 많습니다.

가장 흔한 오류 코드는 0xc1900201(시스템 요구사항 미충족)과 0x80240069(설치 실패)입니다. 0xc1900201은 대부분 여유 저장공간 부족이나 TPM 2.0·보안 부팅 같은 하드웨어 조건이 원인이고, 0x80240069는 업데이트 구성 요소 손상이나 외부 장치 간섭으로 발생하는 경우가 많습니다.

일반 월간 업데이트가 반복 실패하는 것과는 원인이 다르므로, 이 페이지는 24H2처럼 버전을 올리는 대규모 업데이트에 특화된 점검 순서를 다룹니다. 매달 나오는 누적 업데이트가 반복 실패한다면 업데이트 반복 실패 가이드를 먼저 확인하세요.

이 가이드가 필요한 상황

  • 설치 진행률이 어느 지점에서 항상 되돌아간다.
  • "이 PC는 아직 Windows 11, 버전 24H2를 사용할 준비가 되지 않았습니다" 문구가 뜬다.
  • 0xc1900201 또는 0x80240069 코드가 표시된다.

먼저 확인할 항목

  1. 여유 저장공간 확보 — 기능 업데이트는 이전 버전을 임시로 함께 보관하기 때문에 일반 업데이트보다 훨씬 많은 여유 공간이 필요합니다. 설정 → 시스템 → 저장공간에서 C드라이브 여유 공간을 확인하고, 최소 20~30GB 이상을 확보한 뒤 다시 시도하세요.
  2. TPM 2.0·보안 부팅 상태 확인 — 24H2도 Windows 11의 하드웨어 요구사항을 그대로 따르므로, TPM이나 보안 부팅이 꺼져 있으면 0xc1900201로 막힙니다. tpm.msc를 실행해 TPM 버전이 2.0인지 확인하고, BIOS/UEFI에서 보안 부팅(Secure Boot)과 TPM(펌웨어 TPM 포함)이 켜져 있는지 확인하세요.
  3. 외장 장치 모두 분리 — 프린터, 외장 하드, 일부 USB 장치가 설치 도중 드라이버 충돌을 일으켜 0x80240069로 이어지는 경우가 보고됩니다. USB로 연결된 프린터·외장 저장장치·도킹스테이션을 모두 뽑은 뒤 다시 시도하세요.
  4. 업데이트 문제 해결사 실행 — 구성 요소 손상은 수동으로 하나씩 찾기보다 자동 진단 도구가 더 빠르게 잡아내는 경우가 많습니다. 설정 → 시스템 → 문제 해결 → 기타 문제 해결사에서 'Windows 업데이트'를 실행하세요.

원인을 더 정확히 나누는 방법

0xc1900201과 0x80240069는 원인이 다릅니다

0xc1900201은 설치를 시작하기 전 '자격 검사'에서 걸리는 코드로 저장공간·TPM·보안 부팅 같은 하드웨어·용량 조건 문제입니다. 0x80240069는 실제 설치가 진행되다 실패하는 코드로, 업데이트 구성 요소 손상이나 외부 장치 간섭 쪽을 먼저 봐야 합니다.

설치 미디어로 직접 올리는 방법도 있습니다

Windows Update로 계속 실패한다면, Microsoft 공식 설치 관리자나 미디어 생성 도구로 24H2를 직접 설치하는 방법이 있습니다. 이 경우 Windows Update 경로의 일부 검사를 우회하지만, 시스템 최소 요구사항(TPM 2.0 등) 자체는 여전히 충족해야 합니다.

확인 결과에 따른 다음 단계

  • 0xc1900201이 뜰 때 — 저장공간과 TPM·보안 부팅부터 확인하세요. 대부분 이 둘 중 하나가 원인입니다.
  • 0x80240069가 뜰 때 — 외장 장치를 분리하고 업데이트 문제 해결사를 실행한 뒤 재시도하세요. 그래도 안 되면 설치 미디어로 직접 업그레이드하는 방법을 검토하세요.

피해야 할 실수

  • 저장공간 확인 없이 재시도만 반복하는 것
  • TPM·보안 부팅을 끈 채로 레지스트리 우회 방법부터 찾는 것 — 요구사항을 우회해 설치해도 이후 다른 업데이트에서 계속 문제가 생길 수 있습니다

자주 묻는 질문

  • 24H2 업데이트를 꼭 지금 해야 하나요? 당장 필수는 아닙니다. 다만 이전 버전은 지원 종료일이 정해져 있으므로, 지금 실패한다고 무한정 미루기보다 원인(저장공간·TPM)을 먼저 해결해두는 것이 안전합니다.
  • TPM 2.0이 없는 PC인데 24H2를 설치할 방법이 있나요? 레지스트리 우회로 강제 설치하는 방법이 커뮤니티에 공유되어 있지만, Microsoft가 공식 지원하지 않는 방식이라 이후 업데이트나 보안 기능에서 문제가 생길 수 있습니다. 신중하게 판단하세요.
  • 설치 미디어로 업그레이드하면 데이터가 지워지나요? '업그레이드' 방식(기존 Windows 실행 중 설치 관리자·미디어 생성 도구를 실행)을 선택하면 파일과 앱을 유지한 채 진행됩니다. 다만 예기치 못한 상황에 대비해 중요한 파일은 미리 백업해두세요. (참고: Microsoft Learn: Windows 11 24H2 알려진·해결된 문제)
