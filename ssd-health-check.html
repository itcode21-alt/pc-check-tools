DISK HEALTH CHECK

SSD·디스크 건강 판정

SSD가 갑자기 나빠져 데이터를 꺼내지 못하는 일이 적지 않습니다. 저장장치의 상태·수명 소모율·오류 기록·온도와 드라이브 여유 공간을 한 번에 읽어 지금 백업과 교체가 필요한지 판정합니다. 계산은 이 페이지 안에서만 이루어지고 서버로 보내지 않습니다.

English version

먼저 결과 화면이 어떻게 보이는지 궁금하다면 예시(가상의 값)로 미리 볼 수 있습니다.

방법 1 · 점검 파일을 실행하면 끝 (가장 쉬움)

  1. 아래 버튼으로 점검 파일을 내려받습니다.
  2. 내려받은 파일을 더블클릭하고, 권한 확인 창이 뜨면 "예"를 누릅니다. 관리자 권한이 있어야 수명·온도·오류 기록까지 읽힙니다.
  3. 잠시 뒤 브라우저에 결과가 자동으로 표시됩니다. 복사·붙여넣기는 필요 없습니다.
점검 파일 내려받기

최근 30일의 저장장치 관련 이벤트 기록(오류 종류별 횟수만)도 함께 읽습니다. 읽기 전용이라 설정을 바꾸거나 파일을 지우지 않고, 결과는 이 PC의 브라우저로만 넘어갑니다(주소의 # 뒤 값은 서버로 전송되지 않습니다). 권한 확인 창에서 "아니요"를 눌러도 디스크 상태와 여유 공간은 확인됩니다.

내려받을 때 경고가 나오나요?

브라우저가 "이 파일은 위험할 수 있습니다"라고 알리면 유지를 선택하세요. 실행할 때 "게시자를 확인할 수 없습니다" 또는 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행(또는 실행)을 누르면 됩니다. 인터넷에서 받은 실행 파일에는 항상 나오는 경고입니다. 걱정되면 아래에서 내용을 먼저 확인하거나, 방법 2를 쓰세요.

결과 붙여넣기

방법 2의 결과나 수집 스크립트의 hardware.json이 있을 때 사용합니다. 붙여넣으면 바로 판정합니다. 로그 수집 스크립트 사용법

CrystalDiskInfo 값을 직접 입력해 판정하기 (선택)

CrystalDiskInfo를 이미 쓰고 있다면, 화면에서 보이는 값을 그대로 입력하세요. 점검 파일이 읽지 못하는 재할당·대기 섹터, NVMe 예비 영역 같은 항목까지 판정에 반영합니다. 모르는 칸은 비워 두면 됩니다. CrystalDiskInfo 화면 보는 법

이렇게 판정합니다

  • 위험 — Windows가 디스크 상태를 Healthy로 보지 않거나, 고장 예측(Predictive Failure), 복구되지 않은 읽기·쓰기 오류, 수명 소모 90% 이상 중 하나라도 있을 때. CrystalDiskInfo 값을 넣었다면 상태 '나쁨', 대기·복구 불가능 섹터, 재할당 섹터 100개 이상, NVMe 치명적 경고·예비 영역 기준 이하·무결성 오류도 위험입니다.
  • 주의 — 수명 소모 70~89%, SSD 70℃·HDD 55℃ 이상, 동작 상태가 OK가 아닐 때, 재할당 섹터가 있을 때, NVMe 예비 영역이 30% 이하일 때.
  • 이벤트 로그 신호(최근 30일, 점검 파일·방법 2에서 함께 읽음) — 불량 블록·하드웨어 입출력 오류(Disk 7·154)가 1회 이상이면 주의, 3회 이상이면 위험. 고장 예측 경고(Disk 52)는 1회라도 위험. 컨트롤러 오류·재설정(Disk 9·11, stornvme 11·129, storahci 129)은 3회 이상이면 주의, 데이터 오류와 함께 나타나면 위험. 파일 시스템 손상(Ntfs 50·55·57·140)은 1회 이상 주의, 3회 이상이거나 하드웨어 오류와 함께면 위험. 입출력 재시도(Disk 51·153)는 5회 이상, 디스크 연결 끊김(Disk 157)은 3회 이상이면 주의입니다. 이벤트는 간접 신호라 케이블·드라이버 문제도 반영하며, 디스크 번호를 알 수 있는 Disk 기록은 해당 디스크 결과에 붙이고 나머지는 별도로 표시합니다.
  • 연결되어 있지 않은 디스크 — Windows가 통신하지 못하는 디스크, 이벤트 로그에는 기록이 있지만 지금 목록에 없는 디스크, 지난 점검에는 있었지만 지금 보이지 않는 디스크를 따로 표시합니다. 사라진 디스크가 내장(SATA·NVMe 등)이면 주의, 외장 USB면 안내만 합니다(이전 점검 기록을 저장하는 경우에 한함).
  • 확인 불가 — 수명·온도·오류 값을 읽지 못했을 때. 이 경우 관리자 권한으로 다시 실행해야 하며, 값 없이 양호로 판단하지 않습니다.
  • 여유 공간 부족 — 드라이브 여유 공간이 10% 미만(5% 미만은 매우 부족)일 때. 디스크 건강 판정과는 별개로 표시합니다. 디스크가 멀쩡해도 공간이 부족하면 속도 저하·저장 실패가 생길 수 있어 정리가 필요하지만, 고장을 뜻하지는 않습니다.
  • 참고 정보(등급을 바꾸지 않음) — 사용 시간이 길 때(약 4년 이상 상시 사용 수준), 최대 지연 값이 클 때, 교체 시점 추정(지금까지의 수명 소모 속도가 이어진다고 가정한 대략적인 값), 지난 점검과의 비교(수명 소모가 30일에 3%p 이상 늘었거나 오류가 늘었다면 그때는 주의·위험으로 올립니다).

SMART 값이 정상이어도 SSD는 컨트롤러·펌웨어 문제로 예고 없이 고장 날 수 있습니다. 그래서 이 판정은 "고장 날 때까지 안전하다"는 보증이 아니라, 지금 백업을 서둘러야 하는지 알려 주는 참고 도구입니다. 중요한 자료는 항상 다른 저장장치에 따로 두세요.

SSD SMART·건강 상태 확인 방법 SSD 수명(TBW) 계산기 백업 저장공간 계산기 SSD 교체·추가 설치 가이드 Disk 7 · 불량 블록 Disk 153 · 입출력 재시도

이 도구의 사용 방법은 운영자의 네이버 블로그에도 사진과 함께 정리해 두었습니다. SSD가 곧 고장 날지 미리 확인하는 방법, 건강 상태·수명·오류 기록으로 백업 시점 판단하기 (Windows 11)

이 도구로 알 수 있는 것과 알 수 없는 것

알 수 있는 것

  • Windows가 보고하는 디스크 상태(Healthy 여부)와 동작 상태, 연결이 끊긴 디스크
  • 수명 소모율, 온도, 사용 시간, 복구되지 않은 읽기·쓰기 오류(장치가 값을 알려 주는 경우)
  • 드라이브별 여유 공간과 어느 디스크에 속한 드라이브인지
  • 최근 30일의 컨트롤러 재설정·불량 블록·파일 시스템 손상 같은 저장장치 관련 이벤트 기록
  • 지난 점검과 비교한 변화(수명 소모 증가, 오류 증가, 사라진 디스크)와 대략적인 교체 시점

알 수 없는 것

  • 컨트롤러·펌웨어의 갑작스러운 고장 — 수치가 정상이어도 예고 없이 일어날 수 있습니다.
  • 장치가 상세 값을 Windows에 알려 주지 않는 경우의 수명·오류 상태 — 이때는 '확인 불가'로 표시하고 양호라고 말하지 않습니다.
  • 데이터를 복구할 수 있는지, 하드웨어 고장이 확정됐는지 — 이 판정은 참고용입니다.

자주 묻는 질문

  • SSD 상태를 확인하는 가장 쉬운 방법은 무엇인가요? 이 페이지의 점검 파일을 내려받아 더블클릭하면 됩니다. 권한 확인 창에서 '예'를 누르면 디스크 상태·수명 소모율·오류 기록·온도·여유 공간과 최근 30일의 저장장치 관련 이벤트를 읽어 결과를 바로 보여 줍니다. 파일을 쓰고 싶지 않다면 관리자 PowerShell에 명령을 붙여넣거나, 이미 CrystalDiskInfo를 쓰고 있다면 그 값을 직접 입력해도 됩니다.
  • 판정이 '양호'인데도 SSD가 갑자기 고장 날 수 있나요? 네, 그럴 수 있습니다. 이 판정은 Windows와 디스크가 보고하는 수치와 이벤트 기록에 근거하므로, 컨트롤러나 펌웨어 문제로 예고 없이 인식이 끊기는 고장은 미리 알려 주지 못할 수 있습니다. 판정 결과와 상관없이 중요한 자료는 다른 저장장치에 따로 백업해 두세요.
  • SSD가 갑자기 인식되지 않으면 어떻게 하나요? 전원을 껐다 켜는 시도를 반복하지 말고, 디스크 관리에서 '초기화'나 '포맷'을 묻는 창이 나오면 누르지 마세요. 케이블·슬롯을 다시 꽂거나 다른 슬롯·USB 케이스·다른 PC에 연결해 보고, BIOS에서 보이는지 확인하세요. 그래도 보이지 않거나 자료가 중요하다면 직접 시도를 멈추고 상담을 받는 것이 안전합니다.
  • 수명 소모가 몇 %가 되면 교체해야 하나요? 이 도구는 수명 소모 70% 이상을 '주의', 90% 이상을 '위험'으로 봅니다. 다만 제조사가 보증하는 쓰기량(TBW)과 사용 패턴에 따라 실제 여유는 다를 수 있으니, 총 쓰기량을 아는 경우 SSD 수명(TBW) 계산기로 함께 확인하세요. 수명 소모가 높아도 바로 고장 나는 것은 아니지만 백업과 교체 계획은 미리 세워 두는 편이 안전합니다.
  • 드라이브 여유 공간이 부족하면 SSD가 고장 난 건가요? 아닙니다. 여유 공간 부족은 디스크 고장과는 별개의 문제입니다. 공간이 거의 가득 차면 속도가 떨어지고 저장·업데이트가 실패할 수 있어 정리가 필요하지만, 디스크 상태 판정에는 영향을 주지 않도록 따로 표시합니다.
  • 점검 파일은 안전한가요? 내 정보가 서버로 전송되나요? 점검 파일은 읽기 전용으로 설정을 바꾸거나 파일을 지우지 않습니다. 내용은 페이지에서 미리 볼 수 있고, 결과는 이 PC의 브라우저로만 넘어가며 판정도 브라우저 안에서 계산합니다(서버로 전송하지 않습니다). 이전 점검과 비교하는 기능을 켜면 모델명과 수치만 이 브라우저에 저장되고, 언제든 끄거나 지울 수 있습니다.
