에러 코드 상세

0x0000009F · DRIVER_POWER_STATE_FAILURE

절전 모드 진입이나 복귀, 혹은 종료 과정에서 특정 드라이버가 전원 상태 전환 요청에 제때 응답하지 못할 때 나타나는 코드입니다.

이 코드를 어떻게 해석해야 하나요?

드라이버 계열 오류는 커널에서 장치가 잘못된 메모리 또는 전원 상태를 사용했을 가능성을 보여줍니다. 최근 추가한 장치와 업데이트 시점을 기준으로 범위를 줄이는 것이 효율적입니다.

먼저 기록할 내용: 0x0000009F가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 네트워크 어댑터나 USB 장치의 절전 관련 드라이버가 응답하지 않는 경우
  • 전원 관리 설정이 하드웨어와 맞지 않게 구성된 경우
  • 그래픽 드라이버가 절전 복귀 시 초기화에 실패하는 경우
  • 최근 연결한 외장 장치가 절전 신호를 제대로 처리하지 못하는 경우
  • 바이오스 전원 관리 설정과 윈도우 전원 옵션이 충돌하는 경우

첫 점검 항목

  1. 절전 모드에서 복귀한 직후에만 증상이 나타나는지 확인하세요.
  2. 장치 관리자에서 네트워크 어댑터의 전원 관리 탭에 있는 '전원 절약을 위해 이 장치를 끌 수 있음' 옵션을 해제해 보세요.
  3. 그래픽 드라이버를 최신 버전으로 업데이트하세요.
  4. 최근 연결한 USB 장치를 분리한 뒤 절전 모드 진입/복귀를 테스트하세요.
  5. 전원 옵션에서 절전 모드 대신 최대 절전 모드나 화면 끄기만 사용하도록 임시로 바꿔 재현 여부를 확인하세요.

확인 결과에 따른 다음 단계

  • 특정 USB 장치를 분리했을 때 재현되지 않을 때 — 그 장치의 드라이버를 업데이트하거나 전원 관리 옵션을 해제하세요.
  • 네트워크 어댑터 전원 관리 옵션을 껐을 때 해결될 때 — 그 설정을 그대로 유지하세요.
  • 그래픽 드라이버 업데이트 후에도 반복될 때 — powercfg /a로 최신 대기 모드(Modern Standby) 지원 여부를 확인하고, 해당된다면 관련 가이드를 참고하세요.

데이터와 시스템을 보호하는 주의사항

모든 드라이버를 한꺼번에 갱신하면 어떤 변경이 영향을 줬는지 확인하기 어려우므로 한 항목씩 변경하세요.

앞 단계로 해결되지 않을 때

안전 모드에서 멈추지 않는다면 최근 드라이버와 장치를 하나씩 되돌리고 장치 관리자와 같은 시각의 이벤트 원본을 함께 확인하세요.

이런 조치는 취소가 어려운 경우가 많으므로, 복구·초기화·드라이버 제거를 실행하기 전에 중요한 파일부터 별도 저장장치에 백업해 두시길 권장합니다.

관련 증상 가이드 확인하기

  • 0x80070057 · 매개 변수가 올바르지 않음
  • 0x800F0922 · Windows 업데이트 실패
  • 0x80004005 · Unspecified error

자주 묻는 질문

  • 절전 모드를 아예 꺼야 하나요? 이 문제(0x0000009F)가 반복된다면 절전 기능 자체를 끄기보다 관련 드라이버와 전원 설정을 먼저 점검해, 절전 기능을 그대로 쓸 수 있는지 확인하는 것이 좋습니다.
  • 데스크톱에서도 발생하나요? 데스크톱도 절전 모드(S3)를 사용한다면 발생할 수 있으며, 원인 점검 방식은 노트북과 동일합니다.
