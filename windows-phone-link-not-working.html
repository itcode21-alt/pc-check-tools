    휴대폰과 연결(Phone Link) 안 될 때 원인과 점검 순서

    PC와 스마트폰을 연결하는 '휴대폰과 연결'(Phone Link) 앱이 페어링되지 않거나, 연결은 됐는데 알림·사진·메시지가 동기화되지 않는 경우

    휴대폰과 연결 오류는 대부분 계정 불일치, 배터리 절약 모드, Wi-Fi·공유기 설정, 앱 버전 불일치 중 하나가 원인입니다. Microsoft 공식 지원 문서 기준으로 확인된 원인과 해결 순서를 정리했습니다.

    PC와 스마트폰 양쪽에서 반드시 같은 Microsoft 계정으로 로그인돼 있어야 하며, 배터리 절약 기능이 백그라운드 연결을 차단하는 경우가 가장 흔한 원인 중 하나입니다. 같은 Wi-Fi에 연결돼 있어도 안 될 때는 앱 자체의 문제가 아니라 공유기의 '무선(AP) 격리' 기능 때문인 경우가 있어, 흔히 간과됩니다.

    이 가이드가 필요한 상황

    • QR 코드를 다시 스캔하라는 화면이 반복해서 뜬다.
    • 연결은 됐다고 나오는데 알림·문자·사진이 PC에 동기화되지 않는다.
    • '업데이트가 필요합니다' 페이지에서 더 이상 진행되지 않는다.

    먼저 확인할 항목

    1. Microsoft 계정 일치 확인 — 안드로이드에서 설정 → 고급 기능 → Windows와 연결로 들어가 로그인된 계정 이메일을 확인하고, PC의 휴대폰과 연결 앱에 로그인된 계정과 동일한지 대조하세요.
    2. 배터리 절약 모드·배터리 최적화 해제 — 안드로이드 설정 → 배터리 → 배터리 사용량 관리에서 '휴대폰과 연결' 앱을 '최적화하지 않음'으로 설정하고, PC·폰 모두 배터리 절약 모드가 꺼져 있는지 확인하세요.
    3. 공유기 무선 격리 확인 — 같은 Wi-Fi인데도 안 되면 공유기 관리 페이지의 무선 고급 설정에서 'AP 격리'·'무선 격리' 옵션이 꺼져 있는지 확인하세요.
    4. 앱 최소 버전 확인 — PC는 Phone Link 1.23112.85.0 이상, 안드로이드는 'Windows와 연결' 앱 1.24021.164.0 이상으로 업데이트하세요.

    원인을 더 정확히 나누는 방법

    안드로이드 권한 확인(안드로이드 10 이상)

    알림·사진·메시지 권한이 하나라도 거부돼 있으면 해당 기능만 조용히 안 뜹니다. 안드로이드 설정 → 앱 정보 → 모든 앱 표시 → Windows와 연결 → 권한에서 저장공간·연락처·SMS·전화 권한을 모두 허용하고, 알림은 별도의 '알림 액세스' 메뉴에서 껐다 다시 켜세요.

    삼성 DeX 동시 실행 여부

    삼성 DeX와 휴대폰과 연결을 동시에 열면 두 앱 모두 오작동할 수 있습니다. DeX를 쓰는 중이라면 휴대폰과 연결 앱을 종료한 뒤, 한 번에 하나씩만 실행하세요.

    한국에서만 있는 '두 전화 모드' 제약

    이동통신사에서 두 회선을 하나로 쓰는 '두 전화 모드'를 사용 중이라면, 휴대폰과 연결은 기본값이 아닌 프로필로는 연결을 지원하지 않습니다. 연결하려는 번호가 기본 프로필로 설정돼 있는지 확인하세요.

    '업데이트가 필요합니다' 페이지가 계속 뜰 때

    버전을 최신으로 올렸는데도 계속 뜬다면, PC와 안드로이드 양쪽 앱 설정 화면에서 실제 버전 번호를 직접 확인해 최신인지 재확인하세요. 그래도 해결되지 않으면 Windows 피드백 허브에 진단 데이터와 함께 보고하는 것이 공식 권장 절차입니다.

    확인 결과에 따른 다음 단계

    • 계정을 맞췄는데도 안 될 때 — 배터리 절약 모드와 Wi-Fi 상태부터 확인하세요. 대부분 이 두 가지가 원인입니다.
    • 같은 Wi-Fi인데 연결이 안 될 때 — 공유기의 무선(AP) 격리 기능부터 의심하세요 — 스마트폰이나 PC가 아니라 네트워크 장비 설정 문제입니다.
    • 권한을 다 허용했는데도 알림만 안 뜰 때 — '알림 액세스' 권한은 일반 앱 권한 목록과 별도 메뉴에 있습니다. 설정에서 '알림 액세스'를 검색해 Windows와 연결 항목을 껐다 다시 켜보세요.

    자주 묻는 질문

    • PC와 스마트폰 Microsoft 계정이 다르면 어떻게 되나요? 페어링 자체가 되지 않습니다. 안드로이드에서 설정 → 고급 기능 → Windows와 연결로 들어가 로그인된 계정 이메일을 PC 쪽과 동일하게 맞추세요.
    • 같은 와이파이에 연결돼 있는데도 안 되는 이유는? 공유기의 무선(AP) 격리 기능이 켜져 있으면 같은 네트워크에 있어도 기기끼리 통신이 차단됩니다. 공유기 관리 페이지의 무선 고급 설정에서 AP 격리를 꺼보세요.
    • 삼성 DeX를 쓰는데 휴대폰과 연결이 자꾸 끊깁니다. DeX와 휴대폰과 연결을 동시에 켜두면 두 앱 모두 문제가 생길 수 있습니다. 한 번에 하나만 실행하세요.
