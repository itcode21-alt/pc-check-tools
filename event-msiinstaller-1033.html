EVENT ID 1033

MsiInstaller 이벤트 1033 설치 결과 상태 점검

Windows Installer가 설치 작업을 마치고 결과 상태 값을 남긴 기록입니다. 상태가 0이면 성공이고, 1603 같은 값이면 설치가 실패한 것이므로 11708과 함께 읽습니다.

1033은 Windows Installer가 설치 작업을 마친 뒤 결과 상태 값을 남기는 기록입니다. 성공한 설치에서도 남기 때문에, 이 이벤트가 있다는 사실이 아니라 상태 값이 0인지가 판단 기준입니다.

상태 값이 0이 아니면 같은 시각의 11708과 제품 이름을 먼저 확인하세요. 값의 의미는 Windows Installer 오류 코드 목록에서 찾을 수 있고, 1603처럼 범위가 넓은 코드는 상세 로그에서 원인을 확인해야 합니다.

발생 조건

  • 프로그램 설치·제거·업데이트가 끝날 때마다 기록됨
  • 상태 값이 0이 아니면 설치 실패
  • 11708이 함께 남음

가능성 높은 원인

  • 상태 0: 정상 완료
  • 상태 1603: 설치 중 치명적 오류(원인은 상세 로그에서 확인)
  • 그 밖의 값: Windows Installer 오류 코드(제품과 환경에 따라 다름)

점검 순서

  1. 상태 값이 0인지 확인 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 0이 아니면 같은 시각의 11708과 제품 이름 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 상태 값을 Windows Installer 오류 코드 목록에서 찾아보기 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 상세 로그를 만들어 실패한 단계 확인 — 변경 전후로 증상이 달라지는지 비교해보세요.
주의사항

성공 기록(0)이 대부분이라 1033이 많다는 이유만으로 문제로 보지 마세요.

상태 값이 0이 아닌 경우에만 실패 원인 점검으로 넘어가세요.

자주 묻는 질문

  • 1033이 많이 보이는데 문제가 있는 건가요? 설치·제거·업데이트가 끝날 때마다 남는 기록이라 많은 것이 정상입니다. 상태 값이 0이 아닌 기록만 실패로 보고 확인하세요.
  • 상태 값 1603은 무슨 뜻인가요? 설치 중 치명적 오류가 발생했다는 일반 코드입니다. 구체적인 원인은 값만으로 알 수 없어 상세 로그에서 Return value 3이 적힌 줄 앞부분을 확인해야 합니다.
