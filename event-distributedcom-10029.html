DistributedCOM 이벤트 10029 서비스 종료 대기 시간 초과 점검

특정 COM 구성 요소를 활성화하는 도중 관련 서비스가 종료되기를 기다리다 시간 초과가 났다는 기록입니다. 예를 들어 Xbox 게임 바의 캡처 구성 요소(AppCaptureShell)가 방송 사용자 서비스(BcastDVRUserService)의 종료를 기다리다 실패하는 경우가 있습니다.

DistributedCOM 10029는 어떤 COM 구성 요소를 활성화하려다 해당 서비스가 종료되기를 기다리는 동안 시간 초과가 났다는 오류 수준 기록입니다. 예를 들어 'AppCaptureShell 활성화가 BcastDVRUserService 종료를 기다리다 시간 초과'처럼 게임 바 캡처 구성 요소에서 확인되는 사례가 있습니다.

주로 로그오프·종료 시점에 서비스 종료와 활성화 요청이 겹칠 때 남고 뚜렷한 증상이 없는 경우가 많습니다. 증상이 없다면 조치하지 않아도 되고, 종료가 유독 느리거나 게임 바 관련 멈춤이 있을 때만 해당 기능을 끄고 비교해 보세요.

발생 조건

  • 게임 바·화면 캡처 관련 서비스를 종료하거나 로그오프·종료할 때
  • 사용자 서비스가 종료되는 도중 COM 활성화 요청이 들어올 때

가능성 높은 원인

  • 서비스 종료가 지연되는 동안 다른 구성 요소가 활성화를 요청함
  • 게임 바(Xbox Game Bar) 캡처·방송 구성 요소의 종료 타이밍

점검 순서

  1. CLSID와 서비스 이름(param1·param2)으로 어떤 구성 요소인지 확인 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 게임 바 관련이면 설정에서 게임 바·캡처 기능을 끄고 재발하는지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 반복 횟수와 함께 실제 증상(앱 종료 지연·멈춤)이 있는지 확인 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
주의사항

오류 수준으로 기록되지만 증상이 없다면 대개 긴급하지 않습니다. 이 이벤트만으로 하드웨어 고장을 의심하지 마세요.

자주 묻는 질문

  • 10029가 반복되는데 PC에 문제가 있나요? 증상이 없다면 대개 문제가 아닙니다. 종료 시점에 서비스 종료와 활성화 요청이 겹칠 때 남는 기록입니다. 종료가 느리거나 앱이 멈추는 증상이 있을 때만 해당 서비스를 확인하세요.
  • 게임 바를 꺼도 되나요? 화면 캡처·녹화를 쓰지 않는다면 Windows 설정의 게임 바와 백그라운드 녹화를 꺼도 됩니다. 끈 뒤에도 같은 이벤트가 남는지 비교해 원인을 좁히세요.
