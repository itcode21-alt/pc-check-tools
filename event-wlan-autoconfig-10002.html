EVENT ID 10002

WLAN-AutoConfig 이벤트 10002 무선랜 확장 모듈 중지 점검

무선랜 확장 모듈이 중지되었음을 기록합니다. 보통 무선 드라이버나 제조사 확장 모듈의 재시작 과정에서 나타나므로, Wi-Fi 연결 끊김과 같은 시각인지 먼저 확인합니다.

10002는 무선랜 확장 모듈이 중지되었다는 기록입니다. 무선 드라이버나 제조사 확장 모듈이 다시 시작되는 과정에서 나타나므로, Wi-Fi가 끊긴 시각과 같은지 먼저 봅니다.

이벤트의 Module Path와 무선 어댑터 모델을 기록하고 장치 관리자에서 드라이버 버전을 확인하세요. Wi-Fi가 정상이고 단발성이라면 기록만 보고 드라이버를 삭제하지 마세요. 8002(연결 실패) 기록과 같은 시각인지도 비교할 만합니다.

발생 조건

  • Wi-Fi 연결 끊김·재연결
  • 절전 복귀 후 무선랜 불안정
  • 드라이버 업데이트나 무선 네트워크 전환 직후

가능성 높은 원인

  • 무선랜 드라이버·확장 모듈 충돌
  • 제조사 무선 유틸리티와 Windows WLAN 서비스 충돌
  • 어댑터 전원 관리 또는 절전 복귀 문제
  • 공유기 전환 중 일시적인 링크 변화

점검 순서

  1. 이벤트의 Module Path와 무선 어댑터 모델 기록 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 장치 관리자에서 무선 드라이버 버전 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 제조사 드라이버로 업데이트·롤백하고 무선 관리 유틸리티 충돌 여부 비교 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. Wi-Fi 연결이 정상이고 단발성이면 오류 누적만으로 드라이버를 삭제하지 않기 — 변경 전후로 증상이 달라지는지 비교해보세요.
주의사항

10002가 있다는 사실만으로 무선랜 카드 고장을 확정하지 마세요. 실제 연결 끊김과 반복 시각이 일치해야 합니다.

자주 묻는 질문

  • 10002면 무선랜 카드가 고장 난 건가요? 기록만으로 고장을 판단할 수 없습니다. 실제 연결 끊김이 같은 시각에 반복되는지가 기준입니다.
  • 드라이버는 어떻게 하나요? 제조사 최신 드라이버로 업데이트하거나, 업데이트 직후부터 시작됐다면 직전 버전으로 되돌려 비교하세요.
