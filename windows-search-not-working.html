윈도우 검색 안 됨 원인과 점검 순서

시작 메뉴·파일 탐색기 검색창에 입력해도 결과가 나오지 않거나 일부 항목만 검색되는 경우

윈도우 검색이 안 될 때는 먼저 '전혀 반응이 없는 것'과 '검색은 되는데 원하는 결과만 안 나오는 것'을 구분해야 합니다. 전자는 검색 서비스 자체의 문제, 후자는 인덱싱(색인) 범위나 진행 상태의 문제인 경우가 많습니다.

가장 흔한 원인은 검색 인덱싱이 아직 완료되지 않았거나 중단된 경우입니다. 파일을 대량으로 옮기거나 새 드라이브를 추가한 직후라면 인덱스가 다시 만들어지는 중이라 일시적으로 검색이 부정확할 수 있습니다.

설정을 확인해도 계속 안 된다면 Windows Search 서비스 자체가 멈춰 있거나 시스템 파일 손상이 원인일 수 있어, 서비스 재시작과 인덱스 재구성을 순서대로 시도해야 합니다.

이 가이드가 필요한 상황

  • 검색창에 아무것도 입력해도 결과가 전혀 뜨지 않는다.
  • 분명히 설치된 앱인데 이름을 쳐도 검색되지 않는다.
  • 파일 탐색기에서 특정 폴더만 검색이 안 된다.

먼저 확인할 항목

  1. 반응 없음과 일부 미검색 구분 — 검색창에 여러 검색어를 입력해 완전히 반응이 없는지, 특정 항목만 안 나오는지 확인하세요.
  2. 색인 옵션 확인 — 설정 > 검색 > 색인 옵션에서 대상 폴더 목록과 인덱싱 상태를 확인하세요.
  3. Windows Search 서비스 확인 — services.msc를 실행해 'Windows Search' 서비스가 실행 중인지 확인하고, 중지 상태면 시작으로 바꾸세요.
  4. 인덱스 재구성 — 색인 옵션 > 고급 > 다시 빌드를 눌러 인덱스를 새로 만드세요.

원인을 더 정확히 나누는 방법

인덱싱 중에는 검색이 불완전할 수 있음

대용량 파일 이동, 새 드라이브 추가, Windows 업데이트 직후에는 인덱스가 다시 만들어지는 중이라 일시적으로 검색 결과가 누락될 수 있습니다.

특정 폴더만 검색이 안 되는 경우

색인 옵션의 대상 폴더 목록에 해당 폴더가 포함되어 있지 않으면 아무리 파일이 있어도 검색되지 않습니다.

확인 결과에 따른 다음 단계

  • 완전히 반응이 없을 때 — Windows Search 서비스 실행 상태부터 확인하고, 꺼져 있으면 시작한 뒤 재부팅하세요.
  • 일부 항목만 안 나올 때 — 색인 옵션에서 대상 폴더와 인덱싱 진행 상태를 확인하세요.
  • 위 방법으로도 안 될 때 — 인덱스를 다시 빌드하거나, 그래도 안 되면 시스템 파일 검사(SFC/DISM)를 진행하세요.

피해야 할 실수

  • 인덱싱 진행 상태 확인 없이 바로 초기화나 재설치를 진행하는 것
  • 특정 폴더가 색인 대상에서 빠진 것을 모르고 검색 기능 자체가 고장났다고 판단하는 것

자주 묻는 질문

  • 인덱스를 다시 만들면 파일이 삭제되나요? 아닙니다. 인덱스는 검색을 빠르게 하기 위한 목록일 뿐이며, 다시 만들어도 실제 파일에는 영향이 없습니다.
  • 외장하드나 USB의 파일도 검색되게 하려면요? 색인 옵션에서 해당 드라이브를 대상 폴더로 직접 추가해야 합니다.
  • 재부팅하면 검색이 다시 되나요? 일시적으로 서비스가 멈춘 경우라면 재부팅으로 해결되기도 합니다.
