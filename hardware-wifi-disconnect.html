와이파이 끊김 원인과 점검 순서

무선 인터넷이 자주 끊기거나, 유선랜은 IP를 받아오는데도 실제 인터넷 연결이 안 되는 경우

와이파이 끊김은 공유기 신호 문제처럼 보여도 실제로는 드라이버와 절전 설정이 더 큰 원인일 수 있습니다. 같은 장소에서만 끊기는지, 다른 네트워크에서도 끊기는지 구분하면 방향이 빨라집니다.

특히 노트북에서는 전원 모드 변화만으로도 무선 어댑터가 잠깐씩 내려갈 수 있습니다. 이럴 때는 신호 세기보다 절전 옵션을 먼저 봐야 합니다.

끊김이 몇 초마다 반복되는지, 아니면 특정 시간대에만 생기는지도 중요한 단서입니다.

이 가이드가 필요한 상황

  • 몇 분마다 연결이 끊겼다 다시 붙는다.
  • 유선은 괜찮은데 무선만 불안정하다.
  • 절전 후에 더 자주 끊긴다.
  • 랜선을 꽂았는데도 인터넷에 연결할 수 없다고 뜬다.
  • IP는 정상적으로 할당받았는데 웹사이트가 열리지 않는다.

먼저 확인할 항목

  1. 무선 드라이버 점검 — 어댑터 드라이버가 불안정하면 연결이 살아나도 금방 끊길 수 있습니다. 제조사 드라이버로 다시 설치해 보세요.
  2. 전원 관리와 절전 해제 — 절전 전환이 어댑터를 끊어 버리면 불안정하게 보입니다. 무선 어댑터의 전원 절약 옵션을 확인합니다.
  3. 공유기/채널과 거리 확인 — 신호 간섭이나 채널 충돌도 반복 끊김을 만듭니다. 다른 네트워크나 다른 위치에서 재현되는지 확인하세요.
  4. 유선 연결: IP 재할당과 DNS 초기화 — IP는 받았지만 게이트웨이·DNS 응답이 없어 실제 인터넷 접속만 안 되는 경우가 흔합니다. 명령 프롬프트에서 ipconfig /release, ipconfig /renew로 IP를 재할당받고, 그래도 안 되면 ipconfig /flushdns로 DNS 캐시를 초기화하세요.
  5. 유선 연결: 케이블·포트·랜카드 구분 — 같은 케이블·포트에서 다른 기기도 안 되면 공유기·모뎀 쪽 문제이고, 그 기기만 안 되면 랜카드나 드라이버 쪽 문제입니다. 다른 기기를 같은 케이블·포트에 연결해 재현되는지 비교하고, 재현되지 않으면 랜카드 드라이버를 재설치하세요.

원인을 더 정확히 나누는 방법

무선만 끊기고 유선은 안정적일 때

네트워크 전체보다 무선 어댑터와 전원 관리가 우선 의심 대상입니다. 같은 인터넷 회선이라도 무선 전용 문제일 수 있습니다.

무선과 유선, 어디서부터 다르게 봐야 하는가

무선은 신호·드라이버·절전처럼 '연결 자체가 끊기는' 문제가 중심이지만, 유선은 케이블을 꽂은 상태에서 'IP는 받았는데 인터넷만 안 되는' 경우가 많습니다. 무선 어댑터 설정을 아무리 고쳐도 유선 문제는 해결되지 않으니, 먼저 작업표시줄 네트워크 아이콘에서 유선(이더넷)과 무선 중 어느 쪽 아이콘에 느낌표나 X가 떠 있는지부터 확인하세요.

확인 결과에 따른 다음 단계

  • 절전 후에만 끊길 때 — 전원 관리 옵션이 원인일 가능성이 높아 드라이버 설정을 먼저 점검하세요.
  • 어느 장소에서든 끊길 때 — 공유기보다 무선 어댑터 자체나 드라이버를 더 우선해서 봐야 합니다.
  • 유선인데 IP는 받았지만 인터넷이 안 될 때 — ipconfig /release·/renew·/flushdns로 IP·DNS를 재할당받고, 다른 기기로 같은 포트를 테스트해 공유기·모뎀 문제인지 랜카드 문제인지 구분하세요.

피해야 할 실수

  • 공유기만 재부팅하고 끝내는 것
  • 절전 옵션을 안 보는 것
  • 유선 문제인데 무선 어댑터 드라이버만 재설치해보는 것

자주 묻는 질문

  • 다른 기기는 멀쩡한데 내 PC만 끊깁니다. 그렇다면 공유기보다 PC의 무선 드라이버와 전원 설정을 먼저 보세요.
  • 유선랜인데 IP는 받아오는데 인터넷만 안 됩니다. 게이트웨이나 DNS 응답이 없는 경우입니다. ipconfig /release·/renew로 IP를 다시 받고 ipconfig /flushdns로 DNS 캐시를 초기화해보세요. 그래도 안 되면 공유기·모뎀 쪽 문제일 가능성이 큽니다.

진단 도구에서 증상과 오류 코드 함께 확인하기

무선 어댑터 자체가 노후됐다면 새 와이파이 어댑터로 교체하는 것도 고려해 보세요.

이 증상과 함께 나타나는 오류 코드

  • 0x800704CF · 이 네트워크에 연결되어 있지 않습니다
  • 0x80070718 · IP 주소를 가져올 수 없음
  • 0x80070490 · 요소를 찾을 수 없음 (네트워크 어댑터)
  • 0x80070102 · 네트워크 장치가 연결되지 않음
  • 배틀넷 연결 오류 · 배틀넷 오류로 오버워치 등이 실행되지 않음 (BLZBNTBNA0000)
