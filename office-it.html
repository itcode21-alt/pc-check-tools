사무실 IT

사무실 IT 가이드

직원 몇 명 규모의 사무실에서 자주 막히는 NAS·백업, 공유폴더, 네트워크, 프린터, 원격 접속 문제를 증상별로 모았습니다. 이미 사이트에 있는 가이드를 사무실 기준으로 다시 묶은 목록입니다.

사무실 문제는 한 대의 PC보다 여러 대가 함께 쓰는 공유기, 공유폴더, 프린터, NAS에서 시작하는 경우가 많습니다. 그래서 "어느 PC에서만 안 되는지, 모든 PC에서 안 되는지"를 먼저 구분하면 확인 범위가 크게 줄어듭니다. 아래에서 지금 상황과 가까운 항목을 고르세요.

증상으로 먼저 찾기

  • 공유폴더나 NAS에 우리 PC만(또는 한두 대만) 접속이 안 돼요 → 네트워크 드라이브 연결 오류
  • 특정 직원 계정만 폴더가 안 열려요 → 공유폴더 접근 권한 문제
  • 사무실 전체 인터넷이나 와이파이가 자꾸 끊겨요 → 인터넷 끊김 점검 순서
  • 프린터가 며칠마다 오프라인이 돼요 → IP 주소 고정으로 재발 막기
  • 밖에서 사무실 PC에 원격으로 접속이 안 돼요 → 원격 데스크톱 연결 안 됨
  • PC에 랜섬웨어 안내문이 떴어요 → 랜섬웨어 감염, 첫 1시간에 할 일
  • 백업이 어느 날부터 안 돌아요 → Hyper Backup 실패·멈춤

보안·사고 대응

  • 사무실 PC 랜섬웨어 감염, 첫 1시간에 할 일 — 네트워크 분리, 증거 보존, 백업 보호, 신고까지 우선순위대로 정리했습니다.

NAS·백업

  • NAS 문제 해결 모음 — 외부 접속, 부팅, 용량, 동기화 등 시놀로지 NAS 문제 8가지를 한곳에서 봅니다.
  • Hyper Backup 백업이 실패하거나 멈춤 — 예약 백업이 돌지 않거나 '복원 전용'으로 바뀐 경우의 원인을 짚습니다.
  • NAS에 일반 하드디스크를 써도 되나요 — NAS 전용 디스크와 PC용 디스크의 차이를 확인합니다.
  • 백업 저장공간 계산기 — 현재 데이터량과 증가량으로 필요한 외장하드·NAS 용량을 계산합니다.

공유폴더·네트워크

  • 네트워크 드라이브 연결 오류 — 계정·비밀번호가 틀렸다고 나오거나 연결 자체가 안 될 때 확인합니다.
  • 특정 PC·계정만 공유폴더 접속 안 됨 — 일부 계정만 막히거나 상위 폴더만 보이는 권한 문제를 다룹니다.
  • 인터넷이 자꾸 끊길 때 점검 순서 — 케이블, 공유기, DNS 순으로 유선·무선 문제를 좁혀 갑니다.
  • 와이파이 끊김 — 드라이버, 절전 설정, IP·DNS 재할당 순서로 확인합니다.
  • 인터넷이 안 될 때 자가진단 — 증상을 고르면 순서대로 안내하는 단계별 점검입니다.

프린터

  • 프린터 오프라인·연결 안 될 때 — 스풀러 서비스, 연결 상태, 드라이버를 차례로 점검합니다.
  • 며칠마다 오프라인이 될 때 IP 고정 — 껐다 켜면 돌아오지만 반복될 때 재발을 막는 방법입니다.
  • 프린터 추가 중 멈춤 — 프린터 추가 화면에서 멈추는 원인을 확인합니다.
  • 인쇄 대기열이 멈춤 — Print Spooler 서비스가 멈춰 인쇄가 쌓일 때의 해결 순서입니다.
  • 프린터 오류 해결 마법사 — 증상을 고르면 원인별 해결 순서를 안내합니다.

원격 접속·업데이트

  • 원격 데스크톱(RDP) 연결 안 됨 — Windows Home 에디션 제한 등 연결 실패의 대표 원인을 정리했습니다.
  • 윈도우 업데이트 오류 정리 — 업데이트가 반복 실패할 때 공통 절차와 오류 코드를 봅니다.
  • 윈도우 정품 인증 오류 — 정품 인증 실패 메시지별 원인을 확인합니다.

직접 해결이 어려울 때

가이드대로 확인해도 해결되지 않거나 업무를 오래 멈출 수 없는 상황이라면 원격 점검·방문 출장 안내를 확인하세요. 증상이 시작된 시점과 최근 바꾼 설정(공유기 교체, 윈도우 업데이트 등)을 함께 알려 주시면 점검이 빨라집니다.
