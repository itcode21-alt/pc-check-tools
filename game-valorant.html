VAN 59 오류 · 로그인 대기열을 불러오지 못함

접속/네트워크참고 자료 있음

Riot 고객지원 문서는 VAN 59를 '로그인 대기열을 불러오는 데 실패했습니다'로 설명합니다. 원인은 로그인 대기열 쪽 문제이며, Vanguard 드라이버 오류(44·45·-81)와는 다른 코드입니다.

가능한 원인

  • 로그인 대기열에 문제가 생긴 경우(Riot 안내의 원인)
  • Riot 서버 쪽 일시적 문제로 대기열 정보를 받지 못한 경우(문서 외 일반 해석)

점검 순서

  1. 1단계 - 라이엇 클라이언트 다시 시작 (Riot 공식 안내):
    ① Riot 오류 코드 표는 번호 59를 '로그인 대기열을 불러오는 데 실패했습니다'로 설명하고, 라이엇 클라이언트를 다시 시작하라고 안내합니다.
    ② 라이엇 클라이언트를 완전히 종료한 뒤 다시 실행합니다.
  2. 2단계 - 고객지원 페이지 배너 확인 (Riot 공식 안내):
    ① 같은 표는 고객지원 페이지 배너를 확인하라고 안내합니다. Riot 고객지원 페이지 상단 배너에 서버·로그인 관련 공지가 있는지 봅니다.
  3. 3단계 - 다른 오류 번호 빠른 안내 (Riot 공식 안내):
    ① 0·1·38 연결 오류: 라이엇 클라이언트와 발로란트를 다시 시작합니다.
    ② 5 계정이 다른 기기에 로그인됨: 다른 모든 기기에서 로그아웃해야 합니다.
    ③ 7 세션 서비스 연결 실패: 계정이 이용 제한됐을 수 있으니 이메일에서 추가 정보를 확인하고, 플랫폼 문제일 수 있으니 고객지원 페이지 배너도 확인합니다.
    ④ 29 네트워크 문제: 방화벽이 발로란트를 허용하도록 설정합니다.
    ⑤ 39·46 서버 점검: 정기·긴급 점검일 수 있으니 나중에 다시 로그인합니다.
    ⑥ 44·45·-81 뱅가드 문제: 라이엇 클라이언트를 다시 시작하고, 해결되지 않으면 라이엇 뱅가드를 삭제한 뒤 발로란트를 다시 시작합니다(-81은 PC도 재시작). 이 오류들은 위 '뱅가드 오류' 안내와 같이 봅니다.
    ⑦ 61 정지된 계정: 페이지 하단의 문의하기로 접수합니다.
    ⑧ 128 서버에 연결할 수 없음: 클라이언트를 다시 시작해 재접속하고, PC와 라이엇 클라이언트도 다시 시작합니다.
  4. 4단계 - 반복될 때 (문서 외 일반 점검):
    ① 오류 번호와 발생 시각을 적어 Riot 고객지원에 문의
