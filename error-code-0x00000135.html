에러 코드 상세

0x00000135 · REGISTRY_FILTER_DRIVER_EXCEPTION

레지스트리 필터 드라이버가 예외를 일으킨 것으로, 최근 설치한 보안·최적화 프로그램과의 충돌을 먼저 확인해야 하는 코드입니다.

이 코드를 어떻게 해석해야 하나요?

오류 코드는 고장 부품을 확정하는 판정이 아니라 발생 시점과 함께 원인 범위를 좁히는 단서입니다. 최근 변경, 반복 조건, 안전 모드 재현 여부를 함께 기록하세요.

먼저 기록할 내용: 0x00000135가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 백신·보안 프로그램의 레지스트리 필터 드라이버가 최신 윈도우와 맞지 않는 경우
  • 레지스트리 최적화나 정리 도구가 시스템 키를 건드린 경우
  • 백업·동기화 프로그램의 필터 드라이버 버그
  • 윈도우 업데이트 직후 기존 필터 드라이버와 충돌한 경우
  • 레지스트리 관련 시스템 파일이 손상된 경우

첫 점검 항목

  1. 블루스크린 덤프에서 지목된 .sys 파일명을 기록하고, 어떤 프로그램 소속인지 검색하세요. — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 최근 설치·업데이트한 보안, 백신, 최적화 프로그램을 최신 버전으로 맞추거나 제거하세요. — 첫 확인 결과와 비교해 소프트웨어와 하드웨어 가능성을 나눕니다.
  3. 안전 모드에서 재현되지 않는다면 자동 시작 프로그램을 하나씩 비활성화해 원인을 좁히세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.
  4. sfc /scannow와 DISM으로 시스템 파일과 구성 요소 저장소를 점검하세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.
  5. 위 조치로 해결되지 않으면 시스템 복원 지점으로 되돌려 재발 여부를 확인하세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

같은 코드가 반복되면 이벤트 로그와 장치 상태를 보존하고, 코드가 계속 달라지면 메모리·전원·온도처럼 시스템 전체 안정성을 확인하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

상세 해설

이 코드는 하드웨어보다 소프트웨어 충돌에서 나오는 경우가 많습니다. 특히 보안 프로그램을 설치하거나 업데이트한 뒤부터 시작됐다면, 그 프로그램을 최신 버전으로 맞추거나 제거하는 것이 가장 빠른 확인 방법입니다. 필터 드라이버는 윈도우 깊은 곳에서 동작하므로, 레지스트리를 직접 고치기보다 프로그램 단위로 확인하는 것이 안전합니다.

관련 증상 가이드 확인하기

자주 묻는 질문

  • 레지스트리를 직접 고쳐야 하나요? 권장하지 않습니다. 필터 드라이버 등록 정보는 시스템 동작과 직결되어 있어 잘못 고치면 부팅이 되지 않을 수 있습니다. 프로그램을 제거하거나 업데이트하는 방법을 먼저 쓰세요.
  • 백신을 끄면 해결되나요? 원인이 백신의 필터 드라이버라면 잠시 꺼서 재현 여부를 확인할 수 있습니다. 다만 끈 상태로 계속 쓰지 말고, 해당 프로그램의 최신 버전을 설치하거나 교체를 검토하세요.
