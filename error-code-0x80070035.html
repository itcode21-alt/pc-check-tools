에러 코드 상세

0x80070035 · 네트워크 경로를 찾을 수 없음

공유 폴더나 네트워크 드라이브에 접근하려 할 때 지정한 경로 자체를 찾지 못해 나타나는 오류입니다. 파일 탐색기에서 \\컴퓨터명\공유폴더 형태로 접근할 때 자주 발생합니다.

이 코드를 어떻게 해석해야 하나요?

이런 업데이트 오류 코드는 네트워크·캐시·구성 요소 저장소·디스크 공간·서비스 상태 가운데 어느 지점에서 문제가 생겼는지 알려주는 단서입니다. 반복되는 시점과 이벤트 로그의 세부 코드를 함께 확인하세요.

먼저 기록할 내용: 0x80070035가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 대상 컴퓨터의 전원이 꺼져 있거나 같은 네트워크에 있지 않은 경우
  • 공유 폴더 설정 자체가 비활성화되어 있거나 삭제된 경우
  • 네트워크 검색이나 파일 공유 기능이 꺼져 있는 경우
  • 방화벽이 파일 공유 관련 포트를 차단하는 경우
  • 컴퓨터 이름이나 IP 주소가 변경되어 기존 경로가 유효하지 않은 경우

첫 점검 항목

  1. 대상 컴퓨터 상태 확인 — 대상 컴퓨터가 켜져 있고 같은 네트워크(같은 공유기)에 연결되어 있는지 확인하세요.
  2. 네트워크 검색·파일 공유 활성화 확인 — 설정 > 네트워크 및 인터넷 > 공유 옵션에서 네트워크 검색과 파일 공유가 켜져 있는지 확인하세요.
  3. IP 주소로 직접 접근 시도 — 컴퓨터 이름 대신 IP 주소로 직접 접근해 경로 문제인지 이름 확인(NetBIOS/DNS) 문제인지 구분하세요.
  4. 방화벽 규칙 확인 — 방화벽에서 파일 및 프린터 공유 규칙이 허용되어 있는지 확인하세요.
  5. 공유 설정 재확인·재설정 — 대상 폴더의 공유 설정을 다시 확인하고 필요하면 공유를 삭제 후 재설정하세요.

확인 결과에 따른 다음 단계

  • IP로는 접속되는데 컴퓨터 이름으로는 안 될 때 — 이름 확인 문제이므로 두 PC가 같은 워크그룹인지 확인하거나, hosts 파일에 컴퓨터 이름과 IP를 직접 매핑해보세요.
  • IP로도 접속이 안 될 때 — 네트워크 검색·파일 공유가 꺼져 있거나 방화벽이 차단하고 있을 가능성이 크므로 2번과 4번 항목을 다시 확인하세요.
  • 공유를 재설정해도 반복될 때 — 관리자 권한 명령 프롬프트에서 net use * /delete로 기존 연결 정보를 모두 삭제한 뒤 다시 접근을 시도하세요.

데이터와 시스템을 보호하는 주의사항

저장 공간·네트워크·서비스 상태를 확인하는 것이 시스템 폴더 권한 변경이나 레지스트리 정리 도구 사용보다 먼저입니다.

앞 단계로 해결되지 않을 때

같은 문제가 계속되면 Windows Update 로그와 DISM·SFC 검사 결과를 보관해두고, 설치 미디어 버전이 현재 시스템과 맞는지 점검하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

자주 묻는 질문

  • 탐색기가 멈추면 바로 재설치해야 하나요? 이 문제(0x80070035)는 재설치보다 셸 재시작과 원인이 되는 폴더·드라이브 분리로 대부분 해결됩니다. 재설치는 이 단계 이후에도 반복될 때 고려하세요.
  • 같은 네트워크인데 계속 안 되면요? 두 PC의 워크그룹 이름이 다르거나, 한쪽은 개인 네트워크·다른 쪽은 공용 네트워크로 설정된 경우가 흔한 원인이니 네트워크 프로필 설정을 확인하세요.
