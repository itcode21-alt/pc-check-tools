에러 코드 상세

0x00000124 · WHEA_UNCORRECTABLE_ERROR

CPU, 메모리, 메인보드, 전원 공급 장치가 수정할 수 없는 하드웨어 오류를 보고할 때 나타날 수 있습니다.

CPU, 메모리, 메인보드 전원부, PCIe 장치 등 하드웨어 계층에서 수정 불가능한 오류가 감지되어 WHEA(Windows Hardware Error Architecture)가 시스템을 강제로 정지시킬 때 나타나는 코드입니다. 소프트웨어보다 하드웨어 자체의 불안정성이 원인인 경우가 많아 다른 블루스크린보다 원인 특정에 시간이 걸릴 수 있습니다.

이 코드를 어떻게 해석해야 하나요?

이 계열은 CPU, 메모리, PCIe 장치, 메인보드 전원 또는 냉각처럼 시스템 안정성에 영향을 주는 영역에서 나타날 수 있습니다. 코드 하나로 부품을 확정하지 말고 기본 클럭 상태와 발생 작업을 비교해야 합니다.

먼저 기록할 내용: 0x00000124가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • CPU나 GPU가 고부하 작업 중 냉각이 따라가지 못해 과열되는 경우
  • 램이나 CPU의 오버클럭, XMP/EXPO 프로파일이 실제 하드웨어 조합에서 불안정한 경우
  • 파워 서플라이 용량 부족이나 노후화로 순간적인 전압 강하가 발생하는 경우
  • 메인보드 전원부(VRM)나 PCIe 슬롯의 접촉 불량, 물리적 결함
  • CPU나 램 자체의 하드웨어 결함으로 특정 연산에서 오류가 발생하는 경우

첫 점검 항목

  1. 오버클럭, XMP/EXPO 설정을 모두 기본값으로 되돌린 뒤 재현 여부를 확인하세요.
  2. CPU와 GPU 온도를 모니터링 프로그램으로 확인해 고부하 시 과열되는지 점검하세요.
  3. 이벤트 뷰어에서 WHEA-Logger 항목을 확인해 어떤 구성요소(소스)가 오류를 보고했는지 확인하세요.
  4. CPU, 램, GPU를 각각 따로 부하 테스트(프라임95, 메모리 진단, 퍼니마크 등)해 원인 부품을 좁혀보세요.
  5. 파워 서플라이 용량이 시스템 사양에 충분한지, 케이블 연결이 안정적인지 점검하세요.

실제 사용자 사례

위 점검 순서로도 해결되지 않았을 때, 다른 원인으로 해결된 사례입니다.

CPU 오버클럭 해제로 WHEA 오류 해결

게임 중 불규칙하게 WHEA_UNCORRECTABLE_ERROR가 발생했던 사례가 있습니다. 처음엔 메모리 문제로 의심했지만, BIOS에서 CPU 오버클럭 설정을 기본값으로 되돌리자 이후 재발하지 않았습니다.

포인트: 이 오류는 CPU, 메모리, 칩셋 등의 하드웨어 오류를 운영체제가 감지했을 때 발생합니다. 오버클럭이나 언더볼팅 설정을 기본값으로 복원하는 것이 가장 먼저 시도해볼 조치입니다.

파워서플라이 교체로 WHEA 오류 해결

오버클럭 해제·드라이버 갱신으로도 해결되지 않고 반복되던 WHEA_UNCORRECTABLE_ERROR가 파워서플라이를 교체한 뒤로는 재발하지 않았던 사례가 있습니다.

포인트: 설정·드라이버 쪽에 문제가 없는데도 반복된다면, 노후화되었거나 용량이 부족한 파워서플라이가 부하 순간 전압을 순간적으로 떨어뜨려 하드웨어 오류로 이어졌을 가능성을 의심해 보세요.

CPU 교체로 WHEA 오류 해결

이벤트 뷰어의 시스템 로그에서 이 코드와 함께 WHEA-Logger 이벤트 18번이 반복적으로 기록되던 사례가 있습니다. 오버클럭 해제, 메모리 교차 테스트, 온도·전원 점검을 모두 진행했지만 해결되지 않다가 CPU를 교체한 뒤에야 문제가 해결됐습니다.

포인트: 이벤트 뷰어에서 WHEA-Logger 18번이 이 코드와 같은 시각에 반복 기록된다면, 드라이버나 설정보다 CPU 자체의 결함을 먼저 의심해보는 것이 좋습니다.

확인 결과에 따른 다음 단계

  • 오버클럭 해제로 해결될 때 — 사례처럼 재발 여부만 지켜보면 됩니다.
  • 파워서플라이 교체로 해결될 때 — 사례처럼 재발 여부만 지켜보면 됩니다.
  • 부품별 부하 테스트로도 원인이 좁혀지지 않을 때 — 사례처럼 WHEA-Logger 18번이 반복된다면 CPU 자체 결함을 의심해보세요.

데이터와 시스템을 보호하는 주의사항

오버클럭과 XMP·EXPO를 기본값으로 되돌리고, 과열·타는 냄새·반복 재부팅이 있으면 장시간 부하 테스트를 중단하세요.

앞 단계로 해결되지 않을 때

기본 설정에서도 반복되면 온도와 WHEA 이벤트를 기록한 뒤 CPU, RAM, GPU를 한 번에 바꾸지 말고 한 영역씩 교차 점검하세요.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

자주 묻는 질문

  • 게임할 때만 재부팅되면 그래픽카드 문제인가요? 이 문제(0x00000124)는 그래픽 드라이버 문제일 가능성이 높지만 전원 공급이나 온도 문제와 겹치는 경우도 많아, 드라이버 재설치와 함께 온도·전력 상태도 함께 확인하는 것이 좋습니다.
  • 쿨링 문제인지 전원 문제인지 구분하는 방법이 있나요? 재부팅 직전 온도를 모니터링 프로그램으로 확인해, 온도가 정상 범위인데도 재부팅된다면 전원 문제일 가능성이 높습니다.
  • WHEA 오류는 서비스센터에서 어떻게 진단하나요? 자체 진단 소프트웨어와 부품 교체 테스트로 CPU·메인보드·전원부를 하나씩 배제하며 확인합니다.
