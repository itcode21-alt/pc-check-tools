다른 프로그램에서 사용 중이라 삭제할 수 없음 원인과 점검 순서

파일·폴더 삭제 시 다른 프로그램이 사용 중이라는 메시지가 뜨며 삭제되지 않는 경우

'다른 사람이나 다른 프로그램에서 이 파일을 사용하고 있습니다'라는 메시지는 Windows가 해당 파일에 대한 핸들(사용 권한)이 아직 열려 있다고 판단했다는 뜻입니다. 실제로 그 프로그램을 눈으로 보고 있지 않아도 백그라운드에서 파일을 붙잡고 있는 경우가 많습니다.

가장 흔한 원인은 그 파일을 열어본 적 있는 프로그램이 완전히 종료되지 않고 백그라운드에 남아 있는 경우입니다. 작업 관리자에서 관련 프로그램을 찾아 완전히 종료한 뒤 다시 시도하는 것이 첫 단계입니다.

프로그램을 모두 종료해도 안 된다면 원드라이브 같은 클라우드 동기화 프로그램이나 백신이 파일을 검사·동기화하느라 붙잡고 있을 수 있습니다. 이런 프로그램을 일시적으로 중지한 뒤 다시 시도하세요.

이 가이드가 필요한 상황

  • 삭제·이동을 시도하면 '다른 프로그램에서 사용 중'이라는 메시지가 뜬다.
  • 관련 프로그램을 껐다고 생각했는데도 계속 같은 메시지가 뜬다.
  • 재부팅해도 같은 파일에서 반복적으로 문제가 생긴다.

먼저 확인할 항목

  1. 관련 프로그램 완전 종료 — 작업 관리자에서 관련 프로그램을 찾아 '작업 끝내기'로 완전히 종료한 뒤 다시 삭제를 시도하세요.
  2. 재부팅 직후 시도 — 다른 프로그램을 실행하지 않은 상태에서 재부팅 직후 바로 삭제를 시도해보세요.
  3. 클라우드 동기화·백신 일시 중지 — 원드라이브 동기화나 백신 실시간 검사를 잠시 끈 뒤 시도하세요.
  4. 파일 잠금 해제 도구 사용 — Unlocker 같은 도구로 파일을 잡고 있는 프로세스를 확인하고 해제한 뒤 삭제하세요.

원인을 더 정확히 나누는 방법

탐색기 자체가 파일을 붙잡고 있는 경우

때로는 탐색기(explorer.exe)가 미리보기나 썸네일 생성을 위해 파일을 열어둔 상태로 남아있을 수 있습니다. 작업 관리자에서 explorer.exe를 다시 시작하면 해결되기도 합니다.

네트워크 공유 파일인 경우

네트워크 드라이브나 공유 폴더의 파일이라면 다른 사용자가 실제로 그 파일을 열어보고 있을 수 있습니다.

확인 결과에 따른 다음 단계

  • 프로그램 종료로 해결될 때 — 다음부터는 프로그램을 완전히 종료한 뒤 파일을 삭제하는 습관을 들이세요.
  • 클라우드 동기화 중지로 해결될 때 — 동기화가 완료된 후 삭제를 진행하면 충돌을 줄일 수 있습니다.
  • 위 방법으로도 안 될 때 — 파일 잠금 해제 도구를 사용하거나, 안전 모드에서 삭제를 시도하세요.

피해야 할 실수

  • 관련 프로그램 종료 없이 강제 삭제 도구부터 사용하는 것
  • 네트워크 공유 파일인데 로컬 파일처럼 취급해 원인을 잘못 짚는 것

자주 묻는 질문

  • 작업 관리자에서 어떤 프로그램을 찾아야 하나요? 그 파일 형식과 관련된 프로그램을 먼저 확인하고, 명확하지 않다면 탐색기를 재시작해보세요.
  • Unlocker 같은 프로그램은 안전한가요? 널리 쓰이는 검증된 도구는 대체로 안전하지만 공식 배포처를 이용하세요.
  • 재부팅해도 매번 같은 파일에서 반복되면요? 시작 프로그램 목록을 확인해보세요.
