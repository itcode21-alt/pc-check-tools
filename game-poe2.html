패스 오브 엑자일 2 오류 모음 — 원인과 해결 방법

패스 오브 엑자일 2는 얼리 액세스 특성상 핫픽스가 잦아, 클라이언트와 서버 버전이 살짝 어긋나며 생기는 패치·접속 오류가 자주 보고됩니다. 국내는 카카오게임즈가 서비스하고 있습니다.

바로 이동

  • 패치(업데이트) 설치가 진행되지 않는 문제 (패치 설치 실패)
  • 보스전이나 구역 이동 중 서버 연결이 끊기는 문제 (서버 연결 끊김)
  • 그래픽 렌더링 오류로 게임이 강제 종료되는 문제 (그래픽 크래시)
  • 로딩 화면에서 멈추고 넘어가지 않는 문제 (로딩 화면 멈춤)
  • 게임이 아예 실행되지 않는 문제 (실행 불가)
  • 플레이 시간이 길어질수록 프레임이 점점 떨어지는 문제 (메모리 누수)

패치(업데이트) 설치가 진행되지 않는 문제 · 패치 설치 실패

패치/런처

얼리 액세스 특성상 잦은 핫픽스가 배포되는데, 패치 적용이 멈추거나 실패해서 실행이 안 되는 경우가 자주 보고됩니다.

가능한 원인

  • 이전 패치의 임시 파일이 남아 새 패치와 충돌하는 경우
  • 런처 캐시 파일이 손상된 경우

점검 순서

  1. 1단계 - 런처 보조 실행 파일 삭제 (커뮤니티 확인된 방법):
    ① 게임 설치 폴더에서 PathOfExile_KG.exe, PathOfExile_x64_KG.exe 파일을 삭제
    ② 게임 시작 버튼을 다시 누르면 해당 파일이 새로 받아지며 해결되는 사례가 많습니다.
  2. 2단계 - 런처 재시작:
    ① 카카오게임즈 런처를 완전히 종료한 뒤 재실행
  3. 3단계 - 클라이언트 무결성 재설치:
    ① 문제가 반복되면 런처에서 전체 재설치 진행

접속/네트워크

보스 전투나 구역(존) 전환처럼 서버 부하가 몰리는 순간에 갑자기 연결이 끊기는 문제입니다.

가능한 원인

  • 서버 응답 지연이 순간적으로 몰리는 경우
  • 가정용 네트워크의 순간적인 패킷 손실

점검 순서

  1. 1단계 - 유선 네트워크로 전환:
    ① Wi-Fi 대신 유선 연결로 안정성 비교
  2. 2단계 - 재접속 후 캐릭터 상태 확인:
    ① 재접속해 사망 처리 여부 등 캐릭터 상태를 먼저 확인
  3. 3단계 - 공식 커뮤니티에서 서버 상태 확인:
    ① 카카오게임즈 공식 공지에서 서버 점검·장애 안내 여부 확인

그래픽 렌더링 오류로 게임이 강제 종료되는 문제 · 그래픽 크래시

그래픽/성능

특정 스킬 이펙트가 몰리는 구간에서 화면이 깨지거나 게임이 강제 종료되는 문제로, 오래되었거나 손상된 DirectX 설치가 흔한 원인으로 지목됩니다.

가능한 원인

  • DirectX 구성 요소가 최신이 아니거나 손상된 경우
  • 그래픽 드라이버가 오래된 경우

점검 순서

  1. 1단계 - DirectX 최신 버전 재설치:
    ① Microsoft 공식 DirectX End-User Runtime 설치
  2. 2단계 - 그래픽 드라이버 최신화:
    ① 그래픽카드 제조사 최신 드라이버로 업데이트
  3. 3단계 - 그래픽 옵션 낮춰 재현 확인:
    ① 파티클·이펙트 품질을 낮춰 크래시 빈도가 줄어드는지 확인

참고 자료

로딩 화면에서 멈추고 넘어가지 않는 문제 · 로딩 화면 멈춤

실행/로딩

구역 이동이나 접속 직후 로딩 화면에서 멈춰 진행되지 않는 문제입니다.

가능한 원인

  • 캐시 파일 손상
  • 네트워크 지연으로 로딩 데이터 수신이 지연되는 경우

점검 순서

  1. 1단계 - 게임 재시작 후 재접속:
    ① 완전히 종료한 뒤 다시 접속
  2. 2단계 - 캐시 폴더 정리:
    ① 게임 캐시 폴더를 정리한 뒤 재시작
  3. 3단계 - 공식 커뮤니티에 제보:
    ① 반복되면 발생 시각·구역명과 함께 공식 게시판에 제보

실행/설치

런처에서 시작 버튼을 눌러도 게임 창 자체가 뜨지 않는 문제입니다.

가능한 원인

  • 실행 파일 손상
  • 백신 프로그램의 오탐 차단
  • 관리자 권한 부족

점검 순서

  1. 1단계 - 관리자 권한으로 실행:
    ① 실행 파일 우클릭 → 관리자 권한으로 실행
  2. 2단계 - 백신 예외 등록:
    ① 백신 프로그램에서 게임 설치 폴더를 예외로 등록
  3. 3단계 - 무결성 검사 후 재설치:
    ① 런처에서 파일 무결성 검사를 진행하고, 필요하면 재설치

플레이 시간이 길어질수록 프레임이 점점 떨어지는 문제 · 장시간 플레이 시 프레임 저하

그래픽/성능

접속 직후에는 정상이던 프레임이 오래 플레이할수록 점점 낮아지는 문제로, 균열·환영·심연 같은 콘텐츠가 몰린 맵에서 몬스터가 대량으로 몰릴 때 특히 심해집니다. 재접속하면 일시적으로 프레임이 회복되는 것이 특징입니다.

가능한 원인

  • 장시간 플레이 시 누적되는 메모리 누수(memory leak)
  • 여러 이벤트 콘텐츠(균열·환영·심연 등)와 몬스터 스폰이 동시에 몰리는 경우

점검 순서

  1. 1단계 - 재접속으로 임시 회복:
    ① 프레임이 눈에 띄게 떨어지면 게임을 완전히 종료했다가 재접속해 임시로 회복
  2. 2단계 - 이벤트 콘텐츠 중첩 줄이기:
    ① 균열·환영·심연 등 여러 콘텐츠를 동시에 몰아서 진행하지 않고 나눠서 진행해 재현 빈도 비교
  3. 3단계 - 그래픽 옵션 낮추기:
    ① 파티클·이펙트 품질을 낮춰 메모리 사용량 자체를 줄이기
  4. 4단계 - 공식 게시판에 사양과 함께 제보:
    ① 반복되면 플레이 시간, 사양, 발생 콘텐츠를 함께 공식 게시판에 제보

자주 묻는 질문

  • 패치 보조 파일을 삭제해도 게임 데이터가 사라지지 않나요? PathOfExile_KG 관련 파일은 실행에 필요한 보조 실행 파일로, 삭제해도 캐릭터나 아이템 같은 계정 데이터에는 영향이 없습니다. 삭제 후 게임을 실행하면 자동으로 다시 받아집니다.
  • 얼리 액세스라서 이런 오류가 유독 잦은가요? 네, 패치가 자주 배포되는 시기라 클라이언트와 서버 버전이 살짝 어긋나 발생하는 문제가 늘어날 수 있습니다. 패치 노트의 알려진 이슈를 먼저 확인하는 것이 좋습니다.
  • 프레임이 떨어지는 게 제 컴퓨터 사양 문제 아닌가요? 사양과 무관하게 발생한다는 보고가 많아 순수한 사양 문제로 보기 어렵습니다. 접속 직후에는 정상이다가 플레이 시간이 길어질수록 점점 떨어지고 재접속하면 회복된다면 메모리 누수 쪽 가능성이 더 큽니다.
