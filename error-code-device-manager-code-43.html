에러 코드 상세

코드 43 · Windows에서 이 장치를 중지했습니다 (코드 43)

드라이버가 장치에서 하드웨어 오류나 문제를 감지해 윈도우에 보고했을 때 나타나는 코드로, 그래픽카드나 USB 장치에서 특히 자주 나타납니다.

이 코드를 어떻게 해석해야 하나요?

이 계열은 CPU, 메모리, PCIe 장치, 메인보드 전원 또는 냉각처럼 시스템 안정성에 영향을 주는 영역에서 나타날 수 있습니다. 코드 하나로 부품을 확정하지 말고 기본 클럭 상태와 발생 작업을 비교해야 합니다.

먼저 기록할 내용: 코드 43가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 그래픽카드가 과열되거나 전원 공급이 불안정한 경우
  • USB 장치가 순간적으로 과전류를 발생시켜 컨트롤러가 안전을 위해 차단한 경우
  • 드라이버 버그로 장치 초기화에 실패하는 경우
  • 펌웨어가 오래되어 최신 드라이버와 호환되지 않는 경우
  • 하드웨어 자체의 결함(그래픽카드 고장, USB 컨트롤러 손상 등)

첫 점검 항목

  1. 장치를 다른 포트나 슬롯에 연결해 재현되는지 확인하세요. — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 그래픽카드라면 드라이버를 완전히 제거(DDU 등)한 뒤 최신 버전으로 재설치하세요. — 첫 확인 결과와 비교해 소프트웨어와 하드웨어 가능성을 나눕니다.
  3. USB 장치라면 다른 PC에서도 같은 증상이 나오는지 확인해 장치 자체 결함인지 구분하세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.
  4. 온도와 전원 공급 상태를 점검하세요 (특히 그래픽카드 보조 전원). — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.
  5. 제조사 펌웨어 업데이트가 있는지 확인하고 적용해 보세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.

데이터와 시스템을 보호하는 주의사항

오버클럭과 XMP·EXPO를 기본값으로 되돌리고, 과열·타는 냄새·반복 재부팅이 있으면 장시간 부하 테스트를 중단하세요.

앞 단계로 해결되지 않을 때

기본 설정에서도 반복되면 온도와 WHEA 이벤트를 기록한 뒤 CPU, RAM, GPU를 한 번에 바꾸지 말고 한 영역씩 교차 점검하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.
