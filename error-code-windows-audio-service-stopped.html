에러 코드 상세

Windows Audio 서비스 응답 없음 · Windows Audio 서비스가 중지되거나 응답하지 않아 소리가 나오지 않음

소리 아이콘에 X 표시가 뜨거나 오디오 장치 자체는 정상인데 Windows Audio 서비스가 멈춰 있거나 중지되어 있어 전체 사운드가 나오지 않는 증상입니다. 드라이버 문제와는 원인이 다릅니다.

이 코드를 어떻게 해석해야 하나요?

오류 코드는 고장 부품을 확정하는 판정이 아니라 발생 시점과 함께 원인 범위를 좁히는 단서입니다. 최근 변경, 반복 조건, 안전 모드 재현 여부를 함께 기록하세요.

먼저 기록할 내용: Windows Audio 서비스 응답 없음가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • Windows Audio 서비스가 중지되었거나 시작에 실패한 경우
  • 관련 서비스(Windows Audio Endpoint Builder)가 함께 중지된 경우
  • 최근 업데이트 이후 서비스 설정이 초기화된 경우
  • 타사 오디오 향상 소프트웨어(이퀄라이저·가상 서라운드 등)가 서비스와 충돌하는 경우

첫 점검 항목

  1. 서비스 상태 확인 — services.msc에서 Windows Audio, Windows Audio Endpoint Builder 서비스 상태와 시작 유형을 확인하세요.
  2. 자동 설정 후 시작 — 두 서비스의 시작 유형을 모두 "자동"으로 바꾸고 시작해보세요. 실패하면 나오는 오류 코드를 기록해두세요(예: 오류 1068은 종속 서비스 실패를 의미).
  3. 종속 서비스 확인 — 오류 1068이 뜬다면 RPC(원격 프로시저 호출)와 Multimedia Class Scheduler 서비스도 함께 실행 중인지 확인하세요.
  4. 오디오 문제 해결사 실행 — 설정에서 오디오 문제 해결사를 실행해보세요.
  5. 명령 프롬프트로 직접 시작 시도 — 관리자 권한 명령 프롬프트에서 net start audiosrv를 실행해 나오는 오류 메시지를 기록하세요.

확인 결과에 따른 다음 단계

  • 서비스 시작 시 "오류 1068"이 뜰 때 — RPC, Multimedia Class Scheduler 서비스가 함께 중지되어 있는지 먼저 확인하고 두 서비스를 자동으로 설정하세요.
  • 서비스는 정상 실행 중인데 소리가 안 날 때 — 서비스 문제가 아니라 오디오 드라이버 문제일 가능성이 크므로 장치 관리자에서 드라이버를 재설치하세요.
  • net start audiosrv에서 접근 거부 오류가 날 때 — 맬웨어나 최적화 프로그램이 관련 레지스트리 권한을 변조했을 가능성이 있으므로 백신 전체 검사를 우선하세요.

데이터와 시스템을 보호하는 주의사항

정확한 원인을 파악하기 전에 초기화나 레지스트리 수정, 시스템 파일 수동 교체부터 시도하지 않는 것이 좋습니다.

앞 단계로 해결되지 않을 때

같은 코드가 반복되면 이벤트 로그와 장치 상태를 보존하고, 코드가 계속 달라지면 메모리·전원·온도처럼 시스템 전체 안정성을 확인하세요.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

자주 묻는 질문

  • 소리가 안 나면 스피커나 이어폰부터 바꿔야 하나요? 이 문제(Windows Audio 서비스 응답 없음)는 장치 자체보다 드라이버나 서비스 문제인 경우가 많으니, 다른 장치로 교차 확인한 뒤에 장치 교체를 고려해도 늦지 않습니다.
  • 서비스가 자동으로 설정해도 계속 꺼지면요? 맬웨어나 타사 최적화 프로그램이 서비스를 강제로 중지시키는 경우가 있으니, 시작 유형을 자동으로 바꾼 뒤에도 반복된다면 백신 검사가 필요합니다.
