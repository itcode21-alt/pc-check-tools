장치 관리자 오류 코드 찾기

장치 관리자에서 노란 느낌표가 붙은 장치의 코드 번호를 고르거나, 여러 장치의 PowerShell 출력을 붙여넣으면 코드별 의미와 먼저 확인할 순서를 정리합니다. 장치의 하드웨어 ID가 있으면 제조사 코드도 읽어 드라이버를 찾는 단서로 보여 줍니다. 모든 처리는 이 브라우저 안에서만 이루어지며 입력한 내용은 전송되지 않습니다.

1. 코드 번호로 찾기

장치 속성 창 일반 탭의 "장치 상태"에 적힌 (코드 43) 같은 숫자를 고르세요.

2. 여러 장치를 붙여넣어 한 번에 보기

예시는 설명용 가상 기록입니다.

요약에는 코드 번호, 장치 이름, 설명 페이지 주소만 들어갑니다. 장치 인스턴스 경로는 포함하지 않습니다.

코드를 확인하는 방법

  1. Windows 키를 누르고 장치 관리자를 입력해 엽니다.
  2. 노란 느낌표(또는 빨간 X)가 붙은 장치를 두 번 클릭합니다. 보이지 않으면 해당 분류 앞의 화살표를 눌러 펼칩니다.
  3. 일반 탭의 장치 상태 칸 끝에 적힌 (코드 숫자)를 확인합니다. 장치 이름도 함께 기록해 두세요.

경고가 붙은 장치가 여러 개라면 PowerShell에서 한 번에 모을 수 있습니다. 아래 명령을 실행해 나온 출력을 위 입력칸에 붙여넣으세요.

Get-CimInstance Win32_PnPEntity | Where-Object { $_.ConfigManagerErrorCode -ne 0 } | Format-List Name, PNPDeviceID, ConfigManagerErrorCode

출력이 없으면 현재 연결된 장치 중 코드가 붙은 장치가 없다는 뜻입니다. 연결을 끊은 장치에 남은 코드(예: 코드 45)는 장치 관리자 화면에서 직접 확인해야 할 수 있습니다. 코드가 확인된 장치는 장치 관리자에서 우클릭해 속성을 열고 장치 이름을 기록해 두세요.

코드를 성격별로 묶어 보기

  • 드라이버 상태: 코드 1, 18, 28, 31, 37, 38, 39 — 드라이버가 없거나 손상됐거나, 시작·초기화에 실패한 경우입니다.
  • 장치를 시작·인식하지 못함: 코드 10, 41, 43, 24 — 장치가 응답하지 않거나 Windows가 장치를 중지시킨 경우입니다.
  • 리소스·설정: 코드 12, 14, 34, 40 — 장치가 쓸 자원이 부족하거나 설정 정보를 읽지 못한 경우입니다. 코드 14는 재시작이 필요하다는 뜻입니다.
  • 비활성화: 코드 22, 29, 32 — 사용자가 끄거나, BIOS/UEFI 또는 드라이버 서비스가 꺼져 있는 경우입니다.
  • 연결 상태: 코드 45 — 연결이 끊긴 장치입니다. 쓰지 않는 장치라면 정상일 수 있습니다.
  • 차단·서명: 코드 48, 52 — 호환성 문제로 막혔거나 드라이버의 디지털 서명을 확인하지 못한 경우입니다.
  • 시스템 정보 손상: 코드 19 — 레지스트리의 장치 정보가 손상된 경우입니다.

자주 찾는 코드 설명: 코드 43 · 코드 45 · 코드 10 · 코드 28 · 코드 31 · 코드 39 · 전체 목록은 장치 관리자 오류 코드 모음에 있습니다.

이 도구의 한계

  • 코드는 Windows가 본 결과를 분류한 번호입니다. 코드만으로 부품 불량을 확정할 수 없고, 같은 코드라도 장치 종류와 드라이버 상태에 따라 원인이 다릅니다.
  • 사이트에 해설이 있는 코드만 설명합니다. 그 밖의 코드는 지어내지 않고 Microsoft 공식 문서 링크로 안내합니다.
  • 제조사 코드는 하드웨어 ID에 적힌 값을 읽어 보여 주는 것이며, 알려진 제조사만 이름을 붙입니다. 모르는 값은 번호만 보여 줍니다. 이 번호와 장치 코드를 제조사 지원 페이지나 장치 제조사에서 검색하면 맞는 드라이버를 찾을 수 있습니다.
  • 이벤트 뷰어의 기록을 함께 보려면 이벤트 로그 붙여넣기 해석기를, 증상과 부품 정보까지 종합 분석하려면 진단 도구를 이용하세요.

자주 묻는 질문

코드가 같으면 원인도 같은가요?

아닙니다. 코드 43이 그래픽카드에서 나올 때와 USB 장치에서 나올 때의 원인은 다릅니다. 코드와 함께 어느 장치인지, 최근 드라이버나 Windows 업데이트가 바뀌었는지를 같이 확인하세요.

드라이버 업데이트 프로그램을 써도 되나요?

첫 단계로는 권하지 않습니다. 장치 이름과 하드웨어 ID로 제조사를 확인한 뒤 PC 또는 부품 제조사의 공식 페이지에서 받는 것이 안전합니다. 코드 설명 페이지의 "먼저 확인할 것" 순서를 따르세요.

붙여넣은 내용이 서버로 전송되나요?

아니요. 이 도구는 브라우저 안에서만 동작하며 입력한 내용을 보내거나 저장하지 않습니다. "지우기"를 누르거나 새로고침하면 화면의 내용도 사라집니다.
