디스플레이

외부 모니터 연결 시 화면 전체 꺼짐 원인과 점검 순서

외부 모니터·TV를 연결하면 노트북 화면과 외부 화면이 모두 꺼지는 경우

외부 모니터를 연결했는데 노트북 화면과 외부 화면이 모두 꺼진다면, 대부분 디스플레이 모드 설정이 원인입니다. Windows가 '두 번째 화면에만 표시' 모드로 전환됐는데 외부 화면이 신호를 받지 못하면 결과적으로 양쪽 다 검은 화면이 됩니다.

Windows 키 + P를 누르면 화면에 나타나지 않아도 디스플레이 모드 선택 메뉴가 뜨는 경우가 많습니다. 방향키와 엔터로 '복제' 또는 '확장'을 선택해 화면이 돌아오는지 먼저 확인하세요.

모드 전환으로 해결되지 않으면 케이블 규격·접촉 불량이나 외부 화면의 입력 소스 설정을 다음으로 확인해야 합니다.

이 가이드가 필요한 상황

  • 외부 모니터를 연결하는 순간 노트북 화면도 함께 꺼진다.
  • 케이블을 뽑으면 노트북 화면은 다시 정상으로 돌아온다.
  • 외부 모니터의 입력 소스가 자동으로 바뀌지 않는다.

먼저 확인할 항목

  1. 디스플레이 모드 재선택 — 화면이 안 보이는 상태에서도 Windows 키 + P를 누르고 방향키+엔터로 '복제'를 선택해보세요.
  2. 외부 화면 입력 소스 확인 — 모니터·TV 리모컨이나 버튼으로 입력 소스를 실제 연결한 포트로 맞추세요.
  3. 케이블·포트 교차 테스트 — 다른 케이블이나 다른 포트로 연결해 비교하세요.
  4. 그래픽 드라이버 업데이트 — 그래픽카드 제조사 홈페이지에서 최신 드라이버로 업데이트하세요.

원인을 더 정확히 나누는 방법

Windows 키 + P가 눈에 안 보여도 동작함

화면이 검게 나온 상태에서도 Windows 키 + P를 누르면 메뉴 자체는 백그라운드에서 뜹니다. 방향키로 첫 번째 옵션으로 이동해 엔터를 누르면 최소한 노트북 화면은 돌아오는 경우가 많습니다.

도킹 스테이션을 쓰는 경우

도킹 스테이션이나 허브를 거쳐 연결한다면 도킹 스테이션 자체의 펌웨어 업데이트나 재연결이 필요할 수 있습니다.

확인 결과에 따른 다음 단계

  • Windows 키 + P로 해결될 때 — 디스플레이 모드 설정이 원인이었으므로 이후 연결 시 모드가 유지되는지 확인하세요.
  • 케이블·포트 교체로 해결될 때 — 정상 작동하는 케이블·포트를 계속 사용하세요.
  • 위 방법으로도 해결되지 않을 때 — 다른 PC나 다른 모니터로 교차 테스트해 출력 포트 자체의 고장 여부를 확인하세요.

피해야 할 실수

  • Windows 키 + P를 시도하지 않고 바로 드라이버를 재설치하는 것
  • 외부 화면의 입력 소스 확인 없이 케이블만 계속 바꿔보는 것

자주 묻는 질문

  • 화면이 안 보이는데 Windows 키 + P가 정말 동작하나요? 네, 방향키 두 번과 엔터로 'PC 화면만'을 선택하면 됩니다.
  • 회의실이나 강의실에서만 문제가 생기면요? 그 장소의 입력 소스나 케이블 문제일 가능성이 높습니다.
  • 도킹 스테이션을 쓰는데 자주 생기면요? 펌웨어를 최신 버전으로 업데이트하거나 직접 연결로 비교해보세요.
