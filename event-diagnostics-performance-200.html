EVENT ID 200

Diagnostics-Performance 이벤트 200 종료 시간 기록 점검

Windows 종료가 끝났을 때 종료에 걸린 시간(Shutdown Duration)을 남기는 기록입니다. 종료가 오래 걸릴 때 201~203 같은 지연 원인 이벤트와 함께 읽습니다.

200은 Windows 종료가 끝났을 때 종료 시간을 남기는 Shutdown Performance Monitoring 이벤트입니다. 201~203은 종료를 지연시킨 앱·장치·서비스를 짚는 이벤트라서, 200의 시간이 길 때 함께 확인합니다.

이 이벤트도 시스템 로그가 아니라 응용 프로그램 및 서비스 로그 > Microsoft > Windows > Diagnostics-Performance > Operational에 남습니다. 100과 같은 로그에서 시작·종료 시간을 나란히 비교하면 한쪽만 느린지 양쪽이 모두 느린지 구분할 수 있습니다.

발생 조건

  • 종료나 재시작 화면이 평소보다 오래 걸림
  • 종료 중 특정 프로그램 때문에 멈춘 것처럼 보임
  • 종료 시간이 점점 길어짐

가능성 높은 원인

  • 종료를 지연시키는 앱·서비스·장치 드라이버
  • 저장장치 쓰기 지연
  • 업데이트 적용이 종료 중에 진행됨

점검 순서

  1. 이벤트의 Shutdown Duration(밀리초) 값을 1000으로 나눠 초로 기록 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 같은 로그의 201~203 이벤트가 어떤 앱·장치·서비스를 지목하는지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 종료 직전에 실행 중이던 프로그램 확인 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 저장장치 이벤트(Disk 153, Ntfs)가 같은 시각에 있는지 확인 — 변경 전후로 증상이 달라지는지 비교해보세요.
  5. 빠른 시작 설정을 바꿔 종료 시간을 비교 — 여기까지 확인해도 해결되지 않으면 다음 원인을 검토하세요.
주의사항

업데이트를 적용하는 종료는 오래 걸리는 것이 정상입니다. 한 번의 값으로 판단하지 마세요.

종료 중 전원을 강제로 끄면 Kernel-Power 41 같은 비정상 종료 기록이 남습니다.

자주 묻는 질문

  • 종료가 느린데 어떤 프로그램 때문인지 알 수 있나요? 201~203 이벤트가 종료를 지연시킨 앱·장치·서비스를 지목하는 경우가 있습니다. 같은 시각의 기록에서 이름을 확인하고, 그 프로그램의 업데이트나 종료 설정을 점검하세요.
  • Shutdown Duration이 몇 초면 문제인가요? 정해진 기준은 없습니다. 이 PC의 평소 값 대비 늘어나는지, 같은 프로그램이 반복해서 지목되는지를 보세요.
