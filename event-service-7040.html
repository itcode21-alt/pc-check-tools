EVENT ID 7040

Service Control Manager 7040 서비스 시작 유형 변경 점검

Windows 서비스의 시작 유형이 변경되었음을 기록합니다. Windows 업데이트·드라이버 설치·관리 도구로도 발생할 수 있어 변경 주체와 실제 기능 장애를 함께 확인해야 합니다.

7040은 서비스의 시작 유형이 바뀌었다는 구성 변경 기록입니다. 오류가 아니며 업데이트, 드라이버 설치, 관리 도구로도 남습니다.

이벤트에서 서비스 이름과 이전·새 시작 유형을 확인하고, 변경 시각의 설치·업데이트 기록과 맞춰 보세요. 필요한 기능이 꺼졌다면 그 서비스만 원래 상태로 되돌리고, 전부 자동으로 바꾸지는 마세요.

발생 조건

  • 드라이버·보안 프로그램 설치 또는 업데이트 뒤
  • 서비스가 자동·수동·사용 안 함으로 바뀐 뒤
  • 부팅 후 특정 기능이 동작하지 않음

가능성 높은 원인

  • 정상적인 프로그램·드라이버 설치
  • Windows 구성 요소 업데이트
  • 클린 부팅이나 사용자의 서비스 설정 변경
  • 원치 않는 프로그램이 보안·업데이트 서비스를 끄는 경우

점검 순서

  1. 이벤트의 서비스 이름과 이전·새 시작 유형 기록 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 변경 시각의 설치 기록·Windows Update·보안 이벤트 비교 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 서비스가 실제로 필요한 기능과 연결되는지 확인 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 예상하지 못한 보안 서비스 변경이면 Defender 상태와 최근 설치 프로그램을 점검 — 변경 전후로 증상이 달라지는지 비교해보세요.
주의사항

7040은 오류가 아닌 구성 변경 기록입니다. 모든 서비스를 자동 시작으로 되돌리면 부팅 지연이나 충돌이 생길 수 있습니다.

관련 코드·가이드

0x80070422 오류 코드 확인하기관련 가이드 보기앱 실행 불가 가이드

자주 묻는 질문

  • 시작 유형이 자동에서 수동으로 바뀌었는데 문제인가요? Windows 구성 요소나 프로그램이 정상적으로 바꾸는 경우도 많습니다. 해당 기능이 실제로 안 될 때만 되돌리세요.
  • 보안 관련 서비스가 꺼졌다면요? 예상하지 못한 변경이면 Windows 보안 상태와 최근 설치 프로그램을 확인하고 검사하세요.
