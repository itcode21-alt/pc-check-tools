📑 목차

에러 코드 상세

0x80070490 · 요소를 찾을 수 없음 (네트워크 어댑터)

네트워크 설정을 변경하거나 어댑터 정보를 읽으려 할 때 시스템이 참조하려는 구성 요소를 찾지 못해 나타나는 오류입니다. 네트워크 어댑터 드라이버나 프로토콜 스택 손상과 관련이 깊습니다.

이 코드를 어떻게 해석해야 하나요?

이런 업데이트 오류 코드는 네트워크·캐시·구성 요소 저장소·디스크 공간·서비스 상태 가운데 어느 지점에서 문제가 생겼는지 알려주는 단서입니다. 반복되는 시점과 이벤트 로그의 세부 코드를 함께 확인하세요.

먼저 기록할 내용: 0x80070490가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 네트워크 어댑터 드라이버가 일부 손상된 경우
  • TCP/IP 프로토콜 스택 구성이 손상된 경우
  • 최근 네트워크 관련 업데이트 이후 설정 값이 꼬인 경우
  • 네트워크 어댑터를 물리적으로 제거했다가 다시 연결한 뒤 잔여 구성이 남은 경우
  • 타사 VPN 클라이언트가 설치한 가상 어댑터와의 충돌

첫 점검 항목

  1. 명령 프롬프트(관리자)에서 netsh winsock reset 명령으로 네트워크 스택을 초기화하세요.
  2. 이어서 netsh int ip reset 명령으로 TCP/IP 설정을 초기화한 뒤 재부팅하세요.
  3. 장치 관리자에서 네트워크 어댑터를 제거한 뒤 재부팅해 자동으로 재설치되게 하세요.
  4. 최근 설치한 VPN 클라이언트가 있다면 제거 후 재현 여부를 확인하세요.
  5. 네트워크 어댑터 드라이버를 제조사 최신 버전으로 재설치하세요.

확인 결과에 따른 다음 단계

  • winsock·TCP/IP 초기화로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • 어댑터 재설치로 해결될 때 — 재발 여부만 지켜보면 됩니다.
  • VPN 제거로도 해결되지 않을 때 — 드라이버 재설치로 넘어가세요.

데이터와 시스템을 보호하는 주의사항

레지스트리 정리 도구를 쓰거나 시스템 폴더 권한을 바꾸기 전에, 저장 공간과 네트워크, 서비스 상태부터 점검하는 것이 우선입니다.

앞 단계로 해결되지 않을 때

코드가 재발할 경우 Windows Update 기록과 DISM·SFC 결과를 기록해 두고, 설치 미디어의 Windows 버전이 현재 시스템과 일치하는지 확인해보세요.

작업이 잘못됐을 때 되돌릴 수 없는 경우가 많으니, 복구나 초기화, 드라이버 제거에 앞서 중요 파일을 다른 물리 저장장치에 먼저 복사해 두세요.

관련 증상 가이드 확인하기

같은 증상과 연결된 다른 오류 코드

  • 0x800704CF · 이 네트워크에 연결되어 있지 않습니다
  • 0x80070718 · IP 주소를 가져올 수 없음
  • 0x80070102 · 네트워크 장치가 연결되지 않음
  • 배틀넷 연결 오류 · 배틀넷 오류로 오버워치 등이 실행되지 않음 (BLZBNTBNA0000)

자주 묻는 질문

  • 공유기를 바꾸면 해결되나요? 이 문제(0x80070490)는 공유기 자체 문제보다 어댑터 드라이버나 전원 관리 설정이 원인인 경우가 많아, 장비 교체 전에 드라이버 업데이트와 절전 설정부터 확인해보세요.
  • 무선랜 어댑터의 절전 설정을 꺼야 하나요? 네, 전원 관리에서 무선랜 어댑터의 절전 기능을 꺼두면 백그라운드에서 연결이 끊기는 현상을 줄일 수 있습니다.
  • netsh 명령을 실행해도 안전한가요? winsock reset과 ip reset은 네트워크 설정만 초기화하는 안전한 명령이며, 실행 후 재부팅하면 정상적으로 적용됩니다.
