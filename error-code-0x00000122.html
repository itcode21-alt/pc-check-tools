에러 코드 상세

0x00000122 · WHEA_INTERNAL_ERROR

하드웨어 오류 보고를 처리하는 과정에서 내부 실패가 난 것으로, 이벤트 뷰어의 WHEA 기록으로 원인 장치를 좁혀야 하는 코드입니다.

이 코드를 어떻게 해석해야 하나요?

이 계열은 CPU, 메모리, PCIe 장치, 메인보드 전원 또는 냉각처럼 시스템 안정성에 영향을 주는 영역에서 나타날 수 있습니다. 코드 하나로 부품을 확정하지 말고 기본 클럭 상태와 발생 작업을 비교해야 합니다.

먼저 기록할 내용: 0x00000122가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • CPU나 메모리 컨트롤러의 오류가 보고된 경우
  • 그래픽카드·NVMe 등 PCIe 장치의 연결 불안정이나 전송 오류
  • 오버클럭이나 전압 설정이 안정성 한계를 넘은 경우
  • 칩셋·저장장치 드라이버와 BIOS의 WHEA 관련 설정이 맞지 않는 경우
  • 메모리 불량이나 XMP 설정으로 인한 불안정

첫 점검 항목

  1. 이벤트 뷰어의 시스템 로그에서 WHEA-Logger 항목을 찾아 장치 정보와 발생 시각을 기록하세요. <a href="event-whea-logger-17.html">WHEA-Logger 17 가이드 보기 →</a> — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. CPU·메모리·그래픽 오버클럭과 XMP를 끄고 BIOS 기본값으로 되돌려 재현 여부를 확인하세요. — 첫 확인 결과와 비교해 소프트웨어와 하드웨어 가능성을 나눕니다.
  3. 그래픽카드와 NVMe 장치의 연결 상태를 확인하고, 장치를 뺐다가 다시 꽂은 뒤 재현 여부를 보세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.
  4. 칩셋과 그래픽 드라이버를 제조사 공식 버전으로 맞추고, 최근 업데이트 직후 시작됐다면 이전 버전과 비교하세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.
  5. 메모리 검사를 실행하고, 같은 장치에서 WHEA 기록이 반복되면 해당 장치를 중심으로 추가 점검하세요. — 앞 단계에서 해결되지 않을 때 다음 원인 후보를 검증합니다.

데이터와 시스템을 보호하는 주의사항

오버클럭과 XMP·EXPO를 기본값으로 되돌리고, 과열·타는 냄새·반복 재부팅이 있으면 장시간 부하 테스트를 중단하세요.

앞 단계로 해결되지 않을 때

기본 설정에서도 반복되면 온도와 WHEA 이벤트를 기록한 뒤 CPU, RAM, GPU를 한 번에 바꾸지 말고 한 영역씩 교차 점검하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

상세 해설

WHEA 오류는 코드 하나만으로 CPU가 고장 났다고 판단할 수 없습니다. 같은 시각의 WHEA-Logger 기록에 어느 장치에서 오류가 올라왔는지가 남아 있으므로, 그 장치를 중심으로 범위를 좁히는 것이 핵심입니다. 오버클럭을 끈 상태에서 재발하지 않으면 설정 문제일 가능성이 높고, 기본값에서도 반복되면 장치 연결과 메모리 점검을 이어서 진행하세요.

자주 묻는 질문

  • 0x122가 나오면 CPU가 고장 난 건가요? 아닙니다. WHEA 오류는 CPU뿐 아니라 메모리, 그래픽카드, 저장장치 등 여러 장치에서 올라올 수 있습니다. 이벤트 뷰어 기록의 장치 정보를 먼저 확인하세요.
  • 이벤트 뷰어에 WHEA 기록이 없으면 어떻게 하나요? 덤프 파일의 정지 코드 매개변수를 확인하고, 드라이버 충돌과 메모리 검사를 함께 진행하세요.
