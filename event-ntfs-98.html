EVENT ID 98

Ntfs 이벤트 98 볼륨 정상 상태 확인 기록

볼륨을 검사한 결과 파일 시스템이 정상(healthy)이며 조치가 필요 없음을 기록합니다.

Ntfs 98은 'Volume … is healthy. No action is needed.'로 남는 기록으로, NTFS가 볼륨을 점검해 파일 시스템에 문제가 없다고 판단했다는 뜻입니다. 저장장치 오류를 조사할 때 파일 시스템 쪽은 이상이 없다는 근거로 참고할 수 있습니다.

이 기록은 파일 시스템 수준의 정상 확인이라 디스크의 물리적 상태(불량 섹터, 수명)는 알려 주지 않습니다. 디스크 이상이 의심되면 CrystalDiskInfo의 SMART 값과 Disk 7·11·153 같은 이벤트를 함께 확인하세요.

발생 조건

  • Windows가 볼륨 상태를 주기적으로 확인할 때
  • 부팅·마운트 때

가능성 높은 원인

  • 정상 상태 확인 기록

점검 순서

  1. CorruptionAction 값 확인(정상이면 조치 없음) — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. 같은 볼륨에서 Ntfs 55·98 외의 오류가 있는지 확인 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 저장장치 오류가 의심될 때 이 기록이 있는 볼륨은 파일 시스템 오류 가능성이 낮다는 참고로 사용 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
주의사항

정상 기록입니다. 이 이벤트가 있다고 해서 물리적 디스크 상태까지 보증하지는 않으니 SMART도 함께 확인하세요.

자주 묻는 질문

  • Ntfs 98이 있으면 디스크가 정상인가요? 파일 시스템은 정상이라는 뜻입니다. 물리적 디스크 상태까지는 알 수 없으므로 SMART 확인이 별도로 필요합니다.
  • 몇 번씩 반복돼도 괜찮나요? 볼륨을 확인할 때마다 남는 기록이라 반복돼도 정상입니다.
