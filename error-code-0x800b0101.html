에러 코드 상세

0x800B0101 · 인증서 유효 기간 오류

업데이트 파일의 인증서가 만료됐거나 시스템 시간이 잘못되어 서명 검증에 실패할 때 나타날 수 있습니다.

Windows Update나 설치 패키지의 서명 인증서를 확인하는 과정에서 인증서가 현재 시스템 시간 기준으로 유효하지 않다고 판단될 때 나타날 수 있는 오류입니다. 날짜·시간 오류와 인증서 구성 문제를 구분해야 합니다.

이 코드를 어떻게 해석해야 하나요?

오류 코드는 고장 부품을 확정하는 판정이 아니라 발생 시점과 함께 원인 범위를 좁히는 단서입니다. 최근 변경, 반복 조건, 안전 모드 재현 여부를 함께 기록하세요.

먼저 기록할 내용: 0x800B0101가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • PC의 날짜·시간 또는 시간대가 실제 시간과 크게 다른 경우
  • 업데이트 패키지 서명 인증서가 만료되었거나 신뢰 체인이 완성되지 않은 경우
  • 오래된 Windows에서 루트 인증서 업데이트가 누락된 경우
  • WSUS·프록시·보안 프로그램이 HTTPS 연결을 중간에서 검사하면서 인증서 신뢰가 깨진 경우

첫 점검 항목

  1. 설정의 날짜 및 시간에서 자동 시간 설정과 시간대를 확인한 뒤 지금 동기화를 실행하세요.
  2. 다른 HTTPS 사이트가 정상적으로 열리는지 확인해 PC 시간 문제와 서버 연결 문제를 구분하세요.
  3. 회사·학교 PC라면 WSUS 또는 보안 프록시의 인증서 정책을 관리자에게 확인하세요.
  4. Windows Update 로그에서 인증서·서명 검증 실패가 같은 시각에 반복되는지 확인하세요.
  5. TLS를 낮추거나 인증서 검사를 무시하지 말고 Windows와 보안 구성 요소를 최신 상태로 유지하세요.

데이터와 시스템을 보호하는 주의사항

원인이 확인되지 않은 상태에서 초기화, 레지스트리 수정, 시스템 파일 수동 교체를 먼저 진행하지 마세요.

앞 단계로 해결되지 않을 때

같은 코드가 반복되면 이벤트 로그와 장치 상태를 보존하고, 코드가 계속 달라지면 메모리·전원·온도처럼 시스템 전체 안정성을 확인하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

자주 묻는 질문

  • 블루스크린 코드가 한 번 떴는데 계속 지켜봐야 하나요? 이 문제(0x800B0101)가 한 번만 발생했다면 즉시 부품을 교체하기보다 재현 여부와 최근 변경 사항을 먼저 기록해두는 것으로 충분합니다. 반복된다면 그때 하드웨어 점검 범위를 넓히세요.
  • 덤프 파일은 어디서 확인하나요? C:\Windows\Minidump 폴더에 저장되며, BlueScreenView 같은 도구로 열어 정지 코드와 관련 드라이버를 확인할 수 있습니다.
