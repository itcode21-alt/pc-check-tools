0x80070057 · 매개 변수가 올바르지 않음

Windows 시스템 오류 87(ERROR_INVALID_PARAMETER)로 '매개 변수가 올바르지 않다'는 코드입니다. Microsoft 지원 문서는 업데이트에서 파일 손상·권한·잘못된 시스템 구성이 원인일 수 있다고 안내합니다.

0x80070057은 ERROR_INVALID_PARAMETER에 해당하는 코드로, 설치·업데이트·명령 실행에서 받은 값이 올바르지 않을 때 나옵니다. Windows Update에서는 Microsoft 지원 문서가 손상된 파일, 권한 문제, 잘못된 시스템 구성을 원인으로 설명합니다.

이 코드를 어떻게 해석해야 하나요?

Windows 시스템 오류 코드에서 0x80070057은 매개 변수가 올바르지 않다는 뜻으로 정의됩니다. Microsoft의 업데이트 문제 해결 문서는 이 코드를 손상된 파일, 권한 문제, 잘못된 시스템 구성으로 설명하고, 관리자 권한 명령 프롬프트에서 sfc /scannow를 실행한 뒤 Windows Update 문제 해결사를 실행하라고 안내합니다. Windows 10 문서는 PC 재시작, 문제 해결사, 디스크 여유 공간(32비트 16GB, 64비트 20GB) 확인을 안내합니다. 디스크 파티션 형식이나 설치 미디어 설정은 설치·복원 작업에서 쓰이는 문서 외 일반 점검입니다.

가능성 높은 원인

  • 업데이트 구성 파일이나 레지스트리 값이 손상된 경우
  • 디스크 파티션 형식(MBR/GPT)이 설치 방식과 맞지 않는 경우
  • USB 설치 미디어 제작 시 파일 시스템(FAT32/NTFS) 설정이 잘못된 경우
  • 그룹 정책에서 지원하지 않는 옵션을 강제로 지정한 경우
  • 백업/복원 도구에서 지정한 경로나 옵션 형식이 맞지 않는 경우

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 관리자 권한 명령 프롬프트에서 sfc /scannow를 실행하세요. 손상된 파일이 복구되면 파일 손상이 원인이었습니다.
  2. 공식 문서가 알려 주는 것: 설정 > 시스템 > 문제 해결 > 기타 문제 해결사에서 Windows Update 문제 해결사를 실행하세요.
  3. 공식 문서가 알려 주는 것(Windows 10): PC를 다시 시작하고 디스크 여유 공간이 32비트 16GB, 64비트 20GB 이상인지 확인하세요.
  4. 문서 외 일반 점검: 설치나 복원 작업에서 나왔다면 대상 디스크의 파티션 형식(MBR/GPT)이 설치 방식(UEFI/레거시)과 맞는지 확인하고, 설치 미디어는 공식 생성 도구로 새로 만드세요.
  5. 문서 외 일반 점검: 명령어를 직접 입력하는 작업이었다면 옵션 철자와 형식을 다시 확인하고, 최근 바꾼 정책 설정은 기본값으로 되돌려 보세요.

확인 결과에 따른 다음 단계

  • 파티션 형식 문제로 확인될 때 — 디스크 관리에서 디스크 형식을 확인하세요. UEFI 부팅이면 GPT, 레거시(BIOS) 부팅이면 MBR이어야 합니다. 형식을 바꾸면 데이터가 지워지므로 백업 후 진행하세요.
  • SoftwareDistribution 정리로 해결될 때 — 서비스를 멈춘 뒤 SoftwareDistribution 폴더 이름을 바꾸고 서비스를 다시 시작해 업데이트를 재시도하세요.
  • 명령어 옵션 문제였을 때 — 명령 뒤에 /?를 붙여 실행하면 옵션 설명이 나옵니다. 설명에 맞게 옵션과 따옴표, 공백을 다시 확인해 입력하세요.

데이터와 시스템을 보호하는 주의사항

레지스트리 정리 도구나 시스템 폴더 권한 변경은 마지막 수단으로 남겨두고, 저장 공간과 네트워크, 서비스 상태부터 확인해보세요.

앞 단계로 해결되지 않을 때

같은 코드가 반복되면 Windows Update 기록과 DISM·SFC 결과를 저장하고 설치 미디어의 버전이 현재 Windows와 맞는지 확인하세요.

되돌리기 어려운 조치(복구, 초기화, 드라이버 제거 등)에 들어가기 전에는 반드시 중요 데이터를 다른 저장장치로 옮겨 두는 것이 안전합니다.

자주 묻는 질문

  • 0x80070057은 무슨 뜻인가요? Windows 시스템 오류 87, 즉 매개 변수가 올바르지 않다는 뜻입니다. 코드가 나온 작업(업데이트, 설치, 백업 등)에 따라 원인이 다르므로 어떤 작업에서 나왔는지부터 구분하세요.
  • 업데이트에서 0x80070057이 나오면 무엇부터 하나요? Microsoft 지원 문서는 sfc /scannow와 Windows Update 문제 해결사 실행을 안내합니다. Windows 10에서는 PC 재시작과 디스크 여유 공간 확인도 안내합니다.
