    마우스·키보드 인식 안됨 원인과 점검 순서

    마우스나 키보드가 갑자기 작동하지 않거나, 부팅 후 인식되지 않는 경우

    키보드·마우스 미인식 문제는 USB 포트 불량, 드라이버 충돌, Windows HID 서비스 오류, 또는 하드웨어 자체 결함 중 하나인 경우가 대부분입니다. 증상이 시작된 시점(업데이트 이후인지, 포트 교체 이후인지)을 먼저 떠올리면 원인을 빠르게 좁힐 수 있습니다.

    일부 경우는 절전 모드 복귀 이후 USB 포트 전원이 제대로 공급되지 않아 발생합니다. 장치 관리자에서 USB 루트 허브의 절전 설정을 끄면 해결되는 경우가 많습니다.

    무선 기기라면 배터리와 수신기 연결 상태를 먼저 확인하세요.

    이 가이드가 필요한 상황

    • 업데이트 직후 키보드·마우스가 모두 인식되지 않는다.
    • 재부팅 후에는 잠깐 인식됐다가 다시 연결이 끊어진다.
    • 특정 USB 포트에 꽂았을 때만 인식된다.

    먼저 확인할 항목

    1. 다른 USB 포트로 연결 — 특정 포트의 전원 공급 문제나 물리적 결함일 수 있습니다. USB 허브를 경유하지 않고 PC 본체 후면 포트에 직접 연결해 보세요.
    2. 다른 PC에서 동작 확인 — 장치 자체 고장인지 PC 설정 문제인지 구분할 수 있습니다. 키보드·마우스를 다른 PC에 연결해 정상 동작하면 드라이버·설정 문제, 안 되면 장치 교체를 고려합니다.
    3. 장치 관리자에서 드라이버 재설치 — HID 장치 드라이버가 손상되면 인식에 실패합니다. 장치 관리자 → 휴먼 인터페이스 장치 항목에서 키보드·마우스를 제거한 뒤 장치 검색을 실행합니다.
    4. USB 루트 허브 절전 해제 — 절전 복귀 후 USB 포트 전원이 꺼진 채 유지될 수 있습니다. 장치 관리자 → 범용 직렬 버스 컨트롤러 → USB 루트 허브 → 속성 → 전원 관리에서 '절전을 위해 컴퓨터가 이 장치를 끌 수 있음'을 해제합니다.

    원인을 더 정확히 나누는 방법

    부팅 시 BIOS에서는 인식될 때

    BIOS 화면에서는 키보드가 작동하지만 Windows 진입 후 안 된다면 드라이버 또는 HID 서비스 문제입니다. 안전 모드로 진입해 장치 관리자를 확인하세요.

    Bluetooth 장치 연결 불안정

    Bluetooth 키보드·마우스는 드라이버 외에 Bluetooth 어댑터 펌웨어 문제나 다른 장치와의 주파수 충돌로 끊기는 경우가 있습니다. 2.4GHz 무선 장치와 같이 사용 중이라면 USB 수신기 위치를 바꿔 보세요.

    확인 결과에 따른 다음 단계

    • 드라이버 재설치 후 해결될 때 — HID 드라이버 손상이 원인이었습니다. 이후 업데이트 이후 재발 시 같은 방법으로 해결 가능합니다.
    • 다른 PC에서도 인식 안 될 때 — 장치 자체 고장입니다. 보증 기간 내라면 교체 요청, 아니라면 새 장치를 구매하는 것이 빠릅니다.

    피해야 할 실수

    • 드라이버 확인 없이 새 장치부터 구매하는 것
    • USB 허브 경유 연결 상태에서 포트 불량으로 단정하는 것

    자주 묻는 질문

    • BIOS에서는 키보드가 작동하는데 Windows에서는 안 됩니다. 드라이버 또는 HID 서비스 문제일 가능성이 높습니다. 안전 모드로 진입해 장치 관리자에서 HID 장치 드라이버를 재설치하세요.
    • 무선 마우스인데 수신기가 꽂혀 있어도 안 됩니다. 배터리를 먼저 교체하고, 수신기를 뽑았다가 다시 꽂아 보세요. 수신기 자체 불량이라면 제조사에서 수신기만 별도 구입할 수 있습니다.
