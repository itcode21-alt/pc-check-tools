에러 코드 상세

0x800F0831 · Windows 구성 요소 저장소 손상

Microsoft 문서에서 CBS_E_STORE_CORRUPTION, 즉 Windows 구성 요소 저장소가 손상되었다는 코드입니다. 필요한 패키지가 없거나 레지스트리에 완전히 적용되지 않았을 때 나타납니다.

이 코드를 어떻게 해석해야 하나요?

Microsoft의 0x800F0831 문서는 이 오류가 구성 요소 저장소 손상을 뜻하며, 필요한 패키지가 저장소에 없거나 레지스트리에 완전히 적용되지 않았을 때 생긴다고 설명합니다. CBS.log(C:\Windows\Logs\CBS)에서 'Store corruption, manifest missing for package'와 HRESULT 0x800f0831 항목으로 확인할 수 있습니다. 물리 PC의 해결 방법은 문제의 업데이트를 Microsoft 업데이트 카탈로그에서 새로 받아 DISM으로 제거한 뒤 다시 설치하는 것이며, 작업 전에 운영 체제 디스크를 백업하라고 안내합니다.

가능성 높은 원인

  • 이전 업데이트가 중간에 중단되어 필요한 패키지가 완전히 적용되지 않은 경우
  • WinSxS 구성 요소 저장소의 매니페스트나 패키지 정보가 손상된 경우
  • 현재 Windows 빌드와 맞지 않는 설치 미디어를 복구 원본으로 사용한 경우
  • 보안 프로그램이나 정리 도구가 업데이트 구성 요소 파일을 격리·삭제한 경우

첫 점검 항목

  1. 공식 문서가 알려 주는 것: 작업 전에 운영 체제 디스크를 백업하세요. 이후 단계는 패키지를 제거·재설치하는 작업입니다.
  2. 공식 문서가 알려 주는 것: 설정의 Windows Update 기록과 C:\Windows\Logs\CBS\CBS.log에서 실패한 업데이트의 KB 번호를 확인하세요. 로그에는 'Failed to resolve package ... CBS_E_STORE_CORRUPTION'처럼 패키지 이름이 남습니다.
  3. 공식 문서가 알려 주는 것: 먼저 DISM.exe /Online /Cleanup-image /Restorehealth와 sfc /scannow로 손상을 복구한 뒤 업데이트를 다시 시도하세요(관리자 권한 명령 프롬프트).
  4. 공식 문서가 알려 주는 것: 해결되지 않으면 Microsoft 업데이트 카탈로그에서 해당 KB를 Windows 버전과 아키텍처에 맞게 받아 C:\temp에 두고 expand -F:* <패키지명>.msu C:\temp로 풀어 .cab 파일을 찾으세요.
  5. 공식 문서가 알려 주는 것: 업데이트가 일부 설치된 것 같으면 Dism /online /remove-package /packagepath:C:\temp\<CabFileName>.cab으로 제거하고 재부팅하세요. 이어서 Dism /online /add-package /packagepath:C:\temp\<CabFileName>.cab으로 설치한 뒤 재부팅하고 업데이트나 기능을 다시 설치하세요.
  6. Azure 가상 머신이라면 Microsoft는 인플레이스 업그레이드를 강하게 권합니다(Azure VM 해당).

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한 변경이나 레지스트리 정리 도구 사용보다 저장 공간, 네트워크, 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

같은 코드가 반복되면 Windows Update 기록과 DISM·SFC 결과를 저장하고 설치 미디어의 버전이 현재 Windows와 맞는지 확인하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

자주 묻는 질문

  • 0x800F0831은 디스크가 고장 났다는 뜻인가요? Microsoft 문서는 구성 요소 저장소 손상, 즉 필요한 패키지가 없거나 레지스트리에 완전히 적용되지 않은 상태로 설명합니다. 디스크 고장을 직접 말하지는 않습니다.
  • 패키지를 제거했다가 설치해도 괜찮나요? Microsoft 문서는 물리 PC의 해결 방법으로 업데이트를 제거하고 다시 설치하는 절차를 안내하며, 작업 전에 운영 체제 디스크를 백업하라고 강조합니다. DISM 명령을 직접 다루기 어렵다면 전문가에게 맡기세요.
