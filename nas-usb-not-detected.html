    하드웨어

    NAS에 연결한 외장하드가 인식 안 됨 원인과 점검 순서

    NAS의 USB 포트에 외장하드나 USB 메모리를 연결해도 저장소 관리자에 나타나지 않는 경우

    NAS의 USB 포트는 외장하드 백업이나 USB Copy 기능에 흔히 쓰이는데, 연결해도 저장소 관리자나 File Station에 나타나지 않는 경우가 있습니다. 가장 흔한 원인은 파일 시스템 미지원(특히 exFAT)이고, 그다음으로 흔한 것은 전원이 부족한 연결 경로(무전원 허브, 전면 포트)입니다.

    DSM은 Btrfs, ext4, FAT/FAT32, exFAT(별도 패키지 필요), NTFS, HFS+ 등을 지원하지만, 일부는 읽기 전용으로만 지원되거나 패키지를 추가로 설치해야 합니다.

    이 가이드가 필요한 상황

    • 외장하드를 연결해도 저장소 관리자나 File Station에 아무것도 나타나지 않는다.
    • 장치는 인식되는데(제어판 → 외부 장치) 파티션·파일에는 접근이 안 된다.
    • USB Copy 버튼을 눌러도 아무 반응이 없다.

    먼저 확인할 항목

    1. 파일 시스템 확인·exFAT 패키지 설치 — PC에서 외장하드의 포맷을 먼저 확인하고, exFAT이라면 패키지 센터에서 'exFAT Access'를 설치하세요.
    2. 연결 위치 변경 — 허브를 거치지 말고 NAS 후면의 USB 포트에 직접 연결하세요. 자체 전원이 있는 외장하드라면 어댑터를 연결한 상태로 시도하세요.
    3. 장치 인식 여부와 파티션 인식 여부 구분 — 제어판 → 외부 장치(External Devices)에서 장치 목록에 나타나는지 먼저 확인하세요. 나타난다면 파일 시스템 문제, 안 나타난다면 연결·전원 문제일 가능성이 큽니다.
    4. 다른 포트·다른 PC에서 교차 확인 — 같은 외장하드를 PC에 연결해 정상 인식되는지 확인하고, NAS의 다른 USB 포트에도 연결해보세요.

    원인을 더 정확히 나누는 방법

    왜 exFAT은 기본 지원이 안 되나요

    exFAT은 마이크로소프트의 특허 기술이라 시놀로지가 별도 라이선스 패키지(exFAT Access)로 제공합니다. Windows에서 포맷한 대용량 USB 메모리나 외장하드는 exFAT인 경우가 많아 이 패키지 설치가 필요한 경우가 흔합니다.

    NTFS 외장하드는 쓰기가 되나요

    DSM은 NTFS를 지원하지만 일부 구성에서는 읽기 전용으로 동작할 수 있습니다. 데이터를 자주 쓰기·수정할 계획이라면 처음부터 NAS와 궁합이 좋은 파일 시스템(exFAT+패키지, 또는 ext4)으로 포맷하는 것을 고려하세요.

    확인 결과에 따른 다음 단계

    • exFAT 패키지 설치 후 인식될 때 — 파일 시스템 미지원이 원인이었던 것입니다. 앞으로 새 외장하드를 NAS용으로 쓸 계획이라면 포맷 시점부터 이 점을 고려하세요.
    • 포트를 바꿔도 장치 자체가 안 잡힐 때 — 외장하드 또는 케이블 자체의 고장일 가능성이 큽니다. PC에 연결해 정상 인식되는지 먼저 확인하세요.

    자주 묻는 질문

    • exFAT Access 패키지는 무료인가요? 모델과 시기에 따라 다를 수 있어 패키지 센터에서 정확한 가격 정책을 확인해야 합니다. 유료인 경우가 많으므로, 자주 쓸 계획이 아니라면 NAS에서 직접 포맷(ext4 등)하는 것도 대안입니다.
    • 장치 관리자에는 나오는데 파일이 안 보입니다. 장치는 인식됐지만 파일 시스템을 DSM이 읽지 못하는 상태입니다. exFAT이라면 패키지를 설치하고, 그래도 안 되면 파티션 방식(GPT/MBR)이나 포맷 손상 여부를 PC에서 먼저 확인하세요.
