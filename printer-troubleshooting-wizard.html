프린터 오류 해결 마법사

프린터가 오프라인이거나 인쇄가 멈췄을 때, 증상을 고르면 원인에 맞는 해결 순서를 한 단계씩 안내합니다. 어디서부터 손대야 할지 모르겠을 때 질문에 답하며 따라가 보세요. 선택한 내용은 이 브라우저 안에서만 쓰입니다.

USB 프린터가 오프라인일 때

프린터 자체보다 대기열 설정이나 스풀러 상태 때문에 오프라인으로 표시되는 경우가 많습니다.

  1. 프린터 전원을 끄고 1분쯤 기다렸다가 다시 켭니다. USB 케이블을 뽑았다 다시 꽂고, USB 허브를 쓰고 있다면 PC 본체의 포트에 직접 연결합니다.
  2. '설정 > Bluetooth 및 장치 > 프린터 및 스캐너 (Windows 10은 설정 > 장치 > 프린터 및 스캐너)'에서 프린터를 선택하고 '인쇄 대기열 열기'를 누른 뒤 위쪽 '프린터' 메뉴에서 '오프라인으로 프린터 사용'과 '인쇄 일시 중지'가 체크돼 있으면 해제합니다.
  3. 대기열에 남은 문서가 있으면 모두 취소합니다.
  4. Win+R → services.msc → 목록에서 Print Spooler를 찾아 우클릭 → '다시 시작'합니다.
  5. 그래도 오프라인이면 프린터를 제거한 뒤 제조사 홈페이지의 최신 드라이버로 다시 설치합니다. 윈도우 기본 드라이버로 잡히는 모델은 제조사 패키지가 필요할 수 있습니다.

네트워크(Wi-Fi·LAN) 프린터가 오프라인일 때

프린터의 IP 주소가 바뀌었거나 공유기와의 연결이 끊긴 경우가 흔합니다.

  1. 프린터 전원을 껐다 켠 뒤 프린터 화면(또는 설정 메뉴)에서 Wi-Fi 연결 상태와 IP 주소를 확인합니다.
  2. PC와 프린터가 같은 공유기(같은 네트워크)에 연결돼 있는지 확인합니다. 게스트 Wi-Fi나 2.4GHz·5GHz 분리 환경이면 프린터가 붙은 쪽에 PC도 맞춥니다.
  3. 프린터 속성의 '포트' 탭에서 윈도우가 쓰는 IP와 프린터가 지금 쓰는 IP를 비교합니다. 다르면 '포트 구성'에서 IP를 바꿔 줍니다. 재발을 막으려면 공유기에서 프린터 IP를 고정(DHCP 예약)해 두세요.
  4. '설정 > Bluetooth 및 장치 > 프린터 및 스캐너 (Windows 10은 설정 > 장치 > 프린터 및 스캐너)'에서 프린터를 선택하고 '인쇄 대기열 열기'를 누른 뒤 위쪽 '프린터' 메뉴에서 '오프라인으로 프린터 사용'과 '인쇄 일시 중지'가 체크돼 있으면 해제합니다.
  5. Win+R → services.msc → 목록에서 Print Spooler를 찾아 우클릭 → '다시 시작'합니다.
  6. 계속 안 되면 프린터를 제거하고 '원하는 프린터가 목록에 없습니다' → 'TCP/IP 주소 또는 호스트 이름으로 프린터 추가'로 IP를 직접 입력해 다시 추가합니다.

인쇄 대기열이 걸려서 아무것도 안 나갈 때

대기열에 손상된 작업이 남아 있으면 뒤따르는 문서도 모두 막힙니다. 작업 파일을 비우면 대부분 풀립니다.

  1. 프린터 전원을 끄고 60초 이상 기다렸다가 켠 뒤 PC도 한 번 재시작합니다. 이것만으로 풀리는 경우가 많습니다.
  2. '설정 > Bluetooth 및 장치 > 프린터 및 스캐너 (Windows 10은 설정 > 장치 > 프린터 및 스캐너)'에서 프린터의 인쇄 대기열을 열고 남은 문서를 모두 취소합니다. 취소가 안 되고 계속 남아 있다면 다음 단계로 갑니다.
  3. 관리자 권한으로 명령 프롬프트를 열어 아래 세 줄을 순서대로 실행합니다. 스풀러를 멈추고 작업 파일을 비운 뒤 다시 시작하는 명령입니다.
  4. PRINTERS 폴더 안의 파일만 지우는 명령이며 폴더 자체를 삭제하면 안 됩니다. 실행 후 프린터를 다시 인쇄해 봅니다.

관리자 권한 명령 프롬프트에서 실행:

net stop spooler
del /Q /F /S "%systemroot%\System32\spool\PRINTERS\*.*"
net start spooler

특정 문서 하나만 인쇄가 안 될 때

프린터나 윈도우 문제가 아니라 그 문서의 인쇄 데이터가 문제일 수 있습니다.

  1. 같은 프린터로 다른 문서(예: 메모장에 글자 몇 줄)를 인쇄해 봅니다. 그것이 나가면 프린터는 정상이고 문서가 원인입니다.
  2. 문제 문서를 다른 프로그램으로 열어 인쇄하거나, 'PDF로 인쇄(저장)'한 뒤 그 PDF를 인쇄해 봅니다.
  3. 문서에 큰 이미지나 특수 글꼴이 많다면 이미지를 줄이거나 글꼴을 바꿔 저장한 뒤 다시 시도합니다.
  4. 대기열에 이 문서가 멈춘 채 남아 있다면 취소한 뒤 스풀러를 재시작합니다. 안 지워지면 '대기열 걸림' 순서로 넘어가세요.

프린터를 추가·검색할 수 없거나 추가 중 멈출 때

오래된 프린터 항목, 드라이버 충돌, 스풀러 상태가 자주 원인입니다.

  1. 목록에 같은 프린터가 중복으로 남아 있으면 모두 제거합니다. 이전에 추가하다 멈춘 항목이 충돌을 일으킵니다.
  2. Win+R → services.msc → 목록에서 Print Spooler를 찾아 우클릭 → '다시 시작'합니다.
  3. 제조사 홈페이지에서 모델명으로 최신 드라이버를 받아 먼저 설치합니다. 기본 드라이버로는 추가가 안 되는 모델이 있습니다.
  4. 무선 연결이 꼬였다면 USB로 연결해 추가해 보고, 반대로 USB가 안 되면 네트워크 연결을 시험합니다.
  5. 네트워크 프린터가 검색되지 않으면 '원하는 프린터가 목록에 없습니다' → 'TCP/IP 주소 또는 호스트 이름으로 프린터 추가'를 선택해 프린터 IP를 직접 입력합니다. IP는 프린터 화면이나 설정 출력 용지에서 확인합니다.

공유 프린터에 연결이 안 될 때 (0x0000011b·0x00000709 등)

다른 PC에 연결된 프린터를 네트워크로 쓰는 환경에서 업데이트 이후 자주 생기는 문제입니다. 원인이 여러 가지라 안전한 확인부터 순서대로 합니다.

  1. 프린터가 연결된 PC(호스트)가 켜져 있고 프린터가 '공유'로 설정돼 있는지 확인합니다. 호스트에서 프린터 이름을 바꾸었거나 공유를 껐다 켰다면 공유 이름이 달라졌을 수 있습니다.
  2. 내 PC에서 문제의 프린터를 제거합니다. 그리고 파일 탐색기 주소창에 \\호스트PC이름 을 입력해 열린 목록에서 프린터를 더블클릭해 다시 연결합니다. IP나 별칭 대신 호스트의 실제 컴퓨터 이름을 쓰면 풀리는 경우가 있습니다.
  3. 호스트 PC와 내 PC 모두 Windows 업데이트를 최신으로 맞춥니다. 한쪽만 업데이트된 상태에서 연결 방식 차이로 오류가 나는 경우가 있습니다.
  4. 제조사 홈페이지에서 내 PC(클라이언트)에도 해당 프린터 드라이버를 먼저 설치한 뒤 다시 연결해 봅니다.
  5. 호스트 PC에서 스풀러를 재시작하고, 호스트에서는 인쇄가 정상인지 먼저 확인합니다. 호스트에서도 안 되면 공유 문제가 아니라 프린터 자체 문제입니다.
  6. 인터넷에 도는 '레지스트리 값을 바꿔 인쇄 보안을 낮추는' 우회 방법은 보안을 약하게 만들므로 먼저 시도하지 마세요. 위 단계로 해결되지 않으면 이 방법 대신 프린터를 네트워크 IP(TCP/IP 포트)로 직접 추가하는 방식을 먼저 고려하는 것이 안전합니다.

인쇄 스풀러 서비스가 실행되지 않을 때

스풀러가 멈추면 프린터 추가, 인쇄, 오프라인 표시까지 연쇄로 문제가 생깁니다.

  1. Win+R → services.msc → Print Spooler를 더블클릭해 '시작 유형'이 '자동'인지 확인하고 상태가 '중지됨'이면 '시작'을 누릅니다.
  2. 시작이 바로 꺼지거나 오류가 나면 같은 서비스 목록에서 Remote Procedure Call(RPC)이 '실행 중'인지 확인합니다. 스풀러는 이 서비스에 의존합니다.
  3. 스풀러를 중지한 뒤 C:\Windows\System32\spool\PRINTERS 폴더 안의 파일을 모두 삭제하고 다시 시작합니다(폴더 자체는 삭제하지 않습니다). 아래 명령으로 한 번에 할 수 있습니다.
  4. 스풀러가 반복해서 멈추면 오래되거나 중복된 프린터 드라이버가 원인인 경우가 많습니다. 쓰지 않는 프린터와 드라이버를 제거하고 제조사의 최신 드라이버만 남깁니다.

관리자 권한 명령 프롬프트에서 실행:

net stop spooler
del /Q /F /S "%systemroot%\System32\spool\PRINTERS\*.*"
net start spooler

잉크젯 인쇄 품질 문제 (줄·흐림·번짐)

소프트웨어보다 헤드 막힘, 잉크 상태, 용지 설정이 원인인 경우가 많습니다.

  1. 프린터 메뉴나 제조사 프로그램의 '노즐 체크(노즐 패턴 인쇄)'를 출력해 끊기거나 빠진 선이 있는지 봅니다.
  2. 선이 끊겨 있으면 '헤드 청소'를 한두 번 실행하고 다시 노즐 체크를 합니다. 청소를 반복하면 잉크가 많이 소모되니 두 번 이상 효과가 없으면 멈춥니다.
  3. 잉크 잔량과 카트리지 장착 상태를 확인합니다. 호환·재생 잉크는 인식 문제나 색 번짐을 일으킬 수 있습니다.
  4. 인쇄 설정의 '용지 종류'와 '인쇄 품질'이 실제 용지와 맞는지 확인합니다. 일반 용지에 사진 용지 설정으로 인쇄하면 번질 수 있습니다.
  5. 오래 사용하지 않았다면 잉크가 굳었을 수 있습니다. 청소를 여러 번 해도 같다면 제조사 서비스 점검이 필요합니다.
레이저 인쇄 품질 문제 (줄·얼룩·흐림)

토너와 드럼 같은 소모품 상태가 가장 흔한 원인입니다.

  1. 토너 잔량을 확인하고, 토너 카트리지를 꺼내 좌우로 가볍게 흔든 뒤 다시 장착합니다. 토너가 한쪽으로 뭉치면 흐리게 나올 수 있습니다.
  2. 줄이나 얼룩이 매 장 같은 위치에 반복되면 토너 카트리지나 드럼 같은 소모품 문제일 가능성이 큽니다.
  3. 내부에 용지 가루나 토너가 묻어 있지 않은지 전원을 끈 상태에서 확인합니다. 열이 남아 있을 수 있으니 식은 뒤 만집니다.
  4. 용지가 눅눅하거나 규격이 맞지 않는지 확인하고 새 용지로 시험해 봅니다.
  5. 소모품을 바꿔도 같으면 제조사 서비스 점검이 필요합니다.
용지 걸림·급지 불량

무리하게 잡아당기면 찢어진 조각이 남아 반복 걸림의 원인이 됩니다.

  1. 프린터 전원을 끄고 전원 케이블을 뽑습니다.
  2. 용지함, 뒷덮개, 카트리지 주변 순서로 열어 걸린 용지를 용지가 나아가는 방향으로 천천히 당겨 제거합니다.
  3. 손전등으로 내부를 비춰 찢어진 용지 조각이 남아 있지 않은지 확인합니다.
  4. 용지를 새것으로 바꾸고 장수를 너무 많이 넣지 않습니다. 가장자리를 가지런히 하고 구겨졌거나 눅눅한 용지는 빼 둡니다. 용지 가이드가 용지 폭에 맞는지도 확인합니다.
  5. 같은 증상이 반복되면 급지 롤러가 마모됐을 수 있어 제조사 서비스 점검이 필요합니다.

작업 전에 알아 두세요

  • 프린터 전원부터: 전원을 끄고 1분쯤 기다렸다 켜는 것만으로 풀리는 경우가 많습니다. 소프트웨어를 만지기 전에 먼저 해보세요.
  • 명령어는 그대로: 스풀 폴더를 비우는 명령은 PRINTERS 폴더 안의 파일만 지웁니다. 다른 폴더나 경로를 바꿔 실행하지 마세요.
  • 레지스트리·보안 설정은 마지막: 인터넷의 '한 줄 해결법' 중에는 인쇄 보안을 낮추는 설정이 있습니다. 공유 프린터 오류에서 먼저 쓰지 마세요.
  • 회사·학교 PC: 관리자가 정책으로 프린터 연결을 제한한 경우가 있어, 개인이 설정을 바꿔도 안 풀릴 수 있습니다. 전산 담당자에게 문의하세요.

자주 묻는 질문

프린터가 오프라인인데 실제로는 켜져 있어요. 왜 그런가요?

윈도우가 프린터와 통신하지 못할 때 오프라인으로 표시합니다. USB는 케이블·포트·스풀러 상태, 네트워크 프린터는 IP 변경이나 Wi-Fi 끊김이 대표적인 원인입니다. 대기열의 '오프라인으로 프린터 사용' 항목이 켜져 있어도 오프라인으로 보일 수 있습니다.

인쇄 대기열 문서가 취소해도 안 지워져요.

손상된 작업 파일이 스풀 폴더에 남아 스풀러가 놓지 못하는 상태입니다. 스풀러를 멈추고 PRINTERS 폴더의 파일을 비운 뒤 다시 시작하면 지워집니다. 마법사의 '대기열이 걸려서 아무것도 안 나갈 때' 순서에 명령어가 있습니다.

프린터 드라이버는 꼭 제조사 것을 설치해야 하나요?

윈도우 기본 드라이버로 인쇄되는 모델도 많지만 추가가 안 되거나 일부 기능이 빠지는 모델이 있습니다. 문제가 반복되면 제조사 홈페이지에서 모델명으로 최신 드라이버를 받아 설치하는 것이 가장 확실합니다.

업데이트하고 나서 공유 프린터가 안 돼요.

호스트 PC와 클라이언트 PC 둘 다 최신 업데이트인지 먼저 맞추고, 프린터를 제거한 뒤 호스트의 실제 컴퓨터 이름으로 다시 연결해 보세요. 레지스트리 우회법은 보안을 낮추므로 마지막 수단으로만 고려하세요.

마법사 순서를 다 해봤는데도 안 돼요.

프린터 본체의 고장, 네트워크 장비 문제, 드라이버 충돌이 겹쳐 있을 수 있습니다. 이 페이지 아래의 원격점검 안내로 증상과 해본 작업을 알려 주세요. 원격으로 확인하면 현장 방문 없이 해결되는 경우도 많습니다.
