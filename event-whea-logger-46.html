WHEA-Logger 46 메모리 계층 오류 점검

메모리 계층을 포함한 치명적 하드웨어 오류 기록으로 나타날 수 있습니다.

46은 메모리 계층을 포함한 치명적 하드웨어 오류로 나타날 수 있는 기록입니다. RAM 자체뿐 아니라 메모리 컨트롤러나 XMP·EXPO 설정, 보드 접촉 문제도 원인이 될 수 있습니다.

메모리 모듈을 한 개씩 장착해 슬롯을 바꿔가며 테스트하면, 모듈 불량인지 특정 슬롯의 접촉 문제인지를 비교적 빠르게 구분할 수 있습니다.

발생 조건

  • 메모리 부하 중
  • 부팅·절전 복귀 중

가능성 높은 원인

  • RAM·메모리 컨트롤러 불안정
  • XMP·EXPO 설정
  • 보드·CPU 접촉 문제

메모리 계층이 지목됐다는 의미

46은 오류가 발생한 위치로 메모리 계층이 보고된 경우입니다. 여기서 메모리 계층은 RAM 모듈뿐 아니라 CPU 안의 메모리 컨트롤러와 캐시까지 포함합니다.

따라서 메모리를 교체해도 재현된다면 모듈이 아니라 컨트롤러 쪽, 즉 CPU나 메인보드 접촉 문제일 수 있다는 점을 염두에 두고 확인해야 합니다.

점검 순서

  1. 중요한 데이터 백업 — 메모리 계층 오류는 데이터 손상으로 이어질 수 있습니다. 조치 전에 백업을 확보하세요.
  2. 메모리를 기본 속도로 되돌리기 — BIOS에서 XMP·EXPO를 끄고 기본 속도(JEDEC)로 며칠 사용합니다. 이 단계에서 사라지면 모듈 불량이 아니라 프로파일 안정성 문제입니다.
  3. 모듈과 슬롯 교차 시험 — 메모리를 한 개씩만 장착해 재현 여부를 보고, 같은 모듈을 다른 슬롯에도 꽂아 봅니다. 모듈 불량과 슬롯 불량을 이렇게 구분합니다.
  4. 메모리 컨트롤러 쪽도 고려 — 모듈을 모두 바꿔도 재현된다면 CPU 내부 메모리 컨트롤러나 소켓 접촉 문제일 수 있습니다. CPU 쿨러 장착 압력이 고르지 않은 경우에도 발생할 수 있으니 재장착을 검토하세요.
주의사항

오류가 반복되면 메모리 검사 결과만으로 정상 판정하지 마세요.

자주 묻는 질문

  • 46은 메모리만 관련된 오류인가요? 메모리 계층(Cache Hierarchy)을 포함할 수 있지만 CPU 캐시 문제로도 나타날 수 있어 메모리 전용 문제로 단정할 수 없습니다.
  • XMP를 껐는데도 발생하면 어떻게 해야 하나요? 기본 속도에서도 반복된다면 모듈이나 슬롯 자체, 혹은 CPU의 메모리 컨트롤러 문제일 가능성을 열어두고 부품을 교차 테스트하세요.
