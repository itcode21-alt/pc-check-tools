에러 코드 상세

0x80070570 · 파일이 손상되었거나 읽을 수 없음

설치나 복사 과정에서 파일이 손상되었거나 읽어올 수 없을 때 나타나는 오류로, 설치 미디어 문제나 디스크 불량이 흔한 원인입니다.

이 코드를 어떻게 해석해야 하나요?

업데이트·설치 코드는 파일 누락, 구성 요소 저장소, 서비스, 권한, 여유 공간 중 작업이 중단된 지점을 나타냅니다. 실패 비율과 업데이트 기록의 세부 코드를 함께 봐야 합니다.

먼저 기록할 내용: 0x80070570가 발생한 시각, 직전에 실행한 작업, 최근 설치한 드라이버·업데이트, 재부팅 뒤 같은 코드가 반복되는지를 적어 두세요.

가능성 높은 원인

  • 설치 파일 자체가 다운로드 중 손상된 경우
  • USB 설치 미디어의 불량이나 손상
  • 대상 디스크의 배드섹터
  • 압축 해제 도중 오류가 발생한 경우
  • 램 불안정으로 파일 복사 중 데이터가 손상되는 경우

첫 점검 항목

  1. 설치 파일이나 이미지를 공식 출처에서 다시 받아보세요.
  2. USB 설치 미디어를 다른 USB 포트나 다른 USB 메모리로 새로 만들어 보세요.
  3. 대상 디스크의 상태를 chkdsk나 진단 도구로 점검하세요.
  4. 다른 저장장치(외장하드 등)에 파일을 저장한 뒤 다시 시도해 보세요.
  5. 메모리 진단 도구로 램 상태를 점검하세요.

확인 결과에 따른 다음 단계

  • 새로 받은 설치 파일이나 USB로 해결될 때 — 원본 파일이나 USB 자체의 손상이었으므로, 다음부터는 다운로드 후 체크섬을 비교해 무결성을 확인하세요.
  • chkdsk에서 배드섹터가 발견될 때 — 대상 디스크 교체를 검토하고, 우선 다른 정상 디스크에 설치해보세요.
  • 메모리 진단에서 오류가 발견될 때 — 램 모듈 문제로 파일 복사 중 데이터가 손상되고 있을 수 있으므로 모듈 교체를 검토하세요.

데이터와 시스템을 보호하는 주의사항

시스템 폴더 권한 변경이나 레지스트리 정리 도구 사용보다 저장 공간, 네트워크, 서비스 상태를 먼저 확인하세요.

앞 단계로 해결되지 않을 때

오류가 반복된다면 Windows Update 기록과 DISM·SFC 실행 결과를 남겨두고, 사용 중인 설치 미디어 버전이 현재 Windows와 일치하는지 확인하세요.

복구, 초기화, 드라이버 제거처럼 되돌리기 어려운 작업 전에는 중요한 파일을 다른 물리 저장장치나 신뢰할 수 있는 백업 위치에 보관하세요.

관련 증상 가이드 확인하기

같은 증상과 연결된 다른 오류 코드

  • 0x0000007B · INACCESSIBLE_BOOT_DEVICE
  • 0x00000133 · DPC_WATCHDOG_VIOLATION
  • 0x00000024 · NTFS_FILE_SYSTEM
  • 0x00000077 · KERNEL_STACK_INPAGE_ERROR

자주 묻는 질문

  • SSD·NVMe를 바로 교체해야 하나요? 이 문제(0x80070570)만으로 저장장치 고장을 단정하기는 어렵습니다. 슬롯 재장착과 펌웨어 업데이트를 먼저 확인한 뒤에도 반복되면 다른 슬롯이나 드라이브로 교차 테스트해보는 것이 안전합니다.
  • SSD 상태를 확인하는 무료 도구가 있나요? CrystalDiskInfo 같은 무료 프로그램으로 SSD의 건강 상태와 온도를 확인할 수 있습니다.
  • USB로 설치할 때 특정 파일에서만 반복 실패하면요? 매번 같은 파일에서 실패한다면 원본 이미지 자체의 손상 가능성이 크므로 체크섬을 비교해 이미지를 다시 받아보세요.
