GRAPHICS · WHEA

블루스크린 0x116과 WHEA 17(PCIe 오류)이 함께 나올 때 점검 순서

게임 중에 화면이 멈추고 모니터에 신호 없음이 뜬 뒤 PC가 재부팅된다면, 이벤트 뷰어에서 정지 코드 0x116(VIDEO_TDR_FAILURE)을 보게 될 수 있습니다. 같은 기간 로그에 WHEA-Logger 17이 PCI Express(PCIe) 쪽에서 반복해서 남아 있다면, 그래픽카드를 바꾸기 전에 확인할 것이 하나 더 생깁니다. 이 글은 두 기록을 함께 읽는 방법과 점검 순서를 정리합니다.

먼저 알아 둘 점

이 글의 "두 기록이 함께 나오면 PCIe 경로를 먼저 의심한다"는 해석은 Microsoft가 직접 밝힌 규칙이 아니라, 이 사이트가 로그와 해결 결과를 함께 확인한 수리 사례를 바탕으로 세운 참고 기준입니다. 사례 수가 적어서 모든 PC에 들어맞는다고 할 수 없고, 이벤트 하나로 부품 고장을 확정할 수도 없습니다.

1. 0x116은 무엇을 뜻하나요

Windows는 그래픽 처리가 정해진 시간 안에 끝나지 않으면 드라이버와 GPU를 초기화해서 화면을 되살리려 합니다. 이를 TDR(Timeout Detection and Recovery)이라고 하며, Microsoft 문서에 따르면 기본 제한 시간은 2초입니다. 복구에 성공하면 "디스플레이 드라이버가 응답을 중지했다가 복구되었습니다"라는 메시지와 함께 화면이 한 번 깜빡이는 정도로 끝납니다.

0x116은 이 복구가 실패했을 때 나오는 정지 코드입니다. 짧은 시간에 TDR이 여러 번 반복될 때도 시스템이 정지 코드를 낼 수 있고, 상황에 따라 0x117이 기록되기도 합니다. 그래서 0x116은 "드라이버 버그"의 확정이 아니라, 그래픽 처리 경로 어딘가가 제때 응답하지 못했다는 결과 신호에 가깝습니다.

Microsoft 문서가 원인 후보로 드는 항목도 그래픽 드라이버에만 한정되지 않습니다. 드라이버 업데이트 외에 오버클럭된 부품, 메모리 구성과 타이밍 설정, 냉각 부족, 전원 부족, 메모리 모듈이나 메인보드 같은 불량 부품이 함께 나열되어 있습니다.

2. WHEA 17은 무엇을 뜻하나요

WHEA는 Windows가 하드웨어 오류를 받아서 기록하는 구조입니다. 이벤트 뷰어의 WHEA-Logger 17은 하드웨어가 스스로 정정한 오류가 있었다는 기록으로, 이 사이트의 WHEA-Logger 17 해설에서는 정정된 오류라 시스템이 계속 동작하더라도 신호 상태가 불안정하다는 뜻일 수 있다고 설명합니다.

기록 상세의 오류 원본(Error Source)이 PCI Express로 분류되어 있으면, CPU와 그래픽카드·NVMe SSD 같은 PCIe 장치를 잇는 링크에서 난 오류라는 뜻입니다. WHEA는 오류 원본을 MCE, CMC, PCIe 등으로 구분하며, PCI Express는 그중 별도 분류입니다. 건수가 적을 때는 의미를 두기 어렵고, 며칠에 걸쳐 계속 늘어나는지가 중요합니다.

3. 두 기록이 함께 있을 때 이렇게 읽습니다

드라이버 쪽에 가까운 경우

0x116만 있고 WHEA 17은 거의 없으며, 그래픽 드라이버를 바꾼 직후부터 증상이 시작됐다면 드라이버나 특정 게임과의 호환 문제 가능성이 큽니다. 클린 설치와 이전 버전 되돌리기로 먼저 확인합니다.

연결 경로(PCIe)에 가까운 경우

드라이버를 여러 번 다시 설치하고 BIOS를 최신으로 올려도 같은 증상이 남고, 로그에 PCIe 원본의 WHEA 17이 오래 반복되어 있다면 그래픽카드 자체보다 슬롯, 메인보드, 라이저·연장 케이블, 전원 같은 경로를 의심할 근거가 됩니다. 이 사이트의 이벤트 로그 분석기도 정지 코드(0x116·0x117·0x119)와 PCIe 오류가 함께 있으면 "그래픽카드 교체 전에 PCIe 경로 교차 테스트"를 안내합니다.

판단이 어려운 경우

로그 기간이 짧거나 한 번만 재부팅된 경우에는 두 기록이 우연히 같은 시기에 남았을 수 있습니다. 며칠 더 사용하며 기록이 늘어나는지, 같은 조건(특정 게임·고부하)에서 반복되는지부터 확인합니다.

4. 점검 순서

되돌리기 쉽고 비용이 들지 않는 것부터 진행하고, 한 번에 하나씩 바꿔서 결과를 비교하세요. 전원이 켜진 채로 부품을 만지지 마세요.

  1. 기록 확인: 이벤트 뷰어 → Windows 로그 → 시스템에서 41, 1001, WHEA-Logger 17, Display 4101을 필터링하고, 정지 코드와 WHEA 17의 개수·기간을 메모합니다. 직접 세기 번거롭다면 로그 파일 분석에 .evtx를 올리면 조합 판정이 나옵니다.
  2. 오버클럭·XMP/EXPO 해제: CPU·GPU·메모리를 기본값으로 돌리고 같은 게임에서 재현되는지 봅니다. Microsoft 문서도 오버클럭과 메모리 설정을 원인 후보로 듭니다.
  3. BIOS·칩셋 드라이버 업데이트: 메인보드 제조사 지원 페이지의 최신 BIOS와 칩셋 드라이버를 적용합니다. BIOS 업데이트 중에는 전원을 끄지 마세요.
  4. PCIe 세대 낮추기: BIOS에서 그래픽카드 슬롯의 PCIe 속도(Gen) 설정이 있으면 한 단계 낮춰 보고 증상과 WHEA 17이 줄어드는지 확인합니다. 메뉴 위치와 이름은 제조사마다 다릅니다.
  5. 슬롯 재장착과 직결 확인: 전원을 끄고 전원 케이블을 뽑은 뒤 그래픽카드를 빼서 다시 꽂고, 보조전원 케이블이 끝까지 들어갔는지 확인합니다. 라이저 케이블이나 연장 케이블을 쓰고 있다면 빼고 메인보드 슬롯에 직접 연결해 봅니다.
  6. 그래픽 드라이버 클린 재설치: 드라이버 가능성도 배제하지 않기 위해 그래픽 드라이버 재설치 가이드대로 진행합니다.
  7. 교차 테스트: 가능하면 그래픽카드를 다른 PC에 꽂아 같은 게임을 돌려 보고, 반대로 다른 그래픽카드를 이 PC에 꽂아 봅니다. 아래 표처럼 해석합니다.

5. 교차 테스트 결과 해석

그래픽카드를 다른 PC에 꽂아도 같은 증상이 나올 때

카드 자체나 카드와 드라이버 조합의 문제 가능성이 큽니다. 제조사 A/S나 교환을 확인하세요.

다른 PC에서는 정상이고, 다른 카드를 이 PC에 꽂아도 같은 증상이 나올 때

이 PC의 메인보드 슬롯, CPU, 전원 쪽을 의심합니다. 파워의 보조전원 공급이 충분한지, 같은 케이블을 다른 포트로 바꿔도 같은지 확인한 뒤 메인보드 점검을 고려합니다.

어느 쪽도 바꿀 수 없을 때

교차 테스트 없이 부품을 교체하면 원인을 놓치기 쉽습니다. 한 번에 한 가지만 바꾸고, 바꾼 뒤 며칠간 로그의 WHEA 17 개수가 늘어나는지 비교하세요.

6. 하지 말아야 할 것

  • 이벤트 한 건이나 정지 코드 하나만 보고 그래픽카드나 메인보드를 바로 교체하는 것
  • WHEA 17이 있다는 이유만으로 고장으로 단정하는 것(정정된 오류는 지금 당장 고장 난 상태를 뜻하지 않으며, 반복되는지를 지켜봐야 합니다)
  • 출처가 불분명한 드라이버 자동 업데이트·레지스트리 정리 프로그램을 쓰는 것

자주 묻는 질문

  • 0x116이 나오면 무조건 그래픽카드 불량인가요? 아닙니다. Microsoft 문서는 드라이버 외에도 오버클럭, 메모리 설정, 냉각·전원 부족, 메모리나 메인보드 불량을 원인 후보로 듭니다.
  • WHEA 17은 몇 건부터 문제인가요? 공식 기준은 없습니다. 이 사이트의 분석기는 로그 전체에서 5건 이상 반복되면 알려 주지만, 이 숫자도 참고용 초안입니다. 기간과 증상을 함께 보세요.
  • 메모리 검사도 해야 하나요? 정지 코드가 매번 달라지거나 오버클럭을 풀어도 재현된다면 메모리 검사를 함께 진행하는 편이 좋습니다. Microsoft 문서도 메모리 진단을 점검 항목으로 듭니다.
