EVENT ID 1026

.NET 예외 문장과 충돌 모듈을 함께 보세요

.NET Runtime 1026은 .NET 프로그램에서 처리되지 않은 예외가 발생해 프로세스가 종료된 기록입니다. 1000 이벤트가 같은 시각에 있다면 오류 모듈과 예외 코드까지 비교해야 합니다.

점검 순서

  1. 예외 유형과 메시지, 앱 이름을 이벤트 일반 탭에서 기록합니다.
  2. Application Error 1000의 오류 있는 응용 프로그램·모듈과 발생 시각을 비교합니다.
  3. 특정 앱에서만 발생하면 앱 복구, 설정 초기화, 플러그인 제거를 순서대로 확인합니다.
  4. 여러 .NET 앱에서 반복되면 필요한 .NET 버전과 Windows Update, 시스템 파일 상태를 확인합니다.
  5. 권한·파일 접근 예외라면 보안 프로그램 차단과 개인 폴더 권한을 확인합니다.
주의

1026이 보인다고 .NET을 모두 삭제하거나 임의의 런타임 파일을 내려받아 덮어쓰지 마세요. 앱이 요구하는 버전과 공식 설치 경로를 먼저 확인해야 합니다.
