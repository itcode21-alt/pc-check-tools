Windows 11 버전 26H2

윈도우 11 26H2 업데이트 방법 · 안 뜰 때 확인할 것

Microsoft는 Windows 11 버전 26H2를 적격 기기에 제공하고 있고, 11월 18일부터는 자동 배포 범위를 단계적으로 넓히고 있습니다. 이 글은 Microsoft 공식 릴리스 상태 문서에 적힌 내용을 기준으로 직접 설치하는 방법, 업데이트가 안 뜰 때 확인할 것, 버전별 지원 종료일을 정리합니다(2026-11-27 확인).

지금 상태 (2026-11-27 확인)

26H2는 2026년 9월 29일에 일반 공급이 시작됐고, 10월 말부터 모든 적격 기기가 업데이트를 직접 확인해 받을 수 있었습니다. 11월 18일부터는 IT 부서가 관리하지 않는 Windows 11 24H2·25H2 기기부터 자동 배포를 단계적으로 넓히고 있으며, 자동으로 받는지는 Windows 업데이트 설정에 따라 달라집니다. 문서에는 26H2에 25H2·24H2에서 최근 발표된 기능이 모두 들어 있고 서비싱 기술로 제공돼 설치가 빠르다고 적혀 있습니다.

1. 지금 내 PC가 어느 버전인지 확인하기

Windows 로고 키 + R을 누르고 winver를 입력하면 버전과 OS 빌드가 표시됩니다. 빌드 번호의 앞부분으로 버전을 알 수 있습니다.

  • 24H2 — OS 빌드 26100 (11월 정기 업데이트 기준 26100.9974)
  • 25H2 — OS 빌드 26200 (11월 19일 선택적 업데이트 기준 26200.10075)
  • 26H2 — OS 빌드 26300 (11월 19일 선택적 업데이트 기준 26300.10075)

출처: Microsoft Learn 「Windows 11 릴리스 정보」 (2026-11-27 확인). 월간 업데이트가 나올 때마다 빌드 번호 뒷자리는 계속 바뀝니다.

2. 직접 설치하는 방법 (공식 절차)

  1. 설정 → Windows 업데이트로 이동합니다.
  2. 업데이트 확인을 누릅니다.
  3. 이 기기에 Windows 11 버전 26H2가 제공되면 다운로드 및 설치를 선택합니다.
  4. 업데이트가 제공되는 즉시 받고 싶다면 같은 화면의 사용 가능한 즉시 최신 업데이트 받기 스위치를 켭니다(Microsoft 한국어 문서의 표기이며, 화면 문구는 버전에 따라 조금 다를 수 있습니다).

출처: Microsoft Learn 「Windows 11 버전 26H2 알려진 문제 및 알림」 (2026-11-27 확인)

3. 가만히 있으면 언제 오나요 — 자동 배포 규칙

  • 11월 18일부터 IT 부서가 관리하지 않는 24H2·25H2 기기를 시작으로 자동 전송을 넓히고 있습니다. 개인 기기와 관리되지 않는 사업용 기기가 대상으로 안내돼 있습니다.
  • 배포는 단계적이라 같은 버전을 써도 받는 시점이 기기마다 다릅니다. 직접 업데이트를 확인하면 더 일찍 받을 수 있습니다.
  • 회사·학교 등 IT 부서가 관리하는 기기는 IT 부서가 정한 일정과 정책을 따르므로 개인이 임의로 올리기 전에 확인하세요.

4. 업데이트 확인을 해도 26H2가 안 보일 때

공식 문서에 근거한 확인

① 자동 배포는 단계적이라 아직 내 기기 차례가 아닐 수 있습니다. ② 관리되는 기기는 IT 부서가 시기를 정합니다. ③ Microsoft는 알려진 호환성 문제가 있는 기기에 업데이트 제공을 보류(보호 조치)할 수 있고, 현재 등재된 문제는 릴리스 상태 문서의 알려진 문제에서 확인할 수 있습니다.

26H2 릴리스 상태 문서(2026-11-23 갱신 기준)에 등재된 알려진 문제는 3건입니다.

  • SQL Server 연결된 서버 연결이 열린 상태로 남는 문제 — 10월 13일 업데이트(KB5127648) 이후 서버 장치에서 나타나는 문제이며 확인됨 상태입니다. 서버·기업 환경 대상이라 일반 PC와는 무관합니다.
  • USB 오디오 클래스 1.0 장치 코드 10 — 해결됨(2026-11-10, KB5132061). 장치가 시작되지 않거나 소리가 안 나던 문제입니다. 아직 증상이 있다면 장치 관리자 코드 10 가이드도 함께 보세요.
  • 관리자 보호가 켜진 상태에서 관리자가 아닌 사용자의 원격 데스크톱 연결 실패(0xC000000D) — 해결됨(2026-10-28, KB5127936).
문서 외 일반 점검

아래는 Microsoft 문서에 적힌 절차가 아니라 일반적으로 먼저 확인하는 항목입니다. Windows 업데이트 화면에 업데이트 일시 중지가 켜져 있지 않은지, 이미 받은 다른 업데이트가 재시작 대기 상태가 아닌지, 시스템 드라이브(C:)에 여유 공간이 충분한지 확인한 뒤 다시 업데이트를 확인하세요. 설치 중 오류 코드가 나오면 업데이트 오류 코드 가이드, 같은 시도가 반복되면 업데이트 반복 실패 가이드를 따라가세요.

5. 버전별 업데이트 지원 종료일

Microsoft 릴리스 정보 기준입니다. 에디션에 따라 종료일이 다릅니다.

  • 26H2 — 2026-09-29 공급 시작. Home·Pro 2028-10-10 종료, Enterprise·Education 2029-10-09 종료.
  • 25H2 — 2025-09-30 공급 시작. Home·Pro 2027-10-12 종료, Enterprise·Education 2028-10-10 종료.
  • 24H2 — Home·Pro는 2026-10-13에 업데이트가 끝났습니다(10월 보안 업데이트가 마지막). Enterprise·Education은 2027-10-12까지.
  • 23H2 — Enterprise·Education도 2026-11-10에 업데이트가 끝났고, Microsoft는 26H2로 올리라고 안내합니다.

출처: Microsoft Learn 「Windows 11 릴리스 정보」, 「Windows 메시지 센터」 (2026-11-27 확인). 24H2에서 25H2로 올리다 막히는 문제는 25H2 업그레이드 전 확인할 것을 참고하세요.

자주 묻는 질문

  • 26H2로 꼭 올려야 하나요? 24H2 Home·Pro는 2026년 10월 13일에 업데이트가 끝나 보안 업데이트를 받으려면 25H2나 26H2로 올려야 합니다. 25H2 Home·Pro는 2027년 10월 12일까지 업데이트를 받지만, Microsoft는 최신 상태를 유지하려면 26H2로 올리라고 권장합니다.
  • 업데이트 확인을 눌러도 26H2가 안 보여요. 자동 배포는 단계적으로 넓어지는 중이고 기기마다 받는 시점이 다릅니다. 회사·학교처럼 IT 부서가 관리하는 기기는 IT 부서가 정한 일정을 따릅니다. 일시 중지가 켜져 있지 않은지, 이미 받은 다른 업데이트의 재시작이 남아 있지 않은지 먼저 확인하고, 그래도 안 보이면 며칠 뒤 다시 확인하세요.
  • 26H2에는 어떤 기능이 들어 있나요? Microsoft 문서에는 25H2와 24H2에서 최근 발표된 기능이 모두 들어 있다고 적혀 있습니다. 새 기능은 월간 업데이트로 단계적으로 배포돼, 설치해도 바로 보이지 않을 수 있습니다. 이번 달 업데이트 내용은 업데이트 이슈 트래커에 정리해 두었습니다.
  • 26H2 설치 후 문제가 생기면 어디서 확인하나요? Microsoft가 공식으로 등재한 문제는 Windows 11 26H2 릴리스 상태 문서의 알려진 문제에서 확인할 수 있습니다. 이 사이트의 업데이트 이슈 트래커에도 같은 내용을 한국어로 정리합니다.
