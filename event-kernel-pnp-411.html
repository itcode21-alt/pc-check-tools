EVENT ID 411

Kernel-PnP 이벤트 411 장치 시작 문제 점검

특정 장치가 시작되는 중 문제가 생겼다는 기록입니다. 이벤트에 장치 인스턴스 ID, 드라이버 INF, 서비스와 Problem 코드가 들어 있어 어느 장치인지부터 특정해야 합니다. 시스템 로그가 아니라 Kernel-PnP/Configuration 로그에 남습니다.

411은 장치가 시작되는 과정에서 문제가 있었다는 Plug and Play 기록입니다. 219가 드라이버 로드 실패·지연을 나타낸다면, 411은 장치 시작 문제를 장치 인스턴스와 Problem 코드와 함께 남깁니다.

이 이벤트는 이벤트 뷰어의 응용 프로그램 및 서비스 로그 > Microsoft > Windows > Kernel-PnP > Configuration에 남기 때문에 시스템 로그만 봐서는 보이지 않습니다. 이 사이트의 이벤트 로그 해석기에서 수집 명령 만들기의 "장치 인식·드라이버 문제"를 고르면 이 로그까지 함께 모읍니다.

발생 조건

  • 장치 관리자에 노란 느낌표가 표시됨
  • USB·터치패드·지문 인식기 같은 장치가 갑자기 동작하지 않음
  • 드라이버 업데이트·제거 직후

가능성 높은 원인

  • 드라이버가 오래됐거나 손상됨
  • 장치·포트·케이블 접촉 불량
  • 다른 소프트웨어나 드라이버와의 충돌
  • 하드웨어 자체 불량

점검 순서

  1. 이벤트의 장치 인스턴스 ID로 장치 관리자에서 해당 장치 찾기 — 되돌리기 쉬운 항목부터 확인해 위험 없이 범위를 줄입니다.
  2. Problem 코드와 Problem Status 값을 기록 — 첫 확인 결과와 비교해 원인 후보를 좁힙니다.
  3. 장치 관리자 오류 코드와 대조 — 이 단계에서도 재현되면 다음 항목으로 넘어가세요.
  4. 제조사 드라이버로 재설치하거나, 최근 업데이트 직후라면 이전 버전으로 롤백 — 변경 전후로 증상이 달라지는지 비교해보세요.
  5. USB 장치라면 다른 포트로 바꾸고 허브·연장 케이블 제거 — 여기까지 확인해도 해결되지 않으면 다음 원인을 검토하세요.
주의사항

장치가 지금 정상 동작한다면 부팅 중 한 번 남은 기록은 관찰 대상일 수 있습니다.

드라이버는 제조사 사이트의 정식 배포본을 사용하세요.

관련 코드·가이드

장치 관리자 오류 코드 모음USB 미인식 가이드이벤트 뷰어 확인 가이드

자주 묻는 질문

  • Problem 코드는 무엇을 뜻하나요? 이벤트에 표시된 Problem 코드와 Problem Status 값을 적어 두고, 장치 관리자의 상태 메시지와 오류 코드 모음에서 같은 장치의 설명을 찾아보세요. 값만으로 원인을 단정하지는 마세요.
  • 장치는 지금 잘 되는데 411이 남아 있어요. 부팅 중 한 번 시작에 실패했다가 다시 시작된 기록일 수 있습니다. 같은 장치에서 반복되거나 실제 끊김이 있을 때 드라이버와 포트를 점검하세요.
